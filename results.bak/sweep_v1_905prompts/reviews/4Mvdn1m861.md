## Summary

This paper proposes TokenCount, a training-free framework for class-agnostic object counting that operates entirely through SAM without auxiliary models. The method has two main components: (1) a probabilistic prompt generation stage that iteratively samples point prompts from a dynamically updated probability distribution, and (2) an output token-based verification stage that uses SAM's decoder output tokens (rather than image embeddings) with a hybrid TS-SS similarity metric to distinguish positive from negative detections. On FSC-147, the method achieves 16.25 MAE (best among SAM-only training-free methods) and on CARPK it achieves 4.68 MAE (outperforming all listed training-based methods).

## Strengths

- **Novel use of SAM's output tokens for verification.** The core insight — that SAM's output tokens, which encode both semantic and positional information through bidirectional attention, can serve as a more discriminative verification criterion than image embeddings — is genuinely novel and well-motivated by the architecture of SAM. Table 5 and Figure 5 provide evidence that the output token space yields better separation between positive and negative instances than the image embedding space (MAE 16.25 vs. 16.94).

- **Best SAM-only results on FSC-147 among training-free methods.** In Table 1, the method achieves MAE 16.25 compared to TFOC (19.95) and C-Anything (27.97), a meaningful improvement over prior SAM-only approaches without any additional models or training.

- **Strong CARPK results.** On the aerial vehicle counting dataset, MAE 4.68 outperforms all listed training-based methods (e.g., BMNet+ 5.76, SAFECOUNT 5.33, LOCA 9.97) and is competitive with TFCAC (4.39) which uses an additional DINO encoder. This is a genuinely strong empirical result that demonstrates the method's practical value in the right setting.

- **The ablation of the verification metric (Table 3) is well-designed.** Testing dot product, cosine similarity, L2 distance, and TS-SS under otherwise identical conditions provides clean evidence that the hybrid metric is beneficial, and confirms that the output token space has a geometric structure where both angle and magnitude matter.

## Weaknesses

### Major

- **The abstract and main claims outpace the evidence.** The abstract states the method "outperforms existing training-based and training-free counting methods." This is false as written for FSC-147: LOCA (10.79), PseCo (13.05), SAFECOUNT (14.32), and BMNet+ (14.62) all substantially outperform the reported MAE of 16.25. The claim only holds for SAM-only training-free methods on FSC-147 and for training-based methods on CARPK, but the abstract presents it unconditionally. This overclaim is the single most significant weakness and will undermine reviewer trust.

- **No error bars, confidence intervals, or repeated trials anywhere in the paper.** All MAE/RMSE values are reported as point estimates. Several comparisons involve small differences (e.g., TS-SS 16.25 vs. cosine 16.48, Δ=0.23). Without variance estimates, the reader cannot assess whether observed differences are meaningful or noise. The CARPK evaluation uses random exemplar selection ("12 objects randomly selected from the training set") with no repeated trials, introducing uncontrolled variance.

- **The probabilistic prompt generation is not validated against simpler alternatives.** The ablation (Table 4) only sweeps iteration count and prompts-per-iteration within the proposed scheme. There is no comparison to a uniform grid baseline, random sampling, or superpixel methods (e.g., SLIC) — all discussed in the paper's own related work. The central claim that probabilistic exploration "intelligently explores the image and reduces redundant background sampling" is therefore unsupported by direct evidence. The best configuration uses ~1438 prompts on average, a substantial number; whether a fixed grid with a similar prompt budget would match or exceed performance is unknown.

- **No runtime comparison with competing methods.** The paper claims "inference time that is more than twice as fast" as TFCAC but does not report runtimes for TFCAC or any other method. The only runtime given is 1.69s per image for the proposed method on an A100, with no context for whether this is fast or slow relative to the task or to alternatives.

### Minor

- **The TS-SS improvement over cosine similarity is marginal.** Table 3 shows a 0.23 MAE improvement (16.48 → 16.25, ~1.4% relative). While consistent across metrics, this is a small gain to hang a contribution on, and the strong claim that standard metrics are "inadequate" is disproportionate to the evidence. The paper also does not provide a sensitivity analysis of the TS-SS threshold (fixed at 300).

- **One-shot counting results are weak.** On FSC-147 one-shot (Table 2), MAE 18.57 lags substantially behind training-based LOCA (12.53) and even training-free TFCAC (15.15). The paper describes this as "competitive," which is an overstatement. This suggests the method's strengths are dataset-dependent and it struggles when limited to a single exemplar.

- **Several implementation details are unspecified.** (a) The exemplar prompt type (point, box, mask) for SAM is not stated — FSC-147 provides bounding boxes, so how these are converted to SAM prompts should be clarified. (b) SAM returns up to 3 masks per prompt; the paper does not specify which mask's output token is used. (c) The update rule for negative detections (decrease probability rather than zero) is described but not ablated or justified.

## Novel Insights

The most interesting observation that emerges across the reviews but is not fully articulated in the paper is the tension between the method's architecture and its evaluation. The output-token-based verification is conceptually elegant — it uses SAM's internal representations the way SAM was designed to use them — but the evaluation focuses on aggregate benchmarks where the improvement is small. The paper would benefit from a diagnostic experiment that directly measures how often the output token space resolves ambiguities that the image embedding space cannot, rather than relying on aggregate MAE. The PCA visualization (Figure 5) hints at this capability but with only two examples. A systematic study of "cases where image embedding similarity fails but output tokens succeed" would be more compelling than another MAE table.

## Suggestions

1. **Fix the overclaim.** Calibrate the contribution language to match what the evidence supports: "best among SAM-only training-free methods on FSC-147, and beats all training-based methods on CARPK." Remove or qualify the unconditional "outperforms existing training-based and training-free methods" claim.
2. **Add error bars.** Run the full evaluation 3–5 times with different random seeds for prompt sampling and exemplar selection, particularly for CARPK where exemplars are randomly selected.
3. **Add a grid-baseline comparison for prompt generation.** Use the same total prompt budget with a uniform grid, and report MAE/RMSE. This is the single most important missing experiment.
4. **Add a runtime comparison table** with wall-clock times for all competing methods on the same hardware.
5. **Report a threshold sensitivity curve** for TS-SS to show the chosen value (300) is not cherry-picked.
