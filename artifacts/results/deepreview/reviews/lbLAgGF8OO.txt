# Review

## Summary
This paper studies decision making with structured observation (DMSO) and proposes an algorithm with regret bound improvements in both the stochastic and hybrid (stochastic transition and adversarial reward) settings. The algorithm is based on the optimism-based algorithm proposed by [FGQ+23], and the improvements come from replacing the optimism with a more information-theoretic approach and improving the concentration of the function estimators.

## Strengths
1. The proposed algorithm is built on a general framework that captures the algorithm in [LWZ25] and the algorithm in [FGQ+23] as special cases. The framework also allows the incorporation of different function estimation errors.
2. The regret analysis in the stochastic setting improves the results in [FGQ+23] in the $T$ dependence, and the results in the hybrid setting resolve the open question in [LWZ25].

## Weaknesses
1. The algorithm is built on the optimism-based algorithm proposed by [FGQ+23], and the improvements come from replacing the optimism with a more information-theoretic approach and improving the concentration of the function estimators. Although the results are new, the techniques are not very novel.
2. The writing is not very clear, especially regarding the definitions and the comparison with the algorithm in [FGQ+23]. See Questions 1-4.

## Questions
1. The definitions of the function set $\mathcal{F}$ and the partition $\Phi$ are unclear to me. For example, in the stochastic setting, what is the function set $\mathcal{F}$? Is it the set of all possible $Q^*$ functions? In the hybrid setting, what is the function set $\mathcal{F}^{\pi}$? Is it the set of all possible $Q^{\pi}$ functions? Also, is the partition $\Phi$ a partition of $\mathcal{M}\times\Pi$ or a partition of $\mathcal{M}$? In Definition 4, what is the set $\mathcal{M}$? Is it the set of all possible transition kernels? 
2. In the stochastic setting, what is the difference between optimistic DEC and Dig-DEC? From equation (9), it seems that optimistic DEC is larger than Dig-DEC. However, the remark after Theorem 13 says that Dig-DEC has an extra KL term that can be further decomposed into two terms, which seem to be the difference between optimistic DEC and Dig-DEC. 
3. In Theorem 14, is the regret bound $\max_a \mathbb{E}[\text{Reg}(a)]$? If so, what is the regret bound $\mathbb{E}[\text{Reg}(\pi_{M^*})]$? 
4. In the stochastic setting, [FGQ+23] uses a single-timescale algorithm, while this paper uses a two-timescale algorithm. What is the reason for using a two-timescale algorithm? Can the algorithm in [FGQ+23] be improved to a two-timescale algorithm as well? 
5. What are the technical difficulties in the regret analysis? It seems that the regret analysis follows the same outline as the analysis in [FGQ+23] and [LWZ25]. 
6. In the stochastic setting, the paper improves the regret bound from $T^{\frac{3}{4}}$ to $T^{\frac{3}{5}}$ in the on-policy case and from $T^{\frac{5}{6}}$ to $T^{\frac{7}{8}}$ in the off-policy case. In the hybrid setting, the paper gives the first regret bound in the bandit feedback setting. However, the regret bound is $T^{\frac{13}{8}}$, which is not optimal. What are the challenges in obtaining a better regret bound? 
7. In the hybrid setting, what is the regret bound if the reward function is stochastic? 
8. What are the technical difficulties in extending the results in this paper to the adversarial setting?
