# Review

## Summary
The authors present an empirical evaluation of an algorithm called GOEI on a card game called Hol's der Geier. GOEI is an algorithm designed to learn a compressed representation of the observations in the game, which can then be used to learn a strategy that performs well in the game. The authors show that GOEI is able to achieve performance that is similar to the Nash equilibrium strategy in the game, using a representation that is 2.9% as large as the full set of observations in the game.

## Strengths
The authors' empirical results are quite strong. They show that a very small compressed representation of the game observations can be used to learn a nearly optimal strategy for the game. This is a promising result for the use of compression in decision making problems.

The authors' results also suggest that GOEI is much more sample-efficient than the standard Q-learning algorithm. This is also a promising result, and it would be interesting to see if GOEI can be used in other settings where Q-learning is typically applied.

## Weaknesses
The paper has a few weaknesses that should be addressed.

First, the paper is not self-contained. Many of the important details about the GOEI algorithm are left out of the paper. For example, the paper does not include any description of how the Dirichlet distributions are used to model the actions and rewards. This makes it very difficult to understand how the GOEI algorithm works, and it also makes it difficult to assess how novel the algorithm is.

Second, the paper does not provide any theoretical analysis of the GOEI algorithm. This is a problem because it is not clear how general the algorithm is, or under what conditions it is likely to perform well. For example, is it possible that the algorithm will fail in certain games? If so, under what conditions will it fail? These are important questions that should be addressed in the paper.

Third, the paper does not include any comparison with other state-reduction techniques. This makes it difficult to assess how effective the GOEI algorithm is relative to other approaches. For example, are there other algorithms that can learn a compressed representation of the game observations, and if so, how do those algorithms compare to GOEI in terms of performance and sample efficiency?

Finally, the paper does not include any discussion of the limitations of the GOEI algorithm. For example, are there any types of games or state spaces where the algorithm is unlikely to perform well? Are there any assumptions that need to be made in order for the algorithm to work effectively? These are important questions that should be addressed in the paper.
