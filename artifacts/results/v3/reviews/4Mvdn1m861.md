## Summary

The paper proposes TokenCount, a training-free object counting framework that repurposes SAM for counting without architectural modifications. It has two main components: (1) probabilistic prompt generation that adaptively samples point prompts based on a probability distribution derived from image embeddings, and (2) output token-based verification that uses SAM's decoder output tokens with a hybrid geometric similarity metric (TS-SS) to distinguish positive from negative instances. The method is evaluated on FSC-147 and CARPK, achieving an MAE of 16.25 on FSC-147 (best among SAM-only training-free methods) and 4.68 on CARPK (beating all listed training-based methods).

## Strengths

1. **Best FSC-147 accuracy among SAM-only training-free methods.** Table 1 reports MAE 16.25, substantially lower than SAM (42.48), C-Anything (27.97), and TFOC (19.95), demonstrating a clear improvement over methods that also use only SAM without additional models.

2. **CARPK performance surpasses all listed training-based baselines.** On CARPK, the method achieves MAE 4.68 and RMSE 6.13, outperforming every listed training-based method (e.g., SafeCount 5.33, BMNet+ 5.76, FamNet 18.19) while using no training (Table 1).

3. **TS-SS metric improves over standard alternatives in output token space.** Table 3 shows the proposed hybrid geometric metric yields MAE 16.25, compared to dot product (19.58), cosine similarity (16.48), and L2 distance (16.53), establishing that combining semantic and positional information is beneficial in this space.

4. **Output token space shows some evidence of being more discriminative than image embedding space.** Table 5 reports MAE 16.25 in output token space vs. 16.94 using image embeddings, and Figure 5 provides PCA visualizations suggesting better separation in the token space.

## Weaknesses

### Fatal
None.

### Major

1. **The abstract's headline claim is factually inconsistent with Table 1.** The abstract states the method "achieves superior accuracy with an MAE of 16.25, outperforming existing training-based and training-free counting methods." However, Table 1 shows several training-based methods achieve substantially better MAE on FSC-147: LOCA (10.79), BMNet+ (14.62), SAFECOUNT (14.32), and PseCo (13.05). The training-free TFCAC (12.26) also outperforms. The abstract is therefore inaccurate — the paper does not outperform all methods, only a subset. The introduction ("outperforms mostly existing training-free methods") is more measured and should be the standard used throughout.

2. **Probabilistic prompt generation is never compared against deterministic baselines.** The paper motivates probabilistic prompt generation by arguing it is more efficient and effective than grids or superpixels (Section 3.1), yet provides no ablation comparing against these alternatives. Table 4 only varies the number of iterations and prompts *within* the probabilistic method. Without a grid-prompting or random-sampling baseline using the same verification stage, the reader cannot attribute any performance to the probability distribution itself rather than simply the number of prompts (~1600 per image in the best configuration). This undermines a core claimed contribution.

3. **No variance or statistical confidence reported for any result.** The method involves stochastic sampling (multinomial draws from a probability distribution, random exemplar selection for CARPK), yet every metric is a single point with no standard deviation, confidence intervals, or multi-run averages. This is critical because several reported improvements are small: TS-SS over cosine similarity is 0.23 MAE (16.25 vs. 16.48), output tokens over image embeddings is 0.69 MAE (16.25 vs. 16.94). Without variance estimates, the reliability of these differences cannot be assessed, and the paper's central quantitative claims rest on uncharacterized measurements.

### Minor

4. **The core hypothesis — that SAM's output tokens serve as a reliable verification criterion — rests on thin evidence.** The paper provides only Table 5 (a single paired comparison, 16.25 vs. 16.94) and Figure 5 (PCA on two example images). A more systematic analysis (e.g., measuring intra- vs. inter-category output token similarity across multiple categories) would substantially strengthen the claimed benefit. The improvement over image embeddings (0.69 MAE) is also modest for a claimed architectural breakthrough.

5. **Several methodological details are underspecified for reproducibility.** (a) The probability update rule for negative detections says "the value of the probability distribution at that mask region is decreased" — by what amount or factor? (b) The number of exemplars for FSC-147 few-shot evaluation is not stated (only CARPK's 12 objects is specified). (c) The "t-scale factor of 0.066" in implementation details is not explicitly linked to the temperature parameter τ in Equation (1), leaving ambiguity.

6. **The "more than twice as fast" speed claim relative to TFCAC is unsupported.** The paper states an average inference time of 1.69s per image for the proposed method, but provides no runtime numbers for TFCAC or any other baseline. Without a runtime comparison table, the efficiency advantage is an unsubstantiated assertion.

7. **The TS-SS vs. cosine similarity improvement (0.23 MAE) is very small.** Given the lack of variance reporting, this difference could easily be within noise. The paper interprets this as breaking through a "performance plateau" (Section 4.4), which overstates the evidence.

8. **Table 5 may confound vector space with similarity metric.** The comparison between "output token" and "image embedding" spaces does not explicitly state whether the same similarity metric (TS-SS) is used for both. If image embeddings are evaluated with cosine similarity (as is standard in prior work), then the comparison conflates the choice of space with the choice of metric, and the observed difference cannot be attributed to the space alone.
