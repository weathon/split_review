## Summary

The paper proposes TokenCount, a training-free object counting framework built on SAM. It has two components: (1) a probabilistic prompt generation stage that adaptively samples prompts based on a probability distribution derived from exemplar-image similarity, and (2) an output token-based verification stage that uses SAM's decoder output tokens with a TS-SS geometric similarity metric to classify prompts as positive or negative. The method achieves MAE 16.25 on FSC-147 (best among SAM-only training-free methods) and MAE 4.68 on CARPK (outperforming all listed supervised methods), while using no additional models or fine-tuning.

## Strengths

1. **Best accuracy among SAM-only training-free methods on FSC-147.** Table 1 shows the method achieves MAE 16.25, clearly beating TFOC (19.95), C-Anything (27.97), and the naive SAM grid baseline (42.48). This demonstrates that the framework extracts more value from SAM than previous training-free approaches using only the same model.

2. **Strong CARPK results with practical efficiency advantage.** The method achieves MAE 4.68 and RMSE 6.13 on CARPK, outperforming all listed supervised methods (FamNet 18.19, BMNet+ 5.76, SAFECOUNT 5.33). It trails TFCAC (4.39) but the paper reports >2× faster inference (1.69s/image), a meaningful practical advantage.

3. **Ablation studies isolate the two claimed contributions.** Table 3 shows TS-SS (16.25) outperforms dot product (19.58), cosine (16.48), and L2 distance (16.53) for verification. Table 5 confirms output token space (16.25) beats image embedding space (16.94). Table 4 explores the iteration/prompt trade-off. The PCA visualization in Figure 5 provides qualitative support that output tokens yield better positive/negative separation.

4. **Training-free, single-model design.** The method requires no training and uses only SAM without auxiliary models (DINO, CLIP, etc.), yet achieves competitive results. This is a genuine practical contribution over methods like TFCAC that rely on additional encoders.

## Weaknesses

### Fatal
None.

### Major

1. **Abstract makes a false superiority claim.** The abstract states "our method achieves superior accuracy with an MAE of 16.25, outperforming existing training-based and training-free counting methods." This is contradicted by the paper's own Table 1: SAFECOUNT (14.32), PseCo (13.05), LOCA (10.79), and the training-free TFCAC (12.26) all achieve strictly lower MAE. The body text in Section 4.2 correctly admits the method is best "among training-free SAM only methods," but the abstract's broader claim is factually wrong. This misrepresentation undermines trust and must be corrected.

2. **No baseline comparison validating the probabilistic prompt generation.** The ablation (Table 4) varies iteration count and prompts per iteration but never replaces the probability distribution with a simpler alternative (e.g., uniform grid, random sampling) while keeping the verification stage fixed. Without this, the claim that probabilistic prompting "enhances computational efficiency by intelligently exploring the image" is unsupported — the same MAE improvements might be achievable with a fixed grid at the same prompt budget. This is a central component of the method, and it lacks direct validation.

3. **Very high RMSE on FSC-147 is not discussed or analyzed.** The method's RMSE on FSC-147 (133.11) is dramatically worse than TFCAC (56.33), SAFECOUNT (85.54), and LOCA (56.97), and even exceeds OmniCount (112.98). This indicates severe failures on some images. The Discussion (Section 5) briefly mentions degradation for "dense distributions of very small instances" but does not quantify how many images are affected, connect this to the RMSE gap, or analyze whether the verification threshold or prompting strategy causes the instability. For a counting method, large error variance is a reliability concern.

4. **Several reproducibility gaps in the method description.**
   *After prompts are verified as positive and added to the "exemplar list," it is never specified how the multiple exemplar output tokens are aggregated for comparison with candidate prompts (maximum similarity, average, or something else?).
   *The probability update for negative prompts is described only as "its value is decreased" (Section 3.1) with no multiplicative or additive factor specified, making the update rule ambiguous.
   *The "t-scale factor of 0.066" in the implementation details is not explicitly linked to τ in Equation (1), creating ambiguity about whether this is the temperature or a different parameter.
   *The 300 threshold for TS-SS verification is given without any sensitivity analysis or discussion of the scale of the TS-SS product.

### Minor

1. **TS-SS improvement over cosine similarity is small and lacks significance testing.** Table 3 shows TS-SS (16.25 MAE) vs. cosine (16.48) — a 0.23 MAE gain. Table 5 shows output token vs. image embedding space improves MAE by 0.69. No error bars, variance, or multiple-run statistics are reported, so the reader cannot assess whether these differences are meaningful or within noise.

2. **The "SAM" baseline row in Table 1 is never described.** The row labeled "SAM" (MAE 42.48) appears in the "SAM only" group but the paper does not state how it was constructed — grid density, number of prompts, verification method, or any details needed to interpret this baseline.

3. **No comparative runtime numbers.** The paper reports its own inference time (1.69s/image) and claims to be >2× faster than TFCAC, but does not provide TFCAC's runtime or any other method's timing on the same hardware, making the efficiency claim difficult to evaluate.

4. **No sensitivity analysis for the threshold (300) and temperature (τ=0.066).** These hyperparameters could significantly affect the accuracy-efficiency trade-off, but no ablation or analysis is provided.
