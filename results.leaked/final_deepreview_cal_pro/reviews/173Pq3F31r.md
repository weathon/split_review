## Summary

This paper proposes a unified transformer-based Seq2Seq framework that jointly handles expressive performance rendering (EPR) and automatic piano transcription (APT) by disentangling note-level score content from global performance style. It also introduces a diffusion-based Performance Style Recommendation (PSR) module that generates stylistically appropriate style embeddings directly from score content. The framework is trained without requiring fine-grained note-level alignment and leverages both paired (ASAP) and unpaired data. Evaluated through objective metrics, subjective listening tests, and representation analyses, the model demonstrates competitive performance on both tasks alongside effective content-style disentanglement and style transfer.

## Strengths

- **Novel joint EPR–APT framework with disentangled representations**: The paper presents a genuinely novel unification of two historically separate tasks through a shared content representation and a separate global style representation. The connection to ASR/TTS joint modeling provides solid motivation, and the architecture is clearly specified. This is well-motivated and creatively executed.

- **Seq2Seq EPR formulation obviates note-level alignment**: The model achieves competitive or superior alignment metrics (92.27% alignment, 3.77% insertion rate in Table 3) compared to alignment-dependent baselines (DExter, VirtuosoNet) without requiring expensive note-level paired supervision. This is a practically significant advance for scaling EPR systems.

- **PSR module is a creative and useful addition**: The diffusion-based style recommender that generates style embeddings from score content alone mimics a pianist's interpretive ability and is independently trained on frozen representations. Subjective ratings (Figure 2) show PSR-generated styles perform close to ground-truth target styles and above all baselines. The era-level clustering in Figure 4 provides qualitative evidence that the PSR module learns meaningful style priors.

- **Comprehensive evaluation across multiple dimensions**: The paper evaluates APT (Table 1), EPR (Tables 2–3, Figure 2), disentanglement (Table 4, Figures 3, 5), and PSR (Figures 2, 4) using both objective metrics with statistical significance tests and subjective listening tests. The breadth is commendable.

- **Joint modeling improves EPR**: The Ours (Target) variant consistently outperforms the EPR-Only baseline on KL divergence and MAE metrics in Table 2, with the authors appropriately noting that this improvement comes from "joint modeling, together with training on additional unpaired data." The EPR-Only baseline, trained solely on ASAP, provides a useful (if imperfect) ablation point.

## Weaknesses

### Fatal

None.

### Major

- **No ablation isolates the effect of joint training from data scale on APT**: The Ours model in Table 1 is trained on ASAP paired data *plus* ~76k unpaired scores and YouTube-transcribed performances, while the key end-to-end baseline (Beyer & Dai, 2024) uses only ASAP. The paper lacks an APT-only model trained on the identical augmented dataset (or a joint model trained on ASAP only) to determine whether APT improvements stem from joint training, additional data volume, or both. The paper's contribution statement claims "mutual supervision" between the two tasks, but the APT side of this claim is not isolated. This does not invalidate the overall framework — the model remains competitive on APT regardless — but it leaves the "mutual benefit" claim for APT unverified.

### Minor

- **Disentanglement evaluation partially confounded by representation structure**: The content-style disentanglement analysis (Table 4) compares a single global style vector (z_s) against average-pooled note-level content vectors (z_c) for composer/performer classification. The paper acknowledges that "as a global embedding, z_s is better suited for capturing high-level stylistic features than the note-level z_c," which partially addresses the concern. However, the use of naive average pooling rather than a learned global aggregation (e.g., a CLS token from the content encoder) may artificially depress content-based classification accuracy. The overall pattern (77.46% vs. 29.99%) is still informative, but the magnitude of the gap may be inflated by the aggregation choice.

- **Subjective evaluations are underpowered**: The main listening test uses 11 participants rating 5 pieces (Section 4.3), and the style-transfer test reports only 3 samples (Figure 5). While error bars are shown, no formal statistical tests are reported for the subjective results. These small sample sizes limit the confidence with which the perceptual-quality claims — e.g., that PSR-generated performances are "stylistically appropriate" and comparable to target styles — can be asserted. This is not uncommon in music MIR research but weakens the subjective evidence.

### Trivial

- The conclusion is brief and does not include a dedicated limitations section (e.g., dependence on the training style distribution, reliance on clean paired data, scope limited to classical piano). The current conclusion mentions only future extension to popular music as future work.

- The paper does not report inference cost or sampling steps for the PSR diffusion module, which matters for practical accessibility.

## Nice-to-Haves

- A PSR control experiment using a mismatched or random style would strengthen the claim that PSR provides *appropriate* (not just high-quality) style. Currently, PSR is compared against target styles and baselines but not against deliberately inappropriate styles.

- Reporting transcription error rates for the YouTube audio used in the unpaired performance dataset, and analyzing whether transcription artifacts affect the learned style representations.

- Replacing average pooling with a learned global aggregation (e.g., using a CLS-token from the content encoder or attention pooling) for the content-based classification in Table 4 to ensure comparability with the style vector.

## Novel Insights

The paper's most novel conceptual contribution is the explicit framing of EPR and APT as inverse processes mediated by a shared content representation and a separate style representation — analogous to the ASR/TTS duality in speech. This framing enables both tasks to be learned jointly in a single architecture, using only sequence-aligned data. The PSR module, which learns to predict style from score content via a diffusion model trained on frozen disentangled representations, is a cleanly modular addition that separates the style generation problem from the core rendering architecture. The paper also provides useful empirical evidence that composer identity is more strongly encoded in performance style than performer identity (77.46% vs. 42.07% accuracy), which has implications for how we think about expressiveness in classical piano performance.

## Suggestions

- Train a joint model on ASAP *only* (no unpaired data) and report both APT and EPR results. This would cleanly isolate the contribution of joint training from data volume, directly addressing the major weakness identified above.

- Scale the subjective listening test to at least 20–30 participants and add proper statistical tests (e.g., mixed-effects models or pairwise comparisons with correction). This would substantially strengthen the perceptual quality claims.

- Use a learned global pooling for the content representation in the disentanglement classifier (e.g., a CLS token or attention pooling) to enable a fairer comparison with the global style vector.

- Add a PSR control condition using randomly sampled or deliberately mismatched styles to demonstrate that the PSR module specifically provides *appropriate* style rather than just stylized variation.
