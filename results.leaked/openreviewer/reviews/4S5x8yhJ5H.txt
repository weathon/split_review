# Review

## Summary
This paper presents a new dataset for face recognition, which contains 2250 images and 1550 videos of 50 individuals. The dataset includes different scenarios such as standardized photos, selfie photos, selfie videos, and verification videos. The authors evaluated the performance of face detection and face verification on the dataset using several methods.

## Strengths
1. The dataset includes different scenarios and sessions, which can be used to evaluate face recognition systems under different conditions.

2. The dataset contains both images and videos, which can be used to evaluate face recognition systems that handle different modalities.

3. The authors evaluated the performance of state-of-the-art face detection and face verification methods on the dataset.

## Weaknesses
1. The dataset only contains 50 individuals, which is much smaller than existing face recognition datasets. This limits the use of the dataset to evaluate face recognition systems in a wider range of tasks.

2. The evaluation of face detection and face verification is only performed using a limited number of methods. More methods should be evaluated to get a more comprehensive understanding of the performance of different algorithms on the dataset.

3. The authors did not provide any new insights or findings based on the evaluation results.

## Questions
1. What are the unique characteristics of the proposed dataset that are not covered by existing face recognition datasets?

2. How can the dataset be used to improve the generalization ability of face recognition systems for real-world applications?
