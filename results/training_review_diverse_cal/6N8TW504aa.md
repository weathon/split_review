## Summary

This paper proposes Graphical Multioutput Gaussian Process (GMOGP), a framework that models output dependencies in multi-output regression using directed graphical models with an attention mechanism. Each output is treated as a target node conditioned on learned parent outputs via attention-weighted linear combinations, with shared kernel hyperparameters learned across outputs. The model extends to non-Gaussian data through element-wise normalizing flows (TGMOGP) and supports distributed training without block-diagonal approximations. Empirical results on synthetic and real datasets (KUKA, SARCOS) show competitive or superior predictive performance compared to LMC-based and other MOGP baselines.

## Strengths

1. **Novel integration of attention-based structure learning into MOGP.** The paper introduces a per-edge scoring function (Eq. 18) with disparate parameters \((\mathbf{w}_{ij}, c_{ij})\) that overcomes the "static attention" problem identified by Brody et al. (2022). This enables the GMOGP to learn asymmetric, conditional-dependence structures among outputs, which is a genuine departure from the symmetric covariance-based approaches in standard LMC models.

2. **Clean distributed learning property.** Remark 3.2 correctly identifies that the separable per-output formulation avoids block-diagonal approximations, extra prediction fusion, and data segmentation required by classic distributed GPs. The shadowed results in Table 2 validate that two distributed computing units achieve comparable accuracy with reduced time on KUKA and SARCOS₂.

3. **Consistent empirical performance across datasets.** The TGMOGP achieves lower RMSE than full-data baselines with only 100 inducing points (Table 2: SARCOS₁ 0.0233 vs. 0.0247) and substantially reduced training time (3s vs. 90s for V-LMC). Figure 5(a) shows the TGMOGP maintains the lowest RMSE across training sizes 300–1200.

4. **Interpretable graphical representations.** Table 3 shows learned attention coefficients that recover meaningful parent sets aligned with high Pearson correlations (e.g., α₃,₄=0.9998 with Pearson 0.9657 on SARCOS), supporting the claim that the model produces interpretable output-dependence structure.

## Weaknesses

### Fatal
None.

### Major

1. **The joint distribution over all outputs is never properly specified, undermining the "graphical model" claim.** The paper writes Eq. (14) as \(p(f_X^{(1)},\dots,f_X^{(S)}) = p(f_X^{(i)}|\mathrm{pa}_i)\prod_{j\in\mathrm{pa}_i} p(f_X^{(j)})\), which picks a single target \(i\) and factorizes through its parents. This is not a standard Bayesian network factorization \(\prod_{i=1}^S p(f_X^{(i)}|\mathrm{pa}_i)\) over all nodes simultaneously. The paper then says "we can treat each output as the target node" and learns separate conditionals, but never defines a coherent joint distribution over all \(S\) functions. Proposition 3.1 gives marginal priors per target assuming marginal GPs for parents, resulting in a collection of conditional models sharing hyperparameters rather than a joint multi-output GP in the graphical-model sense. The core framing claim — that the model "can directly learn the conditional dependence" as a probability graphical model — is overstated relative to what is actually constructed.

2. **Experiments lack error bars, statistical significance, or multi-run variance.** Tables 1–2 report single numbers per method without any indication of variance across runs, number of random seeds, or confidence intervals. This makes it impossible to assess whether the reported improvements (e.g., GMOGP RMSE 0.0028 vs. FICM 0.0031 in Table 1) are meaningful or within noise. Given that the synthetic data (Eq. 21) uses an additive structure with shared latent functions that favors the GMOGP's own modeling assumptions, the lack of variance reporting is a significant gap. The real-data experiments partially mitigate the synthetic-data concern, but the absence of basic uncertainty quantification weakens the empirical claims throughout.

### Minor

1. **Multi-objective optimization framing adds little substantive value.** The paper formulates training as minimizing \([\mathcal{L}^{(1)}(\Theta),\dots,\mathcal{L}^{(S)}(\Theta)]^T\) and applies the weighted-sum method with equal weights to obtain "Pareto optimal solutions." In practice, this reduces to \(\sum_i \mathcal{L}^{(i)}(\Theta)\) — the natural sum of per-output negative log marginal likelihoods — which is a standard scalarization. The MOO/Pareto framing is technically correct (positive weights yield Pareto points) but does not constitute a methodological advance over simply sharing hyperparameters across outputs.

2. **Attention mechanism integration into the probabilistic framework is underspecified.** The scoring function (Eq. 18) uses the inner product \(\langle f_X^{(i)}, f_X^{(j)}\rangle\) of latent function values, but the paper states "we substitute the observation values \(\langle\mathbf{y}^{(i)},\mathbf{y}^{(j)}\rangle\) at the initial learning phase" without specifying how the transition occurs, how the scoring parameters \((\mathbf{w}_{ij}, c_{ij})\) are optimized jointly with GP hyperparameters, or what objective drives the attention learning. The attention coefficients \(\alpha_{i,j}\) appear in Eq. (15) as conditional-prior parameters and are clearly part of the learned \(\gamma^{(i)}\), but the training dynamics — whether the inner product uses observed or latent values during training — are left ambiguous.

3. **Synthetic data design aligns with the model's own additive structure.** The five outputs in Eq. (21) are all generated as linear or element-wise-transformed combinations of shared latent functions \(f_1,\dots,f_4\), which mirrors the GMOGP's additive conditional prior \(f_X^{(i)} = \sum \alpha_{i,j} f_X^{(j)} + m_i + \psi_i\). While the non-Gaussian outputs (y₃, y₄) test the TGMOGP extension, the basic structure gives the GMOGP an advantage over methods not designed for this particular form of dependence. This is partially mitigated by the real-data experiments.

### Trivial

1. The heterotopic data extension ("introducing an extra weight matrix to Eq. (18)") is mentioned in one sentence with no details on how the weight matrix is incorporated or learned.
2. The distributed learning scheme (Remark 3.2) claims "all parameters can be learnt jointly" but does not address how shared hyperparameters \(\Theta\) are communicated or synchronized across computing units.
3. Implementation details (optimizer, learning rate, number of inducing points for full-data baselines, hyperparameter selection protocol) are not reported, limiting reproducibility.

## Nice-to-Haves

- An ablation comparing GMOGP against a variant with all \(\alpha_{i,j}=0\) (isolated GPs with shared \(\Theta\)) would isolate the contribution of the learned graph structure.
- Sensitivity analysis of the threshold used to unlink nodes (\(\alpha_{i,j} \approx 0\)).
- Reporting uncertainty in the learned attention coefficients (e.g., via bootstrapping) would strengthen the "graphical representation" claim.

## Suggestions

1. **Clarify the joint distribution.** Either (a) specify the full Bayesian network factorization \(\prod_{i=1}^S p(f_X^{(i)}|\mathrm{pa}_i)\) over all outputs with a consistent DAG, or (b) reframe the model honestly as per-output conditional GPs with shared hyperparameters and learned attention weights, dropping the graphical-model formalism where it does not apply.
2. **Add error bars.** Report at least means and standard deviations over 5–10 random seeds for all experiments. For time comparisons, report variance across runs.
3. **Temper the MOO claim.** Replace "Pareto optimal solutions" with "joint learning of shared hyperparameters" unless a genuine trade-off analysis (conflicting objectives) is shown.
4. **Specify attention learning details.** Clarify how the scoring function parameters \((\mathbf{w}_{ij}, c_{ij})\) are optimized, whether the inner product uses observations or latent function values during training, and how the "initial learning phase" transitions to the main training phase.
5. **Report implementation details.** Include optimizer, learning rate, number of inducing points for baselines, and hyperparameter selection procedure.
