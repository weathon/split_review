# Review

## Summary
This paper studies the kernel density estimation problem, which, given a dataset and a kernel, builds a data structure that approximates the average result of the kernel function between a query point and all points in the dataset. Previous work, which is based on locality sensitive hashing, has a space complexity of linear in $1/\mu$, where $\mu$ is the value of the kernel function between the query and the data point, and a query time of $1/\mu^{0.173}$. This work improves the query time to $1/\mu^{0.05}$, at the cost of increasing the space complexity to approximately $1/\mu^{4.15}$. The main technique is to use a more advanced hashing scheme (asymmetric LSH) than previous work.

## Strengths
The paper is well-written. The presentation is clear. The theoretical result is solid.

## Weaknesses
The main weakness is that the improvement over the previous work is mostly due to a more advanced (and complicated) hashing scheme. This makes the technical contribution of this paper a bit incremental. 

The other weakness is that the running time of the algorithm is not practical. As the author mentioned, the query time is $1/\mu^{0.05}$. This means if $\mu$ is small, the running time is very long. Even though the author claims that $\mu$ is usually not too small in practice, it is still better to have a more reasonable running time. For example, in the abstract, the author claims that the previous work has a running time of $1/\mu^{0.173}$, which is much better than the proposed $1/\mu^{0.05}$. If $\mu$ is close to $1$, the previous work is much more efficient.
