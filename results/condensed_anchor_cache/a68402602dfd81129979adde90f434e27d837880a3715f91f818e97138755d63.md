## Merged Review

### Summary
This paper implements and experimentally tests an O(n²) algorithm from Liu (2023) for computing the all-pairs minimax (widest path) distance matrix (APPD) in an undirected dense graph. The algorithm first builds an MST and then uses the fact that the minimax distance between any two vertices is the maximum-weight edge on the MST path. The paper claims this is the first actual code implementation of an O(n²) algorithm for this problem.

### Strengths
- The all-pairs minimax path problem is interesting and well-motivated within machine learning (Reviewers 2, 3).
- This appears to be the first implementation of an O(n²) time algorithm for the all-pairs minimax path problem in dense graphs, and the algorithm is optimal for dense graphs (Reviewer 4; but note that Reviewers 1-3 consider the implementation trivial and not a significant contribution).

### Weaknesses
- The paper makes no significant contribution to machine learning or algorithms: it simply implements the existing Liu (2023) algorithm in a straightforward way with no technical challenge, no new methodology, and no novel implementation techniques. The algorithm is easy to implement (short Python code, Figure 1) and Section 3 merely restates the existing method (Reviewers 1, 2, 3, 4).
- The paper falsely claims that previous quadratic-time algorithms have never been implemented. In fact, Sibson (1973) includes a FORTRAN implementation of the SLINK algorithm, and multiple SLINK implementations are publicly available (e.g., GitHub). The authors should have implemented and compared with SLINK rather than dismissing it as hard to implement (Reviewers 1, 3, 4).
- No experimental comparison with any existing O(n²) algorithm, such as SLINK, is performed (Reviewers 3, 4).
- Presentation issues: grammatical errors (“works good” → “works well”, “the sense” → “the sign”, abstract phrasing “it is a code implementation of…”); citations are not enclosed in brackets (likely \citet instead of \citep); Tables 1 and 2 exceed the paper width (Reviewers 2, 3, 4).
- The paper does not discuss whether the implementation involves any obstacles or dedicated techniques; implementing Liu’s algorithm appears to be a classroom exercise (Reviewer 2, 3, 4). The authors are asked to clarify what obstacles exist in this implementation (Reviewer 3).
- Missing discussion of related work: are there other papers that implement an algorithm from a previous paper? (Reviewer 2)
- The authors do not consider a variant: for graphs with m = o(n²) and m = ω(n), can preprocessing time or space be reduced below O(n²) at the cost of query time? Do any existing works address this? (Reviewer 4)
- One reviewer lists “The paper does not contain any significant contribution” under Strengths, which is almost certainly a misplacement; the substantive criticism is covered above (Reviewer 1).
