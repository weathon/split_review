## Merged Review

### Summary
The paper introduces Selective Attention, a parameter-free modification to the standard attention mechanism that reduces attention to irrelevant tokens. It uses a selection mask derived from previous tokens’ attention logits (from one head) to mask currently attended tokens, and also prunes tokens from the context buffer to save memory. Experiments on language modeling (C4 dataset) show that transformers with Selective Attention achieve comparable perplexity to standard models with ~2× more attention heads/parameters, and yield downstream gains on HellaSwag. Additionally, it reduces attention module memory by up to 47× (e.g., 100M-parameter model, context size 2048) while preserving perplexity.

### Strengths
- **Simple, parameter‑free method**: No new parameters, negligible compute overhead, easy to implement. (R1, R2, R3, R4)
- **Clear motivation and clever execution**: Intuition that tokens already heavily attended can safely receive less attention; implemented by reusing a head’s logits. (R1, R3, R4)
- **Strong, consistent empirical gains**: Language modeling perplexity improvements across various model sizes and context lengths; equivalent performance to standard models with 2× attention heads/parameters. (R1, R4)
- **Impressive memory reductions**: Up to 16×, 25×, 47× memory savings for context sizes 512, 1024, 2048 respectively (100M model, C4). (R2, R4)
- **Efficiency without modifying pretraining loss**: Memory/compute savings are a viable alternative to other efficient attention mechanisms. (R2)
- **Extensive experiments (some reviewers)**: R1 and R4 praise experimental rigor and thoroughness. R4 calls results “very strong and consistent” and agrees with the claim that Selective Attention could be a good default for transformer decoders.

### Weaknesses
- **Limited task/architecture scope** (R1, R2, R3, all agree this is a weakness, though R4 disagrees partially):
    - Only decoder‑only transformers tested; no encoder or encoder‑decoder models (e.g., translation, summarization). (R1)
    - Only one downstream task (HellaSwag) evaluated; need more diverse tasks (e.g., text generation, long‑document understanding, question answering, counting tokens). (R1, R2, R3)
    - C4 dataset is noisy and deprecated; stronger validation requires replicating a state‑of‑the‑art pretrained LLM recipe with Selective Attention. (R2)
- **Missing comparisons to other efficient attention mechanisms** (R1, R2): No direct comparison to sparse attention, linear attention, cache‑pruning methods like H20 (Zhang et al., 2023) or TOVA (Oren et al., 2024). (R1, R2, R4 notes similarity to these methods.)
- **Potential hyperparameter sensitivity** (R1, R4): Performance may depend on optimal per‑layer memory budget; no clear guidelines given for tuning beyond language modeling. (R1)
- **Novelty concerns** (R4): The idea of pruning least‑important tokens is similar in spirit to prior cache‑pruning methods applied at training time; novelty claims should be toned down.
- **Unconvincing intuition claims** (R4):
    - Section 2 examples lack baseline: does a vanilla transformer already attend little to those pruned tokens?
    - Claim that Selective Attention propagates negative signals about irrelevant tokens is unclear. The method penalizes tokens that *received* high attention (high cumulative mask value), but if a token gets no attention, its low mask value prevents propagating information to future tokens—a limitation.
- **Presentation issues** (R2, R4):
    - One full page for a single figure and another for intuition; important plots relegated to appendix. Restructure to give more space to experiments and comparisons. (R2)
    - Section 3 confusing: not explicitly stated that each token is penalized by attention from all subsequent tokens; formal masking definition needed. (R4)
- **Ablation missing** (R2, R4): Why use a single head’s logits to mask all heads? Code uses the first head. Does using a different head or averaging heads make a difference? (R2, R4)
- **Disagreement among reviewers**: R2 and R3 find the experimental validation weak and limited; R1 and R4 consider it thorough and extensive. The paper’s claims about broad applicability are not fully supported given the narrow evaluation.
