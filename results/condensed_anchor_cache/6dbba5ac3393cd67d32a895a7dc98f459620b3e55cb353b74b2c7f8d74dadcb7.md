## Merged Review

### Summary

The paper proposes a parameter-efficient fine-tuning method (SPSFT) that combines structured network pruning and matrix decomposition. It identifies “important” neurons using importance metrics (Taylor score, L2 norm) from pruning, then fine-tunes only the weights involving those neurons, fixing one of two low-rank matrices to binary values. Experiments on vision (ViT, ResNet) and language (DeBERTa, Llama) tasks demonstrate memory and parameter savings while maintaining accuracy comparable to LoRA and its variants. Reviewers generally find the method well-motivated and the experiments reasonably broad, but raise significant concerns about missing baselines, incomplete memory-efficiency evidence, limited novelty, and experimental gaps.

### Strengths

- The method is well-grounded in network pruning research, using structured pruning and importance metrics (Taylor score, L2 norm) to identify output channels that contribute most to performance. This motivation is clear and principled.
- By fixing one of the low-rank matrices to binary values from the importance mask, the approach further reduces the number of learnable parameters compared to LoRA, leading to additional memory savings.
- Experiments cover both vision models (ViT, ResNet) and language models (DeBERTa, Llama), demonstrating generalizability across domains and tasks.
- The paper provides a helpful section on practical memory considerations when using the Adam optimizer (Sec. 5.4).
- The class-aware Taylor importance is noted as a useful side contribution.
- The approach is modular, allowing different pruning strategies to be applied.

### Weaknesses

- **Missing baseline comparisons.** The paper lacks comparisons with several relevant methods: LoRAPrune, RoSA (sparse mask combined with low-rank adaptation), DoRA, VeRA, SVFT, LoRA-XS, Movement Pruning, FISH-Mask, and sparse training methods. RoSA is particularly relevant as it combines sparse fine-tuning with low-rank adaptation, and the paper should benchmark against it or consider combining its own pruning with a low-rank component.
- **Insufficient evidence for memory efficiency.** Despite the title emphasizing memory efficiency, the only memory consumption data comes from a brief section (Sec. 5.4, Table 6) for Llama models. Table 6 shows lower parameter count but significantly lower performance in several cases; a fair comparison would scale both methods to the same parameter count (or performance) and show a curve of performance vs. parameter count / memory consumption.
- **Limited novelty.** Given extensive prior work on LoRA variants and hybrid methods, the contribution of this structured-pruning SFT approach seems insufficient (Reviewer 1). The claim that this is “the first work that can integrate the literature on model compression for fine-tuning” should be removed (Reviewer 4).
- **Dataset selection concerns.** Experiments on vision tasks focus on CIFAR-100 and TinyImageNet, which are low-resolution; evaluations on larger / higher-resolution datasets (ImageNet-10, CUB200, Caltech101) are missing. For image classification, the downstream tasks are very similar to the ImageNet pretraining distribution; more out-of-distribution tasks (e.g., Aircraft, flowers) are needed. For language, only a limited set of tasks is reported; standard 8 zero-shot datasets for Llama should be included, along with an average (AVG) metric.
- **No error bars or statistical significance.** Reported results lack error bars, making it difficult to judge whether improvements are significant.
- **Clarity and presentation issues.** The layout has a large gap between Table 2 and Table 3; the full names of “dft” and “hft” in Table 2 are missing, and placing the proposed method in the middle of the table is confusing. Notation is sloppy (e.g., L161 enumerating rows of matrix M, Eq. 6 using \(F - c_i\) without a new symbol). The term “QTaylor” (line 365) needs definition and reference. The main figure could be clearer with better legends and labels.
- **Missing theoretical analysis.** The paper would benefit from a theoretical analysis of how the handcrafted mask \(M\) impacts the approximation of the true weight update and the resulting error. The operation \(MW_f\) effectively zeros out rows of \(W_f\) based on the binary mask and averages the remaining rows—this should be explicitly stated.
- **Incorrect claim about Taylor importance computational cost.** The statement that “the computational overhead required for computing Taylor importances is already prohibitively large!” (line 187) is not correct, as methods like SparseGPT approximate Taylor importances efficiently.
- **Unclear and unhelpful section on parameter dependencies.** The discussion of parameter dependencies in importance evaluation (lines 262–271) is poorly written, the parameter budget computation is confusing, and the claim that “structured pruning considers parameter dependencies” is uncited. The experimental results show this aspect is unhelpful.
- **Missing experimental details.** For image classification tasks, the pretraining dataset of the models is not mentioned.
- **Minority Reviewer dissent.** Reviewer 1, who gave a score of 3 (vs. 5 from others), found the paper completed rashly, with significant coherence issues between sections, a lack of basic baseline comparisons, and limited novelty.
