## Merged Review

### Summary

MorphoDiff is a generative framework that uses a 2D latent diffusion model conditioned on perturbation embeddings (RDKit for compounds, scGPT for genes) to predict high-resolution Cell Painting images of cellular morphology under chemical and genetic perturbations. The model is fine-tuned from Stable Diffusion v1.4 on three public datasets (RxRx1, BBBC021, Rohban) and evaluated with image quality metrics (FID, KID) and biological metrics using CellProfiler features (PCA, NMI clustering, feature correlation). The authors claim MorphoDiff is the first framework to handle both chemical and genetic perturbations with guided high-resolution generation. Evaluations show improvements over an unconditioned Stable Diffusion baseline and demonstrate that generated images capture perturbation-specific and mechanism-of-action (MOA) signals. Majority reviewers praised the potential impact, clear writing, and biological validation; one reviewer gave a low score citing insufficient benchmarking, limited novelty relative to prior methods, and lack of learned perturbation embeddings.

### Strengths

- **Novel application of guided diffusion to cellular morphology prediction.** Combining latent diffusion with perturbation embeddings (RDKit, scGPT) is a first for this task; generates high-quality images despite small training sets (Reviewers 1,2,4).  
- **Generalization across perturbation types and datasets.** The model works for both chemical and genetic interventions and generalizes across three diverse open-source datasets (RxRx1, BBBC021, Rohban) (Reviewers 1,2,3,4).  
- **Thorough biological validation beyond standard generative metrics.** The use of CellProfiler to extract engineered features and demonstrate clustering by perturbation ID and MOA, along with feature correlation, provides interpretable evidence of biological realism (Reviewers 1,2,3,4).  
- **Clear writing and reproducibility.** The paper is well-organized and accessible; code links for data conversion, fine-tuning, and pre-trained models are provided (Reviewer 2,3,4).  
- **Potential impact on drug discovery.** The method enables in silico screening of large perturbation libraries and provides a baseline for future generative work in cellular profiling (Reviewers 1,3,4).  
- **Minority positive note:** Even the critical reviewer (Reviewer 2) acknowledged the high image quality, clear description, and novelty of applying diffusion models to virtual phenotypic screening for the first time.

### Weaknesses

- **Insufficient comparison to existing methods.** The only baseline is Stable Diffusion without guidance (effectively an ablation). No quantitative comparison against other published methods such as Mol2Image, IMPA, GRAPE, PhenDiff, or GAN/VAE approaches (Reviewers 2,3,4). This undermines claims of superiority and novelty relative to the state-of-the-art (Reviewer 2).  
- **Overstated novelty claim.** Stating MorphoDiff is the “first” to handle both chemical and genetic perturbations in a conditional latent diffusion model is contradicted by prior work like PhenDiff, which addresses similar challenges (Reviewer 4).  
- **Limited evaluation of MOA clustering.** Only a few MOA clusters were considered (Figure 3b); no demonstration on larger MOA sets (e.g., from JUMP or RxRx3). Evaluating MOA inference on an expanded set is crucial for phenotypic screening utility (Reviewer 2).  
- **Correlation with real data is near zero (Figure 4a) and missing replicate baseline.** The Pearson correlation between CellProfiler features from generated and real images for the same perturbation is close to zero. Without comparing to the replicate-level correlation in real data, it is unclear whether the model’s performance is near the noise ceiling (Reviewer 2).  
- **NMI for Perturbation ID not meaningful.** Generated images are naturally more self-consistent than noisy real replicates, making NMI clustering by Perturbation ID a misleading metric. Focus should be on MOA clustering (Reviewer 2).  
- **Perturbation embeddings are not learned.** The model uses fixed RDKit/scGPT embeddings without updating them, limiting its ability to learn improved perturbation representations. This is a key limitation for virtual screening, where the goal is to generalize to unseen perturbations (Reviewer 2).  
- **Out-of-distribution and subtle phenotype generalization unclear.** The model fails to generalize to out-of-distribution compounds, performs better on low-frequency than high-frequency features, and images are shown only for strong phenotypes (e.g., cytoskeletal destabilizers). No evidence that MorphoDiff captures more subtle morphological changes typical in phenotypic screens (Reviewers 1,2).  
- **Statistical significance not properly justified.** Statements like “statistically significant” for FID/KID comparisons lack details on which statistical tests (e.g., t-test, Wilcoxon), p-values, effect sizes, or whether data are paired (Reviewer 3).  
- **Lack of detail in key methodological components.** The perturbation projection module is only briefly described; insufficient depth for full reproducibility. One reviewer noted missing code or repository (Reviewer 4), though another reviewer (2) confirmed code links are provided – still, more detail on the module’s adaptation is needed.  
- **No evaluation of sample variability.** There is no metric (e.g., SSIM) to assess whether generated images for the same perturbation show diverse morphologies or risk mode collapse (Reviewer 4).  
- **Missing ablation studies.** Suggested experiments include: impact of data augmentations on generalization (Reviewer 1); performance with fewer RGB channels (Reviewer 1); effect of perturbation concentration or other prior information (Reviewer 1).  
- **Missing citations and formatting issues.** Some biological claims (e.g., “corroborates established findings”) lack supporting citations; citation formatting is occasionally incorrect (missing parentheses, publication years) (Reviewer 3).  
- **Clarification on clustering technique.** The term “KNN clustering” is ambiguous; likely k-means is intended (Reviewer 3).  
- **Limited dataset size relative to state-of-the-art.** Fine-tuning on ~1,000 perturbations each is small compared to larger datasets like JUMP (120k) or RxRx3 (20k). The model’s scalability and applicability to such datasets are not discussed (Reviewer 2).  
- **Consideration of combination therapies.** The paper does not address whether MorphoDiff could be extended to predict morphology under combined perturbations, though this is important for personalized medicine (Reviewer 3).
