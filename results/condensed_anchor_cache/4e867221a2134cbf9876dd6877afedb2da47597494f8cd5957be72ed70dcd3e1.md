## Merged Review

### Summary
The paper proposes VT-PLUG, a framework integrating visual task plugins with a multimodal large language model (MLLM) and a Visual Decoding Chain-of-Thought (VD-CoT) to handle dense prediction tasks (segmentation, keypoints) alongside standard vision-language tasks. A large-scale dataset VT-Instruct (100M+ samples, 25 task types) is constructed. Evaluations cover visual understanding, referring expression comprehension/segmentation, grounded conversation generation, etc. Reviewer 2 (score 5) praised the comprehensive experiments, code release, and VD-CoT idea, while the other three reviewers (scores 3) raised major concerns about novelty, comparisons, missing details, and insufficient performance gains.

### Strengths
- Unifies multiple vision tasks (e.g., grounding, segmentation, keypoints) into a single framework using modular visual plugins (R1, R3).
- The VD-CoT technique for selecting the proper decoder and providing semantic learnable queries is interesting and could improve decoding accuracy (R2, R3).
- A large-scale, diverse multi-task dataset VT-Instruct is constructed, containing over 100 million multimodal dialogue samples across 25 task types, incorporating various visual prompts (point, box, scribble, mask) and output visual units (point, box, keypoint, depth, mask) (R2, R4).
- Comprehensive quantitative evaluations are performed on multiple tasks, including visual understanding, referring expressions, interactive grounding, open vocabulary identification, and grounded conversation generation (R2, R4).
- The authors will release the source code and dataset, benefiting the research community (R2).

### Weaknesses
1. **Weak comparisons and missing related works** – The paper compares with older or weaker baselines. Examples: Table 2 only includes earlier grounded MLLMs (e.g., LLaVA-1.5-7B achieves 78.5 on VQAv2); Table 3 omits the F1 score on POPE (main metric used by LLaVA-1.5); Table 4 shows REC/RES results behind recent models (GLaMM achieves 83.2 RES cIoU on RefCOCO TestA, UNINEXT achieves 89.4 REC accuracy on RefCOCOg). Keypoint detection is claimed as a major modality but no quantitative evaluation is provided (R3). The framework should also be compared with agent-based systems like HuggingGPT, Visual ChatGPT, MM-REACT (R1, R4). Missing discussion of closely related works: VITRON, Next-GPT, VisionLLM series, and especially VisionLLM v2 which shares task/model design (R2, R4). The paper does not clearly explain differences from prior works exploring the same paradigm (R2).

2. **VD-CoT lacks clarity and justification** – The process of VD-CoT is unclear: when is it performed during inference/training? How is the model supervised with VD-CoT? Figure 2 does not clarify whether the model directly outputs the answer when a visual task is requested (R2). The claim that VD-CoT prevents task conflict is not well studied; it appears to be merely a decoder selection mechanism (R2). The unique advantage over existing chain-of-thought or visual decoding methods is not demonstrated, giving the impression of borrowing the CoT concept without novelty (R4). The ablation study omits key comparisons such as decoding with CoT vs. without CoT, and how data mixture in VT-Instruct affects results (R3).

3. **Poor presentation and missing implementation details** – The paper’s organization is hard to follow; an overview figure from input to target predictions is needed, and the definition of "plugins" should be explained in detail (R1). The presentation is not suitable for an academic paper: only high-level overviews are given in Sections 3 and 4, with many details hidden in the appendix (R3). Specific missing details include: the group hungarian matcher (only briefly mentioned, ablation study exists but no explanation of how it differs from standard hungarian matcher) (R2); training hyperparameters (batch size, epoch, learning rate) not listed (R2); how the model handles iterations where some decoders are not used (potential hanging issue) (R2).

4. **Performance limitations and artifacts** – Segmentation performance is not well: Table 4 and appendix examples show low quality, and it is unclear whether the model was trained only on segmentation tasks (R2). Qualitative results show simple cases with few objects, yet contain artifacts such as duplicate “person” detections (Figure 8 top right) and low-quality masks (Figure 9 top right) (R3). It is unclear how the model performs on more challenging natural images (R3).

5. **Complexity and computational cost** – The reliance on separate plugins for each visual task increases system complexity and may limit scalability and real-world applicability; the computational cost of this integration is not addressed (R4).

6. **Minority contrast** – Reviewer 2 (score 5) was more positive, highlighting the comprehensive experiments, code release, and VD-CoT as strengths, but still raised concerns about missing related works, unclear VD-CoT process, group hungarian details, segmentation performance, and task conflict justification.
