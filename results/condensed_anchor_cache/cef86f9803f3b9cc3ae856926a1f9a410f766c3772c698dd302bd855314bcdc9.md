## Merged Review

### Summary

The paper proposes Tree Attention, a topology-aware algorithm for parallelizing exact self-attention computation across multiple GPUs during decoding. It derives an energy function for self-attention and uses a tree reduction to compute attention with logarithmic communication complexity. Experiments claim up to 8× speedups over Ring Attention on sequences up to 5.12M tokens with 128 GPUs, and 2× less peak memory. Evaluated on H100 DGX, AMD MI300X, and connected RTX 4090s. Reviewers acknowledge the novelty and potential but raise concerns about validation, baseline correctness, generalizability, clarity, and limited scope.

### Strengths

1. **Novel theoretical framing** – The energy-driven argument and Bayesian interpretation are elegant (R1), and the derivation exploiting associativity of logsumexp and max provides a new perspective with potential for deeper theoretical understanding (R2).

2. **Algorithmic advantage** – Tree Attention cleverly achieves logarithmic communication complexity (vs linear for Ring Attention) and demonstrates clear latency improvements in experiments (R2). It effectively scales with GPU count (R3), delivering up to 8× speedups and 2× less peak memory (R3, abstract).

3. **Topology awareness** – The algorithm accounts for two-level network topology (intra- vs inter-node) within GPU clusters, which is a practical and well-considered enhancement for real-world distributed environments (R4).

4. **Communication bottleneck analysis** – The paper includes a microbenchmark of latency and bandwidth between inter-node and intra-node H100 GPUs, effectively highlighting the communication bottleneck (R5).

5. **Novel approach to attention design** – The work introduces a new avenue for designing improved attention mechanisms by considering system topologies (R5). It innovatively uses knowledge from other fields (R3).

6. **Clarity of exposition** – The paper is well-written and pedagogical, making it accessible to readers not expert in physics or distributed computing (R1).

### Weaknesses

1. **Theoretical validation insufficient** – R1 requests proper experimental analysis of scaling trends. Figure 3 shows execution time T vs N and p without linear fits or expected scaling of Ring Attention; more data points in the intermediate range are needed. R1 also questions the memory scaling analysis (δ_M ∝ N/p should be checked). R5 notes inconsistency in Table 1: O(log n) on H100 vs O(n) on MI300X regardless of attention mechanism, requiring explanation and profiling.

2. **Baseline comparison issues** – R5 (most negative, score 3) states the ring attention implementation may be incorrect. Using ring_fwd from flash_attn_jax assumes partitioned Q, K, V; in the authors’ code the query has P tokens (P workers), leading to redundant computation. For the decoding scenario (single-token query, only last row needed), Ring Attention is inappropriate – a direct reduction of partial results is a more suitable baseline (R5). R3 notes the paper only compares to self-implemented Ring Attention and should compare to Linformer, Longformer, Performer. R4 finds it unclear what specific limitations of Ring Attention are addressed.

3. **Limited scope and generalizability** – The method is only applicable when the query has a single token (decoding), not general to training or prefill stages, which limits its usefulness (R5). Evaluation is conducted only on DGX H100 systems, with no real-world deployment or testing on other clusters (R3). The paper lacks end-to-end evaluation on a real-world LLM; only a single attention module is tested (R5).

4. **Clarity and presentation** – R4 and R5 find the method details challenging to follow; R5 states the idea is straightforward but the explanation is overly complicated. R2 suggests Section 3 (energy function derivation and Bayesian interpretation) is unnecessary and may confuse readers; moving it to discussion is recommended. R4 requests clearer explanations or diagrams. Minor issues: replace Wikipedia reference for Helmholtz free-energy with a solid source (Landau, Lifshitz) (R1); index A in the second formula in Section 2 is redundant (R1); define “Absolute” vs “Relative” execution time in Section 5.1 (R1); define batch b in Section 5.2 (R1); fix typos: row 144 “Cumulant”, row 505 “Its communication” (R1); explain notation d_h in line 101 and resolve notation abuse in sums (R2).

5. **Motivation and contribution** – R4 finds insufficient motivation for using the gradient of the energy function; it is unclear how this uniquely benefits attention computation. R5 notes the algorithm does not actually utilize a tree topology (it relies on NCCL library), reducing generalizability and contribution.

6. **Missing experiments/analyses** – R1 requests showing equivalence between Algorithm 3 line 2 and Algorithm 2 line 4 via expanded math. R3 asks for testing with different hidden sizes and varying GPU numbers, memory usage comparisons, and insights on managing communication latency in large clusters. R1 suggests adding D’Amico et al. 2024 to Related Work and expanding discussion of prior complexity methods (Keles et al. 2023). R2 asks whether tree attention saves inter-node communications by reducing number or volume (or both) and why ring attention must store neighboring KV (could be done differently). R4 requests a breakdown of the 8× speedup (communication vs computation) and clarification on whether the tree reduction introduces any approximations or remains exact.

7. **Reviewer disagreement** – R5 (score 3) is significantly more negative than other reviewers (scores 6,6,5,5). Key disagreements: R5 believes the ring attention baseline is incorrect and the method’s scope is too narrow, while others find the approach promising but needing improvement. R5 also doubts the tree topology claim, noting reliance on NCCL. This contrast should be considered in rebuttal.
