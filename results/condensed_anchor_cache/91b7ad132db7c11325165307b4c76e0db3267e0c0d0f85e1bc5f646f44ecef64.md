## Merged Review

### Summary
The paper proposes POST, a framework for private soft-prompt transfer that first distills a large language model (LLM) into a small language model (SLM), performs private prompt tuning on the SLM using DP (PromptDPSGD), and then transfers the soft prompt to the original LLM using a public dataset. Reviewers generally found the setting well-motivated and the framework novel, but raised several concerns about limited evaluation (only classification), lack of analysis on distilled model quality and hyperparameter ablation, missing DP guarantee, unclear practical applicability, and insufficient justification of key assumptions.

### Strengths
- The setting is well-motivated and clearly explained, with clear introduction and figures (Reviewer 1). The paper brings focus on privacy and efficiency issues in prompt tuning (Reviewer 2).
- The proposed framework (POST) is novel, particularly the privacy-preserving prompt transfer through public data (Reviewer 3). It achieves competitive results on test datasets (Reviewer 2).
- The related work and key concepts (prompt tuning, DP, knowledge distillation, prompt transfer) are clearly explained (Reviewer 4). The algorithm is described in detail (Reviewer 4).

### Weaknesses
- **Limited task scope**: Evaluation is only on classification tasks. Practical applicability for open-ended generation (e.g., QA, reading comprehension) is not demonstrated (Reviewers 1, 2, 3). Reviewer 2 notes that classification inputs contain private data, which may conflict with the privacy setting; Q&A tasks would have less input privacy and be more consistent with the setting.
- **Lack of analysis on distilled model quality**: No study of how the size and performance of the distilled model affect soft-prompt transferability. The trade-off between proxy model quality and transfer effectiveness is not explored (Reviewer 1). There is no termination criterion for the knowledge distillation step; the description that the distilled model should “behave closely to the original model but not meeting the actual inference performance” is vague (Reviewer 3). No ablation on the hyperparameters α_ce, α_lm, α_cos in Eq. (3) (Reviewer 3).
- **Unclear public dataset selection**: There is no guidance on how to choose the public dataset for prompt transfer. Table 1 shows that different public datasets can significantly affect final test accuracy (Reviewer 3). Reviewer 1 also raises this via the missing analysis of how dataset choice impacts performance.
- **Missing DP guarantee**: A formal theorem stating the DP guarantee of the method and its proof are absent. The value of δ is not mentioned in the main paper. Standard deviations for results in Tables 1, 2, and 4 are missing (Reviewer 4).
- **Practical concerns and unclear motivation**: Reviewer 4 questions the motivation: if the LLM provider is closed-source, do they support soft prompts? If open-source (e.g., GPT-2 XL, Llama-2-7b), privacy concerns could be mitigated by running locally. Additionally, it is unclear if a provider would be willing to share a distilled model due to proprietary risks and potential attacks. Reviewer 2 also asks whether the setting is white-box or black-box; for black-box LMs, the provider cannot give an SLM via KD; for white-box, the need for privacy is unclear.
- **Novelty concerns**: Given existing work on knowledge distillation (Sanh et al., 2019) and PromptDPSGD (Duan et al., 2024), the technical novelty of simply combining them is questioned (Reviewer 4).
- **Computational cost comparison missing**: The authors compare runtime of POST vs full prompt tuning in Table 3, but do not quantitatively compare the cost of fine-tuning one soft prompt on the large LLM versus the cost of distilling the LLM and then fine-tuning on the distilled model (Reviewer 1). Similarly, it is not explored whether other compression techniques (pruning, quantization) could replace distillation (Reviewer 1).
- **Missing evidence for soft-prompt transfer difficulty**: The claim that “soft prompts are highly coupled to the LLM they were tuned on, making them difficult to transfer” lacks supporting citations or experiments (Reviewer 2).
- **Missing experimental results**: Llama2-7b results are absent from Table 2 (Reviewer 3). Table 4 does not include larger models like Llama2 (Reviewer 3). Baseline datasets used in prior work (TREC, MPQA, Disaster, LAMA) are not included in experiments (Reviewer 4).
- **Attack success rate low without DP**: Fig. 5 shows low attack success even without DP, raising the question of whether the MIA algorithm used is insufficient and whether there is motivation to add DP (Reviewer 3).
- **Writing and clarity issues**: It is unclear whether the original input x is required during inference; if so, the input may contain private information (Reviewer 2). Reviewer 4 identifies typos: Line 117 “fist” → “first”; Line 119 extra comma; Line 132 “from student to teacher” should be “from teacher to student”; Line 256 missing identity matrix in Gaussian noise notation. The statement that KD compresses LLMs cites Sanh et al. (2019) which discusses BERT, not typically recognized as an LLM (Reviewer 4).
- **General lack of ablation and theoretical analysis**: The proposed method involves many steps and hyperparameters, requiring more ablation studies and theoretical analysis to understand general practical performance (Reviewer 3).
