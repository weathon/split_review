## Merged Review

### Summary
The paper introduces SheaFormer, a method for Text-Attributed Graphs (TAGs) that integrates Sheaf Neural Networks (SNNs) with Large Language Models (LLMs). It encodes node relationships as edge vectors and updates node representations without fine-tuning LLMs. The model pretrains by minimizing prediction error of LLM next-word forecasting on node text, then applies prompt-based fine-tuning for downstream tasks. Node classification experiments across multiple domains show state-of-the-art performance. One reviewer (rating 5) finds the combination of LLM and SNN novel and performance good, while three other reviewers (ratings 3, 3, 1) raise significant concerns about novelty, missing baselines, ablation, experimental scope, and fairness of comparisons.

### Strengths
- **Well-written paper** (Reviewer 1).
- **Identifying limitations of current TAG structures**: The paper effectively reveals that simplified graph structures hinder GNN performance and that predefined single-relation structures fail to capture rich semantic relationships between nodes (Reviewer 2).
- **Extensive experimental validation**: The experiments validate the effectiveness of the proposed framework across various scenarios (Reviewer 2).
- **Novel combination of Sheaf Neural Networks and LLMs**: This is the first work combining SNNs with LLMs for TAGs, providing significant inspiration for the community (Reviewer 4). Reviewer 3 also notes the framework is novel and performs well.
- **Good performance**: The proposed approach outperforms simple GNNs, simple PLMs, and strong GNN+PLM baselines (Reviewer 3).

### Weaknesses
1. **Limited novelty / similarity to prior work**:
   - Equations (3)–(9) in the pretraining phase closely resemble Equations (8)–(11) from “Can GNN be Good Adapter for LLMs?” [1] (Huang et al., WWW 2024), with the only difference being the addition of relational representations. The overall framework (TAG pretraining + task-specific prompt for downstream inference) also aligns with [1] (Reviewer 1).
   - Existing work has already identified the importance of edges (e.g., TEG-DB [1], Edgeformers [2] in Reviewer 2’s references). Many edge-aware GNN models adopt operations similar to Sheaf Neural Networks (e.g., “Can we soft prompt LLMs for graph learning tasks?” [4] in Reviewer 2). The approach of fusing GNN embeddings with text embeddings to predict the next word has been used in prior work (e.g., “Can we soft prompt LLMs for graph learning tasks?” [5] – but note: Reviewer 2’s reference [5] is actually the same as [4]? Keep as stated) (Reviewer 2).

2. **Missing critical baselines and comparisons**:
   - GraphAdapter [1] (Huang et al.) is not compared (Reviewer 1).
   - Missing simple PLM baselines: SPECTER, LinkBERT (Reviewer 3).
   - Missing graph+PLM pretrained baselines: Patton, GLaM, WalkLM (Reviewer 3).
   - Missing Sheaf-only baseline and any GNN (GCN, GAT) with concatenated edge features instead of Sheaf (Reviewer 3).
   - No general PLM+any GNN baseline (Reviewer 3).
   - Missing comparisons with works in the references: [2]–[5] of Reviewer 1 (GraphGPT, GraphLLM, GraphEdit, GLBench) (Reviewer 1).
   - The link prediction experiments in the appendix are not compared with most baseline methods (Reviewer 4).

3. **Lack of extensive ablation studies**:
   - No ablation on: (1) performance without pretraining, (2) impact of different prompts, (3) compatibility with different language models, (4) whether edge information improves performance (Reviewer 1).
   - Unclear contribution of individual parts: SNN to incorporate edge information, LLM-generated edge enrichment, and the pretrain-finetune paradigm (Reviewer 3, also echoed by Reviewer 4).
   - No ablation separating the effects of SNN, LLM edge generation, and pretraining (Reviewer 3).

4. **Unknown/unfair baseline settings**:
   - The input features used for baselines are not specified. It is unclear whether the same set of features (e.g., LLM-generated edge descriptions) are used for all baselines. This makes experimental results questionable (Reviewer 3).
   - The baseline methods do not use extra LLM-generated relational text between nodes, making the comparison potentially unfair (Reviewer 4).

5. **Domain and task limitations**:
   - Evaluation is limited to node classification. Graph classification and link prediction should be added for comprehensive assessment (Reviewer 4; Reviewer 2 also suggests considering link prediction and broader applicability).
   - Datasets lack diversity; evaluation on TEG-DB datasets (which have rich node and edge text) would strengthen findings (Reviewer 2).
   - Applicant is narrow—only TAG node classification; other tasks like link prediction should be considered (Reviewer 2).

6. **Unclear motivation for using Sheaf Neural Networks**:
   - The paper claims SNNs encapsulate richer information (connectivity + relational data), but there are simpler ways to incorporate edge information (e.g., concatenating edge representation to node features and applying any GNN). The specific advantage of SNNs is not justified (Reviewer 3; also mentioned as a question by Reviewer 3).

7. **Presentation and clarity issues**:
   - Figure 1 is hard to follow, not intuitive, and some text is too small to read clearly (Reviewers 3 and 4).
   - The paper is well-written overall (Reviewer 1) but Figure 1 needs improvement (Reviewers 3, 4).

8. **Potential cost concerns**:
   - For large graph datasets, using an LLM to generate relational text may lead to excessive costs (Reviewer 4).

9. **Missing crucial citations**: The paper lacks citations to [1]–[5] listed by Reviewer 1 (GraphAdapter, GraphGPT, GraphLLM, GraphEdit, GLBench) and comparisons with those works (Reviewer 1). Also missing citations to edge-aware GNN works mentioned by Reviewer 2.
