## Merged Review

### Summary
The paper introduces a cross-modality referring segmentation task for abdominal MRI, where users draw scribbles on a reference modality (T1-weighted) to guide segmentation of the reference and four target modalities (T2w, DWI, In-phase, Opposed-phase). A new dataset with 534 cases, 3,277 organ masks across five modalities and four organs is created. The proposed model CrossMR uses paired data augmentation and organ-specific bipartite matching within a referring segmentation framework. Experiments show performance comparable to state-of-the-art on T1w (in-distribution) and better generalization on out-of-distribution target modalities.

### Strengths
- The first work to propose a referring segmentation task for multi-modality MRI organ segmentation, reducing annotation burden by requiring only scribbles on one reference modality (Reviewers 2,5).
- A new multi-modality abdominal MRI dataset comprising 534 cases, 3,277 segmentation masks across five MRI modalities (T1w, T2w, DWI, In-phase, Opposed-phase) and four organs, which can serve as a benchmark (Reviewers 1,2,3,4).
- The CrossMR model demonstrates good generalization on out-of-distribution target modalities, outperforming existing approaches (Reviewer 1). The model is rigorously benchmarked against SOTA models (Reviewer 2).
- The method is clearly written and logically structured (Reviewer 3). The approach of using paired data augmentation and organ-specific bipartite matching is reasonable (Reviewer 2).

### Weaknesses
- The motivation for referring segmentation is unclear when images are well co-registered. In such setting, reference and target modalities share the same ground truth; a simpler solution would be to segment T1w directly with nnUNet (which performs best on T1w per Table 1) and apply the mask to target images via rigid registration, requiring no user input at inference. The paper does not adequately justify the need for a more complex method (Reviewers 3,5).
- The method lacks significant methodological novelty; it largely adapts the natural image referring segmentation framework SEEM without substantial architectural changes or novel mechanisms for medical imaging (Reviewer 3).
- Only T1w is used as the reference modality. The generalizability to other reference modalities (e.g., using T2w as reference) is not validated. Experiments should include multiple reference modality settings (Reviewers 1,4,5).
- Automatic scribble generation is not sufficiently explained; the paper does not evaluate how well it mimics real clinical annotations or how different scribble patterns affect segmentation accuracy (Reviewer 1).
- Performance heterogeneity across modalities (e.g., opposed-phase vs. in-phase) is not studied. Modality-specific factors such as contrast variations may affect accuracy and robustness (Reviewer 1).
- The ablation study is weak: the effectiveness of paired data augmentation is doubtful (according to the ablation table, augmentation does not seem useful) and results are not well illustrated. Qualitative results without bipartite matching are needed (Reviewer 2).
- The model is purely 2D slice-based; it requires a scribble for each organ in every slice, increasing user burden (Reviewer 2).
- No comparison with multi-stage cross-modality methods or analysis of computational complexity (speed, parameter counts) is provided. The paper over-emphasizes its own setup (Reviewer 4).
- Experiments are performed only on a private dataset with only four organs. To demonstrate generalizability, the method should be evaluated on other public datasets (e.g., BraTS) and tasks such as lesion segmentation (Reviewer 4).
- The paper lacks a clear overview of the approach; the role of each subsection in Section 3 is unclear (Reviewer 5).
- The paired data augmentation mechanism is not clearly explained. Specifically, how does one translate a T1w image into an image resembling T2w, DWI, In-phase, or Opposed-phase MRI at high resolution? No existing method is cited that can perform this translation reliably (Reviewers 2,5).
- The paper does not explain the rationale for the specific order of cross-attention, concatenation, and self-attention in the query interactions, nor how many object queries are used per organ and why they are duplicated (Reviewer 5).
- Missing experiments: how does the method handle if the reference modality (T1w) is unavailable? What if CrossMR is trained with multi-modal input without referencing? (Reviewer 3). Robustness to image quality variations and common clinical artifacts is not assessed (Reviewer 1).
- Minor: The introduction of Table 4 appears mismatched with its content (Reviewer 4).
