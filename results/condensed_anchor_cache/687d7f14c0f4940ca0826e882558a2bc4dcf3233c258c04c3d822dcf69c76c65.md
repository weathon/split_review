## Merged Review

### Summary
AgentQuest is a benchmark that evaluates LLM and VLM agents on long‑horizon interactive tasks using six diverse reinforcement‑learning environments (BabyAI, TextWorld, NetHack, Crafter, etc.). It provides fine‑grained metrics (interactivity, spatial reasoning, long‑term planning) and presents zero‑shot baseline evaluations of several state‑of‑the‑art models. Results show that models succeed on simpler tasks but struggle on complex ones, especially when visual inputs are provided; the authors identify a “knowing‑doing” gap where models possess knowledge but fail to apply it. An open‑source toolkit is released.

### Strengths
1. **Integrated diverse environments** – The benchmark consolidates multiple RL environments (e.g., NetHack, TextWorld, BabyAI) that range from simple to extremely challenging, testing a wide set of agentic skills (navigation, reasoning, exploration).  
2. **Timely and valuable to the community** – AgentQuest provides a unified testbed for evaluating LLM/VLM decision‑making, addressing the lack of such a benchmark and facilitating rapid verification. The paper highlights the “knowing‑doing” gap, which may spark further research.  
3. **Detailed metrics and analysis** – The benchmark uses fine‑grained metrics (interactivity, spatial reasoning, long‑term planning) and includes qualitative analysis across capabilities, including understanding environment dynamics and the knowing‑doing gap.  
4. **Clear writing and reproducibility** – The paper is well‑written, motivation is clear, and the code is provided to ensure reproducibility.

### Weaknesses
**Major concerns (raised by multiple reviewers or with high severity):**  
- **VLM underperformance with visual inputs** – The finding that VLMs perform worse when game images are provided is considered “weird” (R1) and “not very surprising” because the game visuals differ from real‑world training data (R4). Both reviewers call for a careful investigation: R1 suggests the prompt may be unsuitable; R4 argues that more general scenarios are needed to support the conclusion.  
- **Only base models evaluated** – The benchmark tests only base LLMs/VLMs, not recent models or methods specifically trained to improve agentic capabilities (e.g., via memory, reinforcement learning, or agent‑specific fine‑tuning). This omission may explain poor performance and does not reflect the full progress in agentic AI (R3).  
- **Lack of innovation in benchmark design** – One reviewer (R3) states that AgentQuest simply combines existing benchmarks without further integration, and does not qualify as innovative work.  
- **Missing environment comparisons** – The paper does not discuss related decision‑making environments such as MineDojo, MineRL, or Overcook, which would strengthen the context (R2).  
- **Missing long‑context models** – The evaluation should include more models with extended context lengths, e.g., Qwen2, Llama‑3‑8B‑Instruct‑80K, LongAlpaca‑7B, LongChat‑v1.5‑7B‑32k (R1).  

**Additional weaknesses and requested clarifications (lower severity or minority views):**  
- **Multi‑agent support** – It is unclear whether AgentQuest supports multi‑agent LLM/VLM decision‑making; if not, this is a limitation (R2).  
- **Handling invalid actions and hallucination** – The authors should explain how AgentQuest deals with cases where the LLM/VLM returns an invalid action (e.g., due to hallucination) (R2).  
- **Visualizations** – More visualizations of the environments, agent behavior, and trajectories would make the analysis more intuitive (R2).  
- **More VLM failure cases** – Additional concrete examples of VLM limitations should be provided (R2).  
- **Code clarity** – The variable name “reasoning” (line 72, “action = self.llm_client(reasoning)”) needs clarification (R4).  
- **Incorporating memory/RL** – The knowing‑doing gap suggests that including memory or reinforcement‑learning methods in future benchmark iterations could be valuable (R1, overlap with R3’s critique of missing agent‑focused methods).  

**Minority reviewer contrast:** Reviewer 3 (score 5, confidence 4) is more negative than the others (scores 6, 6, 8), explicitly questioning the benchmark’s novelty and the omission of agent‑specific models. This contrast should be considered when weighing the weaknesses.
