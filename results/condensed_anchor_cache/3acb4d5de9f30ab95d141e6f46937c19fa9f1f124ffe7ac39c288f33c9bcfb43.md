## Merged Review

### Summary
The paper addresses visual offline RL with distractions by formalizing the setting as an ExoPOMDP and proposing CLEAR, a method that learns an agent-centric state representation via information-theoretic objectives. A VAE-like model with a compositional decoder (reconstructed foreground/background blended with masks) disentangles controllable factors from exogenous distractions. Experiments are conducted on three DeepMind Control Suite tasks (e.g., Hopper, Walker, Cheetah) with multiple distraction types (e.g., 2×2 grid, video, color). The representation is used for policy learning in offline RL.

### Strengths
- The high-level motivation and information-theoretic foundation are solid. The regularization term encouraging \( \hat{s} \) to encode an agent-centric state controllable by actions is particularly interesting, and its effectiveness is well supported by experiments.  
- The method is simple and effective. The architecture focuses on computational efficiency and practicality; results are potentially reproducible even without source code.  
- Thorough evaluation on various distraction types, notably the 2×2 grid distraction—a strong testbed for controllability. CLEAR consistently outperforms baselines, highlighting their failure to discern controllability.  
- A comprehensive set of baselines is included, covering both offline RL (CQL, IQL) and model-based RL (Dreamer-v2, ORE, DeepMDP, InfoGating, TIODM).  
- The paper is clearly written and well-organized; figures and equations are appropriately placed.  
- The ExoPOMDP formalization is practical—visual domain distractions are common in real-world RL, so the work has direct applicability.

### Weaknesses
- **Limited task scope and domain diversity**: Only three tasks from the DeepMind Control Suite (a single MuJoCo domain) are tested. One reviewer considered the experiments thorough, but two others found the number too few (e.g., 5–6 tasks would be stronger) and noted that MuJoCo distractions are synthetic (fixed grids, video overlays) and do not capture real-world clutter like dynamic lighting, occlusions, or diverse object appearances. Adding purely vision-based RL tasks is strongly encouraged.  
- **Missing closely related baselines**: Two important prior works are omitted: [1] (information-theoretic approach to controllability) and [2] (causal disentanglement across controllability and reward relevance, with public code). A detailed methodological and experimental comparison is necessary.  
- **Partial validation of generalization to new distraction types**: The evaluation only varies the instance of a given distraction type (e.g., different videos), not the type itself. The method’s ability to generalize to entirely unseen distraction categories (e.g., trained on video distractions, tested on image overlays or dynamic lighting) remains unexamined.  
- **No empirical motivation for the ExoPOMDP setting**: A toy experiment or controlled example that isolates the effect of exogenous variables on state representation would help justify the framework and illustrate how CLEAR disentangles agent state from distractions.  
- **Hyperparameter sensitivity**: The method requires extensive search over the KL-divergence variance and balancing factors for each task, domain, and distraction type (Table 9). No strategy is provided to reduce this burden.  
- **Unclear representation used for policy learning**: It is implied that \( \hat{s} \) (and not \( \hat{e} \)) is used, but this is never explicitly stated.  
- **Robustness to other nuisance factors**: The assumption in L278 that exogenous factors do not affect task-relevant parts (e.g., color perturbations of the agent) is not addressed. How would CLEAR handle such cases?  
- **Missing analysis of integration with model-based RL**: The method aims to improve representation learning; how would it perform when embedded in an MBRL framework (e.g., as the dynamics model)?  
- **Technical concern about graphical model**: In Fig. 2, if \( e_t \) is influenced by \( s_{t-1} \), do Eqs. (2) and (3) still hold? This could affect the derivation.  
- **Presentation**: Table 3 caption lacks sufficient detail about each column, making interpretation difficult.
