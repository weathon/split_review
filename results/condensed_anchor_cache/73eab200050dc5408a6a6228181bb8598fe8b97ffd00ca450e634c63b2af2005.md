- Decision: Reject
- Scores: 1, 3, 3, 3

## Merged Review

### Summary
The paper proposes Intra-model Ensemble Learning (IEL), a test-time adaptation (TTA) method that uses a set of independently pre-trained classifiers. For each unlabeled sample, the model with the highest predicted probability for the majority-voted class acts as a teacher, and all other models minimize cross-entropy against that teacher’s soft output. The method optimizes all trainable parameters (except batch norm) and claims to work with a single sample. Experiments on CIFAR-10/100-C and ImageNet-C with an ensemble of 5 models show improvements over a non-adapted baseline.

### Strengths
- Addresses the challenging single-sample TTA setting (Reviewers #1, #4).
- The approach is simple, elegant, and generalizes the student/teacher setup; scaling by increasing ensemble size is straightforward (Reviewer #2).
- The ensemble-based dynamic optimization of multiple classifiers is an interesting idea (Reviewer #1).
- The problem is realistic and relevant, and the method is intuitive enough for practical use (Reviewer #3).
- Experiments show improved accuracy over not performing TTA (Reviewer #3).
- The paper is well written and easy to follow (Reviewer #4).

### Weaknesses
- **Insufficient novelty and contribution**: The algorithm is essentially a combination of selecting the most confident prediction and cross-entropy minimization over an ensemble; technical novelty over existing ensemble learning and single-sample TTA is limited (Reviewer #1). The contribution statement is inaccurate and should match what is actually shown (Reviewer #2). The paper does not clearly contrast with extensive prior work on ensemble methods (e.g., Alpaydin, 2014) and self-training for unlabeled data (e.g., Fralick, 1965; Chapelle, 2006; Royer et al., 2015; Ghosh et al., 2021); the claimed novelty relative to these works is unclear (Reviewer #3). [Contrast: One reviewer (#1) found the contribution too weak for acceptance, while others (#2, #3, #4) saw potential but required major improvements.]

- **Missing baselines and comparisons**: No comparisons to single-sample TTA baselines such as NOTE or REALM (Reviewer #1). A necessary baseline is applying a state-of-the-art TTA method (e.g., TENT, EATA) to each model in isolation and then ensembling their outputs (Reviewer #2). The paper only shows improvements over no adaptation, not over existing TTA methods (Reviewers #3, #4). Also missing are obvious ablations, such as self-training each network individually, using hard labels instead of soft majority-vote targets, or using the ensemble average confidence (Reviewer #3). It remains unclear whether the ensembling mechanism is orthogonal to other TTA losses (e.g., substituting IEL’s CE with EATA’s loss) (Reviewer #2).

- **Incomplete experimental evaluation**: Reported accuracy values are “highest accuracy improvements” over all epochs, which are not unbiased and may be overconfident (Reviewer #3). No absolute accuracy numbers are given, making it hard to judge base classifier quality (Reviewer #3). Hyperparameter selection (e.g., the regularization constant α = 10e-11, likely meant 10⁻¹¹) is not described and is so small that it cannot have a regularizing effect (Reviewer #3). The exact ImageNet variant used is unclear (test set vs. validation set, which subset) (Reviewer #3). Ensemble element architectures are only provided in table headers, not in the main text (Reviewer #3). A significance test (e.g., Wilcoxon) is needed to rule out random chance given mixed positive/negative results (Reviewer #3).

- **Claims lacking substantiation**: The claim of no catastrophic forgetting on ImageNet-C is not credible with only 7,000 samples per corruption type (Reviewer #1). The contribution references “continual learning” but no experiment supports it (Reviewer #2). Claim 3 that TTA requires a full batch is misleading: techniques like batch norm adaptation and MEMO work on single samples, and any TTA method can be run single-sample by updating every N steps (Reviewer #2). Claim 4 in the contributions is not corroborated by any result (Reviewer #2). The statement that minimizing diversity facilitates generalization is unsupported; the counterexample of ensemble of perfect models is unrealistic, and prior work (including works cited by the paper) shows diversity of mistakes can benefit accuracy (Reviewers #3, #4). The relationship between lower IEL loss, lower entropy, and better TTA performance is claimed (Figure 2) but prior work (“Entropy is not enough”) warns that reducing entropy can be problematic for TTA (Reviewer #4).

- **Technical issues and clarity**: No termination condition is provided for the iterative adaptation; without one the method cannot be run in practice because no labeled validation set is available (Reviewer #3). The method runs multiple epochs over test data, which implies buffering all data—raising the question of why batch-based TTA would not be applicable (Reviewer #3). The introduction is too lengthy; the method section starts only on page 5, and the related work is cited without later using it for comparison (Reviewer #2). Section 3 needs rewriting; the cross-entropy loss is introduced with a redundant symbol δ (Reviewer #2). The exact meaning of “tuning set samples” is unclear (Reviewer #1). The analogies with human learning are superficial and should be removed (Reviewer #3). Reference section lists many papers as arXiv or without venues that have been published (e.g., Arazo et al., IJCNN 2020; Bucila et al., KDD 2006) (Reviewer #3). Figure 1 lacks a legend and its color coding is hard to interpret (Reviewer #2).

- **Limited scope and practical applicability**: The method requires multiple (here 5) source-trained models, which is a strong assumption that may not hold in practice (Reviewers #1, #4). Only stationary distribution shifts are considered; effectiveness under online imbalanced label shifts or mixed shifts is not evaluated (Reviewer #4). There is no analysis of computational cost, adaptation latency, or memory overhead of maintaining multiple models (Reviewers #1, #4). The approach’s robustness to model collapse over long adaptation intervals is not investigated (Reviewer #2). Ablations on the number of ensemble models are missing (Reviewers #1, #2, #4). If the continual learning claim is retained, the method must be evaluated on standard continual TTA benchmarks (CoTTA, EATA) and long-term adaptation on CCC (Press et al., 2023) (Reviewer #2).
