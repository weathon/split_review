## Merged Review

### Summary

The paper introduces Star Attention, a two-phase block-sparse approximation for efficient LLM inference over long sequences. Phase 1 processes context using blockwise-local attention with an “anchor block” (the first block prepended to each sub-block) to handle attention spikes, enabling parallel processing across hosts. Phase 2 uses online softmax for query and response token generation attending to all prior cached tokens. Evaluated on RULER-NIAH using Llama (8B, 70B) models, the method claims up to 11× speedup while preserving 95–100% accuracy. Ablations study anchor block position, content, and size. Reviewers note the method is simple, provides interesting analysis of attention sinks, and has thorough ablations, but raise major concerns about insufficient baselines, contradictory accuracy results, limited evaluation (only one synthetic benchmark), and significant accuracy drops at longer sequences.

### Strengths

- The method is simple, clear, and easy to understand.
- The anchor block solution is an interesting approach to break long-sequence dependencies and enable parallel processing.
- The ablation study is sufficient and presents detailed effects of anchor block position, content, and size.
- The paper provides an in-depth analysis of the “attention sink” and explores underlying causes.
- The proposed approach improves operational efficiency with limited accuracy degradation in many settings.
- The paper is well-written and well-organized.

### Weaknesses

- **Lack of baselines and related work:** Only RingAttention (exact attention) is used as a baseline. Comparisons are missing with many other relevant methods, including: other sparse attention methods (H2O, StreamingLLM, Longformer, Reformer, Unlimiformer), other exact attention systems (DistFlashAttn), and other approaches that reduce computation (Flash Attention, sliding window attention). Without these comparisons, it is impossible to assess the true performance gains of Star Attention relative to the state of the art.
- **Contradictory accuracy results between Tables:** Table 1 shows the method maintains 95–100% accuracy, but Table 2 shows accuracy drops exceeding 10% in several cases (e.g., Llama-3.1-70B-Instruct at 128K, Gradient-AI Llama3-8B-Instruct-1024K at 512K and 1024K). The paper does not clarify what “delta” in Table 2 refers to (relative error vs. absolute drop). If relative, the effective accuracy is much worse than Table 1 suggests (e.g., 95% × 90% = 85.5%).
- **Only synthetic benchmark:** Experiments rely solely on RULER-NIAH, a fully synthetic benchmark. Real-world evaluations on datasets like InfiniteBench, Bamboo, or BABLONG are missing, which is critical for a method based on the assumption that “global attention is not necessary during context processing.”
- **Significant accuracy degradation in longer sequences/larger models:** In Table 2, accuracy drops >10% occur for Llama-3.1-70B-Instruct at 128K and for Llama3-8B-Instruct-1024K at 512K and 1024K. The paper lacks a detailed analysis of whether this is due to model architecture, sequence length, or other factors, and provides no investigation of attention patterns.
- **Marginal improvement in Table 1:** The accuracy improvements from Star Attention over global attention are very small, raising questions about the method’s practical benefit.
- **Experimental setup concerns:** Llama-3.1-70B shows clearly poorer performance than Llama-3.1-8B on both base and instruct versions in RULER-NIAH, making the experimental setup and implementation questionable.
- **Incomplete presentation:** Figure 3 left is missing a data point for 32K block length, making it inconsistent with Figure 3 right; the paper should have set the sequence length from 64K to 256K to fill the plot. Also, a type error exists: “instruct global att” in Figure 3.
- **Unclear speedup measurement:** It is unclear whether “speed up” measures time to first token or time to complete the response.
- **Unexplained performance variance:** Star Attention clearly outperforms global attention on BABLONG but clearly underperforms on RULER-NIAH; no explanation is provided for this discrepancy.
- **Limited applicability:** The proposed method cannot be applied to cases where the LLM needs to generate a large number of tokens (e.g., writing a paper), which limits its contribution and application.
- **No mitigation for longer-sequence accuracy drops:** The paper does not investigate whether simply increasing block size could mitigate the accuracy degradation observed at longer sequences or whether the degradation is considered acceptable.
