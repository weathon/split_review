## Merged Review

### Summary

This paper benchmarks machine learning models on fMRI data across seven public datasets (HCP, ADNI, OASIS, PPMI, ABIDE, etc.), comparing spatial (connectome-based) and sequential (time-series) models for cognitive task recognition and disease diagnosis. The authors evaluate performance, conduct statistical analyses, and use attention maps to interpret brain activations, aiming to provide empirical guidelines for deep model selection.

### Strengths

- The study addresses the important issue of adopting appropriate deep learning models tailored to fMRI study characteristics.
- The authors implemented several diverse models on both task-evoked and resting-state fMRI data and compared results, providing insights from different perspectives.
- The benchmark uses a diverse range of preprocessed datasets (34,887 samples from six public databases) and establishes standardized testing to facilitate method comparison.
- Comprehensive analysis of several SoTA models shows that selecting the appropriate method is essential for optimal results across tasks.
- Interpretation of performance differences using neuroimaging knowledge introduces a novel perspective, offering inspiration for future research.
- The post-hoc method to create task-specific attention maps and evaluate neural activation patterns is valuable for advancing ML in computational neuroscience and clinical applications.
- Performance comparisons across groups with statistical significance tests identify which method groups performed significantly better on specific datasets.
- Visualization of brain activation through global attention weight provides model explainability.
- The experiments are well-designed, using well-known models and datasets, making results meaningful to the fMRI field.

*Note: Reviewer 3 was notably more positive (score 5) than the other three (score 3), highlighting the novel neuroscience-informed interpretability and the value of the benchmark.*

### Weaknesses

1. **Data contribution and novelty** – The claimed contribution of preprocessed datasets is weak because the work uses existing image data and existing preprocessing algorithms; some datasets were already preprocessed, and there is little description of how the data will be released (Reviewer 1,2). The benchmark primarily consists of datasets previously introduced in BrainGB and NeuroGraph, lacking novelty (Reviewer 4). Additionally, important commonly used datasets such as ABIDE II, CNP, POND, and NKI-Rockland are omitted (Reviewer 3). The paper lacks depth on related methods and quality control of the datasets (Reviewer 3).

2. **Spatial vs. sequential dichotomy and conclusions** – The division into spatial and sequential models overlooks that sequential data has at least as much information as spatial data since connectome is derived from time-series; thus the main performance differences may reflect bias-variance tradeoff rather than biological insight (Reviewer 1,2). The conclusion that spatial models are better for disease classification and sequential for task classification is not surprising given existing results (e.g., Wang et al. 2020, Dadi et al., 2019) (Reviewer 1,2). The paper mentions disease “forecasting” but experiments only classify existing disease, not forecast future disease (Reviewer 1,2).

3. **Model selection and hyperparameter optimization** – Hyperparameter optimization is not properly addressed: graph topology is fixed (top 10% threshold across all datasets), learning rate is fixed at 0.0001, and default architectural settings are used without optimization per model/task on validation set (Reviewer 1,2). Models referred to as SoTA are mostly traditional and fundamental; approaches that integrate spatial and temporal features are not included (Reviewer 1,2). Specific missing models: BrainGNN, BrainNetCNN, Transformer-based models (Reviewer 3,4). Traditional machine learning methods such as deep forest are also overlooked (Reviewer 3). The paper does not provide computational details (parameters, memory, training time) to facilitate comparison across models (Reviewer 4); a table of these would be helpful (Reviewer 4). It is unclear whether models were selected based on highest performance metrics or common architecture testing; clarification needed (Reviewer 4, Q3).

4. **Interpretability/Explainability** – The attention map validation is vague: there is little description of which “brain activation patterns established by neuroscience” are referenced. Figure 5 outlines vary across panels and seem to follow the postcentral gyrus (somatosensory) rather than motor cortex (Reviewer 1,2). Attention maps specific to neurodegenerative/neuropsychiatric disorders are not provided, and a standardized attention module is lacking; comparison with BrainGNN’s explainability approach would be expected (Reviewer 4). The paper conflates interpretability and explainability (see Rudin, 2019) (Reviewer 1,2). The post-hoc attention module details are insufficient; it is unclear how global attention weights are updated (Reviewer 4, Q5). Brain mapping results for all seven HCP tasks are not shown (Reviewer 4, Q5).

5. **Dynamic functional connectivity (dFC) issues** – The paper presents confusion regarding the concept of dynamic functional connectivity (Reviewer 3). The differences and core issues between dFC and static FC are inadequately addressed, and experiments focus on classification performance without analysis of dynamic network connectivity (Reviewer 3). The paper should attempt to use more dFC methods, particularly in state number estimation and connectivity learning (Reviewer 3). The construction of the dynamic FC matrix (if used) is unclear: is it done with fixed window size? No baseline or performance comparison for different window sizes is provided (Reviewer 4, Q1). The format of dynamic FC matrices as model input is not explained (Reviewer 4, Q2). The explanation of why sequential models perform better on task fMRI (Remarks 1.1) – because BOLD signal captures dynamic variability better than dynamic FC – raises the need for explanation of variability differences between task and rs-fMRI (Reviewer 4, Q4).

6. **Presentation and clarity** – There are several typos and grammatical errors: “Since connectome is often encoded...”, “As shown in Table 1, we uses...”, “Human Connectome Project in Aing” (Reviewer 1,2). The equation W=XX^T only works if X is normalized appropriately (Reviewer 1,2). The meaning of the +/- range in Table 3 is not explained (Reviewer 2). The paper lacks a link to the code (Reviewer 4, Q6). More detailed explanation of input data configuration criteria (e.g., different input feature types for FC networks, network topology configuration) would be beneficial (Reviewer 4). A table showing model evaluation per group and scenario would improve differentiation (Reviewer 4). In Figure 3 statistical analysis, it is difficult to identify intuitive individual performance; further performance comparison like Figure 4 for other datasets is needed (Reviewer 4).

7. **Other missing analyses and clarifications** – Additional analysis on why attention map performance for disease diagnosis may not have been as expected (compared to BrainGNN) is required (Reviewer 4). The criteria for selecting spatial and sequential models should be explained (Reviewer 4, Q3). Specific questions about dynamic FC construction (window size, input format) are not addressed in the paper (Reviewer 4, Q1-Q2). The link to code is missing (Reviewer 4, Q6).
