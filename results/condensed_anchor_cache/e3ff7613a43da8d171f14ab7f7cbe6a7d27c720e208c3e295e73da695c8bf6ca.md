## Merged Review

### Summary
The paper introduces TP-BERTa, a pre-trained language model for tabular prediction, built on RoBERTa. Two novel components are proposed: relative magnitude tokenization (RMT) to discretize numerical feature values into discrete tokens, and intra-feature attention (IFA) to fuse feature name and value embeddings. The model is pre-trained on a combination of 101 classification and 101 regression datasets, then evaluated on 145 datasets. Results show TP-BERTa consistently outperforms other tabular deep learning models and is competitive with leading GBDT methods (XGBoost, CatBoost). Ablation studies demonstrate that both RMT and IFA contribute to performance.

### Strengths
- **Novelty of RMT**: Relative magnitude tokenization is a creative technique for adapting pre-trained LMs to tabular data by converting scalar values into tokenized representations that can be treated as meaningful words in the LM’s vocabulary (Reviewer 1, 3). The approach is clearly rooted in relevant prior work (e.g., “On Embeddings for Numerical Features in Tabular Deep Learning”) and significantly outperforms the value2str baseline (Table 2, upper half) (Reviewer 3).
- **Clear and intuitive architecture**: IFA is a commendable addition that provides a contextual understanding of features (Reviewer 1, 4). The overall design is well-motivated and easy to follow (Reviewers 1, 2, 4).
- **Strong empirical results**: On 145 datasets, TP-BERTa surpasses standard tabular DNNs and matches or exceeds tuned XGBoost and CatBoost (Table 1) (Reviewers 1, 3, 4). The evaluation is extensive and includes many relevant baselines (Reviewer 4).
- **Ablations support contributions**: Both RMT and IFA are shown to improve performance; RMT in particular yields a large gain over the value2str approach (Reviewer 3, 4).
- **Clarity and detail**: The paper provides sufficient methodological detail to ensure reproducibility (Reviewer 1, 4).

### Weaknesses
- **Pre-training effect not isolated**: It is unclear whether performance gains come from pre-training or from the increased capacity of the underlying LLM architecture. The experiments do not isolate the effect of the pre-training objective from the model architecture (Reviewer 2). This is a core concern—unlike in text, the distributional patterns in tabular data vary drastically across sources, so the assumption that pre-training can learn transferable knowledge is questionable (Reviewer 2).
- **Sensitivity analysis missing for RMT**: The effect of bin size (granularity) in RMT is not analyzed. Finer bins might capture more detail but raise overfitting and computational cost; coarser bins might discard useful information. How the choice interacts with dataset characteristics (e.g., varying numerical distributions) is unexplored (Reviewer 1).
- **Lack of GBDT vs. TP-BERTa scenario analysis**: The paper does not discuss which dataset properties favor GBDTs (e.g., many irrelevant features, complex interactions) or when interpretability advantages make GBDTs preferable (Reviewer 1).
- **IFA contributes only modestly**: Intra-feature attention is considered marginally novel and does not show a significant performance boost in ablations (Reviewer 3). (Note: this contrasts with Reviewers 1 and 4 who find it a clear and useful addition.)
- **No study of pretraining data diversity**: The impact of the number and diversity of pretraining datasets is not investigated. For instance, how would TP-BERTa perform if pre-trained on only 10 classification + 10 regression datasets? (Reviewer 3).
- **Experiments limited to binary classification**: Multi-class classification is not included; results may not generalize beyond binary tasks (Reviewer 4).
- **Lambda hyperparameter fixed arbitrarily**: The hyperparameter λ in the loss is fixed to 0.1 without ablation or discussion of sensitivity (Reviewer 4).
- **Missing analysis of critical data issues**: No experiments on handling missing values, extreme values, or highly imbalanced data (Reviewer 1).
- **No release of code or model**: The authors claim the model will be made available but have not shared any code at the time of review (Reviewer 4).
- **Token interpretability not examined**: There is no analysis or visualization of what the learned tokens actually capture (Reviewer 1, 2).
- **Computational complexity not discussed**: Scaling behavior of RMT and IFA to larger datasets is unclear (Reviewer 1).
