## Merged Review

### Summary
The paper introduces DELIFT, a data selection method for LLM fine-tuning. It defines a pairwise utility metric (based on in-context learning probability gains) to quantify sample informativeness, then applies three tailored submodular functions: Facility Location (FL) for instruction tuning, Facility Location Mutual Information (FLMI) for task-specific fine-tuning, and Facility Location Conditional Gain (FLCG) for continual fine-tuning. A greedy algorithm selects data points maximizing marginal gain under each function. Experiments on Phi-3-mini (3.8B) and Qwen2-72B-Instruct show that DELIFT can prune up to 70% of data without performance loss and outperforms existing baselines.

### Strengths
- Novel pairwise utility metric that quantifies mutual information between data points; shown to outperform an alternative sentence-embedding (SE) metric.
- Tailored submodular functions for each fine-tuning stage (FL, FLMI, FLCG), addressing stage-specific diversity and relevance objectives.
- Achieves up to 70% data reduction with maintained or improved performance across three fine-tuning stages (instruction tuning, task-specific, continual) on Phi-3 and Qwen2 models.
- Addresses a timely and practical problem (data selection for LLM fine-tuning) with a computationally efficient greedy selection algorithm.

### Weaknesses
- **Starting from instruction-tuned models**: Experiments use post-trained models (Phi-3-mini-128k-instruct, Qwen2-72B-Instruct), so the three fine-tuning stages may all be considered continual fine-tuning. It is unclear if the method works for instruction tuning from scratch. Experiments from base models are requested.
- **ICL-based utility metric**: The pairwise utility is based on probability changes from in-context learning, which is an indirect measure of fine-tuning effectiveness (which directly updates weights via gradients). The transferability of ICL gains to fine-tuning is not justified. Moreover, utility values are computed once statically and are not adapted to model changes during fine-tuning.
- **Incomplete fine-tuning evaluation**: Only QLoRA (parameter-efficient) and ICL fine-tuning results are provided; full parameter fine-tuning is missing, leaving open whether gains diminish. Additionally, task-specific fine-tuning on MMLU leads to performance drop (making it an invalid use case), and MT-Bench is too small for reliable results. The authors should evaluate on reasoning tasks (MATH, GSM8K, ARC-Challenge).
- **Unreported computational overhead**: The data selection algorithm requires forward passes with the LLM to compute probability distributions (no cheap embedding models). Its computational cost relative to QLoRA fine-tuning is not compared or justified.
- **Missing ablations on submodular functions**: It is not clear if the vanilla FL function alone would perform adequately across all three stages. The added complexity of FLMI and FLCG may not be necessary. More thorough ablation (including comparisons with DELIFT using the SE baseline) is needed.
- **Partial baseline comparisons**: Missing comparisons with diversity-based methods (e.g., clustering) and recent data selection works such as DEFT-UCS (Das et al., 2024), Text Quality Pruning (Sharma et al., 2024), and Entropy Law (which addresses informativeness/entropy for instruction data selection). The latter is not discussed in the related work.
- **Clarity and definition gaps**: (a) In Equation 2, it is unclear whether the probability vectors from all predicted tokens (x tokens) are concatenated into an x*d vector. (b) In Equations 3–5, the symbol s_ij is not defined; is it the utility-based kernel UF_ij? Is it recomputed after each selection round? (c) For Equation 1, how is the ground-truth distribution determined? The description “a vector of ones for each token” needs clarification.
- **Presentation issues**: Figure 2 contains a typo (“LAJ scores” should be “LJA scores”). The manuscript also lacks line numbers in the left margin.
- **Diversity interpretation**: It remains unclear how the ICL-derived utility gain reflects sample diversity in the semantic space. An analysis of the types of examples selected by different methods would be valuable.
