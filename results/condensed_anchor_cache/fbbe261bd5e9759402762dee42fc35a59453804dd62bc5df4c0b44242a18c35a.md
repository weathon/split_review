## Merged Review

### Summary
This paper proposes a new algorithm, Monotonic Q-Learning with Upper Confidence Bound (MQL-UCB), for reinforcement learning with general function approximation where the Bellman operator maps value functions into a class with bounded eluder dimension. The algorithm uses a deterministic policy-switching strategy based on cumulative sensitivity of historical data, a monotonic value function structure, and a variance-weighted regression scheme. It claims minimax optimal regret of Õ(d√(HK)) when K is sufficiently large and near-optimal policy switching cost of Õ(dH), where d is the eluder dimension, H is horizon, and K is number of episodes.

### Strengths
- Novel policy-switching strategy based on cumulative sensitivity of historical data; claimed to be the first deterministic rare-switching strategy for general function approximation achieving Õ(dH) switching cost. (R1)
- Generalizes LSVI-UCB++ to general function classes with bounded eluder dimension via a monotonic value function structure. (R1)
- Generalizes the approach of He et al. (2022) by replacing the covariate matrix criterion with the newly proposed D²_{ℱ_h} criterion. (R2)
- Compared to existing work, achieves near-optimal regret with fewer policy switches and uses a simpler planning strategy. (R2)
- The problem is well-motivated; the algorithm achieves improvement over previous works. (R3)
- Includes informative discussions, e.g., the connection between D²_ℱ-uncertainty and eluder dimension. (R3)
- The setting of RL with low switching cost and general function approximation is interesting and important. (R4)
- The paper is solid; the proof appears correct. (R4)
- Both the regret bound and the switching cost bound are nearly minimax optimal. (R4)

### Weaknesses
1. **Technical novelty concerns**: Several reviewers question the novelty beyond existing work (LSVI-UCB++, He et al. 2022). The policy-switching framework is new, but its precise mechanism and theoretical justification in general function approximation are not sufficiently elaborated. The connection to the determinant of the covariance matrix in linear settings needs to be more explicit; specifically, why the D² quantity is a suitable replacement and how it ensures a tractable covering number for the value function class. The paper frequently states “inspired by …” without clearly differentiating novel contributions from prior ingredients. (R1, R2, R3, R4)

2. **Algorithm 1, Line 6 is incomplete**: The update/switching condition is replaced by ‘…’, which is confusing. The algorithm description should be self-contained. This condition is crucial as it decides the switching cost. (R1, R3, R4) (R1 notes it possibly corresponds to the last equation on page 5.)

3. **Policy update when condition not satisfied**: If the condition in Line 6 is not met, how is the policy updated? Without it, how is the rollout in Line 21 performed? (R1)

4. **Strong assumptions on function class completeness**: The assumption that the function class is complete with respect to the Bellman operator *and* also complete with respect to the variance of the value function (second moments) is particularly strong and not common. Its practical implications and limitations are not discussed. (R2)

5. **Missing lower bound for general function approximation**: The optimality of regret is only shown for linear MDPs; no lower bound is proven for general function approximation, limiting the impact and leaving the tightness of the regret bound unclear. (R2)

6. **Unclear relationship to other settings**: The paper does not clearly discuss how its setting relates to linear Bellman complete MDPs or the Eluder Condition class. Prior works (references [2] and [3]) design algorithms with low switching cost and sub-linear regret under those settings. Whether the proposed setting strictly contains or is contained within these should be clarified, along with key differences. (R4)

7. **Switching cost claim requires clarification**: The claim of near-optimal policy switching applies only to deterministic policies; the lower bound Ω(dH) also only holds in that setting. For stochastic or non-Markovian policies, the deployment complexity lower bound can be Ω(H) (as reported in closely related works not cited). The paper should clarify this and discuss the relevant literature. (R3)

8. **Insufficient explanation of monotonic value function structure**: The idea is mentioned only briefly. It is not explained how the pessimistic value maintains a monotonically increasing property and the optimistic value a monotonically decreasing property, nor whether this is the same idea as in He et al. or different. The motivation for caring about monotonicity is also missing. (R1, R2)

9. **Presentation and organization issues**: The paper could be better organized (e.g., discuss main results before Section 3). A proof sketch is expected for a theory paper. Several typos: page 3 missing “O” for regrets in Table 1; page 6 missing parenthesis in the definition of b_{k,h} and an excessive “He et al (2022)”; page 8 “may differs” should be “may differ”. (R2, R3, R4)

10. **Unanswered technical questions**:
    - Why is it reasonable to assume a bounded covering class for the bonus when covering for ℱ is already assumed? Can the covering number of the bonus class be derived rather than assumed? (R1)
    - How can one find the bonus oracle \bar{D}²_ℱ? (R2)
    - Given Theorem 4.4, can the regret bound be rephrased in terms of eluder dimension? (R2)
