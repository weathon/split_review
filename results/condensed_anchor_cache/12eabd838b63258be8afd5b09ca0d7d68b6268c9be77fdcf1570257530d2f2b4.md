## Merged Review

### Summary
The paper introduces “compress then explain” (CTE), a paradigm that replaces i.i.d. sampling with distribution compression via kernel thinning (KT) when estimating removal-based explanations (e.g., SHAP, SAGE). KT yields a sample that better approximates the marginal distribution, reducing the number of model evaluations needed to reach a given explanation approximation error. The method is supported by theoretical error bounds and is demonstrated empirically on several datasets. The proposal is a neat application of an existing technique (kernel thinning) to a new domain (post-hoc explanations), and the experiments are thorough.

### Strengths
- Significantly reduces computational complexity of SHAP and SAGE (R1).
- The proposed method is solid and supported by theoretical guarantees on the error (R2).
- Good summary of related work and background; accessible to non-experts (R2).
- Well written (R3).
- Thoroughness of the experiments; rigour in the empirical demonstration (R3).
- Neat application of an existing technique (kernel thinning) to a new domain, with clear utility (R3).

### Weaknesses
- Main contribution is not clearly described in the introduction: initially the reader may think a new explanation method is proposed, but the focus later shifts to applying kernel thinning to improve KernelSHAP and SAGE (R1).
- The approach is specific to explanation methods that rely on subset selection (e.g., SHAP, SAGE); this limitation should be explicitly acknowledged (R1).
- Experimental evaluation is heavily focused on MAE; the calculation of the baseline (ground-truth) explanation error is unclear. Table 1 compares CTE versus i.i.d. sampling, but it is not stated whether the i.i.d. sampling itself serves as the baseline or another baseline is used. The definition of the explanation error (Definition 4, line 184) is not clearly explained – specifically, how the function output is compared for MAE and how the feature values are computed without i.i.d. sampling (R1).
- Only the Gaussian kernel is explored; the theoretical reasons for choosing it over other kernels are not discussed (R1).
- No qualitative examples are provided (e.g., images, IMDB); the evaluation relies solely on MAE (R1).
- A comparison with influence functions for data attribution is expected but missing (R1).
- There may be intermediate baselines between i.i.d. sampling and the more complex CTE framework (e.g., non-uniform sampling strategies). A comparison with such baselines would help understand the tradeoff between compression complexity, sample size reduction, and approximation error (R2).
- Figure presentation needs improvement: sub-plots within multi-plot figures should be labelled (a, b, c,…) and the caption should describe each sub-plot succinctly so the reader does not have to jump between text and figures (R3).
- The work is largely an application of an existing method (kernel thinning); a stronger contribution would be to adapt the sampling method specifically for post-hoc explanations (R3).
