## Merged Review

### Summary
The paper leverages pre-trained Stable Diffusion to achieve unsupervised semantic segmentation and annotation-free open-vocabulary semantic segmentation without additional training. The core idea is that changing sub-regions of low-resolution feature maps triggers notable changes in semantically related regions of generated images. This correspondence is used to build pixel-level segmentation maps. The method embeds an image into a timestep, passes it through the UNet, collects features at a 16×16 layer, performs k-means clustering, and then uses a modulated denoising process to propagate low-resolution clusters to full resolution. The approach does not require retraining, test-time optimisation, or text prompts. Experiments on COCO-Stuff, PASCAL-Context, ADE20K, and Cityscapes show good performance for unsupervised and open-vocabulary segmentation.

### Strengths
- The idea of exploring semantic knowledge extracted from Stable Diffusion (SD) to build an image segmentor is novel and interesting.
- The finding that changing a sub-region of low-resolution feature maps causes significant changes in semantically related pixels in generated images is interesting.
- The method finds good use of powerful T2I diffusion models for segmentation; prior work extracted masks from DM latent spaces but the resolution mismatch for latent diffusion was not obvious—the paper proposes an adequate solution.
- Impressive qualitative and quantitative results: images are segmented into K classes where pixels belonging to the same object tend to fall in the same segment.
- The method requires no retraining, test-time optimisation, or text prompts, and can be applied to diverse datasets straightforwardly.
- Promising downstream applications (e.g., unsupervised segmentation).
- Extensive evaluation on multiple scene-centric datasets (COCO-Stuff, PASCAL-Context, ADE20K, Cityscapes).
- Qualitative examples of failure cases are provided.
- Well-written paper with interesting ideas.

### Weaknesses
- The process is slow: changing the values in every sub-region of low-resolution feature maps and examining changes in generated images requires many passes through the UNet and VAE decoder, making it impractical for real-time or large-scale use (R1, R3). R1 asks if there is a more elegant way to establish the correspondence.
- The modulated denoising process is computationally expensive; runtime comparisons with methods in Table 2 are missing (R3 question → missing comparison).
- The main idea is not very novel: transforming internal UNet feature representations into segmentation maps via k-means was explored in prior work (e.g., Baranchuk et al., Fig 4). The modification to make it work with SD (Sec. 3.3) is sensible but not particularly insightful (R2).
- The method is strongly tailored to Stable Diffusion and may not be applicable to other types of diffusion models (R2).
- R2 raises a question about zero text input: Xu et al. (CVPR23) noted that using pre-trained SD with zero text input is suboptimal for feature extraction. Did the authors observe suboptimalities or experiment with providing textual descriptions? This potential limitation should be addressed.
- The method uses many sensitive hyper-parameters (number of k-means clusters, modulation timesteps, cross-attention layer choice) that need careful tuning per dataset, with no clear strategy and no validation set. This raises concerns about reproducibility and generalizability (R3).
- Missing ablation for the level of cross-attention layer used for low-resolution feature maps (quantitative numbers needed) and for the modulating timestep (only qualitative shown) (R3).
- The resulting segmentation is often over-segmented (Fig. 1), resembling superpixels; semantic labels are still needed to group regions into meaningful masks, unlike SAM. This over-segmentation limits practical applicability (R3).
- One reviewer (R4) finds the approach inelegant and not performing well, and notes a missing comparison with existing solutions (e.g., INSTRUCTCV).
