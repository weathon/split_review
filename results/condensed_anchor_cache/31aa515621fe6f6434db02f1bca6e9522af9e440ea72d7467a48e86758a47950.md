## Merged Review

### Summary
The paper proposes Earth Mover Distance Optimization (EMO) for auto-regressive language modeling, replacing maximum likelihood estimation (MLE). EMO uses cosine similarity of pretrained LM head embeddings as the cost function and derives a tractable upper bound. The motivation is threefold: recall-prioritization, negative diversity ignorance, and train-test mismatch of MLE. Experiments across model sizes, data scales, and metrics show EMO consistently outperforms MLE, especially on MAUVE, with minimal fine-tuning on 25,000 sentences.

### Strengths
- Well-written and easy to follow. The intuition behind softening the cross-entropy loss with embedding similarity is clear.
- Interesting idea: applying Earth Mover Distance to language model training with a feasible upper bound for backpropagation.
- Extensive and detailed experiments covering different model sizes, data scales, and multiple evaluation metrics (including MAUVE, perplexity in some setups, and downstream tasks). The setup is well-described and appears reproducible.
- EMO demonstrates consistently better performance than MLE across domains and tasks, with promising results as a lightweight calibration method.

### Weaknesses
- **Missing related work and baselines.** A related work section discussing Earth Mover Distance / optimal transport in NLP is absent. The proposed EMO loss is very similar to the d2gpo loss (cited but not compared) and to a word embedding-based loss using Euclidean distance [1]. These should be included as baselines and methodologically compared. Additionally, label smoothing should be compared as a common loss in pre-LLM training.
- **Theoretical concerns about MLE characterization.** The claim that MLE exhibits recall-prioritization is confusing. MLE minimizes forward KL divergence; with sufficient capacity the optimal model converges to the data distribution, otherwise it exhibits mean-seeking behavior. One reviewer (4) strongly argues that under the expected EMO loss, the model converges to a one-hot distribution (outputting only the token that maximizes the weighted sum over the data distribution), which would be recall-prioritization and negative diversity ignorance – directly contradicting the authors' motivation. This fundamental disagreement on the method’s behavior is unresolved.
- **Evaluation methodology concerns.** Comparing MLE and EMO based on unbiased sampling is unfair because the two objectives produce very different model distributions. Reviewer 4 argues EMO yields a much sharper distribution, making sampling from it akin to greedy decoding versus sampling from MLE. The fair comparison should include greedy/beam search decoding for both methods. Reviewer 2 also asks for beam search results, as sampling reflects the full distribution while beam search captures the mode. No such experiments are provided.
- **Missing experiments on diversity and distribution.** Given that EMO is claimed to harmonize recall/precision and better handle synonyms, experiments directly measuring output diversity (e.g., distinct n-grams, self-BLEU) are expected but absent. No analysis comparing the model distributions learned by EMO vs. MLE (e.g., entropy of predicted probabilities, token frequency) is provided.
- **Unexplained choice of cosine similarity.** The use of cosine similarity in the cost function is not justified as the best choice. It relies on pretrained LM head embeddings, introducing bias. The gradient of EMO (Section 3.3) resembles REINFORCE with cosine similarity as reward, suggesting RLHF/RLAIF might offer a better reward model. Why not use a learned reward model or other distance metrics?
- **Perplexity reporting is incomplete.** The paper focuses on MAUVE but should report perplexity on the test set (not just sampled sentences) as a reference point, despite MLE optimizing it. One reviewer notes that if the reported perplexity improvement is from sampled sentences, it should be clearly stated and a separate test-set perplexity table provided.
- **Minority negative view.** One reviewer (score 3) strongly disputes the core motivation and evaluation fairness, while others (scores 6,8) are less critical but still raise concerns about missing comparisons and analyses. This disagreement is not resolved by the paper.
- **Decoding discussion absent.** Since the goal is to improve diversity, a discussion of how EMO interacts with different decoding strategies (e.g., top-k, top-p, temperature) is needed. The paper only uses sampling.
