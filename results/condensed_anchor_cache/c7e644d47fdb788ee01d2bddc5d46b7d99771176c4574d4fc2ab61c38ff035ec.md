## Merged Review

### Summary
The paper introduces Neural Context Flow (NCF), a meta-learning method for dynamical systems governed by ODEs and PDEs with varying parameters. NCF uses a higher-order Taylor expansion to modulate context vectors, enabling self-modulation and information sharing across environments, and provides uncertainty estimation. It is evaluated on several linear and nonlinear benchmarks against CAVIA and CODA, achieving state-of-the-art or competitive out-of-distribution performance.

### Strengths
- Clear writing and methodology that help readers understand differences from prior work (Reviewer 1).
- Novel and interesting use of a three-network architecture with Taylor expansion for context modulation; supplementary ablation studies show the necessity of this design (Reviewer 1). The Taylor expansion is intuitive and fills a gap in context-based methods by leveraging information from multiple context vectors (Reviewer 2).
- Simple and useful uncertainty estimation by aggregating predictions from different context vectors (Reviewer 1).
- The problem of building generalizable neural PDE solvers for varying coefficients is important (Reviewers 2, 4).
- NCF achieves state-of-the-art or competitive out-of-distribution performance across a wide range of PDE problems (Reviewer 2).
- Includes both experimental validation and theoretical analysis (convergence guarantees) (Reviewer 4).
- The method is reasonable and provides interesting analysis of the learned vector field behavior; the related works section covers appropriate baselines and datasets (Reviewer 3).

### Weaknesses
- Overfitting concern: Reviewer 3 identified that the OoD adaptation protocol appears to use the same trajectories for tuning the context vector and computing prediction error, leading to a suspicion of overfitting. The model systematically performs better OoD than in-domain, which is unusual. The rebuttal addressed this, but the code was poorly documented (commented-out functions, no README) and the concern remains significant.
- Missing state-network ablation: Reviewer 1 noted the necessity of the state network in the three-network architecture is not sufficiently justified; an experiment removing the state network while keeping the context network is missing.
- Missing sample efficiency experiments: Reviewer 1 noted the paper claims sample efficiency but provides no experiments to support this.
- Missing comparison of context pool strategies: Reviewer 2 noted that RA, NF, and SF strategies are introduced but not ablated for performance or impact on context representations; guidelines for choosing are absent.
- Missing non-meta-learning baselines: Reviewer 4 noted comparisons are limited to meta-learning methods (CAVIA, CODA). Non-meta-learning methods such as Parameterized NODEs and identification of flux function are not considered.
- Missing LEADS baseline: Reviewer 2 recommended adding the LEADS multi-task learning baseline, especially for new datasets.
- Missing robustness to noise experiments: Reviewer 4 noted the method claims robustness but no tests on noisy data are provided.
- Insufficient uncertainty quantification analysis: Reviewer 1 requested uncertainty as a function of forecast horizon. Reviewer 3 stated the uncertainty quantification is overclaimed; the method only shows prediction variation from different context vectors without providing probabilistic bounds. Deeper analysis of how context vectors relate to physical parameters for interpretability is also missing (Reviewer 2).
- No parallelization benchmarks: Reviewer 2 noted the claimed parallelization property is not experimentally evaluated.
- Taylor expansion motivation unclear: Reviewer 3 found the use of Taylor expansion to keep context vectors close is not well-motivated; a simpler distance-based regularization is not compared via ablation.
- L1 regularization claim unsubstantiated: Reviewer 3 noted the paper states L1 regularization is “vital” for sparsity, but no ablation is conducted to verify this.
- Training order 1 vs. order 2 inconsistency: Reviewer 3 noted order 1 and order 2 NCF models are trained with different algorithms (Algorithm 1 vs. 2), making it unclear whether performance gains come from the Taylor order or the training procedure.
- Complexity and instability: Reviewer 3 noted training NCF requires second-order derivatives and backpropagation through a Neural ODE, leading to high computational cost and unstable training curves (spikes, unrecoverable failure). Many hyperparameters (context size, context pool mode) lack guidance.
- Projection network purpose unclear: Reviewer 3 questioned the additional network to convert context vectors to modulated context; it could be directly learned.
- PDE to ODE conversion details missing: Reviewer 4 noted the conversion of PDE problems to ODEs is not described; error control and sensitivity to numerical schemes are not discussed, which can significantly affect solution accuracy.
- Code and reproducibility issues: Reviewer 4 reported the provided code link is inaccessible. Reviewer 3 noted the code is poorly documented with commented-out functions and no README.
- Writing clarity issues: Reviewer 2 noted the introduction could better define the problem of parametric PDEs and environments; two paragraphs on Neural ODEs and physics-based approaches are overly detailed.
