## Merged Review

### Summary
The paper proposes LongGuide, a method that automatically generates two types of task-specific guidelines—Metric Guidelines (MGs) and Output Constraint Guidelines (OCGs)—from a small training set to improve long-form generation with LLMs. The authors argue that in-context learning (ICL) alone is insufficient for long-form tasks (summarization, simplification, translation, generation) and provide empirical/theoretical support. LongGuide is evaluated on Mistral-7B-it and ChatGPT 3.5 Turbo against baselines (including APO, adv-ICL) using ROUGE-L, BLEU, BERTScore, and human evaluation, showing over 5% improvement in zero- and few-shot settings.

### Strengths
- **Novel dual-guideline approach:** The breakdown into metric-oriented (MGs) and output-statistics-oriented (OCGs) guidelines is well-motivated and novel.
- **Empirical effectiveness:** LongGuide consistently outperforms prompt optimization SoTA (APO, adv-ICL) on multiple benchmarks (SAMSum, CNN/DailyMail, SWiPE, etc.) for both medium-sized (Mistral-7B-it) and large (ChatGPT 3.5 Turbo) models.
- **Thorough analysis:** Extensive ablation studies (detailed in appendix) isolate the impact of each guideline component; hyperparameters and settings are clearly specified; human evaluation (though small) is included with annotator wage details.
- **Theoretical grounding:** The paper provides both experimental and theoretical analysis (Section 2, Remark 2.1, Hypothesis 2.1) to motivate why ICL alone is insufficient for long-form generation.
- **Surprising effectiveness on weaker models:** LongGuide also improves non-instruction-tuned models (line 1036), though less reliably.
- **Solid writing and clear motivation:** The paper is well-written with a clear problem statement.

### Weaknesses
- **Outdated automatic metrics:** The main evaluation relies on ROUGE-L and BLEU, which are simple n‑gram measures. Multiple reviewers note that these are insufficient for long-form generation; LLM-based evaluation (e.g., using GPT as a judge) should be included. The BERTScore reported is similar to ROUGE/BLEU in measuring surface similarity.
- **Weak or non-rigorous formalization:** Section 2 (theoretical claims) is described as “not solid” or “distracting.” Remark 2.1 and Definition 2.1 have only weak relation to Hypothesis 2.1; the proof essentially claims that the method is better if it outperforms baselines (Remark 2.2). The theory ignores the unbalanced and dynamic weights of different objectives (e.g., fluency vs. storyline), assuming fixed equal weights.
- **Missing baseline: many-shot ICL with 50 demonstrations.** Since up to 50 training examples are used to derive guidelines, a natural baseline would be 50-shot ICL (long-context ICL). This is absent.
- **Insufficient comparison with recent automatic prompt optimization methods.** Only APO is included; more recent prompt optimization algorithms should be added for a fair assessment of LongGuide’s utility.
- **Limited novelty:** Some reviewers consider the method incremental—similar to existing automated prompt designs for generation (e.g., [https://arxiv.org/html/2406.14449v1], [https://arxiv.org/abs/2211.01910]). The final step of LongGuide only chooses among four static options (use MG, use OCG, both, or neither) without more sophisticated joint or staged strategies.
- **Metrics description insufficient.** The “12 more metrics for broader evaluation coverage” (line 208) are not explicitly described. The core set of metrics is inadequately explained; specifically, it is worrying that LLM-based metrics are excluded despite proven correlation with human judgments for summarization.
- **Experiments only on instruction-tuned models.** All experiments use fine-tuned/instruction-tuned LLMs (Mistral, ChatGPT), which conflates ICL capacity with instruction following. This undermines the paper’s focus on “in-context learning” in the title. Additional experiments on base (non‑instruction‑tuned) models are needed.
- **Small human evaluation set.** Figure 5 uses only 50 examples, making the results less reliable.
- **Little direct practical takeaway** for engineers/researchers (e.g., hyperparameter choices; main experiments only cover a few datasets: SAMSum, CNN/DailyMail, SWiPE).
- **Performance/cost comparison** between LongGuide and prompt optimization SoTA on runtime and computational cost is missing from the main paper.
- **Minor presentation issues:** Typo in line 1015 (“second not the sam”), formatting error in Krippendorff’s alpha citation (line 431), unclear “mode of 17 response tokens” (line 123), and non‑standard figure links to appendices.
