## Merged Review

### Summary
Reviewers acknowledge the importance of integrating large language models (LLMs) with temporal point processes (TPPs) using textual event descriptions and parameter-efficient fine-tuning (PEFT). However, they find the technical novelty limited, the improvements over baselines marginal, and the baseline comparisons unfair due to omitted state-of-the-art methods (e.g., LAMP, Meta TPP) and the use of non-LLM baselines. Reviewers 2 and 4 gave scores of 6, while reviewers 1 and 3 scored 5, with the latter two expressing stronger concerns about novelty and fairness. All agree the paper falls slightly below the acceptance bar.

### Strengths
- **Interesting and important problem**: Integrating LLMs with TPPs for event sequence modeling is a valuable and timely attempt. The motivation to leverage textual event descriptions to capture rich semantics beyond categorical types is convincing (R1, R2, R3, R4).
- **Clear problem formulation and mathematical derivations**: The paper provides solid derivations of the TPP loss function and clearly separates event type classification and time regression (R2, R3).
- **Comprehensive experiments**: The framework is evaluated on five real-world datasets with detailed ablation studies (including Tables 2, 3, 4, 5), demonstrating the contribution of each component (R1, R2, R3). The experimental setup and metrics are clearly described.
- **Parameter-efficient fine-tuning**: The use of PEFT (LoRA) to adapt pretrained LLMs without full retraining is a practical contribution (R4).
- **Good presentation**: The paper is well-structured, with detailed related work and clear articulation of methodology (R1, R3, R4).

### Weaknesses
1. **Limited technical novelty**: The core idea of using event descriptions as LLM input and fine-tuning with TPP losses is straightforward and incremental. No fundamental innovations in semantic or temporal modeling are introduced (R1, R3). The integration is seen as an application rather than a novel method.
2. **Marginal improvements over baselines**: In Tables 2 and 3, TPP-LLM’s performance improvements are small and not statistically convincing. Several non-LLM baselines (AttNHP, THP) achieve very close or even better results on some metrics (R1, R2, R3). The best results are often from baselines (R1).
3. **Unfair baseline comparisons**:
   - Missing direct competitor LAMP [1], which also leverages generative LLMs for textual events and optimizes embedding-based TPPs (R3). LAMP should be included in Tables 2-5.
   - Missing Meta TPP [ICLR’23], which achieves 46% next event type prediction accuracy on StackOverflow—higher than TPP-LLM’s reported performance (R2).
   - Missing Fully Neural Network for TPP [Neurips’19] (R2).
   - All four selected baselines (NHP, SAHP, THP, AttNHP) do not use pretrained LLMs, making the comparison inherently unfair (R3).
4. **Few-shot experiment design flaw**: The few-shot setting (2% training data) favors TPP-LLM because it builds on a pretrained LLM with only a few trainable layers (LoRA), while baselines are trained from scratch and cannot learn effectively from such limited data. The resulting improvements are unsurprising (R2).
5. **Missing computational complexity analysis**: No explicit comparison of GPU memory usage or average training time between TPP-LLM and baselines is provided. Although PEFT reduces trainable parameters, the full TPP-LLM model uses a large pretrained LLM, so memory footprint during inference is significant (R3). Scalability on larger datasets or longer sequences is not analyzed (R4).
6. **Lack of interpretability and case studies**: The paper does not provide qualitative examples of event or time predictions, nor does it analyze the bottleneck historical vectors between LLM and TPP to demonstrate the benefits of integration (R1, R3). A case study showing how the LLM semantically helps prediction is needed.
7. **Insufficient analysis of design choices**:
   - The effect of different intensity functions on event and time prediction is not investigated (R1).
   - The impact of event type description quality on prediction performance (both type and time) is unexplored (R1).
   - The processing order of event type and time in sequence representation (line 193) is not justified; no guidance is given on when to use which strategy (R1, R2). Experiment 5.7.2 compares positional encoding vs linear embedding but lacks explanation for the observed performance differences (R2).
   - The role of the prompt in multi-task scenarios (line 458) is not explained (R1).
   - Temporal embedding placement and interaction with semantic features are not thoroughly tested (R4).
   - No comparison of LoRA with other PEFT methods (e.g., adapter layers) or analysis of trade-offs (R4).
   - Alternative temporal encoding methods are not explored (R4).
   - The impact of the pretrained LLM size on performance with PEFT is not discussed (R4).
8. **Missing details and clarity**:
   - In Equation (3), the meaning of \( t_j \) (whether it is a single element of \( t_i \)) is unclear (R2).
   - The calculation of the non-event integral term in the log-likelihood (lines 247, 318) is not detailed (R2).
   - The averaging over five runs (line 323) is mentioned, but individual run results are not provided to assess variance (R2).
   - The model’s handling of uncertainty or noise in event timing (e.g., predicting time windows vs. specific times) is not addressed (R4).
   - Real-time or streaming adaptation mechanisms are not discussed (R4).
9. **Limited domain diversity**: Experiments are on five datasets but still limited; generalization to other event sequence types is unclear (R4).
