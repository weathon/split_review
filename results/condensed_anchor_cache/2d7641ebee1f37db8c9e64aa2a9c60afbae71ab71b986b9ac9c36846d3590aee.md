## Merged Review

### Summary
The paper proposes a hierarchical embodied instruction following (EIF) method for unknown environments where object configurations may change. It uses a high-level task planner and low-level exploration controller built on LLaVA, an online semantic feature map (LongCLIP features weight-sum updated), and dynamic region attention. The approach is fine-tuned on 2k GPT-4-generated instructions in ProcTHOR and evaluated on 204 complex tasks (e.g., making breakfast, tidying rooms), achieving a 45.09% success rate. Reviewers commend the motivation and framework, but several raise concerns about experimental rigor, baselines, definition of unknown environments, and scalability.

### Strengths
- Addresses a challenging and realistic problem: completing complex human instructions when objects may be missing or resupplied during execution.
- The hierarchical framework (high-level planner + low-level controller) is well-motivated; the use of scene feature maps as visual input for VLMs is particularly interesting and promising.
- The paper is generally well-written, fluid, and easy to follow.
- Combines planning and action in a cohesive system for instruction following.
- Conducts diverse analyses including ablation studies (Table 3, with Random Attention and No Attention variants) and qualitative examples, which help understand the method.
- The proposed approach achieves strong performance over the evaluated baselines (LLM-P and FILM).

### Weaknesses
- **Definition of “unknown environments” is not clearly distinguished from existing “unseen” setups** (e.g., ALFRED). Several reviewers question what is truly unknown to the agent (layouts, object instances, etc.) and why the training and test data share the same distribution. The paper should explicitly contrast its setting with prior unseen-evaluation protocols and verify the difference quantitatively.
- **Insufficient and potentially unfair baselines**: Only compared against LLM-Planner (few-shot, 9 samples) and FILM. Missing comparisons include: (1) object navigation methods with LLM planners (e.g., MOPA, LGX); (2) directly using multimodal LLMs (GPT-4o, Gemini, LLaMA-3.2, Qwen2-VL) in zero-shot; (3) trained methods that use in-domain data (e.g., EPO); (4) the similar Demand-driven Navigation approach. The comparison is considered unfair because the proposed method is fine-tuned on 2k GPT-4 instructions while the main baseline is few-shot.
- **Unclear task setting and evaluation protocol**: Step limit per task is not specified; success/failure criteria for undocumented solutions (human-viewpoint success vs. simulator judgment) and partial success (e.g., finding cup but not water) are not defined. These details are essential for reproducibility.
- **Action space details missing**: Preconditions for actions (e.g., must hold a knife to Slice, what happens if not); whether the agent can hold only one item at a time (can it PickUp item B while holding item A); and how low-level navigation actions (movement steps) are generated – all need clarification.
- **Dependence on depth input**: The method uses depth information, which is often unreliable in real settings. It is unclear whether the approach would work with RGB-only (as in prior EIF benchmarks) or with noisy depth. One reviewer also questions whether the 7B LLaVA model can effectively process depth maps.
- **Questionable effectiveness of the dynamic region attention component**: In Table 3, the performance drop between “Ours” and “Random Attention” or “No Attention” is marginal, casting doubt on the component’s actual benefit.
- **Inference time and computational resources not reported**: Since the method uses a multimodal LLM (LLaVA), inference speed and resource requirements are critical for real-world deployment; these should be compared with baselines.
- **Limited validation environment**: Experiments are conducted only in ProcTHOR. Reviewers suggest additional evaluation in Habitat, iGibson, or on a real robotic platform to demonstrate robustness.
- **Scalability and computational efficiency concerns**: The approach currently shows limited scalability and relatively low efficiency, which may hinder deployment in larger or real environments.
- **Supervised low-level policy**: The low-level controller is trained with ground-truth navigational labels from simulation; such labels are unavailable in real-world scenarios, raising questions about applicability beyond simulation.
- **Semantic map update method questioned**: Using weight-sum of feature vectors is not obviously better than simply replacing the visible portion of a semantic map (with object classes and depth projection). A simpler alternative may work as well or better.
- **Unanswered questions about model capability**: One reviewer is surprised that the 7B LLaVA can handle such complex tasks and depth understanding; clarifying feasibility (e.g., via ablation on model size or data amount) is needed. Another asks how performance degrades if LLaVA is only given few-shot or zero-shot demonstrations.
- **Code open-source not promised** – requested for reproducibility.
