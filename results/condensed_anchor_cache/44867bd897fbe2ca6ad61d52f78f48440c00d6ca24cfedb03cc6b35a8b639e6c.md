- Decision: Reject
- Scores: 3, 5, 6, 1

## Merged Review

### Summary
The paper proposes EIML, a unified framework for incomplete multi-view clustering that integrates anchor graph construction, anchor learning, and graph partition. It learns a shared anchor graph across views and uses adaptive weights. Reviewers have mixed assessments: some find the integration compelling and experiments comprehensive, while others question novelty, the handling of missing views, and experimental rigor.

### Strengths
- Compelling motivation and insight: integrating graph construction, anchor learning, and graph partition into a unified framework can let these components boost each other; most prior work treats them separately. (Reviewers 1, 3, 4)
- Clarity and quality: paper is easy to read, no technical errors, writing clear. (Reviewers 2, 3)
- Experiments: abundant and comprehensive; extensive evaluations demonstrate superiority in effectiveness and efficiency. (Reviewers 2, 3)
- Significance: orthogonal constraint on the factor matrix enforces a cluster indicator representation. (Reviewer 3)
- The topic of incomplete multi-view learning is meaningful. (Reviewer 4)

### Weaknesses
- **Novelty and contribution** (disagreement): Two reviewers (2, 4) find the method lacks novelty, describing it as an easy combination of existing anchor graph learning and symmetric NMF (Reviewer 2) and a modification of prior CVPR 2022 work (ref 9880247; graph construction follows that work) with graph partition similar to TIP-21 (ref 9305974; Reviewer 4). Reviewer 4 also notes that incomplete anchor graph clustering is extensively studied, so contribution is minimal. In contrast, Reviewer 3 considers the unified integration of the three components as novel and insightful.
- **Handling of missing views**: The method does not address missing views in a meaningful way; it lacks specific techniques for incomplete multi-view clustering, reducing relevance to the stated problem (Reviewer 1). Reviewer 4 questions genuine novelty in handling incompleteness beyond prior work.
- **Experimental evaluation**:
  - Insufficient comparison methods: limited engagement with recent advancements (Reviewer 1); no deep learning–based baselines for incomplete data included (Reviewer 4); baseline comparisons should be updated (Reviewer 4).
  - Datasets: description is brief and does not highlight capacity for large-scale data (Reviewer 1); datasets used are relatively limited in size (Reviewer 4); how does the method perform on truly large-scale datasets? (Reviewer 4).
  - Best clustering results in Tables 1–4 are not bolded (Reviewer 3).
  - In Figures 4–7, clustering performance increases with higher missing rates, which is counterintuitive and requires explanation (Reviewer 1).
  - Running time table (Table 5) lacks memory description of the used device (Reviewer 3).
  - Why is DAIMC unable to handle the smaller WebKB dataset but can handle the larger CIFAR-100? (Reviewer 4)
- **Ablation and parameter justification**:
  - Ablation study does not provide detailed specific values analysis regarding the superiority of the unified framework (Reviewer 3).
  - The range for parameter λ selection ([0.001,0.1,1,10,100,1000]) is not justified; why these values? (Reviewer 3)
- **Theoretical and methodological gaps**:
  - Lacks necessary theoretical explanations such as convergence analysis (Reviewer 2); how many iterations are needed for convergence? (Reviewer 3).
  - Initialization of the cluster assignment matrix F may heavily influence results; experiments on different initializations are needed (Reviewer 2).
  - Optimization method is standard alternating optimization with no new techniques or improvements (Reviewer 4).
  - The paper claims nonnegative matrix factorization but appears to be general matrix factorization; this is mistaken (Reviewer 4).
  - Need to explain why each entry in anchor graph Z describes similarity between data sample and anchor, given the symmetric constraint is removed (Reviewer 3).
- **Presentation and illustration quality**:
  - Low quality illustrations (Reviewer 1); Figure 1 resolution too low (Reviewer 2).
  - Layout inconsistent with poor alignment between text and figures/tables (Reviewer 1).
