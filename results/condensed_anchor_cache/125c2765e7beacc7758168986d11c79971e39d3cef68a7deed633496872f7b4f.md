## Merged Review

### Summary
The paper proposes Neural Attention Memory Models (NAMMs), a learned network trained via evolution (CMA-ES) that prunes the KV cache by scoring token importance from attention maps. The auxiliary model is a small 1-layer transformer, trained on Llama 3 8B long-context tasks, and transfers zero-shot to other models (Llama 3 70B) and modalities (video, RL). NAMMs reduce memory while often improving performance over the full cache.

### Strengths
- The algorithmic design is sound and conceptually simple/easy to understand.  
- NAMMs achieve significant performance gains over H2O, and in several cases even improve upon the full-cache base model—this is impressive.  
- Zero-shot transfer to different architectures and modalities (vision, RL) is interesting and demonstrates generality.  
- Ablation studies are informative (e.g., NAMM drops more tokens from later layers than earlier layers, implying learned strategies differ from hand-designed rules).  
- The paper is well-structured with clear logical flow; figures are appropriately placed and experimental results are effectively highlighted.  
- The proposed architecture is straightforward and reproducible, with extensive experiments validating its effectiveness.

### Weaknesses
- **Missing comparisons and related work.** The authors compare only against L2 and H2O, but omit several relevant methods: Pyramid-BERT [1] and DMC [2] (which also learn a memory management strategy), FastGen [3] (which uses attention scores directly), “Model Tells You What to Discard” (ICLR 2024), and CacheGen (SIGCOMM 2024).  
- **Controlling cache size is essential but not done.** The pruning ratio varies across baselines, making it hard to tell if NAMM’s advantage comes from pruning less. A plot with cache size on the x-axis and performance on the y-axis (as in H2O) is needed so methods are compared at fixed cache budgets. Also, the paper reports only a single cache size per dataset; it is unclear how that size was chosen and why results are not shown for a range of sizes.  
- **Computational cost and complexity are not reported.** The paper lacks runtime and memory comparisons for NAMM vs. baselines, and does not quantify how expensive it is to generate scores from the auxiliary model for each attention layer. The computational cost of STFT and EMA operations with input length and dimensionality should be analyzed. Information on the compute resources (runtime and memory) used to train NAMMs via evolution is missing, as is scaling behavior for larger base models.  
- **Training details are insufficient.** The exact training objective for the auxiliary model is not fully described (only that it optimizes performance on 3 benchmarks). A complete table of hyperparameters (learning rates, STFT/EMA settings, optimization algorithm, search space, tuning strategy) is needed.  
- **Missing ablations.** It is unclear how important the compression step (STFT) is; an ablation comparing performance with and without STFT (i.e., using raw attention values) should be provided.  
- **Dynamic token removal raises consistency issues.** The paper removes tokens with importance < 0, so the number of removed tokens varies. It is not explained how dimension consistency is maintained (padding, masking, or dynamic structures) during training and inference.  
- **Generalization concerns.** Only Llama 3 8B is used for training; H2O was tested on several architectures (OPT, LLaMA, GPT-NeoX). Results on Decision Transformer (Table 7) are significantly worse than numbers reported in prior papers (original DT, Online DT, Aaren), and the experimental setup for D4RL is not detailed.  
- **Benchmark details are missing.** The paper mentions LongBench, InfiniteBench, LongVideoBench, MLVU, D4RL, etc., but does not give concrete task descriptions for readers unfamiliar with them.  
- **Evaluation on LongBench needs separate reporting.** Since a subset of LongBench tasks was used for training NAMM, reporting “All tasks” as a single aggregate is unfair for measuring generalization. Separate scores for training tasks and held-out tasks should be provided.  
- **Presentation gaps.** Limitations (e.g., pruning is inherently lossy) and computational complexity are mentioned only in the appendix, not the main body. An algorithm block detailing inference (including 512-chunking) is missing from the main text. The related work paragraph is too short and incorrectly implies NAMM is the first to use a learned black-box strategy.  
- **Unclear aspects.** The paper should clarify whether the attention map is processed after applying the causal mask, and explain what STFT does and whether it is meaningful. The gradient analysis section lacks motivation and clear takeaways—it could be moved to the appendix. The intuition for why NAMM sometimes improves over the full-cache model should be discussed.

### Reviewer Questions (incorporated as Weaknesses)
- Is STFT applied to the causal-masked attention map? What is it doing?  
- How important is the Fourier transform compared to using the raw attention map?  
- How is the dynamic KV cache size handled after token removal? Are padding or masking used to maintain dimension consistency?  
- Can an ablation be done without the compression step (i.e., compare with raw attention scores directly)?  
- Please provide specific learning rates, parameter settings, and code release information.
