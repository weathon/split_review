## Merged Review

### Summary
This paper introduces FreDF, a frequency-enhanced direct forecast method for multi-step time series prediction. It addresses the bias caused by autocorrelation in label sequences, which is neglected by direct forecast (DF) models that assume conditional independence. FreDF adds a loss term computed in the frequency domain (via FFT) to the standard MSE, effectively decorrelating label errors. Experiments across multiple datasets and base models (e.g., iTransformer, Linear) show significant performance gains. Theoretical analysis and ablation studies support the method. Code is provided.

### Strengths
1. **Novelty and significance**: Identifying and mitigating label correlation bias in DF models is a novel and important contribution (R1, R2, R3). Using the frequency domain to bypass autocorrelation is innovative (R2).
2. **Soundness**: The theoretical derivation demonstrates the bias from label correlation and shows how FreDF eliminates it (R1, R3). The method is straightforward and the effects are clearly motivated (R1, R4).
3. **Experimental comprehensiveness**: FreDF achieves state-of-the-art results on long- and short-term forecasting tasks (R1, R2, R3). Ablation studies confirm the contribution of each loss component (R1). Hyperparameter robustness is demonstrated (R1).
4. **Model compatibility**: FreDF is orthogonal to backbone models and improves multiple modern DF architectures (R2, R3).
5. **Code and reproducibility**: Code is provided for reproducing experiments (R1, R3).
6. **Presentation**: The paper is clearly written and the idea is presented straightforwardly (R4).
7. **Exploration of properties**: The paper examines different prediction lengths, ablation models, and discusses potential extensions to other transformations (R3).

### Weaknesses
1. **Theoretical limitations** (R3):
   - Theorem 1 only considers univariate sequences; the bias formula does not account for cross-correlation terms in multivariate time series, which can significantly impact prediction accuracy. The analysis should include covariance terms between dimensions.
   - Notation errors: “L” is overloaded (both input length and input sequence), Equation 1 has an index mismatch (Y and Ŷ should be compared on the same indices), and Definition 3.2 uses “j” instead of “i”.
2. **Need for alternative transformations** (R1, R2, R3, R4):
   - Only FFT (or FFT2) is evaluated; exploring other decorrelating bases (e.g., wavelet, cosine, PCA) would strengthen the claim (R1).
   - The method assumes frequency domain features are informative; it does not address scenarios with purely non-periodic or noise-dominated series where FFT may not yield meaningful features (R2). A related question: are there settings where transferring predictions to the frequency domain is detrimental? (R3).
   - Prior work on incorporating Fourier transformation in loss functions, DTW-based shape losses, and multiresolution trends (e.g., [1-6]) is not discussed or compared, raising novelty concerns (R4).
3. **Computational overhead** (R2):
   - No analysis of the computational cost of FFT, especially how it scales with sequence length and dataset size. This is critical for large-scale applications.
4. **Generalization and robustness** (R2, R3):
   - Experiments are limited to a small set of standard datasets; results on diverse domains with different statistical properties are missing (R2).
   - Main results do not report performance over multiple random seeds; the impact of initialization on the reported improvements is unknown (R3).
   - Short-term forecasting results (appendix) only present qualitative time spans; exact forecasting lengths should be specified to allow quantitative comparison (R3).
5. **Code and reproducibility issues** (R1):
   - The source code consists of many scripts with unclear mapping to the paper’s experiments, and the environment setup depends on unexpected packages (torchmetrics, patool). A Dockerfile or conda environment file is needed.
   - A reproduction error was encountered: `AttributeError: 'Exp_Short_Term_Forecast' object has no attribute 'seasonal_patterns'` when running short-term forecasting (R1). This needs to be resolved.
6. **Hyperparameter tuning** (R1):
   - The process for determining hyperparameters of FreDF and baselines is not explained.
7. **Ablation insight** (R1):
   - The ablation study suggests the frequency term alone (without the time-domain MSE) nearly matches the full method. This implies the time-domain component may be redundant or the frequency loss alone is sufficient, which should be discussed.
8. **Interpretability** (R2):
   - The paper does not address interpretability of the frequency-domain predictions or how users can understand the results in that space.
