## Merged Review

### Summary
The paper proposes SAL (Separate And Learn), a two-stage framework for wild out-of-distribution (OOD) detection using unlabeled data. The first stage filters candidate outliers based on the top singular value of sample gradients; the second stage trains an OOD classifier on labeled ID data and the identified outliers. The authors provide theoretical guarantees on separability and learnability, and report state-of-the-art empirical results on standard benchmarks. Reviewers appreciate the theoretical foundation and the non‑obvious use of the top singular value, but raise concerns about missing baselines, insufficient validation of key assumptions, hyperparameter sensitivity, and unexplained drops in ID accuracy.

### Strengths
- **Novel two‑phase methodology**: The filtering and classification stages can be optimized independently, offering flexibility (Reviewer 1).
- **Effective use of unlabeled data**: SAL leverages a large volume of unlabeled in‑the‑wild data and outperforms even outlier exposure (Reviewer 4); the method extracts valuable information from unlabeled data to boost detection (Reviewer 1).
- **Strong theoretical underpinnings**: The paper provides a novel and significant theoretical analysis of separability and learnability (Reviewer 2), supports the method with generalization bounds (Reviewer 4), and grounds the approach in provable guarantees for safe ML (Reviewer 2).
- **Innovative distinction criterion**: Using the top singular value (rather than gradient norm) to separate ID and OOD samples is intuitive yet non‑obvious and important for OOD detection (Reviewer 4).
- **SOTA experimental results**: SAL achieves state‑of‑the‑art performance on common benchmarks (Reviewer 1, Review 2) with many comparative baselines (Reviewer 3).

### Weaknesses
- **Missing baselines and literature positioning**: The manuscript omits crucial baselines—STEP [1] (OOD detection with limited labeled data) and TSL [2] (weakly supervised OOD detection with topological learning)—and does not explicitly connect to the existing literature on weakly supervised OOD detection. This makes it difficult to assess the true novelty and performance gains (Reviewer 3, confidence 5).
- **Assumption validation needed**:
  - The discrepancy assumption in Theorem 1 requires more thorough empirical evaluation. The experiments in Appendix F are a start but insufficient; additional datasets (e.g., CIFAR‑10 as ID with another dataset as OOD) should be tested to confirm the assumption holds in practice (Reviewer 4).
  - It is unclear how effective SAL is when the actual test OOD data diverges markedly from the outliers present in the unlabeled set (i.e., distribution mismatch). Both robustness in such scenarios and performance when the test OOD and unlabeled OOD are not identically distributed should be studied (Reviewer 1, Reviewer 3).
  - The method’s effectiveness in a near‑OOD scenario (e.g., first 50 classes of CIFAR‑100 as ID, last 50 as OOD) is not addressed (Reviewer 3).
- **Hyperparameter sensitivity – π (pi)**:
  - Most experiments set π = 0.1 without systematic investigation. Additional experiments with varied π values are needed to check robustness and whether performance aligns with theoretical predictions (Reviewer 2, Reviewer 4).
  - The rationale for choosing π = 0.1 specifically should be explained (Reviewer 2).
- **Choice of top singular vector**:
  - The method relies on the top singular vector. It is unclear how performance changes when considering the top 2, 3, …, k singular vectors (Reviewer 2).
  - Why is the top singular value used instead of the simpler gradient norm? The rationale for this choice over the norm should be clarified (Reviewer 2).
- **ID accuracy drop**: In Table 1, ID accuracy degrades on certain datasets (e.g., those where other methods perform well but SAL underperforms). The authors should provide explanations or conduct experiments to elucidate the cause of this decrease (Reviewer 1, Reviewer 2).
- **Dependence on unlabeled data quality**: SAL’s efficacy is significantly influenced by the quality of the unlabeled data used (Reviewer 1). The generalization performance across different backbone architectures is also not reported (Reviewer 3).
