## Merged Review

### Summary
The paper proposes BarLeRIa, a Parameter-Efficient Tuning (PET) framework for Referring Image Segmentation (RIS). It introduces bi-directional intertwined vision-language adapters—including Adapting Shortcut with Normalizing Flow (SNF), Local Intertwined Module (LIM), and Global Shortcut Tuning (GST)—to exploit frozen CLIP models for cross-modal dense prediction. Experiments on RefCOCO, RefCOCO+, and G-Ref show the method outperforms prior PET methods and even surpasses full fine-tuning approaches on several metrics.

### Strengths
- **Strong performance** across three RIS benchmarks (RefCOCO, RefCOCO+, G-Ref), beating previous PET methods by a significant margin (average +5.6%) and in some cases exceeding full fine-tuning SOTA (Reviewers 1,2,3).  
- **Novel intertwined structure** for modal feature fusion, particularly the Local Intertwined Module (LIM), which achieves strong results with very few parameters (e.g., outperforming ETRIS with far fewer parameters; Table 4) (Reviewers 1,3).  
- **Effective global prior side network** (Global Shortcut Tuning) that produces global priors from combined text+image features via attention; ablation shows notable improvement with this module (Reviewer 2).  
- **Thorough ablation study** demonstrating the contribution of each component (Reviewer 2).  
- **Parameter efficiency**: the method achieves top performance while only tuning a small number of parameters (Reviewer 1).  
- **Well-written paper** with adequate background and coverage of recent related work (Reviewer 2).

### Weaknesses
- **Potential unfair comparison**: The method uses ViT-Large backbone, which may give an advantage over prior PET methods that likely use smaller backbones; the paper does not justify or control for this difference (Reviewer 1; note: this concern is raised by a minority reviewer with lower confidence and lower overall score, while others did not mention it).  
- **Computational cost and inference speed concerns**:  
  - The global prior is predicted after vision-language blocks and fed into the GST module, creating a long processing path that may slow inference. No inference time comparison with other PET methods is provided (Reviewer 1).  
  - The Global Shortcut Tuning Network’s operational mode (parallel or sequential?) is unclear, and the need to cache each \(F_v^i\) raises additional memory/time overhead that is not analyzed (Reviewer 2).  
  - Training time comparison between ETRIS and BarLeRIa is missing (Reviewer 3).  
- **Limited improvement from Global Shortcut Tuning (GST) relative to parameter cost**: According to Table 5, BarLeRIa (with GST) achieves 72.2 on RefCOCO with 2.21M parameters, while the model without GST achieves 71.4 with only 0.39M parameters—suggesting GST adds significant parameters for a modest gain (Reviewer 3).  
- **Insufficient clarity in methodology writing**:  
  - Equations (2)–(4) in Sections 3.3/3.4 are hard to follow; they could be consolidated, and the relationship between \(F_v^i\) and [cls, embed] is ambiguous (Reviewer 2).  
  - Dimensions and meanings of key symbols (e.g., \([F_l, F_v]\)) are not introduced (Reviewer 1).  
  - The decoder used in the pipeline is not described in sufficient detail, despite referencing prior work (Reviewer 1).  
- **Typo**: “interwine” should be “intertwine” in Figure 2 (Reviewer 2).
