## Merged Review

### Summary
The paper proposes MaskTab, a masked tabular data modeling framework that handles missing features by simulating missingness during training and using a missing-related masked attention mechanism. The approach jointly learns missing feature embeddings (shared across all missing features within a row) and downstream tasks. Evaluated on the TabReD benchmark, MaskTab reportedly outperforms other DNN-based methods. Reviewers largely agree the topic is relevant but find the novelty limited, theoretical justification weak, and experimental comparisons insufficient.

### Strengths
- Tackles the prevalent and frequently overlooked problem of missing features in tabular data (R1, R4).
- The approach is simple and could benefit existing Transformer-based tabular models (R4).
- Strong empirical performance on an industry-grade benchmark (TabReD) compared to other DNN methods, and also against GBDT models like CatBoost and XGBoost (R4).
- Extensive ablation study justifying architectural choices and offering insights into model tuning (R4).
- Well-written paper (R2).

### Weaknesses
- **Limited novelty.** Masking features during pre-training/training is already common practice (e.g., SubTab [1], VIME [2]; R1, R3). The specific improvements over existing methods are minimal (R3). The missing-related masked attention ablation shows minimal benefit; attention models inherently prioritize informative features, so explicit adjustment may be unnecessary (R1).
- **Lack of statistical intuition or theory.** It is unclear when/why the masking approach should work (R2). No distinction is made between missing data types (MAR, MCAR, etc.) (R2). The design choices are purely performance-driven without theoretical justification (R4). Assuming training and test have the same missing patterns, why is masking sensible? It may only be useful when emulating test missing patterns under distribution shift, but this is not explored in depth with a formal statistical framework (R2, question).
- **Insufficient baselines and comparisons.** Missing comparisons with SSL methods for tabular data such as SubTab, VIME, SCARF, PTaRL (R3), and SwitchTab (R4). No comparison with foundation models or LLMs (R3). No baseline using existing models with imputed data to clarify performance contrast (R1). The related work is incomplete; LAMDA-TALENT benchmark includes many more methods (R4). How were missing values imputed for deep learning baselines? Some models handle missingness natively, but pre-processing details are missing (R4, question).
- **No confidence intervals or standard deviations.** Results in Table-2 lack error bars, exaggerating performance claims. For example, MLP and MaskTab appear similar on Ecom Offers, and TabNet is comparable on Cooking Time if 95% CI were shown (R1). Standard deviations are missing for all reported values (R3).
- **Unclear implementation details.** How does the shared learnable embedding for missing/simulated missing features work? Do they use column name information? Section 3.2 and 3.3 need more details (R4, question). How do `num_mask_head` and `cat_mask_head` work? Since simulated dropped features differ per row, are these heads reconstructing the whole row but loss computed only for masked values? Section 3.5 needs clarification (R4, question). The missing-related attention mechanism empirically helps only when added in the last layer; intuition is unclear—if no masking in previous layers, information should already be shared, so masking should not matter (R4, question). In Section 4.3 “Performance under Different Missing Rates,” what does “MaskTab without enhancements” mean? If missing feature embeddings are not used, how are missing features handled? (R4, question). Implementation details are not clear overall (R3).
- **Empirical results not convincingly strong.** The results do not seem promising compared to baselines (R2). Claims, aims, and experiments are not competitive with current ICLR standards (R3).
- **Inconsistent reviewer assessment:** One reviewer (R4, score 6) found the approach interesting and strongly empirical, appreciating the ablation and results against state-of-the-art. Others (R1, R2, R3, scores 1–3) judged novelty and empirical contributions very low, citing weak baselines, missing confidence intervals, lack of theory, and limited improvement over existing work.
