## Merged Review

### Summary

The paper proposes Proteus, a method to distill vision foundation models (e.g., DINOv2, CLIP) into smaller equivalents using only ImageNet-1K, as the original training data is inaccessible. Proteus removes designs from conventional knowledge distillation that cause dataset bias (specifically, the cross-entropy and KL-divergence losses) and uses three levels of training objectives: token (CLS token MSE), patch (patch token MSE without masking), and feature (patch token MSE with masking). Experiments show that Proteus-L/14 distilled from DINOv2-g/14 matches DINOv2-L/14 (142M data) across 15 benchmarks and outperforms CLIP-L/14 (400M), OpenCLIP-L/14 (400M/2B), SynCLR-L/14 (600M). Extensive evaluation is performed on classification, segmentation, and depth estimation using multiple downstream datasets and ViT architectures (small, base, large). All reviewers note the simplicity and effectiveness of the method, though concerns about novelty and problem framing are raised.

### Strengths

- **Practical and well-motivated problem**: The paper addresses a real challenge: foundation models are trained on private, inaccessible data, making reproduction and compression difficult. Using a small public dataset (ImageNet-1K) as a proxy is an interesting and practical direction (Reviewer 2, 4).  
- **Strong empirical performance**: The distilled model matches or outperforms same-size models trained on much larger datasets (e.g., DINOv2-L/14 with 142M data, CLIP-L/14 with 400M) across extensive benchmarks including classification, segmentation, and depth estimation (Reviewer 1, 2, 3, 4).  
- **Comprehensive experiments**: Evaluation covers a wide range of CV tasks and datasets; ablation studies are conducted to validate design choices (Reviewer 1, 2, 3).  
- **Interesting empirical finding**: The observation that conventional KD with cross-entropy loss introduces dataset bias is a valuable insight (Reviewer 2).  
- **Well-written and easy to follow**: The paper is clearly structured and effectively communicates the method and results (Reviewer 1, 3, 4).  
- **Simple yet effective**: The approach uses a straightforward MSE loss on intermediate features to transfer generalization ability (Reviewer 3). Feature-based distillation outperforms logit-based distillation like DeiT (Reviewer 1).

### Weaknesses

- **Limited novelty**: The distillation loss at token, patch, and feature levels has been widely explored in prior ViT distillation works (e.g., MiniViT, [2]) and intermediate-feature KD is a standard approach (Reviewer 1, 2, 3). The paper does not cite or discuss these related works, nor does it compare against them. The nuances of applying this to large vision foundation models (scale, complexity) are not addressed (Reviewer 2).  
- **Unconvincing problem framing**: Given that large-scale public datasets (DataComp, LAION) are now available, restricting distillation to ImageNet-1K is not obviously optimal. The paper does not compare different distillation datasets or propose methods to curate better general-purpose KD datasets. A relevant recent work (“Knowledge Transfer from Vision Foundation Models for Efficient Training of Small Task-specific Models”, ICML 2024) shows that using target-task data can improve performance, which further questions the emphasis on ImageNet alone (Reviewer 1).  
- **Lack of theoretical analysis for removing CE loss**: The claim that removing CE loss mitigates dataset bias lacks formal justification. A deeper analysis (e.g., from domain adaptation or transfer learning theories) is needed. The paper also does not explore trade-offs (convergence speed, training stability) or whether other loss functions could achieve a similar effect (Reviewer 2).  
- **Ambiguous or confusing terminology**: The three loss levels (token, feature, patch) are confusing because in ViTs every patch is a token. The “feature-level” and “patch-level” losses are both based on patch tokens, differing only by masking. The paper should clarify which specific intermediate features are used (e.g., last layer, all layers, attention maps, Q/K/V). Reviewer 1 also asks: what does “Hint” refer to in Table 1? (Reviewer 1, 2).  
- **Missing key ablation: performance when using the original teacher model size**: What is the performance of Proteus-L/14 when distilled from DINOv2-L/14 (rather than DINOv2-g/14)? This would quantify the degradation when using the same-size teacher (Reviewer 4).  
- **Missing ablation on integrating all common loss terms**: How does the performance of a combination of hard logits distillation, CE loss, KL-divergence, and MSE compare to using only MSE? Would performance decline? (Reviewer 3).  
- **Incomplete validation on varying data scales**: The paper does not test performance on subsets of ImageNet-1K (e.g., reducing samples per class or number of classes) or on larger datasets like ImageNet-21K. This is needed to understand data efficiency (Reviewer 4).  
- **Unclear experimental details**:  
  - How many fine-tuning epochs were used for fine-grained classification, segmentation, and depth estimation? Was the computational load higher compared to baselines like DeiT and iBOT using the same data? (Reviewer 3).  
  - Figure 7 shows that using 50% of ImageNet data yields better ImageNet linear evaluation results than using 100%; why? (Reviewer 3).  
  - Figure 3 is not referenced in the main text, and its purpose is unclear (Reviewer 3).  
- **Limited generalizability demonstration**: The distillation approach is only shown for vision models. Validation on other modalities (LLMs, diffusion models) is needed to confirm generalizability (Reviewer 4).  
- **Minority reviewer (Reviewer 2) found stronger motivation and performance**: While the other three reviewers gave a score of 6 and raised substantial concerns about novelty and framing, Reviewer 2 (score 8) emphasized the excellent results and the value of the dataset-bias finding. This contrast should be noted.
