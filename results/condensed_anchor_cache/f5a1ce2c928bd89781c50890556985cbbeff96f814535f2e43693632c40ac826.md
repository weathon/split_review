## Merged Review

### Summary
The paper studies causal graph discovery from multimodal data, focusing on identifying latent causal variables across modalities with nonparametric distributions. It proposes identifiability guarantees under structural sparsity and presents an encoder-decoder framework with sparsity regularization. Experiments on synthetic, image, and human phenotype datasets are provided.

### Strengths
- Tackles an important and not well-addressed problem, well-motivated by biomedical applications (R1, R2).
- Provides a more general framework compared to prior work (Table 1) (R1).
- Clear contribution on identifiability, useful for future works (R2).
- Writing is lucid; examples contrast the method cleverly against existing works (R2).
- Offers identifiability guarantees for each latent component, characterizing interactions across modalities (R3).
- Theoretical assumptions (e.g., smooth invertible generating functions, sparsity) appear reasonable (R3).
- Real-world dataset analysis (human phenotype) demonstrates usefulness (R3).
- Includes an adequate literature review (R4).
- Presents meaningful relaxations of assumptions from prior work (R5).

### Weaknesses
**Theory and Mathematical Foundations (Critical — concerns raised by multiple reviewers, especially R5 rating 3 with high confidence 4)**  
- **Identification vs. Estimation Confusion**: Theorems 4.2 and 4.4 conflate identification (a model property) with estimation. Statements like “We estimate the generating process…” blur the distinction. Proof of Theorem 4.2’s step to equation (14) assumes \(x=\hat{x}\) from equal distributions, which is not mathematically justified: equal distributions do not imply equal values of random variables (R5).  
- **“Identification under Regularization” (Theorem 4.4)**: Claiming identification via regularization is conceptually flawed; regularization pertains to estimation, not model identifiability. If regularization is essential, the model should be reformulated with a prior (e.g., sparse prior). Furthermore, regularization (5) can only encourage, not guarantee the required condition in equation (29), so the idea of “identification under regularization” does not work (R5).  
- **Proof of Theorem 4.4**: Condition 4.3 references an undefined matrix \(A\); the proof uses multiple matrices (e.g., equation (28)), and \(d^*(U)\) does not align with \(d^*\) in Condition 4.3. The notation and logic flow are unclear, and the connection between the condition and the proof is missing (R5).  
- **Definition of \(\tilde{g}_x\)**: There is one \(\tilde{g}_x\) per modality \(m\); it is unclear whether these \(m\) functions are the same. This ambiguity is not resolved (R5).  
- **Condition 4.3 Clarification**: The connections between matrices \(A, G, T\) are confusing; \(A\) seems only to denote relationships between modalities 1 and 2 (R1). Multiple reviewers request an intuitive explanation (R1, R2, R4).  
- **DAG Assumptions**: The paper assumes latent variables within the same modality form a DAG, but loss function (6) does not enforce that; how is the DAG structure ensured during learning? (R1). Also, does the causal relationship between modalities need to be a DAG? Would cycles affect identifiability? (R1).  
- **Assumption A.1**: What is a “smooth inverse”? (R1).  
- **Theorem 4.4 Regularization Coefficient**: Does the regularization term need to be scaled by a coefficient? (R1).

**Experimental and Scalability Concerns**  
- **Simulation Scope**: Synthetic experiments focus only on low-dimensional data with simple sparse causal structures. The impact of increasing the number of latent variables or the dimensionality of observed data is not explored. Robustness to violations of the sparsity assumption (a key component) is not assessed (R1).  
- **Data Generation Details**: Implementation details missing — MLP architecture for numerical generation (Appendix D.1), network structure, optimization scheme, hyperparameters (R4). If an invertible neural network is used (as implied by Assumption A1), how is invertibility achieved besides normalizing flow? What is the computational efficiency? (R3, R4).  
- **Number of Latent Variables**: No guideline for practitioners to systematically choose the number of latent nodes (R1). Real-world impact: knowing the number is often unrealistic; bias from user-defined numbers is not analyzed (R3, R4).  
- **Evaluation Metrics**: When computing SHD, permutation of latent variable indices could be problematic (R4). For numerical data, if sample size increases, does MCC approach 1? (R4).  
- **MNIST Experiments**: The causal relationship between colored MNIST and fashion MNIST is not clearly explained; how do latent variables in one dataset influence the other? (R4).  
- **Comparison with Existing Methods**: Is the considered setting a non-linear version of [10]? Authors should compare/contrast (R2). How is the method different from [9] apart from assuming latent independence? (R2). How does the learned adjacency matrix relate to the PC algorithm? (R4).  
- **Robustness to Modality Interference**: Given that \(z^{(m)}\) influences \(x^{(-m)}\) indirectly through \(z^{(-m)}\), how does \(z^{(k)}\) not interfere in identifying the subspace of \(z^{(m)}\)? (R2).

**Biological Application and Assumptions**  
- **Modeling Assumptions Questionable**: A core assumption is that two modalities cannot share any direct causes. This seems to require hidden causes \(z\) to be lower-level features. For example, “age” affects both “sleep” and “eyes” modalities; to satisfy the “indirect” requirement, lower-level features \(z^{eyes}\) would need to mediate, which may not be realistic. This eventually requires most hidden causes to be low-level. It is unclear why the assumptions are satisfied in the sleep patterns/brain imaging examples (R5).  
- **Lack of Depth in Biological Demonstration**: The human phenotype data analysis does not justify the title or abstract highlights. “Strong interpretability” is overstated. How should the learned hidden variables be interpreted? How does the number of latent variables affect the causal graph? (R5).  
- **Specific Phenotype Results Unclear**: Why are causal relationships involving FRight and FLeft not symmetric (e.g., FRight affects Cataract but not FLeft)? Why are there no Sleep variables influencing “Sleep efficiency”? Shouldn’t ocular quality impact hand grip strength rather than the reverse? (R5). More experiments with different modalities and latent variable counts are needed (R5). The authors are encouraged to explicitly present literature evidence supporting the algorithm’s success (R4).  
- **Example Alignment**: The running example (Section 3) using heart sizes and bone structures as latent variables does not align well with the proposed model — what is the rationale? (R4).  
- **KL Divergence Computation**: How is the KL divergence computed? Is \(p(\gamma)\) assumed Gaussian with encoder output providing mean and variance? (R4).

**Minor Writing and Clarity Issues**  
- Typos: Line 78: what is \(n\)? Should it be \(z_i^{(m)}\to z_j^{(n)}\)? (R2). Co-domain of \(G(z,\epsilon)\) correct? (R2). Reference issues (e.g., duplicate Sturma et al., 2023 citation lines 126-127) (R2). Arrow from \(z\) to adjacency matrix in Figure 4 unclear (R4).  
- “Fully share” (line 212): Does this mean “retrieve without errors”? (R2).
