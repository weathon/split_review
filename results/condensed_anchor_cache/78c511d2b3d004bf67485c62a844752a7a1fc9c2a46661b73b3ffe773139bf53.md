## Merged Review

### Summary

The paper proposes MARINE, a training-free and API-free framework that reduces object hallucinations in Large Vision-Language Models (LVLMs) by integrating outputs from open-source vision models (e.g., DETR, RAM++) via classifier-free guidance (CFG). The guidance signal is combined with the LVLM’s logits using a constant weight gamma. Evaluations on multiple LVLMs and metrics (CHAIR, POPE, GPT-4V) show that MARINE outperforms existing fine-tuning methods and preserves detail. Reviewers generally agree the idea is simple and effective, but raise concerns about novelty, missing baselines, and unexplained counterintuitive results.

### Strengths

- Novel use of object detectors (DETR, RAM++) to provide image-grounded guidance for reducing hallucinations in LVLMs, without training or external API calls. (R1, R2, R3)
- The method is clean, self-contained, and easy to understand. (R2, R3, R4, R5)
- Extensive evaluations across multiple LVLMs, datasets, and metrics (including CHAIR, POPE, GPT-4V) consistently show performance gains over baselines, including fine-tuning methods. (R1, R2, R4, R5)
- The paper provides comprehensive comparisons of object detectors, guidance sources, and inference latency, as well as code and evaluation outputs, enhancing credibility. (R2, R5)
- MARINE’s design allows flexible integration with different vision models, improving robustness. (R4)

### Weaknesses

- **Novelty concerns:** The core idea of combining object detection outputs with LVLM generation via a weighted logit scheme is not sufficiently novel. Using CFG for hallucination reduction in VLMs has been explored before (e.g., VCD), and the paper does not compare with other relevant CFG-based methods [1][2][3] that use γ>1. (R2, R5)
- **Missing baselines:** 
  - No comparison to carefully engineered prompts aimed at reducing hallucination (e.g., “Describe visible contents without adding information not clearly visible”). This would isolate the effect of prompt engineering vs. guidance. (R1)  
  - No ablation using ensemble of different LVLMs to see if similar gains could be achieved without external vision models. (R1)  
  - No comparison to specialized non-LLM image captioning/VQA models (Table 16 results not contextualized). (R2)  
  - No comparison to simply replacing the visual encoder of the LVLM with the image-grounded models (DINO, SAM, DETR) to isolate impact of guidance vs. encoder. (R1)
- **Counterintuitive results:**
  - In Tables 1 and 2, introducing ground-truth objects (MARINE-Truth) leads to a significant performance drop in some metrics (e.g., recall in LLaVA). The paper claims “MARINE-Truth generally achieves the strongest results” (line 361), which contradicts the data. Explanation needed. (R3, R4)
  - In Table 6, using a single guidance model causes a significant performance drop, even worse than greedy decoding. This is counter-intuitive; deeper analysis and additional experiments are needed. (R4)
- **Technical limitations:**
  - The guidance weight γ is a constant; no dynamic tuning based on confidence scores or other factors is proposed. (R2)  
  - The detector’s closed-vocabulary output is mismatched with the LLM’s open vocabulary; no bridging method is discussed. (R2)  
  - MARINE focuses only on object hallucination; extension to broader hallucination types remains a challenge. (R4)
- **Evaluation gaps:**
  - No GPU memory consumption analysis alongside latency (Table 5 format). (R4)  
  - No ablation comparing CLIP-extracted features as prompts vs. DETR/RAM++; also SAM could provide more fine-grained features. (R3)  
  - No discussion on whether pre-trained DETR/RAM++ vocabulary influences performance, or whether visual prompts are pre-generated or included in inference time. (R3)  
  - No evaluation on SOTA models fine-tuned on MSCOCO (not generic LVLMs). (R2)
- **Minor writing error:** In section 4.2, “or a rule-based algorithms like XXX” – ‘XXX’ appears to be a typo or placeholder. (R3)
- **Reviewer disagreement:** While most reviewers score 5–6, Reviewer 3 gives an 8, praising the clarity and results. However, even Reviewer 3 notes limited novelty in “applying 2D features from pre-trained models to prompt downstream tasks” and asks for differentiation from direct prompting. The minority positive view is acknowledged but does not override the weaknesses raised by the majority.
