## Merged Review

### Summary
The paper proposes a black-box watermarking method for protecting the copyright of customized LLMs during fine-tuning. It introduces two types of backdoor data (trigger set and reference set) with triggers in the instruction and input, embedding a watermark that can be detected via hypothesis testing. The method is evaluated on harmlessness, robustness, uniqueness, imperceptibility, and validity. Reviewers generally agreed the paper is clear and demonstrates watermarking capability, but noted limited technical novelty and related-work coverage. One reviewer (score 6) was more positive about the experimental rigor and practical framing, while all others (score 5) found the contribution incremental.

### Strengths
- Well-written, comprehensible, with a clear formulation (reviewers 1, 2, 4).
- Discusses innate difficulties of watermarking fine-tuned LLMs (reviewer 1).
- Algorithm is simple and effective; experimental results demonstrate watermarking in five essential properties (reviewer 1).
- Extensive experiments conducted across practical use cases (reviewers 1, 4).
- Design of a reference set to complement the trigger set is interesting (reviewer 2).
- Robustness against removal attacks (reviewer 3).
- Imperceptibility and uniqueness are achieved (reviewer 3).
- Comprehensive evaluation: non-harmful test, robustness to second-time fine-tuning and quantization, ablation study on reference set (reviewers 3, 4).
- Backdoor data paradigm adequately fulfills requirements for uniqueness and imperceptibility (reviewer 4).
- Logical progression from limitations of naive approaches to the proposed framework (reviewer 4).

### Weaknesses
- **Insufficient related work coverage**: Many recent LLM watermarking techniques are not discussed; the most recent cited model watermarking scheme is from 2019 (reviewers 1, 2).
- **Limited applicability**: The strategy is designed only for instruction tuning; other fine-tuning methods are not addressed. The paper does not discuss how to apply the method to tasks like question answering where no instruction is present (reviewer 1).
- **Lack of technical novelty**: The method is an incremental improvement over the naive judge-question approach, lacking theoretical or technical depth (reviewer 2). No quantitative comparison against naive baselines or existing black-box LLM watermarking methods is provided (reviewer 2).
- **Efficiency not evaluated**: Despite repeated claims about efficiency, no efficiency metrics or comparisons are reported (reviewer 2). The required amount of training data and time for effective watermarking are not specified (reviewer 3).
- **Incomplete attack analysis**: Only second-time fine-tuning and model quantization are considered as removal attacks. Structured pruning, adversarial attacks that target the watermark, and other manipulation techniques (e.g., conditional filtering of specific inputs) are not explored (reviewers 3, 4). The paper does not discuss resilience against providers who could preprocess inputs to filter rare trigger decorations (reviewer 4).
- **Ambiguity in watermark verification**: Fisher’s exact test is not introduced; the paper does not show clearly how to accept/reject a hypothesis from the distributions. For example, Table 2 shows the trigger and reference set distributions for a clean LORA model are quite different, yet no explanation is given (reviewer 1). The reasonable verification set size is not justified (reviewer 1).
- **Uniqueness challenges unresolved**: The paper does not provide a robust statistical analysis to demonstrate that watermark-induced behaviors are distinguishable from inherent model traits stemming from pre-training or fine-tuning data (reviewer 3).
- **Dependency on specific paradigms**: No methodology is given for selecting the optimal watermarking paradigm for a given model or task; it is unclear how performance degrades if the chosen paradigm is poorly matched (reviewer 3). The paper also does not consider watermarking without fine-tuning (e.g., injecting the backdoor solely through input design) (reviewer 3).
- **Lack of theoretical support for multiple watermarks**: The claim that embedding multiple watermarks can enhance robustness lacks theoretical substantiation; interaction, overwriting, and capacity limits are not addressed, and no experiments test multiple watermark coexistence (reviewer 4).
- **Underexplored hyperparameter sensitivity**: The paper does not study how varying the ratio of trigger set to reference set in training and verification data affects performance (reviewer 1).
