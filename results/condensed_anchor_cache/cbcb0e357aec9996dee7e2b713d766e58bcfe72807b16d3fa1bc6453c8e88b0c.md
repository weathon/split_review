## Merged Review

### Summary
The paper presents a Planning Neural Operator (PNO) that learns to approximate the value function for motion planning by solving the Eikonal PDE using Fourier Neural Operators. The method encodes obstacle geometries via SDF and enforces triangle inequality for heuristic use in A*. Reviewers acknowledge the novelty of the operator-learning formulation and the potential for zero-shot super-resolution. However, all three reviewers raise critical concerns about the limited evaluation (only 2D/3D point robots, not higher‑DOF tasks like manipulators), the simplicity of test environments (isolated obstacles, not complex mazes), and the lack of ablations and comparisons to more recent methods. One reviewer is notably more critical, emphasizing that evaluation on 2D grid‑worlds is insufficient relative to standard benchmarks in the robotics literature.

### Strengths
- **Novel operator‑learning approach**: Casting motion planning as learning the solution operator of the Eikonal PDE via Fourier Neural Operators is innovative and well‑positioned against prior work (Reviewers 1, 2, 3).
- **Clear presentation & literature review**: The paper is well‑written, explains complex concepts simply, and provides a thorough review of traditional and neural motion planning (Reviewer 3).
- **Generalization across datasets**: The method generalizes to different environments (MovingAI 2D city, iGibson 3D) and resolutions; it outperforms PINN‑based approaches in adaptability (Reviewer 2). The zero‑shot super‑resolution property (e.g., 16× training resolution) is demonstrated (Reviewers 1, 2, 3).
- **Computational efficiency**: For small‑resolution cases the approach is fast, suggesting potential for real‑time applications (Reviewer 2).
- **Heuristic for classical planners**: Using the learned value function as an A* heuristic reduces explored nodes by 33% while keeping near‑optimal paths and maintaining ε‑consistency (Reviewer 3; the paper reports 30%).
- **Design components**: Incorporating obstacle encoding via SDF and enforcing triangle inequality are sensible contributions (Reviewers 1, 3).

### Weaknesses
1. **Limited to low‑dimensional spaces (critical for Reviewer 1)** – All experiments use only 2D/3D point robots, never higher‑DOF systems like 6‑ or 7‑DOF manipulators. The grid‑space convolution architecture inherently restricts scaling to higher dimensions. Other learning‑based planners are routinely evaluated on manipulator tasks, so the current evaluation is insufficient to claim generalizable motion planning. (Reviewers 1, 2, 3; Reviewer 1 considers this the main concern.)
2. **Simplistic environments** – Tested only on environments with isolated cluttered obstacles; not evaluated on complex, maze‑like scenarios (e.g., Gibson with multiple turns) that would better test generalization. The 16×16 map success rate drops without explanation (Table 1). (Reviewers 2, 3)
3. **Dependence on supervised learning** – Requires ground‑truth PDE solutions (optimal value functions) for training, which are expensive or impractical to obtain in complex, real‑world settings. (Reviewer 2)
4. **Missing ablation studies** – No quantitative analysis of key design choices: obstacle encoding, triangle inequality enforcement, choice of DeepNorm vs other normalization, sensitivity to FNO modes and hidden dimensions. (Reviewer 3)
5. **Insufficient baseline comparisons** – Only compared against VIN and NTFields. Should also be compared with more recent methods like Differentiable Spatial Planning using Transformers and Progressive Learning for Physics‑Informed Neural Motion Planning. (Reviewer 2)
6. **Presentation issues** – Pipeline figure uses the same symbol for the SDF operator and PNO, causing ambiguity. The network structure described as “F⁻¹(R(F()))” is unclear; intermediate layers should be explicitly stated, and the output should be denoted as Φ rather than Lₘ. (Reviewer 2)
7. **Unjustified assumptions** – Assumptions (proper policy for all starts, equicontinuity and uniform positivity of the cost function space) are not discussed in the context of real‑world sensor noise and imperfect actuation, raising doubts about practical applicability. (Reviewer 3)
8. **Additional analyses requested** – (a) Investigate training with pure PINN loss instead of supervised learning. (b) Test on general geometries (e.g., using FNO on general geometries [1]) to assess scalability to higher dimensions. (c) Provide contour‑line visualizations of the value function instead of color maps to reveal artifacts. (d) Explain the drop in success rate for 16×16 maps. (Reviewers 2, 3)
