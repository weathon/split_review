## Merged Review

### Summary
The paper integrates a fashion knowledge base into an end-to-end architecture for image captioning, using a mode mapping network to fuse attribute and image features and a filtering strategy to select the best beam search candidate via CLIP score. The idea is reasonable for e-commerce, and examples in Figure 2 are promising, capturing concepts similar to ground-truth descriptions. However, multiple reviewers note that the method is hard to follow, the technical novelty is limited, the experimental comparison is weak, and many critical details are missing.

### Strengths
- Integrating a rich fashion knowledge base into the end-to-end architecture is a reasonable approach that enhances the availability of multidimensional data about fashion items (R1, R2, R3, R4).
- The mode mapping network fuses attribute features from the knowledge base with image features, enabling a more comprehensive representation (R1).
- The filtering strategy selects the best candidate from beam search results using CLIP score, improving description quality (R1).
- The system has clear practical utility in e-commerce, reducing the burden of writing product descriptions (R2).
- The examples in Figure 2 are promising and capture or utilize concepts similar to ground-truth data (R2).
- Experimental results, including comparisons, ablation studies, and case analyses, confirm the effectiveness of the proposed method (R1).
- The paper is a nice application of image caption models to the fashion product domain (R4).

### Weaknesses
- **Limited technical novelty**: The method primarily combines simple embedding and distance calculations (R1). The contributions are not clearly emphasized and appear incremental; e.g., the filtering strategy is not a major innovation (R4). The paper dedicates significant text to simple operations that could be described more concisely, yet lacks deep technical analysis (R4).
- **Method section is hard to follow**: The flow from input image to output description is not clearly described (R2, R3). Specific gaps: how the commodity knowledge base is constructed (R2, R3); whether \(F_t\) is an input to the self-attention module; why similarity between \(F_I\) and \(F_t\) is computed in the feature encoder; where the text in the mode mapping network comes from (is it from the knowledge base?) (R2, R3). Details on mapping network training (lines 252–255) are missing – loss function, how gradients backpropagate, what data is used, network initialization (R1).
- **Equations lack professionalism and clarity**: Eq. (3) must be revised to clearly show the calculation of \(\text{rel}(I,t)\); italic usage for word-derived symbols should be corrected (R2, R3). Eq. (8) is unclear: \(F_I\) is \(l \times 1\)-dimensional but \(F_S\) is a set – concatenation is not straightforward; the aggregation/transformation of \(F_S\) into a vector and the MLP architecture (layers, activation, optimization) are unspecified (R1).
- **Diversity score in Eq. (4) is too simple**: Using only \(\max\) in \(\text{Sim}(F_t, F_s)\) may cause selection bias toward the most similar tag, ignoring other relevant tags. A comparison with measures like entropy or IDF would strengthen the evaluation (R1).
- **Hyper-parameter sensitivity missing**: Values for \(\lambda\), \(k\), \(p\) are given (Section 4.1.3) and said to be determined empirically, but a sensitivity table or graph is needed to assess robustness and generalizability (R1).
- **Tag extraction issues**: The initial tag set is obtained using a CLIP model (Eq. 1), but how CLIP generates diverse keywords (as in Figure 2) is unclear (R1). The accuracy of extracted tags is not quantified – no precision/recall or failure case examples. Tag retrieval uses maximum search (Eq. 6) and k-nearest neighbor, but erroneous tags (e.g., “red” for a green apple) are possible; the impact on generated descriptions is not discussed (R1). No concrete examples of the top-\(k\) nearest neighbor search results are provided (R1).
- **Use of GPT-2 is not justified**: Why not use more recent models like GPT-3.5, GPT-4, or other transformer-based models? A justification or comparative results is expected (R1, R2, R3). Reviewers suggest exploring a variety of large language models, e.g., LLama3 (R4).
- **Baseline methods are outdated**: Compared methods range from 2015–2021 (most recent ClipCap 2021). More recent models such as GPT-3.5, GPT-4, LLaVA (R1) or BLIP2, mPLUG (R4) should be included. GSA-GED lacks proper definition and citation in Table 1 (R2, R3).
- **Improvements are minimal**: In Table 1, gains over GSA-GED and ClipCap are mostly within 1 point (R1). The paper should provide specific caption examples where the proposed method clearly outperforms baselines to demonstrate the practical benefit (R1).
- **Experimental scope is narrow**: Only one dataset is used (R4). Ablation studies focus only on knowledge base inclusion and filtering strategy; more comprehensive experiments are desirable, e.g., comparing different similarity scores and different LLMs (R4). Additionally, the diversity score could be compared with entropy-based methods (R1).
