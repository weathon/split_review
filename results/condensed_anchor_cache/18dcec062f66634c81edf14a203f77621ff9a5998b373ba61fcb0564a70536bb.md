## Merged Review

### Summary
This paper proposes RMP-SAM, a real-time multi-purpose segmentation model that unifies interactive segmentation, panoptic segmentation, and video instance segmentation in a single end-to-end model. It uses an efficient encoder and a decoupled decoder with novel pooling-based dynamic convolutions to refine mask tokens, plus prompt adapters for improved interaction between visual prompts and segmentation tokens. The authors benchmark several strong baselines and demonstrate a good trade-off between accuracy and speed across multiple datasets.

### Strengths
- Fills a gap: first real-time multi-purpose segmentation model combining interactive, panoptic, and video segmentation in one model, whereas prior real-time models are task-specific and large models are not real-time capable.
- Impressive inference speed with a good speed-accuracy trade-off across all tasks and datasets.
- Extensive experiments on panoptic segmentation (COCO Panoptic), interactive segmentation (COCO, LVIS, HQSeg44k, DAVIS), and video instance segmentation (YouTube-VIS) are solid, comprehensive, and persuasive.
- Simple and easy-to-understand architecture; the entire method is straightforward.
- Ablation studies provide useful insights into the contributions of different components.
- Code is provided for easy reproduction by readers.
- Precise implementation details and fair comparisons with other methods (e.g., Mask2Former, YOSO, IDOL, etc.).

### Weaknesses
- Novelty concerns: many architectural elements (e.g., lightweight encoder, adapter, dynamic convolution) are adopted from prior works; innovation appears largely limited to joint training and integration. (Minority reviewer 3 notes particularly strong novelty limitations.)
- Missing comprehensive comparison with other SAM-like methods and universal segmentation models:
  * Only a single COCO instance segmentation comparison is provided in Table 4, and the results are not outstanding. Additional evaluations needed: SegAny task, detailed AP for small/medium/large objects, and evaluation with different object detectors.
  * Some universal methods (cited as [1,2,3]) reportedly achieve better results using ResNet50; a detailed architectural and training strategy comparison with these approaches is missing.
  * Architectural-level comparison with related works is lacking in the related work section.
- Efficiency benchmarks are insufficiently detailed for a model promoting real-time performance. Should include evaluations across multiple GPU platforms (e.g., 3090, V100) with throughput and latency, plus a latency vs. performance plot comparing to other SAM-like methods.
- Joint training details are missing: how does RMP-SAM avoid task domination (e.g., one task dominating the loss) and performance degradation due to conflicts between tasks?
- Differences with SAMv2 should be clarified, especially regarding claimed semantic labels.
- Presentation issues:
  * Tables, especially Table 3, are hard to read due to lack of bold formatting for best results; a plot similar to Fig. 1b would be more useful than the table.
  * References to the appendix are imprecise, and Table 2 is not referenced in the text.
- Missing result: performance of TopFormer in Table 3 should be reported.
- Unclear element in Figure 1b: what does the dot size indicate?
- Potential connection to open-vocabulary segmentation is suggested by the use of CLIP text embeddings and the title “Segment Anything”, but not clarified.
