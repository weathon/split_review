## Merged Review

### Summary
The paper introduces Seq2Exp, a model that predicts gene expression from DNA sequence and epigenomic signals by learning a sparse binary mask over base pairs to select regulatory elements. It combines MAMBA-based Caduceus networks, an information bottleneck with Beta distribution, and a straight-through estimator. Experiments on two cell types (GM12878, K-562) show improved prediction over Transformer- and state-space-based baselines, and the learned mask highlights influential regions comparable to MACS3 peaks. Reviewers generally find the idea well‑articulated and the results strong, but raise concerns about novelty relative to the concurrent EPInformer work, clarity of the task definition and model details, reproducibility (no code provided), evaluation fairness, and some modeling assumptions.

### Strengths
- **Idea and formulation**: The main idea (decomposing regulatory regions into three causal groups and learning a mask via information bottleneck) is well articulated, sensible, and novel (Reviewers 3, 4). The architecture is sound, using the information bottleneck to promote sparsity and a straight-through estimator for differentiability (Reviewer 2).
- **Empirical results**: The model outperforms Transformer- and state-space-based baselines across several metrics on two cell types (Reviewers 2, 3). The experimental evaluation is rigorous and appropriately compared to numerous baselines (Reviewer 4). Table 1 provides good comparison with previous benchmark models (Reviewer 1).
- **Application of advanced models**: Successfully applies MAMBA‑based Caduceus (Selective State Space models) to long sequences (200 kbp), and combines sequence with epigenomic signals in a single jointly optimized architecture (Reviewer 2).
- **Literature grounding**: The paper is well‑grounded in relevant recent literature and clearly written (Reviewers 3, 4).
- **Causal perspective**: The work highlights that gene expression prediction benefits from modeling causal relationships between DNA sequence, epigenomic data, and regulatory elements; deep learning can learn these relationships (Reviewer 1).

### Weaknesses
- **Novelty and overlap with EPInformer**: Reviewer 1 notes that the EPInformer paper (early 2024) shares the same intent, experimental approach, and very close performance; Seq2Exp mainly reinforces EPInformer’s claims. Table 1 reports GM12878 CAGE prediction numbers identical to EPInformer at two decimal places, and the K‑562 Pearson coefficient (0.8517) does not match the original EPInformer paper (0.848). Reviewer 1 questions how MSE, MAE, R² were obtained for EPInformer (only Pearson was reported originally). In contrast, Reviewer 4 finds the three‑group decomposition original. These positions are not reconciled.
- **Task and input registration ambiguity**: Both Reviewer 2 and Reviewer 3 find the definition of gene expression Y unclear (single value per gene or vector across conditions?) and how inputs (200 kbp window) are registered to Y (e.g., is it centered on the TSS?). Reviewer 3 suggests representing Y as a vector over genes with formal indexing. These points are critical for understanding.
- **Model architecture details missing**: The architecture description is deferred to section 5.1.4 and only one sentence for Caduceus‑Ph; Reviewer 2 expects it in section 4.1. Missing: hyperparameters (#layers, hidden dimension), whether the network is trained de‑novo or pre‑trained (Caduceus pre‑trained up to 131 kbp, this model uses 200 kbp – if pre‑trained by the authors, more details needed). The high‑level description of bi‑directionality and reverse‑complement equivariance needs expansion (Reviewer 2).
- **Reproducibility**: No code is provided, and its availability is not mentioned in either the main text or the appendix (Reviewer 4). This is a major concern for reproducibility.
- **Hyperparameter reporting**: There is no mention of hyperparameter tuning or the values used for α₃ and β₃ (parameters of the Beta distribution for the soft mask) (Reviewer 1, Reviewer 4). Reviewer 4 also asks why α₂, β₂ for epigenomics are not learned by a neural network.
- **Evaluation fairness and baseline details**: 
  - Reviewer 3 notes that section 5.1.2 does not clarify whether competing methods were trained using the same cross‑chromosome train/test splits. If the split is not identical, comparisons may be unfair in either direction.
  - Reviewer 3 asks for the field‑of‑view (input window size) of each baseline method to be stated explicitly.
  - Reviewer 4 requests runtime comparisons across baselines.
- **Additional features not clearly described**: Line 420 mentions “additional features such as mRNA half‑life and promoter activity from previous studies” but does not give a complete list. These are not mentioned in Appendix A.3. It is unclear where these features are added (to the predictor g_φ?) and whether all baselines also receive them (Reviewers 3 and 4). Reviewer 4 also asks for clarification on Hi‑C data integration: what exactly is concatenated (a matrix of size #base pairs × #regions?), and does the number of regions vary across chromosomes?
- **Modeling assumptions**: The assumption that selection of regulatory regions is independent across base‑pair positions (bottom of page 4) may be too strong for real data (e.g., CpG islands). Reviewer 4 suggests discussing this further. Reviewer 3 also notes that one would expect the true mask to be “lumpy” (groups of nearby base pairs) and asks how the model accounts for this.
- **Redundant metrics**: Reviewer 3 notes that using both R and R² is redundant because R² is simply R squared.
- **Supporting citation missing**: The sentence “Gene expression prediction is one of the fundamental tasks in bioinformatics.” should be cited (e.g., Nir Friedman 2000) (Reviewer 3).
