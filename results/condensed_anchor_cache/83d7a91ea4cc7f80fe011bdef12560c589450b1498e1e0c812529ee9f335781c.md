## Merged Review

### Summary

The four reviewers acknowledge that ComPC introduces a novel, training-free test-time framework for point cloud completion that leverages 2D diffusion priors (Zero-1-to-3) via 3D Gaussian Splatting and Score Distillation Guidance. The framework operates without text prompts and shows strong generalization to unseen categories. Two reviewers (ratings 8) are overall positive, emphasizing the out-of-domain performance, good ablation study, and empirical superiority over analogical approaches. Two reviewers (ratings 6) note important weaknesses: implicit use of additional information (normals as color encoding), heavy and multi-stage reliance on the input partial point cloud, lack of robustness under noise and high occlusion, missing multi-modal completion analysis, absence of comparisons with very recent works, insufficient clarity in method description (fractal completion, differentiable quantization), no code release, and incomplete evaluation of surface generation capability.

### Strengths

- The framework generates complete point clouds that accurately capture the underlying surface, entirely bypassing the need for training on extensive 3D shape categories. It performs out of the training domain as well as in-domain, with good results that surpass existing single-modality input point cloud completion methods.
- By leveraging a 2D diffusion model to synthesize novel views from a specific input viewpoint, it removes the need for manual text prompts, unlike previous test-time methods. The approach operates on 3D coordinates only (though normals are used for color encoding), maximizing applicability.
- The work achieves superior or comparable performance to other test-time frameworks (e.g., SDS-complete) while significantly reducing computational time.
- The adaptation of the NeuraPull approach, using near and far points from the 3D bounding box of the surface point cloud while incorporating geometric details from the input partial point cloud, produces uniformly-sampled point clouds. In some cases, the point cloud density appears more uniform than the ground truth, which can benefit tracking and segmentation tasks.
- The ablation study is well-structured, split into categories each devoted to a specific part of the pipeline.
- The problem of completing partial point clouds in a generalizable way is important; 2D/3D priors from diffusion models are well-suited for achieving generalization.
- The paper is well-written; the problem is clearly specified and the solution is well presented.

### Weaknesses

- **Implicit use of additional input signal:** Although the method claims to rely solely on 3D coordinates, it incorporates 3D normals to encode the color map \(G_{in}^c\). This additional signal is not used by other methods such as PCN or SDS-complete, and Table 3 and Figure 7 show its significant impact on performance. This may give an unfair advantage.
- **Heavy reliance on input partial point cloud:** The method depends on the input partial point cloud throughout all stages: (a) in the ZFC module, SDS guidance is conditioned on the reference viewpoint image derived from the input; (b) a geometric preservation constraint is based on the original point cloud; (c) in the PCE module, the initial point cloud is merged with \(P_{pull}\) in the Grid Pulling step. This raises questions about how the method would perform under varying occlusion levels and perturbation intensities, especially when the input is significantly more incomplete than a single-view depth map.
- **Lack of robustness under noise and high occlusion:** The method's performance degrades more rapidly under noise compared to other methods, suggesting a lack of robustness to input perturbations. No systematic evaluation is provided for varying occlusion levels or perturbation intensities.
- **Missing multi-modal completion analysis:** As incompleteness increases, the diffusion model may produce different completions per optimization. The paper does not analyze multi-modality. For a small set of shapes, multiple runs on the same partial input should be evaluated using multi-modal metrics such as TMD, UHD, MMD.
- **Missing comparisons with recent related work:** The paper does not compare with recent baselines such as [1] and [2] (reviewer 2). Adding these would better evaluate completion and generalization performance.
- **Insufficient clarity in method description:** Section 3.2 (missing parts completion) references many side methods (Zero-1-to-3, SDS guidance, PFNet) with very few specifics on how they are adapted and integrated. For example, what is the fractal approach taken from PFNet? The justification for applying differentiable quantization to set the Gaussians’ opacity is not explained; the potential benefits over simpler alternatives are unclear. The overall pipeline (Figure 2) is hard to understand; splitting into separate figures with clarified step descriptions is recommended.
- **Surface generation quality unclear:** It is not clear how the method generates a surface like SDS-complete (which uses VolSDF). The paper should clarify that SDS-complete leverages VolSDF (not NeuS) and discuss whether adopting such an implicit surface representation could improve completion under high noise and significant occlusions.
- **Point cloud extraction produces separate clusters:** As noted in the ablation study (Section 4.4), point cloud extraction causes separate clusters. The reason is not explained.
- **No code release:** The source code that aggregates the mentioned methods is not provided, limiting reproducibility and the ability to test the pipeline on custom datasets.
- **Minor clarity issues:** (a) Add a horizontal separator line after the Metrics row in Tables 1, 2, and 9. (b) Add the SeedFormer method in line 418. (c) The experiment in Appendix A.5 could be performed on observations with varying levels of incompleteness (e.g., using depth maps from different numbers of views) rather than artificially eliminating points.
- **Density difference not analyzed:** The method sometimes produces point clouds with more uniform density than ground truth. The reason for this density difference is not investigated.
