## Merged Review

### Summary
This paper introduces Instant-Portrait Network (IPNet), a one-step diffusion-based model for real-time instruction-based portrait image editing. It aims to balance identity preservation, fidelity to editing instructions, and fast inference. Training has two stages: first, an Identity Enhancement Network (IDE-Net) is trained using an annealing identity loss for robust identity preservation; second, IPNet is distilled from IDE-Net using a novel Diffusion Multi-Objective Distillation approach with adversarial loss, identity distillation loss, and a Facial-Style Enhancing loss. The paper also constructs a large-scale paired dataset (10M pairs, 1024×576 resolution) using SDXL with IPAdapter and ControlNet. Experiments show high-quality editing results with better identity preservation compared to existing models.

### Strengths
1. **Visual quality & identity preservation (R1, R2, R3):** The visual results are impressive, with many details created while identity is well-preserved. The model achieves high-quality image editing results with better identity preservation than prior methods.
2. **Reasonable approach design & efficient one-step inference (R1, R2, R3):** The two-stage design is reasonable: first generate identity-preserved images, then distill for efficient one-step inference. The diffusion Multi-Objective Distillation process successfully enables one-step instruction-based editing.
3. **Convincing experiments & large-scale dataset (R1, R2, R3):** Experiments are convincing. The paper constructs 10M paired portrait images (1024×576), which is invaluable for both this paper and future research. The dataset generation pipeline is described in supplementary materials.
4. **Novel loss functions (R3):** The Annealing Identity Loss is proposed to balance identity preservation and text alignment.

### Weaknesses
1. **Task limitation – fixed pose, no expression/pose editing (R1, R2, R3):** The paper confines editing to style, clothing, makeup, and background; it cannot modify expressions, poses, or subject position. One reviewer asks why this is and what future plans are to achieve it. Another notes that comparison methods (IPAdapter, InstantID) offer more versatile functionality (pose/expression generation). The paper does not rule out that fine-tuning those baselines on the proposed dataset could match IPNet’s performance.
2. **Methodology clarity – missing details on distillation process and model architecture (R2, R3):** The description of how teacher (IDE-Net) and student (IPNet) sample time steps during distillation is insufficient. It is not clear how the distillation enables one-step inference. The number of noise-adding and denoising steps for IDE-Net during distillation is not specified. The exact architecture of networks is omitted.
3. **Training details – loss weights, hyperparameters, and reproducibility (R1, R2):** There are many losses (adversarial, identity distillation, Facial-Style Enhancing, annealing identity). How are the loss weights tuned? Is there a guideline? The paper does not provide specific loss weights, batch sizes, optimization parameters, or training details for either stage, making reproduction difficult.
4. **Necessity of IDE-Net vs. using existing methods (R3):** The need to train IDE-Net separately is unclear. Could existing methods like IPAdapter or InstantID be used instead? If IDE-Net were trained directly with the adversarial loss (3.2.1), triplet loss (3.2.3), and its own losses, would results surpass IPNet? A detailed justification is missing. One reviewer also questions whether IDE-Net is purely a reconstruction model and whether it takes text as input; sample results would help.
5. **Diversity and style/texture details (R1):** Using a distilled model often reduces diversity of styles and texture details. The paper does not evaluate diversity, which would make the work more convincing.
6. **Dataset usage clarity (R1):** How the dataset is used in the first stage is not clear. The authors mention using AID loss when creating the dataset, so is the first-stage training data also from a model using AID loss?
7. **Missing comparisons/ablations on supervision signals (R3):** Since the dataset is paired, why wasn’t diffusion loss, photometric loss, or losses used in IDE-Net applied when training IPNet? Could those provide more accurate supervision than the distillation loss?
8. **Missing source code references (R1, R2):** The paper should list the source code link for IP-Control (which achieves impressive results). Also, the exact base models and ControlNet choices for IPAdapter in dataset construction vs. Table 1 comparisons need clarification. Will the dataset be open-sourced?
