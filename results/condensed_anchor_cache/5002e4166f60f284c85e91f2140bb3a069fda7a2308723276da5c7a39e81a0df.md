## Merged Review

### Summary
The paper introduces CoSDA for continual source-free domain adaptation (SFDA), where a source-trained model is adapted sequentially to multiple unlabeled target domains without source data access. The method uses a teacher–student framework with exponential moving average (EMA) updates, mixup-based consistency regularization, mutual information maximization, and a batch normalization statistics update. The goal is to mitigate catastrophic forgetting while adapting to new domains. The paper reimplements previous SFDA methods in a unified framework and evaluates on DomainNet, OfficeHome, Office31, and VisDA, including both single-target and multi-target sequential settings.

### Strengths
1. **Problem relevance**: The continual SFDA setting is practically important, addressing the overlooked issue of preserving source domain performance during adaptation (R4, R5, R6). The method does not require domain IDs, making it suitable for real-world deployment (R5).
2. **Extensive experiments**: The paper conducts thorough evaluations on multiple standard DA benchmarks (DomainNet, OfficeHome, VisDA, Office31) with many baselines and ablation studies (R1, R2, R3, R5). It also reimplements prior SFDA methods within the same framework for fair comparison (R6).
3. **Clarity and organization**: The paper is well-organized, with clear writing, illustrative figures, and sufficient background (R1, R6). The motivation for using mixup augmentation is clearly described (R2).
4. **Simple and general method**: CoSDA is relatively simple and can be easily combined with existing SFDA approaches (e.g., NRC, AaD), as demonstrated in experiments (R3, R5). The approach is efficient and includes theoretical analysis (R3).
5. **Practical advantages**: The method addresses catastrophic forgetting and enhances target adaptation simultaneously, a relevant concern for real applications where test domains appear sequentially (R4, R5).

### Weaknesses
1. **Limited novelty**: The core components—teacher–student with EMA, mixup augmentation, consistency loss, and mutual information maximization—are all borrowed from existing work (R1, R3, R4, R5, R6). The framework bears significant similarity to CoTTA (Wang et al., 2022), which uses the same student–teacher + consistency regularization design; CoSDA simply replaces CoTTA’s general augmentation with mixup (R4). The mutual information loss is directly taken from SHOT (R4). The teacher–student EMA is common in both SFDA and transfer learning literature (R5). Overall, the combination is straightforward and lacks new methodological insights (R1, R3, R4, R5, R6). *Reviewer 3 and 5 also note the method is simple and effective but agree novelty is limited (R3, R5).*
2. **Catastrophic forgetting handling is under-analyzed**: There is no specific module designed to deal with forgetting beyond relying on the teacher’s hard labels and EMA (R1). The student model is not explicitly distilled from the teacher (R1). The trade-off between adaptation and forgetting is controlled only by the EMA momentum parameter *m*, yet no hyperparameter sensitivity analysis or ablation on *m* is provided (R3). The paper also does not discuss existing continual learning approaches and how CoSDA differs from them (R4).
3. **Equations and notation confusion**: Equation (1) uses the same notation *h* for both logits and softmax probabilities, making it unclear whether KL divergence is applied between logits and a probability vector (which would be mathematically invalid) (R2). This ambiguity undermines understanding of the core consistency loss (R2). An ablation study on potential collapse of the consistency loss is missing (R2).
4. **Batch normalization description is incorrect**: The paper claims that mean and variance are calculated over the whole dataset for BN, but the standard practice uses moving averages over mini-batches (R2). This description is inconsistent with common implementation and raises questions about the actual BN update mechanism (R2).
5. **Experimental concerns**:
   - CoSDA does not convincingly outperform existing methods. In Table 1, EdgeMix often yields better results; in Table 2, combining CoSDA with NRC or AaD does not surpass AaD alone (R1). The evaluation setting is unclear, and many baselines perform better without CoSDA (R2).
   - Sequential target experiments are limited: only up to 4 domains are tested, whereas TTA methods handle up to 15; no experiments study domain repetition (R4). Only one fixed domain combination sequence is used; longer sequences with more diverse distribution shifts should be tested (R3).
   - The choice of mixup augmentation is not justified; no experiments compare with other augmentations (R4). The paper claims applicability to NLP/audio but provides no evidence on other domains or tasks (e.g., semantic segmentation) (R4). No analysis of performance varying the number of unlabeled samples per domain (R4).
   - No experiments are shown for the TTA setup; it is unclear whether the competitive CoTTA method had its stochastic restore component removed for fair comparison (R4).
6. **Practical relevance questioned**: The continual SFDA setting is evaluated only on synthetic UDA benchmarks; its real-world applicability is uncertain because in practice one could merge all target domains into a single dataset (R6). Identifying domains in the wild is already challenging (R6). The usefulness of sequential adaptation on large-scale foundation models is not discussed (R6).
7. **Presentation issues**: The result tables are overwhelming, with excessive statistics and multiple colors that hinder interpretation (R6). The paper contains typos: “by by consolidating data” and “In this section, We …” (R6); and “to consist with” should be “to be consistent with” (R2).
8. **Missing literature**: The paper does not cite relevant works on federated learning despite workflow similarities (R2). It also omits references to SFDA methods that use the same teacher–student EMA concept (R4), and does not connect with continual learning studies that investigate BN effects on forgetting (R5).
