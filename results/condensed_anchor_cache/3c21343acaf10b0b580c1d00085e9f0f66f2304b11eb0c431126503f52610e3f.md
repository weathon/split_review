## Merged Review

### Summary
This paper revisits the problem of approximating the matrix product \(A^T B\) using sketches that can be computed independently of each other except for a shared random seed. The key requirements are preserving sparsity of the input matrices and allowing independent computation of sketches, motivated by distributed computing and multi-vector retrieval. The authors propose coordinated random sampling (threshold sampling and priority sampling) that subsamples rows of \(A\) and \(B\) using shared randomness. They prove that for sparse matrices with at most \(s\) non-zeros per row, sketch size \(O(s/\epsilon^2)\) suffices for additive Frobenius norm error \(\epsilon\|A\|_F\|B\|_F\), matching the best known results from dense linear sketches. The method is extended to \(\ell_2\) regression. Experiments on synthetic data, distributed linear regression, and attention matrix approximation in language models show an order-of-magnitude improvement over linear sketches (JL projection, CountSketch).

### Strengths
- Clear and engaging presentation with well-defined problem setting, notation, and thorough explanation of the core ideas (R1, R3, R4).
- Novel setting of preserving sparsity while computing independent sketches, motivated by distributed computing and multi-vector retrieval (R1, R2).
- Solid theoretical analysis with clean proofs; achieves sketch size \(O(s/\epsilon^2)\) for sparse matrices, matching best known results from dense linear sketches (R1, R3). (Some reviewers noted the analysis is straightforward or re-derives existing results – see Weaknesses.)
- Elegant solutions using threshold and priority sampling (R2).
- Strong empirical evaluation on synthetic data, distributed linear regression, and attention approximation; demonstrates order-of-magnitude improvement over linear sketches (R1, R2, R3).
- The method extends to \(\ell_2\) regression and improves the bound when the input matrix is sparse (R4).

### Weaknesses
- **Limited novelty**: The coordinated sampling technique is essentially the same as existing threshold sampling methods (DLT'07, DFMSZ'24); the analysis re-derives conceptually similar results without significant new theoretical insights (R2, R4). The approach is unsurprising given prior work by Bessa et al. and Daliri et al. (R2).
- **Insufficient practical motivation for independent sketching model**: The paper lacks concrete examples or detailed applications where independent sketching is crucial (R1, R3, R4). The attention layer application may not be well-suited because linear compression could degrade downstream model performance significantly; the authors should cite relevant work or add caveats (R1). The regression application would benefit from a comparison with recent active regression work that achieves \((1+\epsilon)\) relative error with fewer samples (Musco et al., Chen et al.) (R3).
- **Missing experimental comparisons and clarifications**:
  - The x-axis "Sketch Size" in Figures 1-5 needs definition (e.g., percentage of rows sampled) (R1).
  - "Layer x" in Figures 4 and 5 and the architecture of the autoregressive language model should be specified (R1).
  - No empirical comparison of memory usage between linear sketches (e.g., JL) and the proposed method (R1).
  - Comparison to previous sampling-based methods is absent (R3).
  - For the regression algorithm, a comparison to the linear regression sketch of Clarkson and Woodruff [CW'13] would be useful (R4).
- **Priority sampling does not outperform threshold sampling** in the experiments (Figures 1 and 4), raising questions about its practical value and the justification for using the more complicated priority sampling (R4). (Contrast: R2 found both methods elegant, but the empirical evidence does not support priority sampling’s advantage.)
- **Theoretical limitations**: Theorem 3 provides only a constant-probability guarantee rather than high-probability; the paper does not discuss the challenges in obtaining a high-probability or multiplicative \((1+\epsilon)\) guarantee (R1). The additive error guarantee for regression is relatively weak (R1).
- **Missing algorithmic details**: For Algorithm 3, the running time of computing leverage scores and \((A^T A)^{-1}\) is not reported; also, for sketched regression, the running time may be more critical than sketch size (R4). Minor issues: bad citation in line 109, typo "is include as" in line 324, and the description of \(\tau_A\) in Algorithm 1 is missing (R1). There is a possible formula error in line 238 (R3).
