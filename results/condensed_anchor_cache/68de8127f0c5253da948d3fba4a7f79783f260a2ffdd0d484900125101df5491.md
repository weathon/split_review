## Merged Review

### Summary
The paper introduces Post-Calibration Truncated Conformal Prediction (PoT-CP), a method that reduces conformal prediction set sizes by identifying and removing “redundant” labels (labels included in the set but not containing the ground truth). It estimates a rank cutoff *r** from the calibration set and truncates prediction sets accordingly. The method achieves asymptotic marginal and conditional coverage and is applicable to various non-conformity scores (e.g., APS, RAPS, SAPS). Numerical experiments across models, datasets, and scores demonstrate reduced set sizes while maintaining adaptivity and coverage.

### Strengths
- **Novel and simple idea**: Motivated by an insightful observation (redundant labels in prediction sets), the approach is straightforward and adds an ad-hoc truncation procedure that can be applied to any existing non-conformity score (Reviewer 1).
- **Plug-in applicable to any conformal method**: No additional hyperparameters to tune; the procedure to tune *r** is data-driven (Reviewer 4).
- **Extends conformity score to two dimensions** and explicitly identifies redundancy (Reviewer 3).
- **Well-written and easy to follow** (Reviewer 2).
- **Extensive numerical experiments**: Evaluated across various models, datasets, and non-conformity scores (APS, SAPS, RAPS). Experiments demonstrate that PoT-CP reduces set sizes while being adaptive and achieving the desired coverage rate (Reviewer 1, Reviewer 4).
- **Proved “no harm” asymptotically**: When sample size *n* goes to infinity, the truncated set and the original conformal set both contain the test label (Reviewer 4).
- **Idea generalizable to any nonconformity function** (Reviewer 2).

### Weaknesses
- **Marginal coverage only asymptotic** (not finite-sample), which undermines a key appeal of conformal prediction. The impact of calibration set size on empirical coverage is not carefully addressed – only set size changes are discussed, but coverage differences with data size are omitted (Reviewers 1, 2, 4). Convergence rates are not discussed (Reviewers 1, 2).
- **Theoretical analysis is sloppy**: 
  - Theorem 2 and Corollary 2 discuss almost sure convergence of probability, but probability is not defined on a measure space (Reviewer 1).
  - There are typos in the proof of Lemma 1 (Reviewer 2).
  - Theorem 3 is considered obvious (Reviewer 2).
- **Statistical reasoning unclear**: Standard CP relies on p-values that are uniformly distributed under exchangeability; the paper does not explain how the two-stage truncation maintains this property, nor whether p-values in the second stage are also uniformly distributed (Reviewer 2). This raises concerns about the method’s statistical validity.
- **Asymptotic results limit practical interest**: For an oracle model with known conditional class probabilities (Eq. 3), *r** increases with *n* until the truncated method coincides with the original – it is unclear why one would implement the method when in the regime where it is provably valid it almost coincides with the base score (Reviewer 4). Reviewer 2 further notes that CP’s strength is finite-sample guarantees; asymptotic results alone are not particularly compelling without convergence rates.
- **Motivation needs strengthening**: The broad implications of reducing set size for the machine learning community should be elaborated (Reviewer 3).
- **Empty sets are not necessarily preferable**: One reviewer disagrees with the implication that empty sets are better than sets with multiple labels but no coverage. CP serves as an uncertainty representation tool; empty sets provide no information about relative uncertainty between instances (Reviewer 2).
- **Missing analysis of under- vs. over-coverage cases**: Reviewer 3 suggests reporting average set size separately for under-coverage (always zero) and over-coverage cases to more directly assess the truncation effect.
- **SSCV measure is questioned**: SSCV is not a good measure of conditional coverage; improvement in SSCV may indicate the metric’s uselessness (Reviewer 2).
- **Unexplained behavior in Figures 3.c and 3.d**: These figures appear not to behave like APS and THR; an explanation is needed (Reviewer 2).
- **Clarify “high uncertainty”**: The claim “eliminate classes with high uncertainty” needs definition – does “high uncertainty” mean 1 – class probability? (Reviewer 3).
- **Missing experiments and ablations**:
  - How empirical coverage varies with calibration set size (Reviewer 1, Reviewer 3).
  - Effect of varying the nominal level α (fixed at 0.1 in experiments) on PoT-CP’s performance (Reviewer 1, Reviewer 3).
  - Why variation of calibration set size has different effects on average set size for different conformity scores (Fig. 3) (Reviewer 3).
  - Impact of increasing α on the truncation operation’s effectiveness in reducing set size (Reviewer 3).
  - Possibility of an additional calibration step to tune *r** for finite-sample validity (first step find *Q* and *r**, second step find *Q** from fresh calibration set) (Reviewer 4).
- **Missing standard errors / error bars** in figures and tables (Reviewer 4).
- **Typographical error**: Line 765: “P[Ev|Ev]” is likely a typo (Reviewer 4).
