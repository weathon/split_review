## Merged Review

### Summary
The paper proposes HCFL, a holistic four-tier framework for Clustered Federated Learning (CFL) that integrates existing methods, and HCFL$^{+}$, an enhanced variant addressing key challenges. The work includes a cost-function-based modeling and algorithmic choices (hard/soft clustering, automatic cluster number determination), with HCFL$^{+}$ allowing per-client data to belong to different clusters. The authors provide comprehensive experimental evaluations, ablation studies, theoretical analysis, and a long appendix with EM derivations, data design, and insights on linear parts. The code is promised to be open sourced. Reviewer 2 found the contribution somewhat unclear, noting the framework appears obvious given existing work and the soft clustering derivation straightforward, while the most interesting part—a new distance measure w.r.t. drift—is briefly presented and lacks references to drift literature. Reviewer 1 and 3 found the problem well-motivated and the framework novel.

### Strengths
- Addresses the important problem of efficient federated learning under data shift (all reviewers).
- Proposes a holistic FL framework (HCFL) integrating different clustered FL methods (hard vs. soft, automatic vs. fixed cluster number). Reviewers 1 and 3 found this novel and comprehensive; Reviewer 2 noted the framework is “rather obvious” given existing work but still considered it a valid contribution.
- Extensive experimental evaluation: comparative studies, ablation studies, and theoretical insight (all reviewers). Reviewer 1 specifically highlights comprehensive empirical evidence; Reviewer 2 notes very detailed experimental analysis.
- Clear motivation and well-written paper (Reviewers 1, 3). Reviewer 2 found presentation suboptimal with main part trivial and important insight in appendix, but overall acknowledges the effort.
- Code will be released open source (Reviewers 1, 2, 3).
- Solid theoretical analysis, including an EM scheme derived from the costs (Reviewers 2, 3).

### Weaknesses
- **Contribution clarity** (Reviewer 2): The specific contribution is unclear. The four-tier modeling and cost function are “rather obvious” given existing work on clustering; it is not clear whether the main contribution is implementation, guarantees, or the abstraction itself. The improved variant (HCFL$^{+}$) with soft clustering and per-data-point assignment is described as “straightforward” given existing soft clustering algorithms. The most interesting part—a new way to measure distances w.r.t. drift—is very briefly presented and lacks references to existing drift literature (e.g., moment trees, Kolmogorov trees). The paper would benefit from clarifying why the holistic framework is non-trivial and providing specific non-trivial benefits or examples.
- **Missing comparison with recent CFL work** (Reviewer 3): A recent work [1] performs clustering based on inferred label distributions; the authors should discuss this strategy and compare to it.
- **Limited evaluation on data heterogeneity** (Reviewer 3): Experiments should be run on a wider range of the Dirichlet parameter beta (e.g., 0.1 to 1.0) and on settings with different numbers of clusters (e.g., C=2, C=3 as in [1]) to demonstrate robustness.
- **Efficiency analysis** (Reviewer 1): The paper lists efficiency as a challenge in Section 4.1 but only reports the final number of clusters. More discussion of time/space complexity or corresponding empirical results is needed.
- **Unsupervised federated clustering vs. this work** (Reviewer 1): The difference between using clustering to enhance classification accuracy in FL and fully unsupervised federated clustering should be discussed to avoid misunderstandings.
- **Source code not provided** in current version (Reviewer 1). Although promised, it is missing.
- **Missing evaluation of clustering quality** (Reviewer 2’s question): There are no results on how well the clustering itself matches ground-truth data distributions (if known). This overlap with a missing experiment is included as a weakness.
- **Generalization and personalization** (Reviewer 2’s questions): The overall objective of FL in a learning theoretical sense (how is generalization error expressed?) is not clarified. Also, how personalized are the models and how does this scale with the required number of data for valid generalization? These are missing theoretical justifications.
- **Presentation imbalance** (Reviewer 2): The main text appears “almost trivial” while important insights (e.g., EM derivation, drift distance analysis) are hidden in the appendix. The main takeaways from the appendix should be highlighted.
