## Merged Review

### Summary
The paper introduces NoisyNN, which leverages “positive noise” (PN) to improve deep neural network performance on image classification and domain adaptation. It categorizes noise into positive noise (PN) and harmful noise (HN) based on information‑theoretic task complexity. A specific linear transformation noise (circular shift Q matrix) is proposed as positive noise. Experiments on CNNs and ViTs across multiple datasets are presented. However, one reviewer (score 1) strongly disputes the claimed 94.8% ImageNet‑1K top‑1 accuracy, noting that no published model has ever reached that level, and reports a missing README that prevents reproducibility. The other three reviewers (scores 6, 5, 5) find the concept interesting and the method effective but raise several weaknesses.

### Strengths
- Introduces a novel perspective on noise by categorizing it into positive noise (PN) and harmful noise (HN) based on impact on task complexity. (R1)
- Provides a theoretical analysis (information entropy) to characterize positive noise. (R3)
- The proposed NoisyNN method is effective, well‑explained, and works with popular architectures (CNNs, Vision Transformers). (R2, R4)
- Helpful for domain adaptation. (R2)
- Presents impressive experimental results. (R1)
- Thorough analysis of noise choices including linear transformation, Gaussian, and salt‑and‑pepper noise. (R4)

### Weaknesses
1. **Suspicious ImageNet‑1K accuracy claim (Major concern).**  
   Table 3 reports 94.8% top‑1 accuracy for NoisyNN on ImageNet‑1K. No model has ever achieved this on the validation set; the best state‑of‑the‑art is below 92.5% (e.g., CoAtNet‑4 achieves 88.56% under the same ImageNet‑21K pretraining + 1K fine‑tuning setting; even web‑scale models PaLi and CoCa reach only ~91%). This discrepancy is a critical red flag. (R4 – minority reviewer is highly negative; other reviewers did not comment on this specific number.)

2. **Reproducibility and codebase completeness.**  
   - The anonymous submission’s README is entirely missing, making reproduction impossible. (R4)  
   - Pretrained models or APIs are not provided, which hinders replication. (R1)  
   - R4 requests detailed installation, training, evaluation commands, data preparation steps, model weights, and package versions.

3. **Performance degradation when combined with input augmentations.**  
   Table 17 shows a drop when input augmentations are added; this incompatibility is a significant limitation. (R2)

4. **Missing comparisons with advanced augmentations and similar methods.**  
   - Only two basic latent‑dimension noises are compared; methods like Manifold Mixup (Noisy Feature Mixup) should be included. (R2)  
   - No comparison with advanced input augmentations (mixup, cutmix, RandAug). It is unclear whether NoisyNN is better or worse, or whether it is compatible. (R2)  
   - Comparisons in Table 18 are overly simplistic (only “RandomFlip + Gaussian Blur + RandAugment”) and the related work section stops at 2020, omitting vision‑Transformer‑era augmentation papers. (R4)

5. **Experimental details unclear.**  
   - It is not specified whether noise is applied during ImageNet‑1K fine‑tuning, or during both ImageNet‑21K pretraining and fine‑tuning. (R4)  
   - The baseline Vanilla ViT‑B achieves 84.33% – the codebase/implementation should be referenced. (R4)  
   - It is unclear whether noise is injected at the feature level or feature‑grid level, and whether it is applied to each feature grid individually. (R4)

6. **Generality of the “positive noise” concept.**  
   - NoisyNN is built only on a specific linear transformation noise; it is not shown how other types of positive noise (if any) would work under the same framework. (R3)  
   - The paper’s claim could be strengthened by showing results with another linear transformation noise. (R2)

7. **Theoretical analysis limited to classification tasks.**  
   The theoretical framework (information entropy, task complexity) is developed for classification, yet experiments cover domain adaptation and other tasks. How the analysis extends to those tasks is not addressed. (R3)

8. **Missing baseline optimization and training details.**  
   - It is unclear whether the baseline noise parameters (e.g., mean/variance of Gaussian noise) were optimized. (R2)  
   - How NoisyNN impacts training loss/accuracy is not reported. (R2, Q5)

9. **Domain adaptation results incomplete.**  
   Results are shown only with ViT‑based approaches; comparisons with CNN‑based domain adaptation methods are missing. (R2, Q4)

10. **Novelty assessment relative to prior noise‑addition methods.**  
    The paper does not clearly differentiate its contribution from existing works that also add noise (e.g., stochastic depth, dropout, etc.). (R3, Q2)

11. **Transferability to downstream tasks not evaluated.**  
    No experiments on object detection or segmentation, where ImageNet‑pretrained backbones are commonly used. (R4, question)
