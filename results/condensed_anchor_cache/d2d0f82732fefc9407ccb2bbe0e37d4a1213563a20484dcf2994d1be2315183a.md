## Merged Review

### Summary
The paper presents a systematic evaluation framework (SEAL) for blind real-world super-resolution. It clusters a large degradation space using spectral clustering on histogram representations, generating a diverse test set of representative degradations. It proposes two metrics: Acceptance Rate (AR) and Relative Performance Ratio (RPR), which use baseline and excellence networks as reference lines. The authors benchmark existing real-SR methods and obtain new insights.

### Strengths
- Addresses an unresolved issue in real-SR evaluation: the need for comprehensive, unbiased assessment beyond average metrics like PSNR. (R1, R2, R3, R4)
- The clustering-based approach for selecting representative degradations is intuitive, reasonable, and offers potential for further extensions. (R1, R2)
- The systematic test set is customizable and offers flexible configurations. (R2)
- New evaluation metrics (AR and RPR) provide a fresh perspective, complement existing metrics, and are supported by experimental evidence. (R1, R2, R4)
- The paper is well-written and easy to follow. (R2)
- Using other networks as baselines for acceptable/excellent performance is an interesting and practical approach. (R1)

### Weaknesses
- *Clustering details insufficient*: The type of histogram used for clustering (RGB, chromaticity, filter bank outputs?) is not specified. (R1) A more detailed explanation of the spectral clustering process in Section 3.2 is needed. (R2)
- *Clustering validation lacking*: The claim that clusters capture similar visual quality and restoration difficulty is intuitive but not rigorously validated. Demonstrations (e.g., Fig. 13) are insufficient. (R3) Visual comparisons should be provided: do random samples from the same cluster show comparable degradation levels, and samples from different clusters show contrasting degradation? (R4)
- *Metric choice question*: The evaluation relies solely on PSNR for ranking and for defining the acceptance line. It is unclear whether using SSIM, perceptual distance, or a combination would yield different rankings. (R1)
- *Potential bias claim disputed*: One reviewer (R3) disagrees with the claim that random selection causes significant bias, arguing that equal-probability random selection should not introduce bias. The authors should re-examine this claim. (R3)
- *Degradation combination calculation error*: In Section 3.1, the total number of degradation combinations appears to be miscalculated. Since the order of degradation types can be switched, it should be \(A^s_s \times k^s\) rather than the stated formula. (R3)
- *Single image for clustering*: Only one image (Lenna) was used to generate 100 degradation parameters for clustering. As Fig. 9 shows, image content can affect results by 0.1–0.3 dB in PSNR, so more images should be used for stable and representative clustering centers. (R3)
- *Evaluation time cost*: Using a hundred test sets may increase inference time. A comparison of the time cost between conventional evaluation and SEAL would be beneficial. (R2)
- *Reference line selection for GAN-based SR*: Why does the MSE-based evaluation use multiple smaller models as reference lines, while the GAN-based evaluation uses a single model? (R2)
- *Purity accuracy definition unclear*: The measure "purity accuracy" used to evaluate clustering reliability is fuzzy and needs better explanation. (R3, R4)
- *Flexibility concerns*: While the protocol offers a coarse-to-fine evaluation, it may be desirable to adjust the sequence of fine-grained indicators according to user needs. (R2)

Note: Reviewers 2 and 4 were more positive overall (scores 8), while Reviewers 1 and 3 were more critical (scores 6). Reviewer 3 expresses strong disagreement on the bias claim (confidence 2), whereas others did not remark on this point. The weaknesses above reflect the combination of all reviewers' concerns.
