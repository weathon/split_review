## Merged Review

### Summary
The paper introduces LynX, a framework to equip pretrained VLMs with visual grounding without forgetting their image and language understanding. It proposes a Dual Mixture of Experts (MoE) module: one frozen MoE for image understanding, one learnable MoE for grounding, with a task classifier that routes between them. The method also introduces SCouT, a synthetic dataset with step-by-step grounded chain-of-thought annotations generated by prompting CogVLM on Flickr30k and COCO. LynX is evaluated on object detection (COCO, LVIS, Pascal VOC), referring expression comprehension (RefCOCO/+/g), and zero-shot localization, while maintaining performance on image understanding benchmarks.

### Strengths
- Addresses a clear limitation of prior VLMs (e.g., PIN) that forget image understanding when fine-tuned for grounding. The dual-MoE design freezes original weights, ensuring no regression on image-understanding tasks when the classifier correctly identifies the task.
- The method is simple and intuitive; the MoE architecture for task separation makes sense and is clear in the methods section.
- SCouT provides richer supervision (step-by-step multimodal reasoning) than previous synthetic datasets, and is beneficial for training the grounding experts.
- LynX outperforms larger models such as Shikra-7B on complex tasks like phrase grounding despite fewer parameters (1.67B vs 7B).
- Many experiments on standard datasets using standard metrics allow cross-referencing with the literature; good ablations on number of experts and amount of SCouT data.
- Significance: Visual grounding is an important community problem. Originality is acceptable (adding experts to an existing architecture, creating a pseudolabeled dataset with specific prompting, distillation strategy).

### Weaknesses
- **Limited novelty and trivial methodology (R1, R2, R4):** The core innovations are seen as Chain-of-Thought (CoT) combined with an adapter, providing no new insights. The step-by-step loss is standard auto-regressive next-token prediction; the BERT-based task classifier is not an elegant solution. More critically, the proposed strategy amounts to hard-selection between frozen original weights (for image understanding) and finetuned weights (for grounding) based on a pre-trained classifier, rather than learned expert routing. This makes the design trivial and not novel.
- **Insufficient performance improvement (R1):** Because the original network is frozen, image understanding performance is unaffected, but the improvement on grounding tasks is limited (e.g., from 83.9 to 85.4 on a referring expression metric) and LynX lags behind Shikra-7B in direct comparisons.
- **Missing key baselines and not state-of-the-art on grounding (R4):** The paper claims SOTA for object localization but omits relevant baselines like GroundingDino, which achieves >60 mAP on COCO object detection, whereas LynX (and PIN) report <20 mAP in the most comparable protocol. Comparisons against PIN alone are insufficient to support SOTA claims. If the authors freeze SOTA image-understanding weights, why not also freeze GroundingDino for grounding and learn only the classifier?
- **Evaluation bias from using CogVLM for both data generation and evaluation (R2, R4):** SCouT labels are generated by CogVLM, and in Protocols 1 and 2 the ground-truth labels also come from CogVLM. This introduces systematic biases; the benefits may reflect model biases rather than true grounding ability. The paper acknowledges this only briefly in Protocol 3.
- **Scalability concerns (R3):** The pipeline strongly depends on adding new trainable expert heads for each new task. Adding more tasks would require significantly increasing the number of experts and parameters. It is unclear how to incorporate new tasks iteratively without massive parameter growth, which undermines the original goal of low-overhead fine-tuning.
- **Experimental presentation issues (R2):** The experimental section is hard to follow; many paragraphs do not explicitly link the experiment to the specific table number in the paper, making it difficult to match text to results.
- **Protocol clarity and fairness (R1, R4):** Table 5 compares LynX (an MoE model with fewer active parameters) against non-MoE models, which may be unfair. The active parameter count for the base model MoE-LLaVA-phi2 appears misreported. Protocols 1 and 2 (unconditional detection and category-rewriting) are of unclear benefit since they require perfect semantic-level prompting, and the added complexity does not seem necessary for a text-output model.
- **Missing ablation on pseudoannotation model (R4):** How does SCouT performance change if a model other than CogVLM is used to generate pseudolabels? This is not explored.
- **Unclear motivation for open-source evaluation pipeline (R4):** The paper claims an evaluation pipeline as a core contribution, but its necessity and added value over existing benchmarks are not justified.
- **Disagreement among reviewers:** Majority reviewers (R1, R2, R4, score 3) find the novelty limited and the results far from SOTA. One reviewer (R3, score 5) finds the method simple and intuitive with strong results, but raises significant scalability concerns.
