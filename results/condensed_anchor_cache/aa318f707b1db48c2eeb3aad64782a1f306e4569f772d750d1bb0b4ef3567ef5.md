## Merged Review

### Summary
This paper introduces VIRT, a Transformer-based policy for robotic manipulation that uses vision-based instructions (goal images) instead of text. It proposes two key components: (1) Robotic Imagery Pre-training (RIP), a pre-training paradigm using visual-only data to enable large-scale pre-training without text annotations, and (2) Robotic Gaze (RG), which emulates human eye gaze to focus on task-critical objects via an object detector. The method is trained via behavior cloning, pre-trained on the DROID dataset, and fine-tuned with teleoperated robot data. It is evaluated on three real-world tasks (including “opening a tightly sealed bottle”) and three simulation tasks, outperforming the baseline policies.

### Strengths
- Vision-centric approach addresses scalability issues of text-instruction methods and could offer a more practical path for real-time robotic applications.
- RIP is an interesting inspiration from cognitive science that enables large-scale pre-training without expensive text annotations, removing dependencies on labeled data.
- RG efficiently focuses attention on key objects via cropping/enlarging (hard attention), balancing computational efficiency with resolution demands; it boosts success in complex tasks.
- Model outperforms baseline approaches (including ACT and diffusion policy) across various challenging tasks in both real and simulated environments.
- Problem is well-defined; the method is straightforward and follows a standard behavior cloning pipeline.
- Paper is well-structured and easy to read.
- First demonstration of positive pre-training results with the DROID dataset for this type of policy.
- Results are shown in both simulated and real-world settings.

### Weaknesses
- The technical contribution is diminished because many prior works (e.g., [1]–[5] by reviewer 2; ViNT, NoMaD, MOKA by reviewer 3) use similar model architectures, goal-image conditioning, or attention mechanisms. The paper renames standard ideas (image-conditioned policy, conditional policy with fixed stages) without introducing significantly new concepts.
- Insufficient comparison with relevant baselines. Missing comparisons with state-of-the-art goal-conditioned imitation learning methods (e.g., [1][2][3][4][5] from reviewer 2), visual prompting methods (e.g., MOKA), and alternative pre-training methods (e.g., DROID’s original pre-training). The paper should also compare with text-image instruction methods to clarify advantages/limitations.
- For real-world experiments, the success rates of ACT and diffusion policy are reported as extremely low (e.g., nearly 0%). No explanation or analysis is provided for this surprising performance. Similarly, in simulation tasks, baseline performances appear unusually low, raising concerns about correct implementation.
- No evaluation is provided on existing robot manipulation benchmarks (e.g., common simulation benchmarks). This limits understanding of generalizability and fairness of comparison.
- The role of the uncertainty score is underexplored; how it manages discrepancies between predicted and actual actions, especially in uncertain segments, is not analyzed.
- Missing ablation: impact of omitting RG fine-tuning (i.e., using only RIP without RG) is not included. Reviewers request this analysis.
- Missing analysis: impact of omitting RIP entirely? Also not clear why the network changes between pre-training and fine-tuning; why not directly train the fine-tuning network with pre-training data (which includes actions).
- Long-horizon task segmentation criteria are unclear: how tasks are divided into segments (Section 3.2)? The assumption that each stage has exactly one object of interest is strong; cannot handle unstructured tasks with varying demonstrator orders or multiple objects of interest. This segmentation needs clearer definition and justification.
- The claim that RIP eliminates need for task-specific priors or manual annotations is misleading: robot action teleoperation data is the most expensive part to obtain, not text annotations; if pre-training still requires robot actions, scalability advantage over existing approaches is unclear.
- The paper’s writing is confusing: abstract and introduction do not clearly define the “robotic imagery paradigm” or the Transformer policy network architecture. The motivation and connections to cognitive science could be reduced to improve clarity.
- Figures 1 and 2 are inconsistent with text: Figure 1 only shows image inputs but VIRT uses proprioceptive data; the “Query Chunk” element in Figure 2 lacks explanation (purpose, role in RIP/RG, random initialization, whether additional heads are added during RG fine-tuning).
- Heavy reliance on object detectors limits adaptability to novel/unseen objects; handling scenes with multiple visually similar objects is challenging and not addressed.
- Experimental section needs clearer task definitions: for each task, the number of segments, initial observations, target vision instructions, and object crop regions should be explicitly stated.
- The novelty of goal-image conditioning is overstated: prior works (ViNT, NoMaD, etc.) already use goal images for pre-training in navigation and manipulation. A rationale for choosing goal images over language for task specification in this manipulation context is needed.
- For RG, it is unclear whether the object of interest is learned or manually defined. Even if manual, the method should be distinguished from visual prompting approaches that generate affordances from natural language.
- Paper would benefit from focusing on a single primary contribution and conducting deeper evaluation/analysis, rather than presenting two contributions with less thorough validation.
- Minor: introductory quotes are intriguing but not clearly connected to core contributions; citation style should use \citep.
- Reviewer disagreement: One reviewer (score 5) found the approach promising and impactful, while three others (scores 3) raised substantial concerns about novelty, evaluation, and clarity. The more positive reviewer highlighted the potential of vision instructions and the cognitive science inspiration, whereas the others questioned whether the technical contributions are sufficiently distinct from prior work.
