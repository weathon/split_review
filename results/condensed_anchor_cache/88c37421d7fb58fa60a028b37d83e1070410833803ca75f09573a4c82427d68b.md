## Merged Review

### Summary
The paper presents an empirical evaluation of existing data valuation methods, analyzing multiple tabular classification datasets (9 per the paper, 12 OpenML datasets per Reviewer 3) and multiple valuation frameworks (4–6). Key findings include: (1) sensitivity of data values to common pre-processing techniques, especially data imputation; (2) exacerbation of class imbalance when data valuation metrics are used for subsampling; and (3) undervaluation of underrepresented groups, raising ethical concerns. The authors propose DValCards, a standardized transparency framework for reporting critical information about data valuation. Reviewers acknowledge the importance of the problem but note that some findings are expected or not novel. Reviewer 2 deems the systematic evaluation valuable and the message essential, while Reviewers 1 and 4 view the contribution as limited and insufficiently supported.

### Strengths
- The paper is easy to follow (Reviewer 1, Reviewer 4).
- Well-motivated: addresses the important question of whether existing data valuation methods are suitable for data compensation in data markets (Reviewer 2).
- Comprehensive experimental analysis covering multiple datasets and valuation methods; yields valuable insights and practical guidelines (Reviewer 2, Reviewer 3, Reviewer 4).
- Provides an elaborate analysis of the impact of preprocessing (especially imputation) and class imbalance on data valuation, including rank stability (Reviewer 3).
- Introduction of DValCards as a standardized framework for reporting critical information about data valuation methods is a valuable contribution (Reviewer 3).
- Raises important ethical considerations and uses a case study to highlight risks to undervalued groups (Reviewer 3).
- The problem of data valuation is important and growing, and experimental results are on real-world datasets (Reviewer 4).
- The paper is relatively well written (Reviewer 1, Reviewer 4).

### Weaknesses
- The paper’s technical contribution is limited; the findings are largely observational and empirical, lacking theoretical support (Reviewer 1, Reviewer 4). Several findings are not novel:
  - Sensitivity to data imputation is straightforward because data valuation inherently depends on the other data used; changing the imputation method changes the dataset, which naturally alters values (Reviewer 1, Reviewer 2 also notes this is not surprising).
  - Directly using data values for removal leads to class imbalance because identical data points get identical scores, so they are either all kept or all removed; Reviewer 1 cites existing theoretical work on this limitation (https://arxiv.org/abs/2405.03875).
  - Undervaluation of minorities depends on the choice of validation set; if validation is from the underrepresented group, their value could be high rather than low (Reviewer 1).
  - It is not unexpected that methods optimizing test accuracy may introduce bias (Reviewer 2).
  Reviewer 2 considers the systematic evaluation valuable despite these issues; Reviewers 1 and 4 find the novelty insufficient.
- DValCards are primarily a documentation tool and do not fundamentally solve the instability or fairness problems identified; the framework is not extensively described or examined for its practical applicability and benefits (Reviewer 2, Reviewer 4). The motivation for DValCards could be stronger: Section 4 presents a transparency framework but does not directly mitigate the criticisms raised earlier (Reviewer 4). If instability is a key limitation, how does advocating for transparency address it? (Reviewer 4).
- The DVal Report currently reports the data value range, but this range can vary with the learning algorithm, performance metric, or valuation framework; using rank stability and performance on standard valuation tasks (e.g., noisy label detection, weighted training) might be more informative (Reviewer 3).
- The effectiveness of imputation preprocessing methods on standard data valuation tasks (e.g., weighted training, noisy label detection) is not thoroughly evaluated, despite the paper’s focus on imputation-induced instability (Reviewer 3). Reviewer 3 asks: do imputation methods actually improve performance on standard valuation tasks?
- The analysis scope could be expanded: runtime analysis (FLOPS), scaling limitations, tradeoffs with performance, and the impact of validation sets (see references [1,2] provided by Reviewer 3) are not considered (Reviewer 3). Reviewer 4 asks whether the method is limited to supervised classification or more widely applicable.
- Only one DVal Card example is shown in the main paper, and it appears generic; more examples would better demonstrate the framework’s utility (Reviewer 3).
- Reviewer 3 suggests using “data valuation methods” instead of “metrics” for consistency with common usage.
