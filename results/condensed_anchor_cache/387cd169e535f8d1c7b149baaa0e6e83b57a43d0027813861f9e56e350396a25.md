## Merged Review

### Summary
The paper introduces Lyfe Agents, an LLM-based generative agent framework (using GPT-3.5) that combines three brain-inspired modules: an option-action framework for hierarchical decision-making, an asynchronous self-monitoring module for contextual awareness, and a Summarize-and-Forget memory mechanism. Agents are evaluated in the custom 3D environment LyfeGame across social scenarios (murder mystery, activity fair, medical treatment discussion). The authors claim a 10–100× reduction in computational cost and a 95% reduction in queries compared to Generative Agents (Park et al.). The work is presented with a clear pipeline (Figure 2) and includes ablation studies.

### Strengths
- **Brain-inspired architecture**: The combination of self-monitoring, dynamic memory (short/long-term with clustering and vector similarity retrieval), and the option-action framework is grounded in neurobiology and shows promising emergent social behavior (e.g., collaborative murder mystery solving).  
- **Multiple experiments and ablation**: Three scenarios (murder mystery – easy/hard, activity fair, medical treatment) are used, and the ablation study (including the police success rate in Figure 3b) demonstrates the importance of each module.  
- **Cost advantage over Generative Agents**: The paper provides a clear cost reduction (10–100× lower; queries reduced by 95%), which is a significant practical contribution given the high expense of existing approaches.  
- **Clarity and presentation**: The pipeline (Figure 2) is clear and interesting; the paper is well‑written and easy to understand, with sufficient detail in the appendix for a conference page limit.  
- **Relevant topic**: Tackling cost‑efficient, real‑time generative agents with effective memory systems is highly relevant to the community.  
- **Engineering quality**: The comprehensive framework required substantial engineering effort, and the technical components are thoroughly evaluated in the ablation.

### Weaknesses
- **Missing implementation details in the main body**: Critical details of all three modules are omitted from the main text and only partially given in the appendix. For the option-action module: What are the available options (discrete list or LLM‑defined)? What are the exit conditions triggering the module? How is the LLM call structured (subgoal/option output)? The self‑monitoring and memory mechanisms also lack descriptions of retrieval algorithms, clustering techniques, and embedding methods. These details are necessary for reproducibility.  
- **Unconvincing cost analysis**: The primary evidence for cost‑effectiveness (a key selling point) is based on a comparison that is considered unfair. The comparison uses GPT‑3.5 for Lyfe Agents and GPT‑4 for Generative Agents, so the cost difference may reflect the model choice rather than architectural improvements. A fairer analysis would report tokens input/output or number of interactions required to solve a given task (e.g., murder mystery solution), not “cost per agent per hour” in USD (which depends on API pricing and electricity costs). Further, it is unclear which module contributes most to cost reduction; the ablation study only reports task success, not per‑module cost impact.  
- **Insufficient baseline comparisons**: The paper compares only with Generative Agents, not with other social simulation LLM‑based agents (e.g., [1], [2]) or general agent frameworks. The framework should also be evaluated on well‑known benchmarks/games (e.g., [3], [4]) to demonstrate generality.  
- **Reliance on a single LLM (GPT‑3.5)**: All experiments use only GPT‑3.5. No experiments with open‑source models (e.g., Llama‑2 70B, Falcon 180B, Alpaca, GPT4ALL) or models of varying capacity are provided. This limits assessment of generalizability, reproducibility, and transparency.  
- **Limited novelty and scientific depth**: Several reviewers consider the paper more a technical report or application of existing ideas than a novel research contribution. The self‑monitoring is seen as similar to “reflecting on reflections” in Generative Agents, and the Summarize‑and‑Forget memory resembles using time as an inverse importance metric (also from Generative Agents). The logic motivating the three modules is not clearly distinguished from prior work.  
- **Weak objective evaluation metrics**: The police success rate (Figure 3b) is based on a self‑designed script with predetermined correct answers, which is not a rigorous scientific metric. No objective metrics (e.g., task completion costs, interaction diversity, or human evaluation) are provided beyond cost per hour (which is themselves problematic).  
- **Environment limitations**: The 3D environment LyfeGame is purely text‑based (agents do not perceive visuals as image inputs); interactions are reduced to walking and talking actions akin to a navigable chatroom. The 3D visuals add no functional benefit and the environment may be too simplistic to incentivize complex social behaviors.  
- **Questions overlapping with criticisms** (incorporated as weaknesses):  
  - How is the option‑action selection module implemented in code (pretrained policy vs. rule‑based)?  
  - What are the exact prompt templates used to interact with ChatGPT?  
  - How does the Summarize‑and‑Forget mechanism differ from the reflection/summarization in Generative Agents?  
  - What clustering technique and embedding model are used for memory summarization?  
  - Could existing LLM‑based agents become real‑time if the LLM is run locally?  
  - Can the framework be evaluated on open‑source LLMs?  
  - Can the cost analysis be performed using number of tokens/interactions until task completion instead of USD per hour?
