## Merged Review

### Summary

This paper extends the random walk-based graph random features of Choromanski (2023) by introducing a modulation function that upweights or downweights walks based on length, enabling unbiased estimation of arbitrary functions of a weighted adjacency matrix. The authors show how to instantiate common graph kernels (d-regularized Laplacian, p-step random walk, heat diffusion) and further parameterize the modulation function with a neural network to learn task-specific kernels with a generalization bound. Experiments cover pointwise kernel estimation, solving non-homogeneous graph ODEs, node clustering, and kernel regression on triangular meshes.

### Strengths

- **Novel extension with modulation function:** The introduction of a modulation function generalizes prior work to unbiasedly approximate arbitrary functions of the weighted adjacency matrix, covering many popular graph kernels.
- **Learnable kernels:** Parameterizing the modulation function with a two-layer neural network allows automatic selection of a graph representation suited to a downstream task, with a generalization bound.
- **Clear presentation:** The paper is well written and easy to follow, with clear statement of contribution relative to prior work.
- **Broad experimental scope:** Experiments demonstrate the method on several different tasks (kernel estimation, ODE solving, clustering, mesh regression), showcasing potential applicability.
- **Theoretical and practical contributions:** The work provides both robust theoretical analysis (unbiasedness, variance, generalization) and a practical algorithm that can be distributed across machines and runs in subquadratic time.
- **Reproducibility:** Authors plan to release code upon acceptance.

### Weaknesses

- **Proof of Theorem 2.1 may be incorrect:** Reviewer 1 indicates that equation (19) in the appendix appears incorrect. The equation involves the modulation function evaluated only on the total walk length, but Algorithm 1 (line 8) uses all values of the modulation function evaluated at \(k \leq \text{length(walk)}\). The derivation may need to account for prefixes and include a factor \(p\) rather than only \((1-p)^{\text{len}}\). This issue, if not resolved, would invalidate the main theoretical claim.
- **Limited scale of experiments:** All experiments are performed on small graphs (e.g., a few hundred nodes). There is no demonstration on larger networks (e.g., \(N=10,000\) or more) to show how the approximation error and computational cost scale with \(N\). Without such evidence, the claim of wide applicability to large real-world graphs is not fully supported.
- **Missing real-world application:** The experiments do not include a direct application to a real-world large-scale problem (e.g., community detection, recommender systems) where standard kernel methods would be infeasible. For instance, using the method to automatically learn a good kernel for community detection on sparse graphs (e.g., comparing to the non-backtracking matrix) would be highly relevant.
- **No experiment demonstrating inversion of \(K(W)\):** The paper motivates the need to avoid \(O(N^3)\) inversion of matrices like \(K(W)\), but no experiment shows how the random feature approximation can be leveraged to efficiently compute or approximate \(K(W)^{-1}\).
- **Clustering evaluation is incomplete:** The node clustering experiments (Table 2) only report the difference between the approximated kernel and the exact kernel using a pairwise metric (Eq. 15). Missing are actual clustering quality metrics such as Normalized Mutual Information (NMI) or Adjusted Rand Index against ground-truth clusters, and a node-wise accuracy comparison with clustering results from the exact kernel.
- **Compute time vs. accuracy trade-off not shown:** The experiments only relate the number of walks to approximation error. No analysis links accuracy to execution time on standard hardware, making it hard to assess the practical break-even point against exact computation or competing methods.
- **Unclear justification for symmetric modulation functions:** The paper does not explain why symmetric modulation functions (Eq. 4) are particularly interesting or whether they reduce estimator variance (theoretically or empirically). A discussion of pros/cons of symmetric vs. asymmetric approaches is needed.
- **Lack of analysis on parameter influence and sparsity:** Practical choices (e.g., stopping probability \(p_{\text{halt}}\)) are not discussed in terms of their impact on performance. Moreover, the method’s behavior on sparse graphs (the most common real-world case) is not explored; simulated experiments varying sparsity would be valuable.
- **Limitation to weighted graphs without attributes:** The kernels considered apply only to weighted graphs without node or edge attributes, which restricts applicability to many real-world graphs that include rich attribute information.
- **Misleading term "universal":** Several reviewers note that the term "universal graph random features" is misleading, as the features can approximate only functions of the weighted adjacency matrix, not all possible graph kernels. The authors acknowledge that the term "general" might be more appropriate; indeed the paper uses "g-GRFs" in the title.
- **Notation and presentation issues:**
  - Table 3 and Table 4: The numbers in parentheses are presumably standard deviations but are given as integers; the notation should be clarified.
  - Figure 3: It is unclear whether the shaded area corresponds to \(\pm 1\) standard deviation.
  - Equation (9): The mapping \(x \mapsto w^\top \psi_K(x)\) appears to miss the parameter \(\alpha\); should be \(w^\top \psi_{K_\alpha}(x)\).
  - Section 3.1, first line: a missing "for" – should read "do indeed give unbiased estimates for the graph kernels".
  - Between Eq. (13) and (14): notation for \(\Phi\) should depend on \(\tau_j\)? The matrix \(\Phi\) is said to be \(n \times N\) with \(j\)-th row \(((t-\tau_j)\phi(i))_{i=1}^N\), which suggests dependence on \(\tau_j\).
  - Algorithm 1: Reviewer 4 questions whether the normalization should be \(1/\sqrt{m}\) instead of \(1/m\).
  - Section 3.4: It is claimed that the learned modulation function transfers to other graphs (Table 3), but the generation of the table is not explained.
  - Equation (2): The sum may not be well-defined for some functions; this is only briefly mentioned and should be discussed more thoroughly.
