## Merged Review

### Summary
UniSpeaker is a unified speech generation model that integrates face images, text descriptions, attribute descriptions, and reference speech for multimodal-driven voice control. It uses a KV-Former-based multimodal voice aggregator (MVA) with soft contrastive loss to map diverse modalities into a shared voice space, and employs self-distillation within a CosyVoice backbone (conditional flow matching) to improve voice disentanglement. The paper also introduces the MVC benchmark covering five tasks (FaceVC, FaceTTS, TextVC, TextTTS, AVE) to evaluate voice suitability, diversity, and quality. Experimental results show UniSpeaker outperforms prior modality-specific models. Reviewers agree on the comprehensiveness of the model and the benchmark, but strongly disagree on novelty, experimental fairness, and depth of analysis. One reviewer (score 8) finds no significant issues, while the other three (scores 3, 3, 5) raise major concerns about novelty, missing experiments, and evaluation rigor.

### Strengths
- **Comprehensive multi-modal support**: UniSpeaker is the first model to condition on four modalities (face, text, attribute, reference speech) for both text-to-speech (TTS) and voice conversion (VC) tasks (Reviewers 1, 2, 3).
- **MVC benchmark**: Introduces a dedicated benchmark for multimodal voice control, which is considered a valuable resource for the research community (Reviewers 1, 3, 4). However, Reviewers 2 and 3 argue that the benchmark largely reuses existing metrics (WER, MOS, speaker-embedding similarity) and that CosyVoice already uses the same formulation.
- **Technical components**: The KV-Former-based MVA, soft contrastive loss, and self-distillation are noted as intuitive and effective, with ablation studies validating each (Reviewers 1, 4). Reviewer 2 counters that the MVA is based on a standard memory mechanism, self-distillation simply removes the mel-spectrogram prompt from the CFM (as done in SeedTTS), and modality encoders are all from previous pretrained models.
- **Performance**: On the MVC benchmark, UniSpeaker achieves the best results among baselines in voice suitability, diversity, and speech quality (Reviewers 1, 2, 3).

### Weaknesses
- **Lack of novelty / incremental contribution** (Reviewers 2, 3, 4): The pipeline is described as a naive combination of existing components – CosyVoice backbone, pretrained modality-specific encoders (e.g., wav2vec 2.0, CLIP, BERT), and a memory-based MVA. Contrastive learning to align features with speaker embeddings and the two-stage approach (AR + flow matching) have been used in many prior TTS works (SeedTTS, CosyVoice, FireRedTTS, Tortoise-TTS, SoundStorm). The self-distillation technique directly follows SeedTTS. Reviewer 1, in contrast, regards these as notable technical innovations.
- **Unfair experimental comparisons** (Reviewer 4): In Table 2, the baselines are compared using their official checkpoints which were trained on different datasets (e.g., CosyVoice-Instruct uses a large internal commercial dataset, while the MVC training set uses academic reading-style datasets like VCTK). This creates a domain gap and makes the results unconvincing. A fairer comparison would require fine-tuning CosyVoice on the same training data. At minimum, the training datasets used for each baseline should be explicitly stated in Table 2.
- **Missing experiments and ablations** (Reviewers 1, 2, 3, 4):
  - **Bi-modal ablation**: The paper shows that combining all four modalities improves performance, but does not ablate two-modality combinations (e.g., face+text vs. text only, face only) to reveal complementary effects (Reviewers 1, 2).
  - **K-V vector analysis**: The number of K-V vectors (memory slots) is not reported, nor are experiments varying this number, utilization rates, or analyses on whether learned vectors correspond to specific voice properties (pitch, gender, age) (Reviewer 2).
  - **Conditioning on multiple modalities**: No experiment explicitly compares performance when conditioning on different numbers of modalities (e.g., face+text vs. text only). (Reviewer 2)
  - **Out-of-domain evaluation**: The model’s robustness to out-of-domain inputs (e.g., text descriptions like “dragon voice” or animated/non-realistic face images) is not assessed. Reviewers suspect results may be poor due to limited training data diversity (Reviewer 3). Related question: Has the model been tested on such inputs? (Reviewer 3)
  - **Fine-tuning on CosyVoice**: Given that the training data volume is much smaller than CosyVoice’s original training data, could the model benefit from directly fine-tuning the full CosyVoice? (Reviewer 3)
  - **MOS statistical significance**: The MOS evaluation shows only modest significance, likely due to a limited number of samples and listeners. Expanding the sample size could improve statistical power (Reviewer 1).
  - **SSD evaluation justification**: The SSD metric (speaker embedding similarity) uses embeddings not optimized for this purpose; subjective analysis might be more appropriate (Reviewer 1).
- **Design choices and limitations** (Reviewer 4):
  - **Multi-condition classifier-free guidance**: The current interpolation of speaker embeddings from face and text descriptions using fixed weights may be suboptimal; multi-condition classifier-free guidance (as in InstructPix2Pix) could be a better alternative.
  - **Global speaker embedding**: Using only a time-averaged global speaker embedding discards time-varying timbre details. Prior works like NaturalSpeech 3 incorporate both global and fine-grained embeddings for better reconstruction quality.
- **Writing accuracy and clarity** (Reviewers 2, 4):
  - Line 290: the shape of the negative disentangled distribution should be 1×(N-1), not “1xN-1”.
  - Line 304: “L_{INTRA}” should be “L_{INTER}” (inter-modality loss is the InfoNCE loss).
  - Line 312: “the CFM is fine-tuned to predict the source speech” should be “the CFM is fine-tuned to predict the converted speech”.
  - Table 2: SST, SSC, SSD, and WER values are all in (0,1); add “(%)” in the table or caption.
  - Appendix F, line 1049: “Figure 8” → “Table 8”.
  - Title: “Unispeaker” → “UniSpeaker”.
  - Figure 2 should include additional details on inter-modal and intra-modal alignment learning to improve clarity.
- **Ethics statement missing** (Reviewer 4): The paper advances multimodal speech synthesis technology, which raises ethical concerns; an ethics statement should be added.
- **Minority positive view** (Reviewer 1): This reviewer finds no significant weaknesses, only minor concerns about evaluation size and missing bi-modal ablations. The other three reviewers collectively identify the major weaknesses listed above.
