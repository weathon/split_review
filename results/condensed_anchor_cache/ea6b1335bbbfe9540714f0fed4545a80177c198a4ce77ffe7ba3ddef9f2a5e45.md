## Merged Review

### Summary
The paper proposes HyperCLIP, which uses a hypernetwork to dynamically adjust weights of a small image encoder based on text inputs within the SigLIP contrastive pre-training framework. It aims to enable deployment of vision-language models in resource-constrained environments. Experiments show zero-shot accuracy improvements of up to 3% on ImageNet and 5% on CIFAR-100 with minimal throughput overhead.

### Strengths
- The approach is novel: using a hypernetwork to adapt a smaller image encoder's weights (specifically normalization layers) at test-time for CLIP/VLMs is a new contribution. (Reviewer 2, Reviewer 3)
- As shown in Table 2, HyperCLIP improves zero-shot accuracy on ImageNet by up to 3% and CIFAR-100 by 5% over the SigLIP baseline with minimal training overhead. (Reviewer 1, Reviewer 2, Reviewer 3)
- The method is compatible with any type of contrastive pre-training, enhancing versatility. (Reviewer 2)
- The paper demonstrates that adapting only normalization layers yields performance gains on standard benchmarks. (Reviewer 2)
- The datasets used align well with prior work. (Reviewer 3)
- HyperCLIP has potential to democratize computer vision by enabling high-performing models on resource-constrained devices. (Reviewer 2)

### Weaknesses
- **Unclear motivation and efficiency claims**: The motivation for using a hypernetwork to address efficiency in edge computing is unclear. Experiments show performance improvement over a baseline without a hypernetwork but fail to directly address efficiency. Efficiency is not clearly defined; the paper implies parameter count is the metric, but FLOPs, memory access patterns, and model quantization are also critical for real-world edge deployment. The hypernetwork adds compute, but this overhead is not fully analyzed. (Reviewer 1)
- **Limited generalization to broader VLMs**: HyperCLIP modifies image encoder weights based on text embeddings. This does not generalize to larger VLMs like LLaVA that use fixed pre-trained image encoders and cross-modal attention within a large LLM. The method is applicable only to architectures similar to CLIP, not to recent larger models. (Reviewer 3)
- **Reduced versatility of CLIP**: HyperCLIP reduces CLIP's application to image classification. Dynamic modification of the image encoder makes it difficult to extract consistent visual features for other tasks (e.g., object detection, segmentation) where stable feature representations are crucial. (Reviewer 3)
- **Zero-shot setting is questionable**: The paper claims zero-shot classification on ImageNet, but Appendix A.5 states the training data selects samples containing text overlapping with ImageNet class names. This contaminates the zero-shot evaluation because the model has seen class names during training. (Reviewer 3)
- **Limited scope of adapted parameters**: By focusing only on normalization layers, the paper may not fully leverage hypernetworks' potential to modify other model parameters. (Reviewer 2, Reviewer 1 implied)
- **Poor writing and presentation**: Several English expressions appear incorrect (e.g., lines 041-044) and sentences are excessively long (lines 045-050), making the paper hard to follow. (Reviewer 1)
- **Insufficient references and related work**: Introduction cites only three prior works (Sun et al., 2023a; Dettmers et al., 2022; Frantar & Alistarh, 2023). The related work section is a single paragraph (L488-503) lacking discussion of established methods like LoRA and adaLN. (Reviewer 1)
- **Missing experimental details**: It is unclear whether the model is trained from scratch or initialized from SigLIP, and which results are zero-shot vs. linear probing. (Reviewer 1)
- **Model size inconsistency**: The text transformer has width 768, 8 heads, feed-forward dimension 2560 — which is not small, yet the method targets compute-restricted scenarios. (Reviewer 1)
- **Code not released**: No statement about code release (Reviewer 2 asked; implied weakness if not provided).
