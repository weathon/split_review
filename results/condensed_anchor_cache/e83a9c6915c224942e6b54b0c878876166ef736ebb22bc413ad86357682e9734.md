## Merged Review

### Summary
The paper proposes a few-shot image classification method that uses frozen public text encoders (e.g., CLIP, word embeddings) together with a learnable metric module to align visual and textual embeddings, and trains the model via MAML with bi-level optimization. One reviewer (score 5, confidence 4) was notably more positive, praising the presentation, direction, and visualizations; the other three reviewers (scores 3, confidence 4–5) found the novelty limited, the experimental evaluation incomplete, and several technical details insufficiently justified.

### Strengths
- The paper is clearly written, well-organized, and easy to follow (R1, R2, R3).
- It tackles an important and timely problem: improving few-shot learning by injecting semantic textual information (R1, R2, R3). The idea is simple and intuitively appealing (R3).
- The experimental evaluation is comprehensive on standard benchmarks (miniImageNet, tieredImageNet, CUB) and shows improvements over several inductive few-shot state-of-the-art methods (R1, R2, R4). The method beats SOTA on multiple benchmarks (R4).
- An ablation study demonstrates the importance of the proposed metric module (R2, R4).
- The visualization in Section 5.4 provides useful insight (R1).

### Weaknesses
- **Limited novelty and overclaim.** The core framework of learning image–text alignment with a bilinear function has been extensively studied in zero-shot learning (e.g., Xu et al., Attribute Prototype Network, IJCV 2022) and few-shot learning using off-the-shelf text encoders (VS-Alignment, Afham et al., 2022; Chen et al., 2023). The proposed method is viewed by multiple reviewers as a trivial combination of MAML with these existing ideas, lacking significant technical contribution (R3, R4). The paper overlooks relevant works that use category names for few-shot learning [4] and a pioneer work [1] on off-the-shelf language models for few-shot learning; it fails to discuss how it differs from or improves upon them (R1, R4). The trade-offs between the proposed learnable metric module and using category name initialization (as in [4]) are not discussed (R1).
- **Incomplete experimental comparisons.** The evaluation does not compare with important few-shot methods such as TRIDENT, BAVARDAGE, and PEMnE-BMS (R1). There is no comparison with transductive state-of-the-art approaches (R2). The experiments are limited to image-only baselines; the paper does not include comparisons with methods that also leverage text information (e.g., [1], [4]) or evaluate on other modalities (e.g., COCO, meta-dataset) (R2, R4). Only one visual backbone (ResNet-12) is used; experiments with ViT, Swin Transformers, or pretrained image encoders (e.g., CLIP image encoder) are missing, which would help assess if the method benefits from stronger architectures or if using a pretrained image encoder would make MAML unnecessary (R2, R4).
- **Insufficient technical details and justification.** The bi-level optimization strategy (metric module updated in inner loop, all parameters in outer loop) is not well motivated; the rationale for this separation is unclear (R1). Missing details on the contrastive learning setup: batch size and negative sampling strategy are not reported (R2). The learnable prompt templates mentioned in Sec. 4.1 lack any technical description (R3). An equation on Page 6 is imprecisely written (gradient w.r.t. I, T, M is incorrect and the expression is missing) and is unnumbered (R4). The citation to the meta-learning paradigm on Page 3 is imprecise (Vinyals et al. 2016 does not discuss meta-learning; MAML would be more appropriate) (R4). The paper should discuss the meta-learning paradigm more thoroughly (e.g., reference to [this paper](https://arxiv.org/abs/2003.11539)) (R2).
- **Limited insights and over-reliance on CLIP.** The reported state-of-the-art results are driven largely by CLIP text embeddings, which is expected given CLIP’s strong zero-shot capability. When weaker text embeddings (word embeddings, language model embeddings) are used, the method underperforms baseline methods, indicating that the approach adds little beyond leveraging CLIP’s textual space (R3). The paper offers limited analysis beyond comparing three text embedding types; it does not formalize what semantic information is being injected or explore how different prompt designs (e.g., emphasizing class relationships vs. attributes) affect performance (R2, R3).
- **Missing positioning to multimodal contrastive learning.** The work does not situate itself relative to multimodal contrastive training approaches (e.g., “Multimodal Contrastive Training for Visual Representation Learning”) that also learn alignments between vision and language (R2).
