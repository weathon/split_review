## Merged Review

### Summary
The paper proposes R-MCTS, a test-time algorithm that extends MCTS with contrastive reflection (storing reflection embeddings in a vector DB for retrieval) and multi-agent debate (aggregating multiple VLM value estimates) to improve VLM agents on long-horizon web navigation tasks. Evaluated on VisualWebArena, R-MCTS (especially with multi-agent debate) achieves significant performance gains over baselines. The paper also shows that search trajectories from R-MCTS can be distilled via fine-tuning back into GPT-4o, matching 97% of the search performance at test time while using 4× less compute, and that the fine-tuned model learns to explore, evaluate states, and backtrack. The work demonstrates compute scaling properties in training (data collection with search) and testing.

### Strengths
- Important contribution to building generalizable agents for complex web navigation, an area where VLMs still fall short of human performance.
- Novel integration of VLMs' reasoning capabilities into MCTS; contrastive reflection (learning from past interactions via memorized reflections retrieved from a vector database) is a novel and well-motivated component.
- Multi-agent debate for state evaluation provides more robust value estimates by aggregating multiple VLM judgments.
- Thorough ablations over different value function constructions (e.g., LLM-only, multi-agent debate) and individual algorithm components, plus informative error analysis (Section 5.3).
- Significant performance boost on VisualWebArena, raising the bar for what VLMs can achieve in long-horizon tasks.
- Demonstrates that search trajectories can be effectively transferred back to base models via fine-tuning, generating high-quality synthetic data without human labels, which is valuable given the cost of human data collection.
- Well-contextualized with respect to current literature on agentic LLM frameworks, search-based methods, and inference-time algorithms.
- Clear emphasis on compute scaling properties, both at training (data collection with search) and test time.

### Weaknesses
- **Core limitation: access to a simulator.** The search algorithm builds the tree using agent-environment interactions with the exact WebArena simulator (similar to Alpha-Zero, not MuZero). This should be explicitly stated, and baselines should be compared under equal access to simulated transitions. ReAct and Tree-of-Thought (ToT) may not have such access, making comparisons potentially misleading. The results must be transparent about the number of simulated interactions (episodes or transitions) used for each method. [Reviewer 1, 4]
- **Unfair compute comparisons.** Baselines in Table 2 are not evaluated with equal compute (e.g., does R-MCTS beat ReAct’s 7-shot performance? ToT’s 2-shot?). The number of tokens varies widely across methods, and it is not shown that simpler alternatives (Best-of-N, larger MCTS, larger ToT) with comparable token budgets would not achieve similar gains. For self-learning results, it is unclear whether fine-tuning on best-of-n ReAct trajectories would yield similar improvements. [Reviewer 1, 2, 4]
- **Missing baselines.** The evaluation omits relevant multi-step exploration methods such as Reflexion and Intelligent Go-Explore, which are natural comparators for contrastive reflection and search-based exploration. [Reviewer 2]
- **Generalization concerns.** The methodology appears specifically tailored to web navigation (requires environment model for simulation) and is unlikely to generalize to other VLM domains (e.g., video games) without a simulator. A clearer explanation of the task scope and assumptions is needed. [Reviewer 1, 4]
- **Fundamental reliability issue with self-learning.** Since LLMs are imperfect, self-generating training data, self-reflecting, and fine-tuning from data produced by the same imperfect model may lead to a learning system with unreliable signal. The paper does not discuss the drawbacks or limitations of training with possibly flawed data, nor does it provide a sound principle explaining why this circular dependency works. [Reviewer 3 – minority more negative; score 5 vs. others’ 6]
- **Presentation clarity issues.** The paper is difficult to follow in places: Figure 1 (left and right) lacks clear captions and messaging (e.g., what is "unseen success rate"?); Section 3.1 states that multi-agent debate was introduced in Section 2.3, but Section 2.3 says it will be described later, causing confusion. [Reviewer 1, 4]
- **Lack of explicit details on simulations and computational budget.** The number of simulations (tree expansions) used for each method is not reported, even for fine-tuning datasets where the number of simulated trajectories matters. The simulation step (random rollouts vs. other) is not clearly described. The meaning of the "Training" column in Table 3 is unclear. [Reviewer 1, 4]
- **Contrastive reflection as a general technique.** The improvement step of storing reflections can be applied independently of the search method (e.g., to BFS, DFS, MCTS); the paper does not ablate this component across other search methods, making it hard to attribute gains to the combination. [Reviewer 1]
- **Single benchmark and limited models.** Evaluation is limited to VisualWebArena and only two underlying models (GPT-4o). Testing on more diverse tasks and models would strengthen generalizability, though cost constraints are acknowledged. [Reviewer 1, 2]
- **Novelty:** The modifications (contrastive reflection, multi-agent debate, self-learning) are individually existing concepts; the paper’s contribution is in their straightforward integration with MCTS on VLMs, which is a valuable study rather than a fundamentally novel algorithm. [Reviewer 1]
