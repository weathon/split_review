## Merged Review

### Summary
The paper proposes 3DFuse, a framework that enhances 3D consistency in text-to-3D generation by fine-tuning a sparse-depth-conditioned Stable Diffusion model using the Co3D dataset and integrating it into SDS/VSD optimization. It also introduces semantic coding to address semantic ambiguity. Experiments demonstrate improved geometry and reduced Janus artifacts, but the method relies on coarse point clouds (e.g., Point-E) which introduces quality bottlenecks, and results lag behind some state-of-the-art methods. Reviewers agreed on the novelty of the approach but diverged on its effectiveness relative to baselines.

### Strengths
- Novel framework 3DFuse that injects 3D awareness into 2D diffusion via fine-tuned sparse-depth-conditioned Stable Diffusion (Co3D dataset), alleviating the Janus problem and improving geometry quality (Reviewer 3).
- Semantic coding technique reduces semantic ambiguity and improves controllability; effectively demonstrated in Fig.12 (Reviewer 2).
- Comprehensive ablation studies, user study (Fig.8), and qualitative results (Fig.3,4) show improved 3D consistency over prompt-based methods (Reviewers 1, 2).
- Uses LoRA for parameter-efficient fine-tuning for semantic consistency (Reviewer 3).
- Code provided and works well (Reviewer 3 verified).
- Coherent and lucid narrative structure (Reviewer 2).

### Weaknesses
- Marginal improvement over baselines (Reviewer 1); results lag behind contemporary methods such as DreamFusion and ProlificDreamer, whose reproduced results appear less robust than original implementations (Reviewer 2).
- Heavy reliance on off-the-shelf point cloud reconstruction or generation (e.g., Point-E) yields low-quality sparse-depth renderings with artifacts, limiting final 3D quality; the method does not address missing/inaccurate depth information (Reviewer 2, Fig.4). Stability and failure cases of the point cloud generative model are not analyzed; it is unclear why direct monocular depth map prediction is avoided instead of point cloud to depth conversion (Reviewer 1 question/criticism).
- Novel view synthesis fails to maintain object identity and produces blurry results (Reviewer 2, Fig.10).
- Video from supplementary material exhibits aliasing despite being rendered from an optimized NeRF (Reviewer 1).
- Missing references to concurrent image-to-3D works (NeuralLift-360, RealFusion) that also address semantic consistency; comparison with image-to-3D methods is needed as the approach decomposes text-to-3D into text-to-image + image-to-3D tasks (Reviewers 1, 3). Major differences from these methods on semantic consistency are not discussed (Reviewer 3 question).
- Reviewer 1 and 2 found the improvement marginal and quality lagging behind baselines, whereas Reviewer 3 considered the method effective and the code working well.
