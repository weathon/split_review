## Merged Review

### Summary
The paper presents a latent diffusion model for mixed-type tabular data synthesis, using a VAE to project data into a regularized latent space followed by a score-based generator. The method is evaluated on six datasets with five metrics, outperforming existing approaches. Reviewers generally find the work solid and practically useful, with clear code and a unified benchmark. However, one reviewer is notably more critical, questioning the motivation and model design for tabular data, while others praise the efficiency and results but raise concerns about novelty, missing baselines, and evaluation choices.

### Strengths
- Unified benchmark beneficial to the community, with public code and detailed supplementary material.
- Effectively manages mixed-type data by transforming columns into a single cohesive latent space, capturing inter-column relationships.
- Faster synthesis with fewer reverse steps than existing diffusion-based methods.
- Comprehensive multi-dimensional evaluation metrics (six datasets, five metrics) with consistent outperformance over strong baselines.
- Model tested with a single hyperparameter configuration across all datasets.
- Well-written with clear illustrations; code is clear and well-commented.
- Results are convincing and the method is reasonable for real-world use on mixed-type tabular data.

### Weaknesses
- Motivation for using latent diffusion on tabular data is not thoroughly discussed, and the model design does not exploit tabular-specific characteristics.
- VAE decoder is tailored separately for numerical or categorical features, limiting applicability to datasets containing a true mixture of both types (contrary to the paper’s claim of generality).
- Scientific contribution is largely incremental and expected; the architecture closely follows Vahdat (2021) with tokenization added for tabular data. The paper should clearly state the technical novelty in the Introduction.
- Method efficacy depends on a well-trained VAE; no comparison between optimally and sub-optimally trained VAEs is provided.
- No results from data generated by the VAE alone (e.g., without the diffusion stage) or explicit comparison with TVAE to isolate the transformer-based VAE’s contribution.
- Hyperparameter enlargement for baselines (e.g., CTGAN, CoDi) might favor the proposed method; performance under default settings across consistent training epochs should be reported. Similarly, no simple baselines (Bayesian Networks, SMOTE with unconditional sampling) are included.
- TabDDPM’s poor performance on the News dataset (primarily numeric) is unintuitive and not explained. The ranking methodology is questioned: TabDDPM ranks second per-dataset but fourth on average; per-dataset ranks or modal/averaged ranks would be fairer.
- Use of MLE as a privacy metric is unconventional; the authors should justify this choice. No standard privacy metrics (e.g., DCR) or detection tests (e.g., C2ST) are provided.
- Confidence intervals in tables are not clearly explained (cross-validation vs. multiple sampling).
- Unclear if all classification tasks are binary; if not, AUC may not be an appropriate metric.
- Missing experiments: accuracy when using the latent code directly (without synthetic data generation); impact of replacing the MLP in the diffusion model with a Transformer; source of results in Figure 3 (training or validation set) should be stated.
- Code had a device attribute error and an index error when training with 40 samples, suggesting robustness issues with small sample sizes. The VAE training epoch default is 4000 (high) without an early stopping mechanism, although 100% train/val accuracy is reached by epoch 1000.
- The benchmark could be strengthened by adding more datasets from prior work (e.g., Kotelnikov et al. 2022) and testing on synthetic 2D examples to illustrate behavior.
