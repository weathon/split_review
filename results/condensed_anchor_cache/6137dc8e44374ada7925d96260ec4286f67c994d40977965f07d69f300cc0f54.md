## Merged Review

### Summary
The paper addresses Federated Continual Learning (FCL) where clients may face unrelated or antagonistic tasks. It proposes Accurate Forgetting (AF) via generative replay with Normalizing Flows (NF) to selectively forget biased or harmful features, using correlation estimation to weight old features. Experiments on image classification datasets (CIFAR100, MNIST-SVHN-F, EMNIST) show superiority over baselines, with code available. Reviewers find the concept novel and methodology solid, but raise significant concerns about problem formulation, privacy, experimental setup, and missing comparisons.

### Strengths
- Novel concept of “accurate forgetting” (AF) that challenges the assumption that forgetting is always detrimental; interesting and well-motivated.
- Broad and realistic problem setting (limitless task pool, LTP) allowing unrelated/contradictory tasks.
- Methodology is solid: uses Normalizing Flows for generative replay and correlation estimation to selectively weight features, effectively excluding biased features.
- Comprehensive experiments: multiple datasets (CIFAR100, MNIST-SVHN-F, EMNIST-Noisy, etc.), comparisons with several baselines, ablation studies, and computation analysis.
- Code is available.
- Paper is well-written and clearly structured.

### Weaknesses
- Problem formulation: Sections 3.1 and 3.2 spend excessive detail on FCL and LTP that are not the main contribution. “Biased features” is not formally defined. The word “task” is used ambiguously (sometimes referring to data domain rather than a common task definition like classification).
- Notation inconsistencies: in CL definition \(T^i\) and \(D^i\) both refer to datasets; index changes between CL and FL definitions; Eq. 1 has an incorrect final loss term.
- Empirical motivation in Sec 4.2 is limited: noise is applied only to the first three tasks, not at random or intermediate stages, which would be more realistic. The problems appear similar to concept drifts in federated learning; the paper should distinguish itself and cite relevant works (FEDDRIFT, ADAPTIVEFEDAVG, Flash).
- Privacy claims are overstated: “learning in feature space avoids the danger of leaking raw data” is not true without additional protection (e.g., differential privacy); raw data could potentially be reconstructed from feature space, and membership inference attacks are possible. Furthermore, AF-FCL allows each client to access a feature space distribution that includes information from all clients from the previous round, introducing a novel privacy risk not present in standard FL.
- The batch-wise feature weighting method based on correlation is relatively simplistic; orthogonal training techniques might be more nuanced. It is unclear whether a large distance in the NF latent space reliably indicates contradictory/harmful tasks – the correlation between distance and harmfulness needs empirical validation.
- Rationale for choosing Normalizing Flows over other generative models is not justified. The architecture, number of parameters, and communication cost of the NF model are not provided.
- Experimental setup limitations:
  * All experiments use image classification tasks, often from the same dataset split or closely related datasets (MNIST, SVHN). Even in LTP with EMNIST, letter classes may share features. Experiments on more diverse datasets like CIFAR-100 in LTP setting would be beneficial.
  * Number of clients is only 10.
  * Baselines FedAvg and FedProx without continual learning mechanisms show only about 8% forgetting, which may indicate poor current-task performance.
  * Non-iid simulation should use a Dirichlet distribution to be more representative.
  * More challenging datasets (e.g., ImageNet) and shuffled task orders for CIFAR-100 are recommended.
  * Comparison with recent baselines such as TARGET (ICCV 2023) is missing.
  * Memory size for memory-based baselines (GFCL, FLwF2T) is not reported.
  * Information on client participation, task transition timing (simultaneous vs independent), and data heterogeneity is missing.
- Additional concerns:
  * For tasks that are unrelated but not contradictory, the method may harmfully weight down previous knowledge.
  * If malicious (falsely labeled) data appears in the middle of the FL task, AF-FCL might forget prior correct data; the effects in such scenarios are unclear.
  * The paper should provide a more plausible real-world scenario where multiple different classification tasks are trained together in a single FL model rather than separate FL environments.
  * Forgetting in the NF model itself: how is it initialized and updated?
  * Communication cost for AF-FCL is not reported.
