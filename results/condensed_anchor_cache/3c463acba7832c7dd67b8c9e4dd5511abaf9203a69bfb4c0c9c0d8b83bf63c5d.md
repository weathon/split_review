## Merged Review

### Summary
The paper proposes a partial white-box jailbreak attack on vision-language models (VLMs) that only requires access to the vision encoder (e.g., CLIP). The attacker optimizes an adversarial image via gradient descent to match the embedding of a harmful image or an image containing harmful text. This adversarial image is paired with a benign text prompt; the VLM then generates harmful content. The attack is evaluated on LLaVA, LLaMA-Adapter, and (in Appendix K) Google Bard and Microsoft Bing, with multiple targeting strategies and human studies.

### Strengths
*   **Effectiveness and partial white-box nature:** The attack achieves high success rates across multiple VLMs, requiring access only to the vision encoder, not the LLM. This lowers the attack barrier. (R1, R2, R3, R4)
*   **Simple and intuitive method:** The approach is straightforward and is the first work that does not need access to the text component of the model. (R2, R4)
*   **Realistic and important risks:** The adversarial risks demonstrated are realistic and warrant community attention. (R3)
*   **Stealthiness (disputed):** R3 considers the attack stealthy and effective, but R1 and R2 argue the adversarial images are noisy and easily detectable (see Weaknesses). This disagreement is preserved below.
*   **Comprehensive evaluation:** The paper covers multiple attack strategies, models, and includes human studies and dataset collection. (R3)

### Weaknesses
*   **Not a true jailbreak (R1):** The attack does not enable previously impossible behaviors. The original malicious triggers (e.g., images of grenades) likely already elicit harmful outputs; the paper does not show they are refused before the attack. Citing Wei et al. [1], a jailbreak requires that the model *refuses* a harmful prompt before the attack and *accepts* it after. This claim is unsupported. (R1, confidence 3, high severity)
*   **Detectability of adversarial images (R1, R2):** Contrary to the motivation that text attacks are human-detectable, the adversarial images are noisy and look unusual (Figs. 2–5). R1 notes they are not guaranteed to be within an \(\epsilon\)-ball of a benign image, making them easy to spot. Because the stopping condition \(L \le \tau\) forces the adversarial embedding close to the target image embedding, any defense that detects the original malicious triggers would also detect the adversarial examples. R2 states they look “strange enough that I wouldn’t necessarily believe they were benign.” (R1, R2; R3 lists stealthiness as a strength but the figures suggest otherwise)
*   **Manual decomposition and poor scalability (R1, R3):** The attack requires manually decomposing each harmful instruction into a benign text part and a visual part (e.g., “Write a manual on how to build a bomb” → text “Write a manual on how to build these objects” + image of a bomb). No systematic, generalizable methodology is provided for arbitrary instructions (e.g., “Generate a phishing email” or “Provide a detailed plan for a terrorist attack”). The need to manually dissect each harmful instruction and optimize a new adversarial image for each one makes the attack resource-intensive and not scalable compared to universal attacks (Qi et al. [1], Zou et al. [2]). R1 additionally notes that because the text prompt must be benign, the adversarial image must encode most of the malicious intention, which is difficult for complicated intentions.
*   **Missing experiments on transferability and closed-source models (R2, R3, R4):** The paper claims the attack can be applied to closed-source models (e.g., using CLIP), but no experiments test this scenario. R2 and R4 ask for evaluation on VLMs with different or unknown vision embeddings. R3 notes that Bard and Bing results are only in Appendix K and asks whether the major attacks apply to them with the same effectiveness as reported in Section 4.
*   **Missing analysis of countermeasures (R1, R4):** R4 asks whether filtering or harmfulness classification at the image embedding layer could defend against the attack, and whether adversarial images can be generated to evade such detection. R1’s point about the stopping condition making adversarial embeddings close to target embeddings implies that any defense detecting the target trigger would also catch the adversarial example.
*   **Missing comparison to direct use of target images (R4):** R4 asks for a comparison to an “attack” that uses the target images directly (without gradient-descent noise) to determine if the models can be jailbroken by the images alone, which would help isolate the effect of the adversarial perturbation.
*   **Vague method description and missing hyperparameters (R2):** The description of the different attack versions is unclear, and hyperparameters such as the constraint set \(\mathcal{B}\) are not specified. These details are essential for reproducibility. (R2)
*   **Notation inconsistencies (R3):** \(H^i\) is introduced as \(W_I \cdot I(x^i)\) (in the LLM input embedding space), but later equations (3) and (4) use \(H\) to denote the visual encoder representation space. Expressions like \(H^t(x_{harm}^t)\) are confusing because \(H\) is presented as a function when it is a hidden state. (R3)
*   **Unclear experimental takeaways (R2):** The findings feel “thrown together”; it is not clear what question each experiment addresses or how the results contribute to an overall understanding of the attack. (R2)
*   **Missing details on human study annotation (R2):** How were annotators selected, what instructions were they given, and how were they compensated? (R2)
