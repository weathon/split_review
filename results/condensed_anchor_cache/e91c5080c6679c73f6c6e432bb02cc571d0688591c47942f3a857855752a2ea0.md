## Merged Review

### Summary
The paper introduces Multi-Agent Causality (MAC), a general framework for causal discovery that uses multi-agent LLM interactions. It proposes three models: Meta Agents Model (debate and reasoning among LLM agents), Coding Agents Model (agents plan, write, and execute code using statistical libraries), and Hybrid Model (combining both). Experiments on Auto MPG, DWD Climate, and Sachs Protein datasets report Structural Hamming Distance (SHD) and Normalized Hamming Distance (NHD). The idea is novel but evaluation and theoretical grounding are limited.

### Strengths
- First work to leverage a multi-agent LLM system for causal discovery (Reviewers 1, 3, 4, 5).
- The three-model framework (Meta, Coding, Hybrid) allows causal discovery from multiple angles (reasoning, statistical analysis) and provides structured debate and coding execution (Reviewers 2, 3, 4).
- Thorough evaluation using SHD and NHD across three datasets with varying complexity (Reviewer 2).
- Includes extensive comparison of diverse LLM models and an informative ablation analysis (Reviewer 3).
- Resource efficiency analysis (token consumption per model) offers practical insights for optimizing multi-agent frameworks (Reviewer 2).
- Meta-Debate module is designed to enhance LLM reasoning capabilities (Reviewer 5).
- Coding Agents model leverages statistical algorithms and internal LLM knowledge for more accurate discovery (Reviewer 5).
- Full graph discovery experiment using the latest LLM models (Reviewer 5).

### Weaknesses
- **Methodological novelty is limited:** Primary contribution appears to be applying multi-agent debating to causal reasoning, with much effort on prompt engineering; additional innovative aspects are unclear (Reviewer 3).
- **Lack of formal convergence guarantees:** No mathematical model defines or ensures convergence of agents' outputs to a stable causal graph; in high-dimensional settings this can lead to oscillating or suboptimal solutions (Reviewer 2).
- **Inadequate quantification of noise propagation:** No quantitative model of how errors in initial data or agentic decision-making propagate, especially in Coding Agents and Hybrid Models (Reviewer 2).
- **Ad hoc agent role and workflow justification:** Choices of debate vs coding agents and sequencing lack theoretical basis; no framework explaining why specific configurations should perform better on certain tasks (Reviewers 2, 3).
- **Scalability constraints:** Significant token and computational costs, especially in Coding-Debating Hybrid and Debating-Coding Hybrid models; no concrete solutions to reduce overhead (Reviewers 1, 2, 4).
- **Hybrid model does not consistently outperform:** The hybrid approach does not significantly beat other methods; performance depends heavily on dataset complexity, requiring tuning per dataset (Reviewers 1, 4).
- **Coding agents can enter debugging loops:** Handling longer/complex code or coordinating multiple agents can produce unexpected outputs needing extra debugging (Reviewer 4).
- **Experimental robustness insufficient:** Only three datasets used; LLM response stability not discussed; no statistical significance results provided (Reviewers 3, 5).
- **Generalizability unclear:** Performance on more complex causal structures, causal event identification, or diverse settings is not tested (Reviewers 2, 5).
- **Clarity issues:**
  - Distinction between “debate-coding module” and “coding agent” unclear (Reviewer 3).
  - Missing figure references (lines 463, 478, also “Figure ?”) and other formatting errors (empty citations, missing periods) (Reviewers 1, 3, 4, 5).
  - Rationale for Hybrid Model not explained (how coding agent enhances meta-agent, how prior knowledge from meta-agent is used by coding agent) (Reviewer 3).
  - “Agentic ability” and “multi-agent” in Table 1 are undefined (Reviewer 1).
  - Why Gemini 2 9b rows are empty in Table 2 (Reviewer 1).
  - The role prompt includes “Today is <current date>”—is this essential? (Reviewer 3).
- **Debating phase algorithm selection:** The method enumerates all causal discovery methods with functions and parameters; scalability and accuracy may degrade with more methods; no verification of assumptions behind algorithm recommendations (Reviewer 3).
- **Coding agent outperforms traditional algorithms on Sachs—unexplained:** Since coding agent just implements the algorithm chosen in debate, its performance should align with that algorithm; rationale for improvement is missing (Reviewer 3).
- **Ablation analysis gaps:**
  - Single-agent vs. Causal Agent Debate: what prompt is used for the single agent? If a single LLM handles both debating and judging, would performance be comparable? (Reviewer 3)
  - Eliminating the Judge: why not include GPT-4o mini comparison? (Reviewer 3)
- **Inference cost not considered:** Improvements in SHD/NHD may not justify the cost of multiple LLMs (Reviewer 1).
- **Relevant prior works not discussed:** e.g., multi-agent debate (ICML 2024), Causal Parrots (TMLR 2023), LLM4Causal (COLM 2024), causal evaluation (Reviewer 5).
- **Contrast:** Reviewer 1 (score 1) finds the work unimpressive, poorly written, with opaque experimental setup and insignificant benefits. Reviewers 3 and 5 (score 5) consider it a promising novel framework with strong performance and useful ablation, despite some clarity and robustness concerns. Reviewers 2 and 4 (score 3) note theoretical and scalability limitations.
