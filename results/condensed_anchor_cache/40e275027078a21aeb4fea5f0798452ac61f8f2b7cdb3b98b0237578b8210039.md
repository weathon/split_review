## Merged Review

### Summary
Reviewers recognize KGExplainer’s contributions: a model-agnostic, perturbation-based greedy search for synergistic path explanations, and a distillation-based evaluator for fidelity assessment. Strengths include theoretical scalability, concrete motivating examples (Alibaba-JD.com, Acetaminophen-Warfarin), and competitive F1@1/Recall@1 improvements over path-based baselines. However, reviewers raise significant concerns: the synergy concept lacks formal definition and optimality guarantees; scalability experiments are incomplete (missing degree distribution and memory footprint analysis); the human evaluation is limited to academics without domain experts; the evaluator’s quality and architecture are insufficiently analyzed; only KGE-based models are tested (not GNN-based KGC like Grail); retraining costs are not accounted for in runtime; and key experimental settings (e.g., hop size, evaluator inputs) are unclear. One reviewer (R2) was notably more critical on theoretical rigor and practical usefulness (soundness 2, contribution 2 vs. 3 from others).

### Strengths
- **Model‑agnostic design.** Can be applied to different KGE models (all reviewers).
- **Theoretical scalability justification.** Complexity depends on local parameters (path length *L*, number of paths *N*) rather than total graph size (Section 4.4), supporting application to large KGs with small average degree (R1, R2).
- **Novel distillation‑based evaluator.** Achieves predictive performance nearly matching the original KGE model (e.g., KGExp‑RotatE Hits@1 17.33% vs. RotatE 17.12% on OGB‑biokg, Table 1; R2) and is used to quantitatively assess explanation fidelity (R3).
- **Concrete motivating examples.** Figure 1 illustrates the need for synergistic paths via Alibaba‑JD.com competitor analysis and Acetaminophen‑Warfarin drug interaction (R2).
- **Consistent empirical improvements.** Outperforms prior path‑based explainability methods on multiple datasets, with substantial gains in F1@1 and Recall@1 (R3).
- **Human interpretability.** Reports 83.3% human evaluation accuracy (R2, though R2 also criticises the evaluation design).

### Weaknesses
- **Limited scalability experiments.** Discussion focuses only on average degree; lacks analysis of varying degree distributions, memory footprint, and how computational cost scales with total nodes/edges (R1). Retraining the KGE model is computationally expensive; greedy search efficiency alone does not guarantee overall scalability (R3). Discrepancy between theoretical scalability and large empirical runtime differences across datasets (Table 4) is not explained (R2 Q2; R3 Q2).
- **Lack of rigorous synergy definition.** The concept of “synergistic paths” is not formally defined; there is no information‑theoretic or formal analysis of what constitutes meaningful synergy versus independent supporting paths. The greedy search lacks optimality guarantees (R2). The paper does not provide empirical evidence for what fraction of predictions actually need multiple paths vs. a single path (R2 Q1).
- **Insufficient real‑world evaluation.** Human evaluation involved academics (students/professors), not domain experts or end users. No experiments on practical tasks like error analysis or model debugging; no case studies showing how synergistic paths provide better insights than single paths. Recommended user studies with domain experts (e.g., biomedical researchers for OGB‑biokg), case studies for correct/incorrect predictions, and concrete application scenarios (R2).
- **Human evaluation details missing.** Criteria given to participants, whether explanations were shown simultaneously or sequentially, and whether the 20 test cases were randomly selected or curated are not reported (R2 Q3).
- **Limited scope of models and structures.** Evaluation only covers KGE‑based models; GNN‑based KGC methods (e.g., Grail) are not tested. Explanations are restricted to paths; higher‑order structures (subgraphs, motifs) are not considered (R3).
- **Evaluator quality not dissected.** It is unclear how well the distilled evaluator captures the target KGE model’s decision process. Questions remain: How is its evaluation accuracy assessed? Does evaluator architecture (e.g., Grail‑style subgraph methods) affect robustness? Does input consist of graph structure alone or include pretrained embeddings? Are results consistent across different evaluator designs? (R3 Q1).
- **Unclear experimental settings.** It is not described how the distilled model’s predictive performance is measured—whether via retrained embeddings or subgraph input to the evaluator (R3 Q3). The effect of enclosed subgraph hop size is not studied; only hop = 2 is used, but FB15k‑237’s average shortest path length is ≈3, potentially missing long‑range dependencies (R3 Q4).
- **Retraining efficiency omitted.** The computational cost of retraining the KGE model is not included in the complexity analysis nor in the runtime comparison of Table 4 (R3 Q2).
