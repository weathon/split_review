## Merged Review

### Summary
This paper proposes MoE-Retriever, a model that retrieves embeddings for missing modalities in multimodal data by combining intra-modal context (from other samples with the same missing pattern) and inter-modal context (from available modalities) via multi-head attention and a sparse mixture-of-experts (SMoE) router. Experiments on medical and general datasets show improvements over existing methods.

### Strengths
- The missing modality problem is significant and well-motivated.
- The approach of leveraging intra-modal context (other samples) to impute missing modalities is intuitive and interesting.
- Using a sparse MoE architecture is reasonable for embedding selection.
- Extensive experiments on multiple datasets (medical: ADNI, MIMIC; general: CMU‑MOSI, ENRICO) with recent baselines (FuseMoE, MUSE, SMIL, etc.) demonstrate robust performance.
- Ablation studies are thoroughly performed (intra‑/inter‑modal context, number of experts, router design).
- Code is provided for reproducibility.

### Weaknesses
- **Limited novelty (all reviewers):** The model largely applies existing techniques (FuseMoE router, SMoE architecture) without substantial new design. The main addition is the intra‑/inter‑modal context. More adaptation of SMoE to the missing‑modality setting (e.g., how experts are selected based on modality groupings) is expected. One reviewer (score 8) was less convinced that the contribution meets the bar.
- **Serious presentation and clarity issues (reviewers 1, 3, 4):** Notation is confusing – Eq. (2) and (3) are ambiguous (e.g., set operations, matrix union not defined). The term “input token” is not clearly defined. Expert parameterization is missing. Inter‑modal context description lacks a concrete connection to the problem (e.g., early AD detection). English could be improved (vague phrases like “specialized knowledge”). A large margin appears on page 6. Reviewer 1 rated presentation 1/5; reviewer 3 and 4 gave 2/5 and 3/5 respectively.
- **Unfair comparison due to hyperparameter settings (reviewer 1):** Baselines used optimal hyperparameters from their original papers without re‑tuning on the target datasets, which may invalidate the reported improvements.
- **Potential attribution concerns (reviewer 2):** FuseMoE baseline results in Table 1 exactly match those reported in Flex‑MoE (Yun et al., 2024), and Fig. 3(a) appears to be a modified version of Fig. 2(c) from that work without citation. The source of these results and figures must be clarified.
- **Insufficient robustness and missing ratio analysis (reviewers 2, 3):** Results are only shown for a single dropout ratio (0.3 on CMU‑MOSI/ENRICO); no ablation across different missing ratios is provided. Support samples are selected randomly, potentially causing inconsistency – a similarity measure could improve retrieval. Data statistics on missing modalities (e.g., for MIMIC) are missing.
- **Limited evaluation metrics (reviewers 2, 4):** Only accuracy and F1 are reported, which are threshold‑sensitive. For imbalanced datasets like MIMIC, AUROC (used by MUSE) or PRAUC should be included.
- **Unexplained performance patterns (reviewer 2):** On CMU‑MOSI, using three modalities (V+A+T) yields worse performance than using two (A+T) across all models; no explanation is given. The computational efficiency plot (Fig. 4) shows MoE‑Retriever scaling up with more modalities while other methods stay flat – further insight is needed.
- **Lack of clarity on inter‑modal context mechanism (reviewer 1):** How the model uses available genetic/clinical data to infer early AD from missing imaging is not well‑defined.
- **Minor concerns (multiple reviewers):** (a) Appendix A.1.1 duplicates preprocessing text from A.1.2; (b) MIMIC dataset linkage to mortality registry should be explicitly stated; (c) No specific case study from MIMIC to interpret retrieval decisions; (d) The advantage of the method on medical vs. general datasets is not discussed; (e) Code for CMU‑MOSI experiments is not released.
