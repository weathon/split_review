## Merged Review

### Summary
The paper proposes PUMA, a unified MLLM that uses multi-granular visual features (from CLIP at multiple scales) as both inputs and outputs, with an array of diffusion decoders conditioned on scale-specific features. The model is pre-trained on generation and understanding tasks, then fine-tuned separately for each of four downstream tasks (text-to-image, editing, colorization, etc.). Reviewers acknowledge the interesting idea of multi-granularity for balancing diversity and control in generation, but raise significant concerns about task-specific fine-tuning, novelty, missing baselines/metrics, inference cost, and clarity of ablations.

### Strengths
- The idea of multi-scale visual features for targeting different generation tasks is original, useful, and a compelling step towards unifying generation and understanding (Reviewer 1, Reviewer 2, Reviewer 3).
- To the best of reviewers’ knowledge, this is the first work to combine multi-granularity image and text modeling in an autoregressive MLLM, which could spark future directions (Reviewer 2).
- The paper clearly states the problem of balancing diversity and control in MLLM-based generation, and the proposed solution is relatively simple, clean, and in principle straightforward to implement (Reviewer 4).
- Evaluations are thorough, and the visualizations of multi-granularity images are clear and look good (Reviewer 2, Reviewer 3).
- The paper is well written, well organized, and easy to follow, with detailed training and evaluation in the appendix (Reviewer 1, Reviewer 3, Reviewer 4).

### Weaknesses
- The main promise of a single integrated model is not fulfilled: the evaluated models are different checkpoints fine-tuned for each downstream task, not one model that balances tasks jointly (Reviewer 1; also noted by Reviewer 4 as inconsistent with the problem formulation).
- Missing FID metric for generative evaluation; the paper focuses on diversity and prompt adherence but bypasses standard quality measures (Reviewer 1).
- Missing comparisons to recent unified models that are fine-tuned jointly on generation and understanding tasks, such as GILL (Koh et al. NeurIPS 2023), Unified-IO 2 (Lu et al. CVPR 2024), and GenLLava (Hernandez et al. 2024) (Reviewer 1).
- Understanding is negatively affected by multi-granularity modeling: Appendix Table 5 shows that for half of the metrics performance worsens, one stays the same, and only one improves. The authors do not provide an intuition for this—e.g., whether the coarse features or the compute budget spent on them confuse the model (Reviewer 2).
- The ablation in Appendix C is unclear: were models trained with encodings from only a single granularity, or were other granularities removed at inference time? (Reviewer 2).
- The reconstruction improvement over previous methods may be due to the encoder/decoder combination rather than the multi-granularity learning itself (Reviewer 2).
- Limited novelty: existing works (SEED-X, Matryoshka) already explore multi-granularity visual features in MLLMs and image generation. The implementation simply uses different pooled visual features and separate diffusion decoders, which adds parameters and computation without introducing new techniques (Reviewer 3).
- In Table 1, PUMA uses (1+4+16+64+256) visual tokens, which is much larger than previous methods. When using the same number of visual tokens, PUMA underperforms compared to other methods (Reviewer 3).
- It is unclear whether the model can perform single-granularity or human-specified multi-granularity image generation during inference (Reviewer 3).
- Tables 3 and 4 should indicate the number of visual tokens used by each model for fair comparison (Reviewer 3).
- Inference is slow: the image feature sequence length is essentially doubled with redundant information, leading to a larger context and at least 2× inference cost for visual generation tasks (Reviewer 4).
- Model size is large because several SDXL UNet checkpoints (~2B parameters each) are needed, one for each feature granularity (Reviewer 4).
- The paper does not discuss how to select the feature scale for the final output; this is only vaguely mentioned in Appendix D but is a critical part of the generation flow (Reviewer 4).
- Is using multiple decoders necessary, or could a conditioning signal be used to tell a single decoder what type of inputs are being fed? (Reviewer 2).
- Reviewer 4 asks whether a more compact top-down representation (encoding only information not present in coarser levels) could be considered, and also asks for the authors’ opinion on using existing diversity-enhancing approaches for diffusion models (e.g., arXiv:2310.17347, arXiv:2310.12583) instead of multi-granular generation to address diversity needs.
