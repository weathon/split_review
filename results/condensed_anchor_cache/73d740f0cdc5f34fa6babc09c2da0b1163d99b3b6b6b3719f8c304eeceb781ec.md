## Merged Review

### Summary
RNAformer is an axial-attention-based deep learning model for RNA secondary structure prediction from a single sequence without MSAs or thermodynamic parameters. It employs a homology-aware data pipeline with multi-step filtering (CD-Hit, BLAST, covariance models) to avoid train/test leakage. The model achieves state-of-the-art performance on experimental data and is validated on synthetic data. Reviewers acknowledge the rigorous dataset construction and strong results, but raise concerns about the limited novelty of axial attention (adapted from AlphaFold2/MSA Transformer), insufficient justification for its use on single sequences, unclear methodological details (embedding, loss, data splitting), missing baselines and metrics (e.g., INF, e2efold), and questionable synthetic data design (using RNAfold as ground truth). Ratings range from 3 to 6, reflecting disagreement on the contribution's significance.

### Strengths
- **Rigorous homology-aware data pipeline** (R2, R3, R5): Three-step filtering using CD-Hit (≥80% similarity), BLAST-N with high e-value, and covariance models (LocaRNA-P/Infernal) to remove sequence and structure similarity. Distinct FT-Homolog and FT-Non-Homolog test sets allow structured evaluation of generalization.
- **Well-designed experiments with superior performance** (R2, R4): RNAformer consistently outperforms baselines, including thermodynamic models (RNAfold, Linearfold), and is validated on synthetic data against AlphaFold3. Careful data preparation brings DL performance to a realistic level comparable to traditional methods (R3).
- **Model simplicity and efficiency** (R1, R2, R5): Single sequence input, no MSAs or external features. Axial attention enables handling of variable sequence lengths with linear scaling. Reduced computational overhead and enhanced generalizability.
- **Validation via biophysical alignment** (R3): Demonstrating alignment of DL predictions to thermodynamic models like RNAfold is a useful validation approach.
- **Code availability** (R4): Code for the model is provided, though one reviewer (R5) found the link inaccessible.

### Weaknesses
- **Limited novelty of axial attention** (R1, R2, R3, R4): The axial attention (row- and column-wise self-attention) is nearly identical to that used in AlphaFold2’s Evoformer and MSA Transformer. The authors do not design the algorithm specifically for RNA data (R1). There is no inherent difference between rows and columns in a single-sequence input, so the motivation for axial attention over standard attention is unclear (R2, R4). The paper lacks justification for why this architecture is beneficial for secondary structure prediction from a single sequence (R4). One reviewer (R1) further states that the key technique was already proposed in 2019, and that rigorous data splitting is too common sense to be a significant contribution.
- **Insufficient explanation of key architectural components** (R2, R5):  
  * *Sparse adjacency loss*: Limited discussion of design choices, calculation (how paired/unpaired bases are selected, ratio), and its impact on handling sparse contact maps (R2).  
  * *Embedding process*: The description of row- and column-wise embeddings is confusing. It is unclear how the one-hot encoded sequence is transformed into a 3D matrix L^(0) and why it is called a 2D latent space. The mathematical expressions and textual explanation need clarification on weight matrices and dimensions (R5).
- **Missing baselines and metrics** (R2, R3, R5):  
  * On synthetic data, only AlphaFold3 is compared; models specifically designed for secondary structure prediction (e.g., MXfold2, SPOT-RNA, E2EFold) should be included (R2, R5). E2EFold is notably missing from Table 3 (R3).  
  * The INF (Interaction Network Fidelity) metric should be added (R5).  
  * The linear scaling results would benefit from comparison to other deep learning baselines (R3).
- **Data preparation and splitting need clarification** (R1, R3, R4, R5):  
  * The novelty of homology-aware splitting is considered "too common sense" by R1; others find the description vague. Specific parameters (e-value threshold of 0.1 for covariance models, CD-Hit similarity threshold) are not adequately justified (R3, R5). The selection of "50 random PDB samples" and construction of TS-Hard set are unclear (R4). Overlaps between FT-Homolog/Non-Homolog and Rfam sets need explicit statement (R4). The meaning of "2) only for TS-PDB" (line 291) is ambiguous (R4).  
  * The data splitting section (page 6) is confusing; the relationship between TS-PDB, TS-Hard, FT-Homolog, FT-Non-Homolog, and validation sets should be clarified (R3, R4).  
  * The deduplication tools should be referred to as CD-HIT-EST and BLAST-N, not CD-Hit and BLAST (R5).
- **Synthetic dataset design issues** (R3, R5):  
  * Using RNAfold-generated structures as ground truth is questionable because other energy-based methods (e.g., MXfold2) perform better (R5).  
  * Non-coding RNA families may have substantial sequence/structure similarity, potentially making the synthetic dataset flawed in theory (R3).
- **Other concerns**:  
  * Section 4.2.1 (“Impact of homology on prediction quality”) does not directly address the topic as it mainly compares to AlphaFold3 (R3).  
  * The paper does not enforce RNA secondary structure constraints (e.g., symmetry, no sharp loops) – the authors should discuss how they handle or enforce such constraints (R1).  
  * The code repository link provided in the paper is inaccessible; an updated link is needed (R5).
