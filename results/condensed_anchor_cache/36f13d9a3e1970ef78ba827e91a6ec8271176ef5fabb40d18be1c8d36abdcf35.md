## Merged Review

### Summary
This paper proposes a skeleton-based zero-shot video anomaly detection framework. It comprises two main components: a Language-Guided Typicality Modeling module that projects skeleton snippets into a semantic space and learns normal/abnormal distributions using an LLM, and a Test-Time Uniqueness Analysis module that examines spatio-temporal differences among skeleton snippets (cross-person and self-inspection graphs) to derive scene-adaptive boundaries. The model is trained on a human behavior dataset (e.g., Kinect-based action dataset) and achieves state-of-the-art results on ShanghaiTech, UBnormal, NWPU, and UCF-Crime without using target domain training data.

### Strengths
- Good attempt at leveraging both typicality and uniqueness, utilizing LLMs and test-time adaptability (R1).
- The Language-Guided Typicality Modeling module innovatively incorporates an LLM for normal/abnormal label classification, akin to human contextual judgment (R2).
- The analysis of skeleton snippets addresses temporal and spatial inconsistencies for cross-scene recognition; inference filters results based on proximity of spatiotemporal context graphs (R2).
- Achieves SOTA performance on four large-scale datasets (ShanghaiTech, UBnormal, NWPU, UCF-Crime) without using any training data from the target domain (R2, R4).
- Dual-graph computation: one graph captures motion relationships between adjacent individuals within the current data segment, another captures the motion state of the same individual across different data segments, providing a comprehensive understanding of human motion (R3).
- The model learns high-level semantic features, enabling better representation (R3).
- Using an action recognition dataset allows learning a wider range of behavior categories, leading to better generalization across scenarios (R3).
- The insights in test-time uniqueness analysis are appreciated (R4).
- Experiments are comprehensive and solid (R4).

### Weaknesses
- **Scene-adaptive anomaly definition**: Without any normal data, the task reduces to change detection based on prior knowledge of pre-defined actions; unusual but scene-normal behaviors (e.g., a person running in a normally quiet park, if regular) risk misclassification as anomalous. The model lacks the ability to learn scene-specific normal nuances (R1).
- **Lack of environmental context**: Using only skeleton data loses interaction information with the environment (e.g., picking up a prohibited item), limiting detection of complex anomalies in real-world surveillance (R1).
- **Heavy reliance on skeleton estimation and action recognition**: The rationale for skeleton-text alignment, the selection of typicality knowledge, and the process for learning typicality distributions are not adequately explained. Uncertainty in skeleton estimation, especially in crowded or occluded scenes, is not addressed. Reliance on pre-defined action categories limits generalization to novel anomalous actions (R1). Number of parameters, training, and inference costs should be reported (R1, R4).
- **Knowledge Collection robustness**: Classifying action class texts using a single prompt may not be feasible; what if the LLM classifies a normal behavior (e.g., riding a bicycle) as abnormal in the actual test set? The robustness of typicality scores when the LLM’s understanding diverges from dataset ground truth is questionable; reliance on a single prompt is overly simplistic (R2).
- **Skeleton-based method limitations**: The model struggles with detector/tracker issues and single-person stable motion scenarios (acknowledged in the appendix). Many real-world anomalies involve single individuals with subtle deviations. Skeleton extraction is affected by occlusions, lighting, and other environmental factors (R2, R3).
- **Originality of Uniqueness Analysis**: The Uniqueness Analysis during inference (filtering based on proximity of spatiotemporal context graphs) seems applicable to any skeleton-based method; the paper does not demonstrate a unique advantage over existing approaches. One reviewer (score 3, higher confidence) noted that this component lacks novelty and is essentially an extension of STG-NF [3] with language-guided and zero-shot capabilities (R2, R3).
- **Language-guided action learning is common**: Language-guided action learning is a standard technique in zero-shot action recognition (e.g., [1,2]); the method merely applies it to anomaly detection (R3).
- **Unfair backbone comparison**: The backbone is multi-scale CTR-GCN, while STG-NF uses ST-GCN; direct experimental comparison may be unfair. The authors should report performance on the popular VAD setting (R3).
- **Visualization quality**: The anomaly score font size in Figures 4 and 6 is too large, making the visualizations ugly (R3).
- **Paper clarity**: The paper is not well-written; many symbols and details are unclear (R4). Specific notation issues: (i) What does \(T\) in line 197 denote? The decomposition process and variables \(g_i, g_j\) and indices \(i,j\) should be described clearly. (ii) In typicality knowledge distillation, the equation appears to select the one skeleton sequence most similar to the text label per category; how does this address the challenges in Lines 225-227? (iii) In line 281, how is \(A_i\) associated with person graph \(p_i\) and timestamp \(t_i\)? The subscript confuses spatial and temporal indices. Symbols in Eq. (8) and (9) are unclear; person and timestep indexes use the same notation (R4).
- **Uniqueness scores ambiguity**: The uniqueness score would also be high if different normal actions exhibit low similarity/distance across timesteps; how does the method ensure that high distance accurately indicates anomaly? (R4)
- **Training dataset inconsistency**: The training dataset is inconsistent with previous methods; how does the author ensure equitability when comparing with other SOTA methods? (R4)
