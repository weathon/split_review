## Merged Review

### Summary
This paper studies residual error estimation for matrix and vector norms using linear sketches. For the matrix case (Frobenius norm), it provides a bilinear sketch $SAT$ of size $O(k^2/\epsilon^4)$ (improving the prior $O(k^2/\epsilon^6)$ from Andoni and Nguyen, SODA 2013) and a matching lower bound for bilinear sketches. The sketching matrices $S$ and $T$ can both be sparse (CountSketch). For the vector $\ell_p$ norm with $p>2$, the paper gives an upper bound of $\widetilde{O}(\epsilon^{-2p/(p-1)} k^{2/p} n^{1-2/p})$ for the sketch dimension, which also yields a $k$-sparse approximation; a lower bound of $\Omega(k^{2/p} n^{1-2/p})$ is shown for the sparse recovery problem. Experiments demonstrate speed advantages for the matrix case.

### Strengths
- Solves an interesting open problem and is technically solid (R1).
- High-level explanations in the paper help readers (R1).
- For matrix residual norm estimation, the bilinear sketch is optimal in size and, because sketching matrices can be sparse, fast to compute (R2, R3).
- Lower bound proof for matrix case uses minimum singular value separation (R2).
- The vector algorithm also outputs a $k$-sparse $\ell_p$ approximation that is optimal up to polylog $n$ factors (R2).
- Upper bound for residual vector estimation extends to $\ell_p$ sparse recovery, almost matching the lower bound when $\epsilon$ is constant (R3).
- Experimental results show at least ten times faster than the Andoni–Nguyen method for roughly the same sketch size and accuracy (R3).
- Paper is mostly well-written and easy to follow (R1, R2, R3).
- Use of projection-cost-preserving sketches to improve the Andoni–Nguyen result is novel and interesting (R4).
- Lower bound for matrix case is nice (R4).

### Weaknesses
- Improvement for the matrix case from $O(k^2/\epsilon^6)$ to $O(k^2/\epsilon^4)$ is incremental (R1).
- The practical usefulness of estimating residual error for $\ell_p$ sparse recovery ($p>2$) is limited (R1); one reviewer sees little interest for machine learning (R4).
- It is unclear how good the upper bound for residual norm estimation is compared to the optimal, because the given lower bound applies to the harder sparse recovery problem, not the norm estimation itself (R2).
- Dependence on $\epsilon$ in the vector upper bound $\widetilde{O}(\epsilon^{-2p/(p-1)} k^{2/p} n^{1-2/p})$ is not known to be tight (R2).
- Experiments only cover the low-rank approximation case; no experiments for residual error estimation of vector norms. Supplementing them would strengthen the paper (R3).
- **Use case for matrix residual estimation questionable** (R4):  
  – For dense data, the runtime difference between the residual estimate ($O(mn)$) and a rank-$k$ approximation ($O(mn \log k + (m+n)k^2)$) is not significant if $k \ll m,n$.  
  – In streaming, the method requires two passes (one for the diagnostic, a second for the actual low-rank approximation), and the low-space diagnostic is not useful if the actual approximation needs more space.
- **Use of CountSketch in numerical experiments is problematic** (R4):  
  – A test on a diagonal matrix $A = \operatorname{diag}(i^{-6} : i=1,\dots,10^4)$ with $m=50$, $k=20$ (as in Table 1) showed that CountSketch underestimates the residual error by a factor of **58**, whereas OSNAP (with just 2 nonzeros per column) underestimates by only a factor of 2.  
  – The introduction claims the method works with OSNAP (sparse embeddings), but this analysis is omitted from the main text; it should be included.  
  – The runtime comparison in Table 1 should be against a randomized low-rank approximation (e.g., randomized SVD or generalized Nyström with OSNAP), not a full dense SVD.
- **Practical significance of the improved $\epsilon$ dependence is limited**: An error estimate within a factor of two is often sufficient for the screening use case, so tightening the sketch dimension from $O(k/\epsilon^3)$ to $O(k/\epsilon^2)$ is not that meaningful in practice (R4).
- **Potential correctness issues**:  
  – **Lemma 3.2 proof appears flawed** (R4): The argument that $d_{TV}(S(G), S(G + \beta\sqrt{\varepsilon/k}\cdot wz^\top)) \le 1/10$ and scaling imply $d_{TV}(S(G), S(G + c\alpha\sqrt{\varepsilon}\cdot uv^\top)) \le 1/9$ is not convincing. The claim that $d_{TV}(X+Z,Y+Z) \le d_{TV}(X,Y)$ does not hold in general; a counterexample is given ($X=-Y=Z$ leads to $d_{TV}=0$ but $d_{TV}(X+Z,Y+Z)=1$). The authors should revise this proof.  
  – **Lemma 4.3 decomposition** (R2): The proof states $(I \cap J) \cup T_1 \cup \ldots \cup T_{m+1} = I$, but it may be that $i \in I \setminus J$ and $x_i > \|x_{-k}\|_p$ does not belong to any $T_i$. A suggested alternative decomposition is $J = (I \cap J) \cup T_1 \cup \ldots \cup T_{m+1}$, which would still give the same result.  
  – **Reliance on Lemma 5.2 of Price and Woodruff (2011)** for $p>2$ used in Lemma 4.10 has not been checked; it is not obvious that the result generalizes to $p>2$ (R2).
- **Typos** (R2):  
  – In Definition 3.4, $S$ should be $s \times n$.  
  – Proof of Theorem 3.7 should refer to Lemma 3.5 instead of Lemma 3.4.
- **Missing analysis**: It would be useful to know how good $SAT$ is as a rank-$k$ approximation compared to $A_k$ (R2).
