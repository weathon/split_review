## Merged Review

### Summary
This paper introduces the Kolmogorov–Arnold Transformer (KAT), which replaces the MLP layers in standard transformers with modified Kolmogorov-Arnold Network (KAN) layers, termed Group-Rational KAN (GR-KAN). The authors identify three key challenges in scaling vanilla KANs: (C1) B-spline base functions are not optimized for parallel GPU computation; (C2) KAN requires a unique function per input-output pair, leading to parameter/computation explosion; (C3) weight initialization is difficult due to learnable activation functions. They propose three solutions: (S1) rational functions replace B-splines for hardware efficiency, with a CUDA implementation; (S2) Group KAN shares activation weights across grouped neurons to reduce computation; (S3) variance-preserving initialization stabilizes training. Experiments on image classification (ImageNet-1k), object detection, instance segmentation (MS COCO), semantic segmentation (ADE20K), and graph/table classification demonstrate consistent improvements over ViT baselines within similar computational budgets. While the method addresses scalability and efficiency, the experimental scope is limited to vision tasks, and several components lack sufficient ablation and comparison.

### Strengths
- The paper tackles key challenges in integrating KANs into transformers (scalability, GPU inefficiency, parameter blowup, training instability) and proposes a practical solution (GR-KAN) with three concrete innovations: rational base functions, grouped parameter sharing, and variance-preserving initialization. (Reviewers 1,2,4,5)
- Replacing B-splines with rational functions significantly improves GPU compatibility; the CUDA implementation yields faster inference while maintaining expressiveness. (Reviewers 1,2,3)
- Group KAN elegantly reduces parameters and FLOPs via weight sharing over neuron groups; the re-expression as a specialized MLP is seen as clever and practical. (Reviewers 1,2,3)
- Variance-preserving initialization is identified as crucial for convergence; the analysis of instability in higher-order B-splines and the proposed initialization are valuable contributions. (Reviewers 2,3)
- Extensive experiments across image classification, object detection, instance segmentation, and semantic segmentation on large-scale datasets demonstrate consistent improvements over ViT of various sizes (T, S, B, L) with minimal training time overhead. (All reviewers)
- The paper is well-written with a clear narrative, each section is well-motivated, and technical details are balanced with intuition. (Reviewer 3)
- The topic is highly relevant, as improving the MLP component of transformers has received limited attention, and KANs are an emerging alternative. (Reviewer 4)
- The method is general and applicable to different transformer architectures (e.g., ViT, DETR), with sufficient implementation details provided. (Reviewer 5)
- A minority of reviewers found the contributions to be creative and practical, particularly the connection between KANs and rational neural networks. (Reviewer 3, partially Reviewer 1)

### Weaknesses
- **Missing ablation studies**: The paper does not isolate the contribution of each component (rational functions, grouping, initialization). Ablations comparing KAT with/without these parts (e.g., on ViT-T with accuracy & training time) are lacking. Also missing comparisons to simple KAN with only grouping, and to rational activation networks (e.g., Boulle et al.), which GR-KAN strongly resembles after the base function change. This makes it difficult to assess which element drives improvements and the true novelty. (Reviewers 1,3,4)
- **Insufficient initialization details**: The choice of parameters \(a\) and \(b\) for fitting rational functions to target activations is not explained with sufficient reproducibility. The optimization algorithm, loss function, and sampling scheme are unspecified. (Reviewer 3)
- **Undiscussed hyperparameters**: The number of groups and the maximum rational order \(m\) are not justified or analyzed experimentally. No study shows the effect of different group numbers on performance. (Reviewers 4,5)
- **Performance gaps**: KAT underperforms traditional architectures like ConvNeXt and SwinT on segmentation tasks (e.g., KATDet-S 41.5 vs ConvNeXt 41.7 and SwinT 41.6 in Table 4). (Reviewer 4)
- **Limited experimental scope**: No results on language processing or PDE solving (as in the original KAN paper). The claims of general superiority are not substantiated beyond vision tasks, and the applicability of GR-KAN outside vision is unclear. (Reviewer 1)
- **Novelty concerns**: A minority of reviewers consider replacing MLP with KAN in transformers an obvious direction, and the main contribution (rational functions over B-splines) as incremental, especially given the absence of comparison to existing rational activation techniques. (Reviewer 2, echoed by Reviewer 3)
- **Philosophical issue with KAN naming**: After replacing B-splines with a single rational function, the method no longer uses a composition of univariate functions (as per the Kolmogorov-Arnold theorem). Thus calling it a “KAN” is questionable. (Reviewer 4)
- **Contradictory statements**: The paper states that KANs require fewer parameters than MLPs (line 46) but later shows KANs require more parameters (lines 176-189). This inconsistency is not explained. (Reviewer 2)
- **Missing GPU timing and hardware details**: Table 1 reports only FLOPs; actual inference/forward time on a specified GPU is needed. Also GPU information for the image classification experiments is not provided. (Reviewer 5)
- **Unverified claim about speed**: The paper states KAN is “10x slower than MLPs” but does not specify the source or provide empirical support for this factor. (Reviewer 5)
- **Typographical and presentation errors**:
    - Eq. 2 top row right element should be \(\phi_{1,d}\) instead of \(\phi_{1,n}\). (Reviewer 2)
    - Line 433: “ViT-L + KAN fails to converge” should be ViT-B. (Reviewer 3)
    - Notation MSA and LN in Eqs. 5-7 not defined. (Reviewer 4)
    - Missing text in paragraph name line 485. (Reviewer 4)
    - The rational function multiplication count derivation (Appendix D) uses \(\frac{m(m+1)}{2}\) for exponent multiplications; correct is \(\frac{m(m-1)}{2}\) (as \(m=1\) yields 0 multiplications). This affects Table 1 and Appendix D values. (Reviewer 1)
    - Figure 3 shows graphs of activation functions but could be replaced by quantitative measures of fit. (Reviewer 3)
- **Unexplained gradient statement**: L248 claims the gradient computation is “similar to Monila et al.” but it is actually identical; the details are not used elsewhere. (Reviewer 3)
- **Missing code availability discussion**: No mention of plans to release the CUDA implementation or integrate it into PyTorch/JAX, limiting community impact. (Reviewer 3)
- **Unaddressed theoretical questions**: The paper explains KAT as learning univariate functions on edges (lines 146-147), but the output dimension is multivariate; this discrepancy is not clarified. Also, no theoretical explanation is given for the behavior described in lines 316-317 regarding parameter adjustment under different base functions. (Reviewer 1)
