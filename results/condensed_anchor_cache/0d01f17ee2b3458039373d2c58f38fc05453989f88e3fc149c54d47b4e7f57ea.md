## Merged Review

### Summary
This paper proposes JoPA, a counterfactual explanation framework for prompt attribution: identifying which tokens in the input prompt most influence an LLM’s generation. The task is formulated as a combinatorial optimization over a binary mask on prompt tokens, solved with an improved MCMC approach that uses gradient-guided masking and a probabilistic search (swapping one masked token per iteration). The method is evaluated on three datasets using Llama2(7B-Chat) and another LLM with BLEU, ROUGE, SentenceBert, and other metrics. The problem of joint token effects is real, and the local search shows some advantage over prior work. Strengths and weaknesses are noted with varying levels of reviewer agreement.

### Strengths
- The paper addresses an important and under-explored area: how input prompts collaboratively affect LLM generation, specifically the joint (interaction) effects of tokens.
- JoPA can search for combinations of multiple important tokens simultaneously, rather than scoring tokens independently.
- Time cost is lower than baselines; gradient guidance improves search efficiency.
- The experiment setup is reasonable, using a comprehensive set of evaluation metrics (BLEU, ROUGE, SentenceBert) across multiple datasets and models, and empirical results are positive.
- The paper is clearly organized and easy to read; the algorithm is described logically.
- There is a genuine advantage in the local search method for finding a better optimum compared to prior prompt attribution approaches.

### Weaknesses
- **Limited novelty and incremental contribution.** The method is essentially a standard discrete optimization (gradient-guided + MCMC-style swapping) already used in adversarial attacks (e.g., HotFlip) and attribution. While some reviewers find the problem important, others argue the contribution is insufficient for ICLR’s broad audience without demonstrating clear downstream impact (e.g., detecting toxicity, prompt compression, prompt optimization).
- **Theoretical guarantee is tautological and unconvincing.** The proof that the algorithm converges to a local optimum with enough iterations is trivial (local optimum defined by 1‑step swaps). It does not prove convergence in a bounded number of iterations, and it ignores how gradient information guides the search – an essential part of the method. The claim “solves the combinatorial optimization problem efficiently” (L434) overstates the result.
- **Missing baselines and comparisons.** Important baselines are absent: leave‑one‑out, attention‑based token importance (e.g., selecting top attention weights), or simple rule‑based methods (e.g., asking ChatGPT to identify important words). The 2024 paper ReAGent is mentioned but not experimentally compared.
- **Insufficient experimental evidence.** Only 110 samples per dataset are used – too few for statistical significance. The main body gives only a brief application description, and the appendix adds only two examples; the usefulness in concrete applications is not convincingly demonstrated.
- **Practical usage unclear.** It is not explained how a user would apply JoPA through a web‑service API (e.g., ChatGPT) that does not expose gradients or log‑probabilities. More general guidance for practitioners is needed.
- **Hyperparameter K is arbitrary and unexamined.** K (the number of masked tokens) is a critical hyperparameter; its relation to input length is not discussed, and there is no study of how it affects results. How was K chosen? How many tokens are typical in prompts? Could the search be safely limited to top‑2K tokens from initialization?
- **Sensitivity to initial mask.** Starting from different random masks (e.g., 0…01…1 vs 1…10…0), how often does the algorithm converge to the same final mask? Figure 4 suggests convergence is slow.
- **Explanation of core concepts is sometimes vague.** The difference between prior work (only next‑word prediction) and this paper (full generation) is not clearly distinguished. “Prompt attribution” is not defined at the outset, which may confuse readers new to the area. The counterfactual explanation logic is not fully explained, and the case study (Sec. 5.5) is not informative.
- **Questions about gradient computation.** When the mask is initialized as all‑ones, x and m⊙x are identical, so the loss would be zero and the gradient zero – how does the method obtain non‑zero gradients? Is the mask implemented as a learnable parameter? Figure 1 is too vague on this point.
- **Does not consider harmful content.** The method only measures output differences but does not address whether the identified tokens relate to unsafe or toxic model behavior; this could be an important application.
- **Formatting and writing issues.** Many typos and formatting errors: table headers (Tables 1, 2) do not follow ICLR template (headers above tables), missing punctuation in table captions, inconsistent capitalization (Llama2 vs LLaMA‑2), misaligned Figures 3 and 4, repeated “the the” (L118), “pipline” (L195), punctuation errors throughout. The narrative can be overly verbose and could be condensed.
