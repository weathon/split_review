## Merged Review

### Summary
This paper proposes a transformer-based image and video tokenizer, BSQ-ViT, using Binary Spherical Quantization (BSQ). BSQ projects high-dimensional visual embeddings to a lower-dimensional hypersphere, then applies binary quantization. It is parameter-efficient (no explicit codebook), scalable to arbitrary token dimensions, and compact (up to 100× compression). The tokenizer uses a transformer encoder/decoder with block-wise causal masking to handle variable-length videos. BSQ-ViT achieves state-of-the-art reconstruction quality on ImageNet and UCF-101, with 2.4× throughput over prior methods. It also obtains competitive video compression results against H.264/H.265, and enables masked language models to rival GAN- and diffusion-based image synthesis.

### Strengths
- **Novel and effective quantization method**: BSQ is a parameter-efficient, scalable alternative to VQ/LFQ, with proven bounded quantization error (reviewers 1, 3, 4).
- **Clear motivation and thorough theoretical grounding**: The paper explains BSQ well with mathematical derivations and places it in context of prior work (reviewers 1, 3, 4).
- **Strong experimental results**: BSQ-ViT achieves state-of-the-art image/video reconstruction (e.g., ImageNet rFID, PSNR, LPIPS) with significant speedup (2.4× throughput) (reviewers 1, 2, 4).
- **Generalizability across tasks**: The same tokenizer works for image and video reconstruction, compression (comparable to JPEG2000/WebP/H.264), and image generation (competitive with GAN/diffusion models) (reviewers 1, 3).
- **Presentation is coherent and easy to follow** (reviewers 3, 4).

### Weaknesses
- **Insufficient rate-distortion comparisons**: Table 4 reports only a single bitrate point (BPP, PSNR, MS-SSIM) for image/video compression. Standard compression papers require rate-distortion curves, BD-Rate metrics, and analysis at low/high bitrates (reviewer 2). Reviewer 3 additionally notes the lack of LPIPS for perceptual evaluation of compression (reviewer 3).
- **Fairness of ablation studies is contested**:
  - Table 5 ablation uses only ImageNet 128×128; more tasks (e.g., higher resolution, video) should be tested (reviewer 4).
  - The reproduction of LFQ (baseline) is poor in behavior and code usage, making it premature to conclude LFQ is less compatible with transformer codecs (reviewer 1).
  - To isolate the quantization bottleneck, experiments should freeze other network parts and train only the bottleneck; it is unclear if VQ/LFQ/BSQ used the same tokenizer in Table 5 (reviewer 2). Reviewer 4 similarly requests “Ours-VQ” comparisons like in Table 2 for image tasks.
- **Missing comparisons and controlled variables**:
  - No VQ/LFQ based methods are compared in image compression (reviewer 4). In video reconstruction (L389), BSQ uses more bits (18 vs 14) yet quality is only comparable to VQ (reviewer 4).
  - In image generation (Table 3), BSQ uses more steps than VQ/LFQ; what if same steps are used? (reviewer 4).
  - Limited comparative data in video reconstruction (reviewer 1). No experiment on BSQ without causal masking (reviewer 1).
- **Lack of complexity details**: Computation complexity and encoding/decoding times are not provided (reviewer 2).
- **Transformer resolution limitation**: Fixed patch size and quadratic self-attention cost limit resolution flexibility; model handling of non-multiple patch sizes (padding/resizing) is not discussed (reviewer 3).
- **Some weaknesses are less severe but noted:**
  - When BSQ and VQ use the same number of indexes, BSQ performs less effectively, and codebook utilization decreases as bits increase (reviewer 1).
  - No arithmetic coding used for image compression (reviewer 3’s question: why not? This overlaps with missing efficiency analysis). Video compression: is intra-frame information used? If not, why? (reviewer 3).
  - Typos and missing derivations: Eq. (7) may need factor 2; page 16 line 837 has denominator typo; page 3 line 118 uses same symbol for downsample factor and bottleneck module; Eq. (13) derivation not provided; line 878 and 886 have symbol errors (reviewers 3, 4).
- **Minority reviewer (reviewer 2) is more negative**: emphasis on missing rate-distortion curves, ablation setting flaws, and complexity; they rated the paper 5, while others rated 6. This contrast should be preserved.
