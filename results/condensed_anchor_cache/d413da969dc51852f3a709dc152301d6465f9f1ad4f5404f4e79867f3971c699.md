## Merged Review

### Summary
The paper studies transfer learning in linear regression under both underparameterized and overparameterized regimes. Features are partitioned into a common (shared) part and a task‑specific part. Two parameter‑transfer options are analyzed: Option A directly copies the learned common parameters to the target task and trains only task‑specific parameters; Option B uses the learned common parameters as an initialization and fine‑tunes all parameters on the target. The paper derives generalization error formulas, characterizes benign overfitting, and provides guidelines—e.g., when the total number of source features is fixed, it is more beneficial to allocate redundant features to the task‑specific part rather than the common part; and under high noise and small true parameters, sacrificing some common features for additional task‑specific redundant features can improve performance. Experiments support the theoretical claims.

### Strengths
- Analyzes target generalization error as a function of the number of common/task‑specific features, noise variance, and characterizes benign overfitting regimes. (R1, R2, R3, R4)
- Provides practical insights into choosing transfer methods under linear regression, such as the advantage of allocating redundant features to the task‑specific part. (R1, R2, R4)
- The motivation is clear and the analysis is concise. (R4)
- **Minority reviewer (R3) is much more positive**: found the paper to present a much‑needed theoretical analysis of interesting parameter‑transfer scenarios, with contributions that are original and significant for transfer learning researchers. R3 rated the paper as 8/10 (excellent soundness, presentation, contribution) and praised it as very well‑written, clearly structured, with experimental results that support the theoretical claims. The other reviewers gave scores of 3, 3, 5 (fair to good soundness, fair/poor presentation and contribution). The contrasting view from R3 is explicitly noted.

### Weaknesses
- **Restrictive model assumptions** (R1, R4): The model is only linear, assumes exact shared features exist and are known *a priori* (reviewers point out that in practice one cannot directly separate common and task‑specific features). The source and target training examples are assumed to contain these exact shared features; a previous study (R1 cites [1]) shows transferability can occur without exact feature overlap if ground‑truth parameters are close in Frobenius norm. (Severity: high; R1 confident, R4 fairly confident.)
- **Unrealistic feature separation**: Options A and B explicitly assume we know which features (e.g., \(w\)) are common and which (\(q\)) are task‑specific. In real applications this is unknown; a more practical “Option C” would use all learned features as initialization. (R4; severity: high.)
- **Lack of novelty and simplicity** (R1, R4): The problem setup is simple and unsurprising; conclusions depend heavily on the made assumptions. The paper only considers one source supervised task, whereas practice often involves multiple source tasks or self‑supervised learning. (R4; severity: high.)
- **Lack of deeper insight** (R1): The paper derives formulas and describes how error changes with parameters but does not provide intuition *why* these changes occur—the analysis does not go beyond algebraic relationships. (Severity: moderate; R1 confident.)
- **Unclear contributions relative to existing literature** (R2): The paper should specify which prior works it compares to when discussing related results. (Severity: moderate; R2 confident.)
- **Undefined or unclear terms** (R2): Formal definitions of “generalization performance”, “transferring errors”, “benign overfitting”, and “descent floors” are missing. Specifically, the “transferring error” in Theorem 1 needs a formal definition. (Severity: moderate.)
- **Naming of “Option A” and “Option B” is not descriptive** (R3): Even the positive reviewer (R3) notes that the current names offer little insight into the actual transfer mechanism, making it hard to intuitively connect theoretical findings with practical implications. (Severity: moderate; R3 fairly confident.)
- **Unclear transfer step** (R2): The second step (“extract and transfer the learned parameters of the common features”) needs elaboration. (Severity: moderate.)
- **Claim of Proposition 4 is not significant** (R4): It merely states to keep only common features, providing no new insight. (Severity: moderate.)
- **Missing discussion of connections** (R3, R2): The paper does not connect to well‑known multitask learning theory (e.g., Baxter 2000) or discuss whether insights extend to deep neural networks. (Severity: moderate.)
- **Missing extension to more realistic scenarios** (R1): The paper should consider cases where initially no exact shared features exist, but an unknown transformation can reveal them, or where parameters are close but not identical. (Severity: moderate.)
- **Writing issues** (R4): Assumption 1 should be Definition 1; \(\mathcal{R}\) and \(\mathbb{R}\) are mixed. (Severity: low.)
- **Clarity of “missing features”** (R4): Remark 1 is unclear—a toy example would help. (Severity: low.)
