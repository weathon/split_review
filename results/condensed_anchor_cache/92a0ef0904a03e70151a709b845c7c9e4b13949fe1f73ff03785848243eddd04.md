## Merged Review

### Summary
The paper introduces Marlene, a deep neural network for inferring dynamic gene regulatory networks (GRNs) from time-series single-cell RNA-seq data. It uses self-attention mechanisms with weights that evolve over time via recurrent units (GRUs), and meta-learning (MAML) to improve recovery for rare cell types. The output is a series of directed weighted graphs representing GRNs at each time point, evaluated on three biological datasets (SARS-CoV-2 vaccination, aging, and lung fibrosis) by comparing predicted edges against curated databases (TRRUST/RegNetwork) using Fisher’s exact test and overlap analysis. Reviews are split: one reviewer (score 8) considers the work very solid and comprehensive, while three reviewers (scores 3, 3, 3) find major issues in justification, evaluation, biological validation, and missing comparisons.

### Strengths
- **Task importance and data relevance.** The paper targets an important, well-studied problem (regulatory network inference) using time-series single-cell data, a rapidly growing and information-rich data type.
- **Novel architecture design.** The approach introduces a self-attention mechanism where the projection matrices (query/key) are evolved via a GRU (EvolveGCN-inspired) to capture temporal dynamics—this goes beyond simple application of existing deep learning models.
- **Handling multiple cells per time point.** Marlene uses a pooling-by-multihead-attention (PMA) layer from Set Transformer to convert cell-level expression into a gene feature matrix, eliminating the cell axis and enabling focus on gene-gene attentions.
- **Meta-learning for rare cell types.** The use of MAML (treating cell types as tasks) is a smart way to handle heterogeneous cell populations and improves accuracy for rare types.
- **Clever surrogate task.** Training the model to predict cell type labels from the reconstructed expression is well-motivated: single-cell data is noisy, so predicting labels is more robust than full reconstruction; the adjacency matrix emerges as an intermediate representation.
- **Sparsity control via top‑k edges.** The method of constraining the adjacency matrix to the top‑k edges is practical and helps focus on strong interactions.
- **Strong empirical results on three diverse datasets.** Marlene is shown to outperform both static and temporal baselines in recovering known interactions and identifying relevant biological processes.
- **Comprehensive experiments (minority positive reviewer).** One reviewer (score 8) highlights that the experiments are solid, the method description is clear, and the logic flows well.

### Weaknesses
- **Limited justification that the attention matrix equals the adjacency matrix.** The assumption that the self-attention matrix (A) generated within the model directly captures directed regulatory interactions is not well justified. Would a matrix of different dimensionality (e.g., different number of rows) produce similar performance on the surrogate task? The use of softmax over rows and why this corresponds to a GRN is not explained.
- **Insufficient evaluation metrics and baselines.**
  - Missing AUROC and AUPR values for network-wide edge discovery. The justification that ground truth is too small is unconvincing; these metrics are standard and should be reported despite limitations.
  - No comparison to other dynamic GRN inference methods, notably Dictys (dynamic GRN with single-cell multiomics), nor to methods like BEELINE using time-series datasets (e.g., hESC). A comparison with diverse modeling approaches (ODE-based, Bayesian networks, etc.) is needed.
  - The surprisingly large performance gap between Marlene and alternatives is not explained; all methods perform largely the same task with only minor tweaks.
- **Evaluation overly reliant on static databases.** Overlap analysis uses static, incomplete interaction databases (TRRUST/RegNetwork). Direct experimental validation of novel time-varying predictions (e.g., via CRISPRi/a screens, perturbation assays with scRNA-seq) is lacking. The inferred GRNs should be validated by identifying known key TFs/targets and their functional consequences.
- **Missing biological interpretation of dynamic networks.** The paper does not provide concrete examples of how the time-varying GRNs relate to known pathways, regulatory mechanisms, or biological processes. Merely stating that the model recovers known interactions is insufficient; the functional impacts of the dynamic changes should be discussed.
- **Unclear handling of multiple adjacency matrices for evaluation.** The output is a matrix per time point, but evaluation seems to require a single static network. How are the multiple A^t combined (average, intersection, other)? This needs explicit explanation.
- **Clarity and justification of the GRU mechanism (Eq. 3–6).** The rationale for using a GRU to update the self-attention weights (rather than the gene embeddings themselves) is not well explained beyond citing EvolveGCN. How is the hidden state initialized? Does the GRU capture meaningful temporal dynamics or act only as a complex weight update? The physical meaning of these operations is unclear.
- **Algorithm stability not addressed.** BEELINE considers stability a key metric. How stable are the inferred top‑k edges across different initializations? A quantitative analysis of variability across runs is needed for reliability.
- **Scaling and computational limitations.**
  - Quadratic memory from adjacency matrices forces gene filtering in experiments; a detailed complexity analysis (memory/time as a function of genes, cells, time points) is missing.
  - Performance on datasets with more time points or irregular intervals is untested; the current datasets have only 3–7 time points.
  - Sensitivity to hyperparameters (number of attention heads, hidden units, depth) is not analyzed.
- **No ability to predict perturbation effects.** The model cannot simulate TF knockouts or other interventions, which is a key downstream use of GRNs. Extensions to incorporate interventional data or causal inference are not discussed.
- **Lack of analysis of strength and directionality.** While Marlene outputs weighted directed graphs, evaluation focuses on edge presence/absence against static databases; no analysis of how well the model captures interaction strength or directionality.
- **Handling of technical noise and batch effects not discussed.** No mention of preprocessing steps (normalization, batch correction) or robustness tests.
- **Questions from reviewers overlapping with weaknesses:** (1) Would removing the recurrent part (applying Marlene per time point independently) substantially affect performance? (2) How does Marlene perform on BEELINE multi-timepoint datasets using their EPR/AUPRR metric? (3) How is the model sensitive to dataset size (cells, genes)? (4) Can the method be evaluated in a way that tests real downstream utility beyond static overlap? (5) What explains the extremely large performance differences between Marlene and other methods?
