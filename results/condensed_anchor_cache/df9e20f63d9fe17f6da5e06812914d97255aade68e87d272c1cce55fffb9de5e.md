## Merged Review

### Summary

The paper proposes Fast Multipole Attention (FMA), a self-attention mechanism that reduces quadratic complexity to \(O(n \log n)\) or \(O(n)\) via a hierarchical divide-and-conquer strategy. Queries attend to local neighbors at full resolution and to farther tokens at exponentially lower resolutions, where low-resolution tokens are computed using learned strided convolutions or grouping. Experiments on autoregressive (enwik8) and masked language modeling (Wikitext-103) with sequence lengths up to 2K show FMA outperforming several efficient attention baselines in accuracy and memory.

### Strengths

- The proposed method is conceptually simple and intuitive (R1). The motivation for efficient attention via hierarchical structure is reasonable and the scheme is interesting (R2).  
- Controlled testing is performed: same model architecture with different attention implementations on real-world language modeling tasks (R1).  
- The paper is well written with a comprehensive review of related works (R1).  
- One reviewer (R2) notes that an ablation study is conducted to support efficiency; however, another reviewer (R1) criticizes the lack of ablation on hyperparameters (see Weaknesses).  
- Multi-resolution analysis is a powerful but less explored tool for approximation (R3).  
- Unlike sparse attention variants, FMA provides a global receptive field due to multiple resolutions (R3).  
- The method supports causal attention, which is useful for auto-regressive large language models (R3).

### Weaknesses

- **Missing critical baselines:**  
  - The vanilla (full) transformer is not included in any experiment (R1, R3). The setup uses only 6 layers, while e.g., Reformer uses 12 layers and achieves 1.19 bpd on enwik8. Comparison with vanilla transformer and FMA at larger sizes is needed (R1). Fused full attention like Flash Attention should also be compared for both performance and efficiency (R3).  
  - The work [1] (MRA attention) uses almost the same idea of multi-resolution approximation. The paper does not discuss the difference from [1] nor provide efficiency and accuracy comparisons on enwik8/Wikitext-103/GLUE/LRA/WikiHop (R2). Comparison with other multi-resolution approaches (MRA attention) is limited (R3).  
  - Memory Compressed Transformer (dividing cost by ~3) is not compared, though it would be sufficient for the tested sequence lengths (R1).  
  - The paper should compare approximation quality with low-rank or kernel approximation baselines (R3).  

- **Insufficient ablation study:** There is no ablation on hyperparameters such as group size \(m\) and number of levels, nor their effect on performance, FLOPs, and memory (R1). (R2 states an ablation study is conducted, creating an unresolved disagreement.)

- **Error analysis too rudimentary:** Section 3.6 only analyzes error between \(QK^\top\) and \(Q\tilde{K}^\top\), but does not quantify how this error propagates through softmax and value projection to the final output (R3). The theoretical analysis is not as sound as [1], which provides explicit approximation error bounds (e.g., Proposition 4.5) (R2). A more detailed analysis of error at each stage is needed (R3).

- **Experiments limited to short sequences:** Only sequence lengths 512, 1K, and 2K are tested. Full self-attention is still efficient at these lengths, and the efficiency benefits of FMA are not demonstrated for truly long sequences (4K, 8K, 16K) (R3).

- **Efficiency comparison with batch size 1:** Kernel launch and memory latency may dominate. Larger batch sizes (32, 64, 128) should be used to demonstrate scalability (R3).

- **Potential implementation bug:** A reviewer suspects that causal linear attention requires more memory than the non-causal version, which may indicate an implementation issue (R1).

- **Missing details:**  
  - Does FMA support KV cache during inference, and does it introduce overhead? Was KV cache used when profiling inference time in Figure 3? (R3)  
  - How were autoregressive experiments performed on baselines (Linformer, Nystromformer, H-Transformer) that do not natively support causal attention? (R3)  

- **Need for clarity on difference from [1]** (R2) and comparison with its theoretical guarantees (R2).
