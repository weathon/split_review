## Merged Review

### Summary
This paper proposes a causality-based alignment framework to align a model's decision process with that of experts in disease diagnosis. It uses counterfactual generation to identify image regions that causally determine the model's decision and introduces a causal alignment loss that matches these regions (and, when available, attribute descriptions) to expert annotations. The loss is optimized via the Implicit Function Theorem and conjugate gradient. The method is evaluated on two medical datasets (LIDC-IDRI, CBIS-DDSM) and shows robustness to spurious correlations.

### Strengths
- Uses counterfactual generation to identify regions that causally determine the model’s decision, maximizing the probability of causation (R1).
- Introduces a causal alignment loss and an efficient gradient estimation algorithm using the Implicit Function Theorem and conjugate gradient (R1, R2, R4).
- Significant improvement over baselines in CAM precision and classification accuracy; effectively distinguishes spurious correlations from true causal factors; results are compelling (R1, R3: Table 1, Figure 4).
- Problem is relevant, timely, and the argument for leveraging causal structure in alignment is well-put (R3).
- High novelty and quality of the causal alignment loss and optimization; high significance for medical treatment planning (R4).
- Presentation is concise, theory is clearly explained, numerical experiments are solid with detailed implementation and baseline comparisons (R2).

### Weaknesses
- Attribute subset selection via maximizing CCCE lacks theoretical justification: if an attribute is not a cause of Y, the CCCE would be the same for the true causal subset and any superset (including the full set). The method works in practice only because the datasets contain at most six attributes (R1).
- The claim that previous gradient-based methods capture only associational factors (lines 37–40) is later attributed to limited effectiveness of gradient approaches (lines 405–407). The simulation (Figure 1a) does not explicitly demonstrate the advantage of causal over associational factors when expert annotations are used (R1).
- Figure 3 should clarify that A_{1:p} represent experts' *decisions* about attributes, not the underlying true attributes. How the area marks m fit into the causal diagram should be explained further (R1). Additionally, the diagram implies attributes are independent conditional on X (mass), but latent variables or feature overlap could violate this; the model should be presented as a heuristic (R3).
- The loss function in line 194 is not directly optimized; Algorithm 1 shows a two-step process (first find x_i* by minimizing L_ce, then find θ by minimizing L_align). This optimization procedure needs clarification (R1).
- Computation time compared to baselines is not provided (R1).
- Scalability concerns: the counterfactual generation assumes binary y*; for multiple classes or continuous y*, binning may lose granularity. The hierarchical alignment requires CCCE calculation over attribute subsets, which is problematic for high-dimensional attributes (R2).
- Causal search algorithms exist that could infer similar causal structures but are not compared or discussed; the paper should state why they are not pursued (R3).
- The method does not address cases where multiple masses occur in a single image (R3).
- The model class (e.g., mixed linear Gaussian/discrete) is not explicitly stated (R3).
- Figures 1b and 2 use terms "calcification," "margin," "spiculation" without explanation of whether these are binary attributes; captions need clearer descriptions (R4).
- The distance function in Equation (2) is not discussed; its choice affects counterfactual generation and downstream performance. No ablation or discussion is provided, though common and prior alternatives (squared Euclidean, scaled squared Euclidean, scaled L1 norm) are available (R4).
