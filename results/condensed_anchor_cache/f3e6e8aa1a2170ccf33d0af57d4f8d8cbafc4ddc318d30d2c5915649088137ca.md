## Merged Review

### Summary
This paper addresses node selection in Branch-and-Bound (B&B) for Mixed Integer Linear Programming (MILP). It proposes a Tripartite Graph Neural Network with Reinforcement Learning (TRGNN). The tripartite graph represents the B&B tree by combining a bipartite graph from the root MILP with leaf-node features; the authors provide a theoretical proof (via mutual information) that this representation is sufficient for node selection. A reinforcement learning (RL) framework models node selection as an MDP with a reward function comprising global gap updates, potential for optimality, and path-switching overhead. Experiments on six NP-hard MILP benchmarks show that TRGNN outperforms human-designed heuristics and learning-based baselines, and generalizes to larger instances. One reviewer (score 8) is notably more positive, praising the compact representation and benchmark performance, while other reviewers (scores 6) raise concerns about benchmarking methodology, computational complexity, and missing ablations.

### Strengths
- **Novel tripartite graph representation** that integrates the MILP problem structure (bipartite graph) with global B&B tree information, theoretically proven to contain sufficient data for optimal node selection via mutual information. (Reviewers 1,2,3,4)
- **Compact representation** that bundles principal relaxation features into a common bipartite graph and only encodes changes for leaf nodes. (Reviewer 3)
- **Reinforcement learning for node selection** that learns from delayed rewards, improving over imitation learning and expert-designed heuristics. (Reviewers 1,2,4)
- **Comprehensive reward function** with three components (global gap updates, potential for optimality, path-switching overhead), enabling more informed node quality assessments. The path-switching component is noted as interesting for other node selection methods. (Reviewers 1,3,4)
- **Strong experimental performance**: TRGNN achieves up to 59.42% reduction in solving time and outperforms recent machine learning algorithms and the state-of-the-art best estimate rule. (Reviewers 1,4)
- **Generalization to larger MILP instances** beyond those seen during training. (Reviewer 4)
- **Efficient learning** requiring fewer training samples than conventional models. (Reviewer 4)
- **Well-organized paper** with clear structure: first explains the tripartite graph and its sufficiency, then the RL framework and MDP components. (Reviewer 1)
- **Attention to SCIP version differences**, often neglected in comparisons. (Reviewer 3)

### Weaknesses
- **Theoretical sufficiency assumptions are not general**: The proof assumes a Markov mapping between parent and child nodes, which does not hold in modern Branch-and-Cut solvers (e.g., SCIP) due to restarts, cut pools, and arbitrarily added external information. The representation has no features to account for cutting planes. The sufficiency condition should be qualified for traditional B&B only. (Reviewer 3)
- **Benchmarking methodology is flawed**: The model is trained and tested on instances of the same problem type, whereas SCIP’s node selector is general (one-size-fits-all). This does not demonstrate that TRGNN is a better _general_ node selector. Comparing against an exact solver for specific domains (e.g., a MAXSAT solver) or benchmarking a single selector across all problem domains is needed. The claim “significantly outperforms human-designed and learning-based baselines” is not fully supported because the evaluation standard differs. (Reviewer 3)
- **Computational complexity of the tripartite graph** is not adequately analyzed. The tripartite representation increases graph scale, storage, and computational overhead compared to simpler representations. Memory footprint (node/constraint/leaf features, adjacency matrices) and time to construct and update the graph during B&B are not discussed. The paper should assess how these costs are compensated by performance gains, and quantify the specific contribution of the MILP bipartite part. (Reviewers 2,4)
- **Dependence on a heuristic for candidate node pre‑selection**: Each action requires a heuristic algorithm (truncation to top‑n “best estimate” nodes) to generate candidate nodes. The time complexity and quality of this heuristic, especially on larger MILPs, are not given. It is unclear whether the model improves over the heuristic alone (a comparison is missing). Additionally, the truncation hyperparameter (k<n) is not analyzed; recording the distribution of picked positions would show the impact of truncation and the method’s dependence on the best-estimate heuristic. (Reviewers 1,2,3)
- **Baseline comparisons are limited**: The paper omits recent state-of-the-art MILP solving techniques beyond node selection, newer GNN architectures (attention mechanisms, graph transformers), and advanced RL methods. Using a higher-performance solver like Gurobi would increase credibility. (Reviewers 2,4)
- **Missing ablation studies**:
  - No ablation of the tripartite graph representation versus simpler bipartite or other versions. (Reviewer 4)
  - No ablation of the path‑switching reward component. (Reviewer 3)
  - No sensitivity analysis of key hyperparameters (RL reward weights, graph convolution layer parameters). (Reviewer 4)
- **Implementation and practical details are insufficient**: Training time, hardware requirements, and deployment challenges are not reported. For Table 2, it is unclear whether geometric or arithmetic means are used (the text says geometric, the table says arithmetic). (Reviewers 3,4)
- **Figure 2 is hard to read**: It contains an apparent circular dependency (“n nodes”, TRGNN, “Q‑values”) and is not self‑explanatory without the main text. (Reviewer 3)
- **Related work is incomplete**: Two relevant papers are missing – “Learning to branch with Tree MDPs” and “Reinforcement Learning for Node Selection in Branch-and-Bound”. (Reviewer 3)
- **Presentation clarity issues**: The paper lacks definitions for key terms (e.g., “leaf node vertex”, the LN set) and concrete examples explaining the graph conversion and edge features. (Reviewer 1)
- **Limited applicability discussed**: The paper focuses solely on MILP and does not consider adaptation to other optimization problems (e.g., MINLP, constraint satisfaction). (Reviewer 4)
- **Potential bias from pre‑selected candidate nodes**: The reward function may inherit bias from the heuristic candidate pool, and it is unclear how this is accounted for when comparing to machine learning baselines that do not use such pre‑selection. (Reviewer 2)
