## Merged Review

### Summary

This paper addresses noisy data pruning, proposing a two-stage robust pruning method (RoP). In the first stage, it identifies clean samples using a Neighborhood Label Inconsistency Score (NLI-Score) computed via feature propagation and label propagation. In the second stage, it re-labels the selected subset using existing noisy label learning methods (SOP+) and employs density-based coverage sampling to balance easy and hard samples across pruning rates. Experiments on real-world and synthetic noisy datasets show SOTA results compared to existing baselines. Reviewers’ scores are 5, 3, 3, 1, indicating strong disagreement on overall quality.

### Strengths

- **Innovative NLI-Score** for identifying noisy samples by leveraging neighboring sample consistency (Reviewer 1).
- **Effective combination of feature and label propagation** to reduce selection bias in noisy scenarios (Reviewers 1, 2).
- **Addresses a practically important problem** – noisy data pruning for real-world applications (Reviewer 3).
- **Achieves SOTA results** against existing baselines (Reviewer 3).
- **Extensive experiments** across multiple datasets, including real-world noisy benchmarks and synthetic noise (Reviewers 1, 4).
- **Well-organized presentation** – clear methodology, experiments, and conclusions (Reviewer 4; minority positive).

### Weaknesses

- **Lack of originality**: The method merely applies existing techniques from noisy label learning (e.g., feature propagation [1-4], label propagation [5-6], SOP+ for re-labeling, Coverage Coreset sampling) to data pruning, limiting novelty (Reviewers 2, 4).
- **Missing comparison with noisy label learning methods** – many existing methods could be easily adapted to the scenarios; authors should include such baselines (Reviewers 2, 4).
- **Insufficient analysis of difference from Pr4ReL**, which also follows a selection-and-relabeling paradigm and uses neighborhood information; authors should explain superiority (Reviewers 1, 3).
- **Unclear motivation for feature propagation and label propagation** – what if directly applying label propagation without feature propagation? (Reviewers 1, 3)
- **Unreasonable access to a trained model** – line 237 requires a model trained on noisy labels for pruning, contradicting the goal of reducing training cost; if reasonable, please cite related works (Reviewers 1, 3).
- **Process follows existing works** (SOP+ and Coverage Coreset), limiting novelty (Reviewers 1, 3).
- **Presentation quality issues**: lack of related work on noisy data pruning, unclear distinction between gradient-based vs loss-based methods (lines 15, 51), typo “retaining retaining” (line 309) (Reviewers 1, 3).
- **Unclear step in method**: In line 70, since clean samples are found in stage 1, why relabel them? (Reviewer 2)
- **Clarification needed**: line 250, how to obtain ground-truth labels for evaluation? (Reviewer 3)
- **Minority note**: One reviewer (4) found the paper well-organized, while two others (1, 3) called presentation poor – the latter points above reflect the majority criticism.
