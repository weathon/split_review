## Merged Review

### Summary
The paper presents the Chronicling Germany dataset: 693 annotated historical German newspaper pages (1852–1924), including 1,900 individually annotated advertisements, with layout annotations (polygon) and text transcriptions. The annotations required 1,500 hours of human effort. A processing pipeline for layout detection and OCR is provided, with baseline results on an in-domain test set and an out-of-distribution (OOD) test set of 112 pages (1785–1866). The dataset and code are publicly available. The motivation is to address the lack of annotated historical German-language newspaper data, which features dense layout, Fraktur font, and unique character combinations.

### Strengths
- Useful dataset for digital humanities, filling a low-resource gap for German historical newspapers. (R1, R2, R3)
- Rigorous construction with layout annotations. (R1)
- Interesting particularities (Fraktur font, dense layout) that support language-independent document layout analysis and recognition. (R1)
- Provides baseline pipeline to illustrate dataset utility and enable comparison. (R1, R2)
- Introduces OCR and polygon layout analysis; layout complexity exceeds that of Dell et al. (2024), introducing new challenges. (R4)
- Well-written and easy to follow. (R4)

### Weaknesses
- **Scope/novelty**: The dataset addresses a narrow audience relative to the conference’s representation learning focus. (R1) The novelty is limited compared to existing German historical newspaper datasets [1][2][3] (Clausner et al. 2015, UB-Mannheim NZZ, UB-Mannheim Reichsanzeiger); this dataset lacks uniqueness in size and diversity. (R2 – more negative reviewer, score 5)
- **Missing comparisons and evaluations**: No quantitative comparison with existing datasets to show superiority. (R2) No detailed assessment of annotation quality (e.g., consistency review). (R2) Section 5 lacks detailed OOD test results, insufficient to demonstrate pipeline generalizability. (R2) Full pipeline evaluation is incomplete: only a 6% Character Error Rate is reported without further details; article separation is not assessed, making results preliminary. (R3) No information on image sizes or DPI. (R4) No information on legibility of the data. (R4)
- **Methodological issues**: The pipeline uses an older UNet model for layout detection; more recent YOLO-based architectures outperform UNet in similar tasks. (R3) Table 3 comparison with Dell et al. (2024) shows poor generalization for layout analysis. (R3) The OCR system requires baseline detection, which is questionable for near-horizontal newspaper text; a retrained OCR model (e.g., from HuggingFace: Teklia/pylaia-newseye-austrian) would be more suitable. (R3) The study does not leverage high-performance OCR systems such as Pero-OCR, limiting impact. (R3) Baseline methods lack justification; reviewer asks if existing pipelines trained on modern newspapers were tested on this dataset. (R4)
- **Missing citations**: Does not cite significant existing projects: Newseye, Impresso; the OCR-D project is mentioned only in the annex but should be in the main text. (R3)
- **Inconsistent or unclear comparisons**: In Table 3, it is unclear whether cross-fold validation was performed (i.e., whether the proposed pipeline was tested on American Stories and the Dell et al. pipeline on Chronicling Germany). Both methods should be evaluated on both datasets for a fair comparison. (R1) Legend for Table 3 is unclear, especially “F1 Score in distribution.” (R3)
- **Dataset framing**: The claim that modern readers struggle with the content focuses only on font differences; layout difficulties are not sufficiently highlighted. (R4) It is unclear why reading order is within the dataset’s scope if pages are hard for modern readers to comprehend, and how reading order was automatically assigned and evaluated to achieve “satisfactory results.” (R4)
- **Format**: The paper uses the ICLR 2024 template instead of ICLR 2025. (R2)
