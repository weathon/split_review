## Merged Review

### Summary
This paper introduces Verbalized Machine Learning (VML), a framework that constrains the parameter space to human-interpretable natural language. A text prompt of a large language model (LLM) serves as the model parameters, and an optimizer LLM iteratively updates the prompt. VML claims advantages in encoding inductive bias, automatic model class selection, and interpretable updates. It is tested on classical regression and classification tasks as well as medical image classification. Some reviewers find the perspective novel; others question whether it offers meaningful novelty over existing prompt optimization and LLM-as-optimizer techniques.

### Strengths
- The idea of parameterizing a machine learning model with natural language is niche and provides a new perspective on learning and optimization (Reviewers 1, 3, 5).
- The illustration and mathematical formulation are very clear (Reviewers 2, 3).
- Good overall presentation (Reviewer 5).
- Experiments cover multiple classical ML problems (regression, classification) and include a pilot on medical image classification (Reviewer 4).
- Experiments are thorough and well-designed (Reviewer 3).
- The paper investigates two important problems in machine learning: classification and regression (Reviewer 5).

### Weaknesses
- **Novelty and differentiation from prior work:** Several reviewers question the novelty and insufficient differentiation from existing prompt optimization methods (e.g., Pryzant et al., 2023; Yang et al., 2023; Yuksekgonul et al., 2024; Zhang et al., 2024) and related frameworks like Agent Symbolic Learning [1]. The paper's claim that VML differs because prompt optimization "seeks a generic instruction tuning without changing the original meaning" (line 233) is not convincing; modern prompt optimization techniques perform specific edits. Moreover, there is a lack of experimental comparisons against these baselines—only a qualitative comparison with APE (a search-based method) is provided. This undermines the claimed contributions. (Reviewers 1, 2, 4, 5; Reviewer 5 was more positive overall but still noted the missing comparison.)
- **Unclear representation of model parameters:** It is unclear how the millions or billions of parameters of an LLM are represented by natural language. The claim that optimizing model parameters is effectively a prompt optimization problem (line 161) seems inaccurate; the prompt functions as an additional input providing contextual information rather than directly representing or modifying the underlying model parameters. (Reviewer 1)
- **Limited applicability to strong instruction-following LLMs:** The framework only works with LLMs that are adept at following instructions, which limits its applicability to smaller or non-instruction-based models. This raises concerns about generalizability and practicality. (Reviewer 1; see also Reviewer 2’s comment on strong assumptions about the optimizer LLM.)
- **Unclear practical advantages over traditional ML for classical tasks:** The paper tests on regression and classification tasks that traditional ML models handle well. LLMs are known to struggle with basic numerical computation (cite [1]), making them ill-suited for regression. The practical advantages of VML given the high computational cost and expense of LLMs are not compellingly justified. No efficiency or scalability results (e.g., with data size, LLM size) are provided, nor is a concrete area identified where VML shines over simpler, more efficient alternatives (e.g., decision trees with comparable interpretability). (Reviewers 1, 2, 3)
- **Instability and reliability issues:** The benefit of encoding priors appears unstable (Figure 9a; examples are simple, like "X-ray image for pneumonia"), and the training loss is not stable (Figure 10). It is unclear if such instability is common in VML. (Reviewers 2, 5)
- **Uncertain interpretability benefit:** The interpretability claimed as a benefit may be limited in practice. If the "model parameter" becomes a document-length text, a practitioner might be better off not using the system. The evaluation of interpretability (line 515-516 "validated by medical professional") lacks clarity on what inspection of the "model parameter" entails. (Reviewer 2)
- **Strong assumptions about the optimizer LLM:** The framework assumes the optimizer LLM acts as an oracle that is very strong and faithful to instructions. However, LLMs have been shown to be brittle for explanation [2]. The same effort to obtain such a strong LLM could be spent on alternative frameworks (e.g., better decision trees or interpretable classifiers) that achieve the same desiderata with much higher efficiency. (Reviewer 2)
- **Missing theoretical analysis:** Given the paper's claim that the function approximation view is a major differentiator from prior work (e.g., Yang et al.), the paper should provide theoretical analysis of what functions can and cannot be approximated by this framework, and which properties of the LLM architecture pose constraints. (Reviewer 3)
- **Missing experimental details:** The paper lacks analysis of scalability (e.g., with training data size and LLM size) and efficiency (e.g., FLOPs). For training dynamics (Figure 10a), it would be more informative to use FLOPs instead of steps as the x-axis. It is also unclear if the unstable training loss is inherent. (Reviewers 3, 5)
- **Note on reviewer divergence:** One reviewer (Reviewer 5, score 6, confidence 5) was more positive overall, emphasizing the interesting perspective, good presentation, and investigation of important problems, while others (scores 3, 5, 3) were more critical of novelty, differentiation, and practical merit.
