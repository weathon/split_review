## Merged Review

### Summary
The paper proposes Parallel Quasi-Quantum Annealing (PQQA), which integrates Quasi-Quantum Annealing (QQA), gradient-based updates through continuous relaxation, and parallel run communication. The method uses α-entropy and extended Boltzmann distribution for sampling, solving combinatorial optimization problems via continuous relaxation. Experiments on max independent set, max clique, max cut, graph partitioning, and graph coloring show PQQA achieves high-quality solutions comparable to or better than iSCO and other learning-based solvers, often with superior speed-quality trade-offs on large instances. The paper is well-written with clear background, methodology, and extensive comparisons.

### Strengths
- **Novel approach**: The α-entropy with extended Boltzmann distribution is a well-motivated and novel sampling-based technique for combinatorial optimization. (R2, R4)
- **Clear exposition**: The introduction, background, methodology, theoretical properties, and related work are clearly explained, with very good coverage of prior literature. (R1, R4)
- **Convincing numerical results**: Extensive experiments across multiple benchmarks (MIS, max clique, max cut, graph partitioning, graph coloring) demonstrate high-quality solutions on all instances, often at reduced runtime compared to baselines. The experiments effectively highlight the method. (R1, R2, R4)
- **GPU acceleration**: Parallel GPU implementation accelerates the solution process. (R3)
- **Apparent novelty of main contribution**. (R4)

### Weaknesses
- **Convergence and feasibility**: The algorithm lacks convergence guarantees. Feasibility cannot be guaranteed because constraints are moved to the objective as penalty terms. How binary solutions are obtained after PQQA, how often they are feasible, and what is done with infeasible solutions is not discussed. (R2, R3)
- **Limited constraint complexity in benchmarks**: The evaluated problems (MIS, max clique, max cut, graph partitioning, graph coloring) all have relatively simple constraints. It is unclear if PQQA can handle problems with exponential constraints (e.g., TSP) due to reliance on continuous relaxation. This limitation is not acknowledged. (R2) One reviewer recommends testing on larger benchmarks like MIPLIB 2017. (R3)
- **Missing comparisons and weaker performance on some benchmarks**: iSCO is not compared in Table 2. PQQA is not benchmarked on TSP. On SATLIB, PQQA performs worse than traditional OR solvers like Gurobi. (R2, R3)
- **Confusing runtime measurements**: Time measurements are denoted [s/g], but it is unclear if this is per gradient evaluation or total runtime. Comparison across algorithms using different programming languages and hardware platforms introduces confounding factors that are not adequately addressed. (R4) There is a runtime discrepancy: for the same ApR (0.996), iSCO takes 5–15 minutes while PQQA takes over an hour (Table 1). (R1) Time metrics are inconsistent across tables (seconds vs average time). (R2) Why is iSCO much faster on MIS but slower on Max Clique? (R2)
- **Clarifications needed**: In Table 1, some ApR values are greater than 1 – meaning? (R1) The term “parameters” in line 60 should be clarified. (R1) Why not directly solve the continuous relaxation as an LP? (R3)
- **Presentation errors**: Incorrect table reference on line 314 (cites Table 5.1 instead of Table 1). Incorrect reference in Table E.1 (line 1125). (R1, R2) Consistent time evaluation format is needed. (R2)

*Contrast*: Three reviewers (scores 8, 8, 8) found the method convincing and the experiments strong. One reviewer (score 3) raised significant concerns about lack of convergence guarantees, feasibility, and weaker performance on SATLIB compared to Gurobi, and suggested more challenging benchmarks.
