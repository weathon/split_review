## Merged Review

### Summary
The paper studies quantum-inspired classical algorithms, extending the binary tree data structure from Tang (2019) to ℓ_p norms for inner product estimation and sampling from linear combinations of vectors. It claims improved runtime for the ℓ_1 case, provides a proof-of-concept downstream example, and presents example-driven numerical experiments. Reviewers note the generalization of the data structure, optimal sample access for certain vectors, and two applications studied. However, critical concerns about the optimality claim, inconsistent error guarantees, unclear significance, and missing motivation are raised.

### Strengths
- New insight: considering ℓ_p norm subroutines might lead to faster quantum-inspired algorithms (Reviewer 1).
- Proof-of-concept example of downstream applications (Reviewer 1).
- Example-driven numerical experiments that demonstrate effectiveness; this is intuitive and uncommon in previous work on quantum-inspired algorithms (Reviewer 2).
- Generalization of the data structure used for quantum-inspired classical algorithms (Reviewer 3).
- Optimal sample access established for certain type of vectors (Reviewer 3).
- Two potential applications studied (Reviewer 3).

### Weaknesses
- **Optimality claim not convincingly justified (Reviewer 2, confidence 5; echoed by Reviewer 3).** The proof for Proposition 4 and Proposition 6 only shows that a specific kind of algorithm using SQ₁ yields an optimal bound, but fails to argue that this algorithm is optimal; a different algorithm using SQ_p for p≠1 might achieve a better bound. Reviewer 3 adds that the optimality/advantage for inner product estimation using SQ_p appears to hold only when vectors x and y have zero-mean i.i.d. Gaussian entries, but in practice these vectors often represent quantum states with entries in [0,1] (probabilities), so the setting is not general. Authors should discuss where such zero-mean i.i.d. settings occur.

- **Comparison of error guarantees is inconsistent (Reviewer 3).** For inner product estimation, the additive error guarantees for SQ (Proposition 1) and SQ_p (Proposition 3) differ; setting p=1 yields a worse additive error from Proposition 3 compared to Proposition 1, so the sampling complexity comparison is not for the same error guarantee. For sampling from a linear combination of vectors, the outputs differ (D_{Ax} vs. D^{(p)}_{Ax}), making sample complexity comparisons unclear when the outputs or error guarantees are not the same. Authors need to clarify.

- **Significance and downstream improvement unclear (Reviewer 1, confidence 3; Reviewer 3, confidence 4).** Reviewer 1 states the analysis seems straightforward (based on a variance argument) and it is not clear that the new subroutine gives a better bound for downstream quantum-inspired ML algorithms; more discussion is needed. Reviewer 1 also asks whether the constant improvement in Proposition 4/Corollary 2 can indeed improve the complexity of previous quantum-inspired ML algorithms—this missing analysis weakens the contribution. Reviewer 3 finds the significance of the proposed approach and results unclear overall.

- **Motivation for dequantized quantum classifiers lacking (Reviewer 3).** It is unclear why a dequantized quantum classifier (using classical inner product estimation) should be used over existing powerful classical methods. Quantum classifiers (e.g., PQC-based) are typically beneficial when data is quantum. Authors should discuss the advantage of a classical algorithm for inner product estimation within a quantum classifier.

- **Connection between sections unclear (Reviewer 2).** The connection between Section 3 and later sections on applications is not well explained; adding connecting paragraphs would improve clarity.

- **Title too vague (Reviewer 2).** “Improved Sample Access for Quantum-Inspired Algorithms” is overly broad since only a few examples are discussed.

- **Typos and presentation issues (Reviewer 2).** Examples: line 107: “L^p” should be “L^p-norm”; line 125: missing article (“vector” → “a vector/the vector”); line 170: should be “SQ(y)” instead of “Q(y)?”; reference format: “Andrew J Baldwin” should be “Andrew J. Baldwin”. Reviewer 3 notes line 253: “x” is undefined.

- **Lack of generality for applications (implicit across reviewers).** While the paper lists two applications, the overall significance is questioned, and the settings used (i.i.d. entries) are not typical for real-world data matrices or quantum state vectors.
