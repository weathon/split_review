## Merged Review

### Summary
The paper proposes a single-LLM agent (SALA) that combines reasoning, acting, and self-adaptation by iteratively prompting the same model to correct its plans after task failures in text-based environments (ALFWorld). It reports an 83% success rate on selected tasks, outperforming ReAct. Reviewers note the clarity of writing and illustrative figures, but unanimously find the contribution incremental, the experimental evaluation insufficient, and many implementation details missing. One reviewer (score 1) is substantially more critical of the novelty and evaluation than the others (scores 3).

### Strengths
- **Clarity and presentation**: The paper is clearly written and easy to follow; illustrative figures are helpful for understanding the approach (Reviewers 2, 4).
- **Conceptual simplification**: Combining reasoning, acting, and adaptation within a single language model reduces model complexity compared to methods that use separate models (Reviewer 1; Reviewer 4 notes “may use less memory”). The self-adaptation mechanism can improve decision-making over a single round (Reviewer 1).
- **Empirical result**: The proposed method achieves an 83% success rate on the tested ALFWorld tasks, outperforming ReAct by a substantial margin (Reviewer 1). However, other reviewers dispute the significance of this result (see Weaknesses).

### Weaknesses
- **Lack of novelty and incremental contribution**:
  - The sole difference from Reflexion (Shinn et al., 2023) appears to be using one LLM instead of two or three. Reflexion sequentially uses the same model with different prompts, so using a single model for action and self-adaptation is a minor modification (Reviewers 2, 3, 4). The paper does not clarify whether this is a significant distinction; both methods require the same number of inference steps (Reviewer 2).
  - The paper claims a “new in-context learning algorithm,” but it is a modified prompting strategy (Reviewer 2). Large portions of the method section simply repeat existing methods without providing insight into the proposed approach (Reviewer 3).
  - Without a direct comparison to Reflexion on accuracy or efficiency, the novelty and advantage cannot be assessed (Reviewers 2, 4). The paper states Reflexion uses two models, but Reflexion actually uses three models (Actor, Evaluator, Self-Reflection); this discrepancy needs clarification (Reviewer 4).

- **Insufficient and poorly reported experiments**:
  - **Limited environment and tasks**: Evaluation is only on the text-based game ALFWorld; authors should also test on HotpotQA (reasoning) and code generation benchmarks (MBPP, HumanEval, LeetcodeHardGym) as used in Reflexion (Reviewer 4). Only one open-source model (gemma-2-9b-it) is used; at least three models with different sizes (e.g., 30B, 65B) and API models (e.g., GPT-4o) should be evaluated, with aggregated and averaged results (Reviewer 4).
  - **Missing baselines and ablations**: Only ReAct is compared, but Reflexion is the direct predecessor; no ablations or other competitive baselines are considered (Reviewers 2, 3, 4). Large portions of the results section evaluate ReAct (not the proposed method) on open models, which is not an experimental contribution for a top venue (Reviewer 3).
  - **Missing dataset and metric details**: The paper does not specify test set size, how accuracy is computed, whether Table 2 shows average steps across data points, or the task-specific success rates. Standard metrics for ALFWorld/ALFRED are not reported (Reviewer 2). The prompt for feedback is not provided (Reviewer 2).
  - **No statistical analysis**: No confidence intervals, statistical tests, or robustness checks are given for the reported success rates (Reviewer 1). Hyperparameter settings (learning rates, training duration, selection criteria) are absent, harming reproducibility (Reviewers 1, 2).

- **Unclear motivation and missing justification**:
  - The introduction does not clearly articulate the limitations of existing methods that SALA addresses (Reviewer 1). The motivation for modifying Reflexion to use a single LLM is not explained; why would this minor change differentiate the work? (Reviewer 4). The paper fails to justify the use of a single LLM for both action generation and self-adaptation in terms of scalability or performance on more complex tasks (Reviewer 1).

- **Writing and content issues**:
  - There is no proper discussion of related work (Reviewer 3). Some paragraphs in the results section (around lines 370 and 380) are completely repetitive without insight (Reviewer 3). The claim of a “new in-context learning algorithm” is overstated (Reviewer 2).

- **Suggestions from reviewers**:
  - Add a column for average success rate and average steps in the table for easier comparison (Reviewer 4).
  - Provide the exact prompts, test set size, per-task success rates, and missing implementation details (Reviewer 2).
