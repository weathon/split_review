## Merged Review

### Summary
The paper proposes Open-YOLO 3D, a fast open-vocabulary 3D instance segmentation method that replaces computationally expensive 2D foundation models (SAM, CLIP) with a 2D open-vocabulary object detector (YOLO-World) for multi-view class prediction. Class-agnostic 3D mask proposals are generated by Mask3D. The approach uses Multi-View Prompt Distribution (MVPDist) and Accelerated Visibility Computation (VAcc) to efficiently fuse multi-view bounding box predictions and label 3D instances. Experiments on ScanNet200 and Replica show state-of-the-art performance (mAP 24.7% on ScanNet200) with up to 16× speedup (22 seconds per scene) compared to methods like OpenMask3D.

### Strengths
- **Novel use of 2D bounding boxes only**: Replaces expensive SAM/CLIP feature lifting with fast 2D object detection, achieving significant speedup (up to 16×) while maintaining competitive accuracy. (Rev1, Rev3, Rev4, Rev5)
- **Efficient multi-view fusion**: Multi-View Prompt Distribution (MVPDist) and Accelerated Visibility Computation (VAcc) effectively associate 2D label maps with 3D proposals; VAcc leverages tensor operations and GPU batch processing for highly parallelized visibility computation, robust to label map granularity. (Rev1, Rev3, Rev4)
- **Strong experimental results**: Achieves state-of-the-art on ScanNet200 and Replica under both ground-truth mask and class-agnostic proposal settings; clear ablation studies demonstrate component contributions. (Rev1, Rev3, Rev5)
- **Clear presentation**: Well-organized paper with clear motivation, implementation details, and connection between method and motivation. (Rev1, Rev2, Rev3, Rev4, Rev5)
- **Practical efficiency**: High precision with significantly faster inference is important for real-world deployment; zero-shot capabilities retained via high-performing 2D detector. (Rev2, Rev3)

### Weaknesses
- **Insufficient academic contribution (minority reviewer – score 5)**: One reviewer found the work a trivial combination of a 3D segmentation network and a 2D object detector, lacking novel methodological advancements beyond engineering. The core idea of leveraging 2D detections for 3D segmentation is not novel, and the paper fails to articulate new insights for handling inherent challenges like view inconsistencies or occlusions. The approach essentially repurposes existing tools. (Rev2)
- **Misleading title**: “OPEN-YOLO 3D” implies a direct adaptation of the YOLO architecture to 3D data, but the method uses a 2D detector (YOLO-World) for class predictions, causing potential confusion. (Rev2)
- **Insufficient justification of 3D proposal model**: Reliance on class-agnostic Mask3D for proposals is not fully justified. Mask3D was trained with category information – evidence that it generalizes to novel unseen object categories is lacking. The paper does not adequately address how Mask3D can effectively generate proposals for unseen categories given its training data. (Rev1) Additionally, as noted in Open3DIS, pre-trained 3D models have limited capability for uncommon categories, and the 3D data representation for open-vocabulary segmentation may be uncultivated. (Rev4)
- **Limited evaluation scope**: Experimental evaluation is mostly confined to Table 6 on ScanNet200 and Replica; lacks comprehensive analysis across diverse datasets, scenarios (different occlusion levels, object complexity), and outdoor datasets (e.g., NuScenes where OpenMask3D performs poorly). Evaluation on outdoor environments with sparse-diverse categories is missing. (Rev1, Rev4) Also, inference time (21.8s) is slower than OpenScene (3D Distill) – a missing explanation for this phenomenon (first paragraph of Section 5.1). (Rev5)
- **Insufficient ablation study**: The paper lacks systematic analysis of how different 2D detectors, varying number of views for classification, and different 3D proposal generation methods impact efficiency and performance. Such analysis is needed to understand each component’s contribution. (Rev2)
- **Missing complexity analysis of VAcc**: A deeper theoretical analysis or complexity comparison of VAcc with conventional iterative methods would strengthen understanding of its true computational advantage. (Rev3)
- **Reliance on 2D detector quality**: The method’s performance depends on the 2D object detector’s quality. No analysis of how 2D detection failures (poor lighting, occlusions, difficult conditions) propagate through the pipeline to 3D mask assignments. Mitigation strategies for misclassifications from the 2D detector are not discussed. (Rev3) Furthermore, segmentation performance improvements largely stem from the pre-trained YoloWorld prior, not from novel contributions in the paper. (Rev4)
- **Missing extension discussion**: Possibility of extending the method to 3D panoptic segmentation is not addressed. (Rev5)
- **Minor issues**: Typo on Line 405: “04.29” should be “4.29” for OpenScene (3D Distill). (Rev5) Missing comma after “information” in line 092. (Rev1)
