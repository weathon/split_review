## Merged Review

### Summary
This paper proposes VACO, a bi-level optimization framework for offline RL that addresses the interference between value estimation (Q-function) and behavior cloning (BC). The inner loop performs weighted BC using a meta-scoring network to weight each training sample, while the outer loop maximizes value estimation with Gaussian noise injection for limited exploration. The approach aims to balance out-of-distribution overestimation and convergence to sub-optimal in-distribution actions. VACO is evaluated on D4RL tasks (Hopper, HalfCheetah, Walker2D, AntMaze) and achieves state-of-the-art performance against a range of baselines including diffusion methods, using a simple MLP architecture.

### Strengths
- **Clear motivation and narrative**: The paper clearly establishes the OOD and value alignment challenges in offline RL, uses illustrative figures, and presents the method in an easy-to-understand way. Writing is coherent and well-structured (R1, R2, R3, R4).
- **Method originality**: Combining value estimation maximization with weighted BC via bi-level optimization is a novel and underexplored perspective in offline RL. The approach is intuitive and easy to grasp (R1, R2, R3, R4).
- **Strong empirical performance**: VACO achieves state-of-the-art average results on the D4RL MuJoCo and AntMaze benchmarks, outperforming many baselines including diffusion-based methods despite using only MLPs (R2, R3).
- **Reproducibility**: Source code and detailed experimental information are provided (R1).
- **Relevant baselines**: The selected baselines are relevant to the comparison and assessment of the method (R4).

### Weaknesses
**Major Concerns**
- **Theorem correctness / derivative assumption**: The assumption $\frac{\partial \phi_{t-1}}{\partial \alpha} \approx 0$ (line 261) used to avoid second-order derivatives is justified by an appeal to the Markov property, which seems inappropriate since the dependency is across function iterations, not probabilistic state transitions. The divergence between $\phi_t$ and $\phi_{t-1}$ should be evaluated to validate the assumption. (R1, R4 both question this; R4 also asks why Eq. (8) is valid and what defines the Markov process.)
- **Limited evaluation tasks**: The method is tested only on a small set of simple D4RL tasks (locomotion and AntMaze). Generalization to more complex environments is unclear. Reviewers recommend evaluation on at least Adroit and Kitchen (from D4RL), Robomimic, or visual/manipulation tasks like Fetch. (R1, R2, R4)
- **Performance degradation on AntMaze**: The improvement over baselines is diminished on the more complicated AntMaze tasks, raising questions about scalability to complex scenarios. (R4)
- **Lack of analysis on alignment and weight-value relationship**: There is no direct evidence linking the observed improvements to better alignment between the behavior policy and value function. Visualizations of the meta-score vs. Q-value, and whether the score network assigns low weights to poor-quality state-action pairs (e.g., from low-performing policies), are missing. If meta-score is highly correlated with Q-value, it may be redundant. (R1, R2, R4)
- **Insufficient ablation studies**: The only ablation is on removing inputs to the meta-score network. More comprehensive studies are needed, e.g., visualizing weight distributions across data from different policy qualities, or analyzing training loss curves (inner vs. outer loop) to understand whether the objectives are adversarial or complementary. (R1, R2)
- **Method name misleading**: The algorithm alternately trains two networks (meta-score and policy) without forming a true nested optimization loop, resembling adversarial training (like GANs) more than bi-level optimization. A name like "Adversarial/Complementary Value-Aligned Behavior Cloning" may be more accurate. (R2)
- **Missing training cost analysis**: No discussion of computational cost (wall time, iterations) despite the meta-learning framework likely being more expensive. This is important for practitioners choosing between methods. (R3)
- **Baseline descriptions insufficient**: The paper lacks explanations of each baseline’s key insights or features, making it hard to judge the robustness of the comparisons. (R1)
- **Related works placement**: The related works section (Section 5) is placed after experiments, even though it describes methods compared in experiments, making experiments harder to parse on first read. (R3)

**Minor Concerns / Clarifications**
- **Writing clarity issues**: In the abstract (lines 25-26), the description suggests the outer loop only adds noise rather than training the weighting, which contradicts the algorithm description in Section 3.3. (R3) Also, several typos: line 094/478 “In details” → “In detail”; line 227 “Gauss noise” → “Gaussian noise”; line 236 “square error” → “squared error”; line 239 “Through such bi-level” → “Through such a bi-level”; line 307 formatting issue. (R1)
- **Experimental reproducibility concerns**: Some results are copied from previous works; Table 1 has missing fields. Full re-runs under identical conditions (devices, seeds) would improve fairness. (R1)
- **Gaussian noise injection design choice**: It is unclear why Gaussian noise is added to the state (Eq. 6) rather than to latent variables or output logits, and why noise is needed at all. (R1, R4 asks if Eq.6 is a typo)
- **Claim about loss generality**: The paper claims (lines 748-753) that any value estimation loss and any BC-based policy extraction loss can be used, but no experiments support this claim. (R1)
- **Value network sharing across methods**: It is unclear whether the same value network is used across compared approaches or separately trained for each. (R3)
- **Single-dataset setting**: The studied setting (learning from a single collected dataset) is somewhat dated; newer directions (unlabeled data, primitives, offline-to-online) may have greater impact. (R1, minor)
