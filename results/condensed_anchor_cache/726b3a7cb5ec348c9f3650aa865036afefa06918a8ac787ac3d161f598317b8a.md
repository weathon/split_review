## Merged Review

### Summary
The paper introduces Diffree, a text-guided object addition model that requires only a text prompt (no mask or bounding box). It uses a synthetic dataset OABench (74K tuples of original image, inpainted object-removed image, object mask, and description) built by removing objects with PowerPaint. Diffree extends Stable Diffusion with an Object Mask Predictor (OMP) to simultaneously output the added-object image and its mask. Experiments show high success rates for object addition while preserving background consistency, spatial appropriateness, and object quality. Applications include object addition for real and AI-generated images. Scores: 5, 6, 3, 5.

### Strengths
- **Shape-free object addition with only text guidance** is a novel and user-friendly approach, eliminating the need for manual masks or bounding boxes [R1, R2, R3].
- **OABench dataset contribution**: A large-scale, high-quality synthetic dataset of object removal tuples built via a sophisticated data collection pipeline (74K tuples). This resource can benefit other inpainting tasks [R1, R2, R4].
- **OMP module**: Predicts the object mask and generates the inpainted result simultaneously. [R2] considers this a novel architectural advancement; [R1] notes that integrating a mask head in diffusion is not new (citing [1]).
- **Attractive results** in the main paper and appendix for both real and AI-generated images [R1, R4].
- **Clarity of dataset creation and evaluation metrics** is well described, with helpful figures [R3].

### Weaknesses
- **Mask quality and realism issues**: Predicted masks omit shadows and reflections, leading to “copy and paste” artifacts. Examples: missing shadows in the “Coconut palm” (Fig. 3) and missing reflections for the “boat” (Fig. A2). The LPIPS-based background consistency metric does not capture these lighting/reflection inconsistencies. [R4] Also, Fig. 1 example 2 shows an unrealistic rendering of the added object [R3].
- **Generalization concerns**:
  - **Small objects**: Failure case in Fig. 9(a) when the mask is very small [R4].
  - **Out-of-distribution objects**: How does Diffree perform for objects not in OABench? [R2 Q].
  - **Synthetic dataset bias**: Training on images generated by an inpainting model (PowerPaint) may cause overfitting to artifacts from that model [R1].
  - **Real-world test with multiple dogs**: If two dogs are removed by PowerPaint and then one dog is added, does the new dog’s position duplicate the removed one? [R1 Q].
- **Prompt generality limited**: All training prompts are in the form “add {object}”. The model does not handle more precise spatial descriptions (e.g., “on the left of”, “above”, “below”) or detailed attributes (size, pose, orientation). [R2, R4] The reliance on COCO annotations also limits prompt detail to generic object labels [R3].
- **Lack of mask adjustment**: Users cannot refine the predicted mask, which restricts control needed in practice. The paper does not discuss how masks could be used as a starting point for further editing. [R2]
- **Ambiguity in complex scenes**: When images contain multiple entities, the model has no mechanism to specify which object should receive the addition. No user input for target placement is provided. [R3, Q] E.g., adding “a dragon” in Fig. 1 resulted in a dragon painting inside a frame—is that intended? [R2 Q].
- **Missing ablation studies**:
  - Effect of removing the OMP module [R1].
  - Necessity of joint training of OMP and diffusion model vs. independently training OMP to predict the mask [R4].
  - Analysis of what happens when the model fails (e.g., combining successful and failure cases for Local CLIP Score) [R1 Q].
- **Unfair / insufficient comparisons**:
  - Baseline methods (InstructPix2Pix, PowerPaint) in Fig. A10 were not retrained or fine‑tuned on OABench [R1].
  - Only two methods compared; additional recent text-guided inpainting or object addition baselines are needed [R3].
- **Need for a user study** to evaluate subjective aspects like user satisfaction and perceived realism [R3].
- **Methodology clarity issues**:
  - Explanation of figures lacking detail. For example, links to figures in line 50 of the description, but symbols/captions are insufficiently explained [R1].
  - Fig. 6’s workflow is unclear; caption too minimal [R3].
  - Description of OMP inputs (why image latent and latent noise are concatenated during both training and inference) needs more detail [R3].
- **Missing in-depth comparison with [1]**: The mask prediction module in [1] is closely related; the paper should discuss architectural and training differences and whether Diffree achieves comparable or superior mask quality and insertion accuracy. [R2, also R1 notes it’s not new].
- **Minor typographical error**: Missing period at end of line 101 [R3].
- **Could Diffree be used for mask‑free removal?** OABench includes removal tuples, but this is not explored [R4 Q].
- **Clarify Fig. 8**: What does “with/without mix with previous image” mean? [R4 Q].
