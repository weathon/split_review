## Merged Review

### Summary

Four reviewers rated the paper 3 (fair), with confidence mostly 3. The reviewers found the paper tackles an important problem (online hidden state learning in POMDPs using successor representations) and presents a novel biologically-inspired algorithm, Distributed Hebbian Temporal Memory (DHTM), combining factorial HMMs, Hebbian-like updates, and multi-compartment neuron models. Strengths include biological plausibility, local learning avoiding backpropagation issues, and clear motivation. However, all reviewers consider the empirical evaluation insufficient: only one simple custom pinball environment, non-standard pseudo-surprise metric, missing learning curves, no hyperparameter sensitivity analysis, high variance (Fig. 4), and unknown seeds and baseline tuning. The paper lacks theoretical analysis (e.g., convergence of message passing, justification of approximations like Eq. 11, learning targets for Hebbian rules), does not clarify biological correspondences of factor graph elements, and does not address scaling to larger/horizon POMDPs. Presentation is dense and missing many details (notation glossary, definition of superscripts, full agent architecture, parameter values). Reviewers also note the method’s potential (R2 especially) but agree the current state does not warrant acceptance; R4 found soundness poor (1), and R3 stated the paper is not ready.

### Strengths

- Tackles an important challenge: online inference of hidden Markov state in non-stationary, partially observable environments for decision-making (R2, R3).
- DHTM amalgamates interesting concepts: factorial HMMs, successor representations, multi-compartment neuron models, and sparse distributed representations; biological plausibility is a notable feature (R2).
- Relies on local Hebbian-like updates, avoiding stability and slow-learning issues of gradient-based sequence models like RNNs (R3).
- Implementation of belief propagation within a neural circuit is innovative (R4).
- Writing and presentation are straightforward; motivation is clear (R1). The problem and proposed approach are easy to digest.

### Weaknesses

**Insufficient and poorly explained empirical evaluation**
- Only a single custom pinball environment is used; no standard RL benchmarks (e.g., Minigrid) that would allow quantitative comparison to ground-truth successor representations and better interpretability (R1, R3). The absence of such benchmarks limits generalizability (R1, R3).
- The pseudo-surprise metric is non-standard and its computation is not clearly described; its relevance to the task is unclear (R1, R3).
- No learning curves are provided for baseline models (LSTM, Receptance Weighted Key Value (RMKV), LRU, fchmm), making it impossible to determine if they were given sufficient time to converge or hyperparameter-optimized to the same degree as DHTM (R1). The reported performance is only marginally better than fchmm (R2).
- Figure 4 shows high variance; the number of seeds is not stated (R1). The 1-step model exhibits stability issues (reward not stabilizing before task switch) (R1).
- No hyperparameter search or sensitivity analysis is performed (R2). Parameter values used for DHTM and other methods are not reported (R2).
- The agent architecture is poorly explained (R1, R3). Missing: a computational graph linking the model to Algorithm 1 and Figure 1, details on input to RNNs, what the SR representation is (tabular wrt HMM states?), and explicit description of baseline architectures (R3).
- The comparison to related work on successor representations in POMDPs is insufficient; e.g., no discussion of [1] which also models SR in POMDPs (R3). The paper should clarify how DHTM differs from existing methods addressing partial observability and temporal abstraction (R3).

**Lack of theoretical analysis and missing algorithmic guarantees**
- Many approximations in the algorithm are not justified: e.g., why the “independent” variable can be represented as Eq. (11), what the Hebbian rule for \(w_{ul}\) actually learns (targets, dynamics), and convergence properties of the sum–product message passing (R4).
- It is uncertain whether message passing converges in the given graphical structure; if multiple iterations are needed for \(m_u\) to converge, information transmission from time \(t+1\) to \(t\) is questionable (R4).
- Actions affect the HMM transition matrix, but Section 3.1 does not model actions explicitly (R4).
- Scaling to infinite horizon or large POMDPs is not addressed: the fixed number of hidden variables and their connectivity limits the capacity to represent complex, long-range dependencies; how complexity would grow and impact computational cost and learning stability is not discussed (R3).

**Unclear biological mapping and factor-graph presentation**
- The biological correspondences of ‘f’ (factors) and ‘m’ (messages) in sum–product message passing are not clarified; ‘f’ including more than two nodes does not correspond to typical one-to-one neural connections; how nodes transmit ‘m’ is unspecified (R4).
- The specific “spatiotemporal property of cortical network activity” referenced in Section 2.4 is vague (R2).
- Binary cell activities, presynaptic cells, and receptive fields are introduced but not integrated into Figure 1 (R1).

**Poor presentation, missing details, and organizational issues**
- Notation is dense and difficult to track: superscripts \(i\) and \(k\) are not defined (R2, R1); the variable \(E\) in Figure B and the red circle in Figure C are unclear; indicator function should use \(\mathbb{I}\) instead of \(I\) to avoid confusion with identity (R1). Figure 1 caption lacks detail and does not reference equations (R1).
- No notation glossary is provided in the main paper or appendix (R2). Section 3.1 is a wall of text; it would benefit from subsections separating the Hebbian learning rule from transition-matrix update (R2). The paper is dense and would be better as a longer journal article (R2).
- Abbreviations are not spelled out at first use (e.g., RMKV, HMM) (R1). Grammar errors present (R1, R2).
- The symbol \(M\) is used both for successor representations and messages, creating confusion (R1). Avoid using \(\mathbb{M}\) for both.
- Algorithm 1 is not linked to the equations it optimizes, so its role in the RL framework is unclear (R1).

**Additional specific missing experiments/analyses**
- The successor representation is defined with respect to a policy; DHTM ignores the target policy, and no comment is provided on the difficulties of adapting the estimate with a changing policy (R3).
- In Section 2.1, the optimal policy should be \(\text{argmax}_a\) not \(\text{softmax}_a\) (R3).
- The assumption that the reward function lies in the span of observation features (for value function linearity) is not justified; successor features should be discussed in Section 2.3 (R3).
- The proposed method should be demonstrated more thoroughly: online learning capability, emergence of sparse representations, and adaptation to non-stationarity are not adequately shown (R2).
