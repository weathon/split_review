## Merged Review

### Summary
This paper proposes a simple method for object-centric representation: apply multi-scale k-means clustering (with varying K) to patch features from an off-the-shelf backbone (DINOv2). The cluster centroids are treated as object-centric embeddings with different granularities, requiring no training or fine-tuning. The method is evaluated on downstream tasks (single-label classification, video action recognition) and unsupervised segmentation benchmarks. One reviewer (R3, rating 5) praises its advantages (no training, multi-scale, semantic centroids), while others (R1, R2, R4, rating 3) emphasize that clustering pretrained features is a well-known baseline and argue the experiments/novelty are insufficient.

### Strengths
- Clear motivation, straightforward method, and well-written paper (R1, R2, R4).
- No additional training or fine-tuning required; directly uses off-the-shelf backbone (R1, R3).
- Multiscale granularity captured by multiple K-means runs with varying K (e.g., K = 1,2,4,8) (R3).
- Evaluates object-centric representations on downstream tasks beyond segmentation, including video action recognition, using diverse datasets (R3, R4).
- Extensive experiments and thorough analysis of embedding characteristics (R2).

### Weaknesses
- **Lack of novelty**: Applying k-means to DINO/DINOv2 features is a well-known baseline. Prior works (DINOSAUR, SOLV) reported k-means results in ablations, and clustering DINO features has been used for segmentation in videos and images (R2, R4). The paper presents no new information beyond evaluating this established approach (R1).
- **Insufficient experiments**: Only single-label classification and unsupervised segmentation are tested. More diverse tasks are needed to support the claim of generally learned representations (R1). (Note: R4 finds the evaluation diverse; this disagreement is preserved.)
- **Hyperparameter sensitivity**: Choice of K and hierarchical structure are dataset-specific, limiting flexibility (R2). Ablation on the number of clustering K is missing (R3).
- **Interpretability**: Patch-level features from ViT may not guarantee object-level semantics. The rationale for calling these features “object-centric” is unclear; self-attention extracts patch-level, not object-level, information (R3).
- **Reliance on pretrained backbone**: Method depends entirely on well-trained features from DINOv2; whether fine-tuning the backbone could refine semantic information is not explored (R3).
- **Unfair comparisons and baseline advantages**:
    - Multi-scale representation (multiple K) gives an unfair advantage over SPOT, which uses a single fixed number of slots. For fair comparison, SPOT should also use multi-scale representations (R4).
    - The method uses DINOv2, while other baselines (DINOSAUR, SPOT) use DINO. Despite this advantage, at a single scale (fixed K/slots) the proposed method is outperformed by those baselines, suggesting performance gain comes from multi-scale, not from clustering quality (R4). A multi-scale version of prior methods (e.g., a collection of DINOSAUR slots with S = {1,2,4,8}) is expected to provide richer information (R4).
- **SAM comparison lacks justification**: SAM can extract overlapping masks at any scale with pixel precision; the advantage of patch-level clustering over SAM for object-centric representations is not addressed (R4).
- **Missing analysis in video action recognition (Figure 3)**: Dropping tokens in the “all-patches” setting – how does token reduction affect the tradeoff between token count and performance? Redundant tokens are common in video understanding, so this comparison is important for efficiency (R4).
- **Missing implementation details**: Which self-attention layer and which features (keys, queries, or values) are used to extract patch tokens? (R3). Time and efficacy analysis compared to baselines is needed (R3).
- **Motivation for video action recognition**: Evaluating more video/image segmentation tasks would better show the semantic quality of the learned features (R3).
