## Merged Review

### Summary
The paper proposes UniPredict, a generative LLM trained on 169 aggregated tabular datasets to predict arbitrary target columns. It uses prompt engineering to serialize tabular data and metadata, and target augmentation with XGBoost-derived confidence estimates. Experiments report improvements over tree-boosting and neural baselines (5.4–13.4%) and strong few-shot performance (over 100% better than XGBoost on low-resource setups).

### Strengths
- Novel method for serializing tabular data samples that includes both column values and dataset metadata (Reviewer 2).  
- Novel use of XGBoost confidence estimates as teaching signals to train the LLM to produce probabilistic outputs for tabular prediction (Reviewers 2, 3).  
- Extensive prompt engineering enabling the LLM to accept arbitrary tabular inputs and predict for any specified target variable (Reviewers 1, 3, 5).  
- Strong performance as a single model across many datasets, especially in low-data regimes (Reviewers 1, 2, 5).  
- Introduces target augmentation as a technique to handle diverse targets (Reviewer 5).  
- Well-written and organized with clear problem formulation (Reviewer 5).  
- Reviewer 4 (score 8) found the experiment solid and the performance improvement solid, noting the potential benefit to the community if code/data are released.

### Weaknesses
- **Missing model backbone details:** The paper does not specify which LLM architecture was used (e.g., LLaMA, Falcon, GPT-3.5). Based on the logo in Figure 2, it appears to be OpenAI’s fine-tuning API (GPT-3.5 or GPT-4). Training hyperparameters are also omitted (Reviewers 2, 3, 5).  
- **Title claim not validated:** The paper seems to assume ChatGPT represents all LLMs; results may not generalize to other LLMs. The title “Large Language Models are Universal Tabular Predictors” is not convincingly demonstrated (Reviewer 3).  
- **Data leakage concerns:**  
  - Example in Listing 7, A.3 shows “Unnamed: 0 is 2346”, which could leak target ordering if data is sorted by target magnitude (Reviewer 1).  
  - Test data from public Kaggle may have been seen during pretraining of the underlying LLM, confusing the source of improvements (Reviewer 3).  
- **Weak baselines and missing comparisons:**  
  - TabLLM baseline uses GPT-2 instead of the original T0 with T0-Few recipe, making it artificially weak (Reviewers 2, 4).  
  - Stronger baselines like TabPFN are missing (Reviewer 2).  
  - CatBoost, which handles categorical variables well, is not included; ordinal encoding for categoricals may be suboptimal (Reviewer 1).  
  - No comparison to per-dataset state-of-the-art (e.g., Kaggle top results) (Reviewer 5).  
- **XGBoost distillation concern:** The large performance gap from the XGBoost teacher signal suggests success may stem from distilling XGBoost rather than the LLM’s intrinsic reasoning. Ablation does not test alternative classifiers for target augmentation nor exclude target augmentation entirely (Reviewers 4, 5).  
- **Limited task scope:** The paper appears to evaluate only classification tasks; regression tasks are not addressed. It is unclear which datasets are classification vs. regression and how continuous targets are handled, undercutting the claim of “universal” prediction (Reviewers 3, 5).  
- **Metadata reformatting quality:** The process uses ChatGPT to generate descriptions, but there is no measurement of hallucination impact or post-processing to control content quality (Reviewers 2, 4).  
- **Unclear calibration and confidence:** The interpretation of model-output class probabilities as confidence is not defined. No calibration metric (e.g., Expected Calibration Error) is provided (Reviewers 1, 2).  
- **Statistical significance missing:** No statistical tests (e.g., critical difference plots) are shown to confirm that UniPredict significantly outperforms baselines (Reviewer 1).  
- **Reproducibility:** No code or materials are released (Reviewer 3).  
- **Missing ablation experiments:**  
  - The effect of using vs. not using target augmentation is not ablated (Reviewer 5).  
  - UniPredict-light (no metadata) performs comparably to UniPredict-heavy, questioning the benefit of metadata. The ablation does not explain why metadata should affect handling of confidence estimates (Reviewer 2).  
- **Hyperparameter tuning of baselines:** Details on hyperparameter selection for baselines are not provided, and tuning appears insufficient (Reviewer 1).  
- **Few-shot evaluation scope:** Only datasets with very few samples are tested; the method should be evaluated with more samples in the few-shot regime (Reviewer 1).  
- **Performance comparison with XGBoost:** Reviewer 5 noted that UniPredict’s results are not significantly better than XGBoost and that it “feels like distilling XGBoost,” contrasting with the claimed 5.4–13.4% improvement reported by other reviewers.  
- **Typographic errors:**  
  - Abstract: “Here, we show that scaling up an LLM to extensive tabular inputs and predicting of target variables following the input instructions” is unclear.  
  - “our method outperforms XGBoost over 100% on the low-resource setup” is ambiguous.  
  - Page 1, para 2: “most previous methods fall short of assuming a fixed target” should be “fall short by assuming”.  
  - Sec-3.5: table number is wrong, and “Abl-h” appears twice (Reviewers 2, 4).
