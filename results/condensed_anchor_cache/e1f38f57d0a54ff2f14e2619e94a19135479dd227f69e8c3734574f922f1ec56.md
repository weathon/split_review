## Merged Review

### Summary
The paper introduces DVDet, a Descriptor-Enhanced Open Vocabulary Detector that uses conditional context prompts and hierarchical textual descriptors to improve region-text alignment. Condition context prompts expand ROI regions to create more image-like features for CLIP, while an LLM iteratively generates and refines fine-grained descriptors for each category. Experiments on COCO and LVIS show consistent gains over existing open-vocabulary detectors.

### Strengths
- Using an LLM to generate fine-grained descriptors without extra annotations is a cost-effective and well-motivated approach that addresses granularity challenges in object detection.
- The conditional context prompt effectively bridges the gap between region embeddings and image-level features, aiding open-vocabulary recognition.
- The iterative descriptor extraction and refinement process is interesting and provides a dynamic way to enhance category descriptions.
- DVDet can be plugged into various SOTA open-vocabulary detectors and consistently improves performance, with convincing ablation studies verifying each component.
- The paper is clearly presented with helpful figures (Fig. 2, Fig. 3) that aid understanding.

### Weaknesses
- **Missing comparison with related concurrent works**: Region-level prompting was previously proposed in CORA (CVPR 2023), and using LLMs to generate textual descriptors appears in recent/concurrent work [1] and [2]. Numerical and architectural comparisons with these methods are needed to assess the novel contribution.
- **Marginal performance gains vs. added complexity**: The average improvements are ~2% on benchmarks, which may not justify the extra computation, hyperparameters, and LLM calls. No analysis of training/inference speed or computation overhead is provided.
- **Limited open-vocabulary specific benefit**: Gains on base categories are similar to those on novel categories (e.g., Detic + DVDet: +2.7 Novel AP vs +2.2 Base AP on OV-COCO; +1.8 mAPᶠ vs +1.3 mAPʳ on LVIS). This suggests the method primarily improves general detection rather than specifically boosting open-vocabulary capability. Evaluating in a standard detection setting and on LVIS-trained models transferred to Objects365 (a more common transfer setting) is recommended.
- **LLM descriptor quality and sensitivity**: There is insufficient analysis of descriptor semantic coherence, diversity, biases, or redundancy. The LLM may produce only generic descriptions without seeing objects, and the prompt design’s impact on final results is unclear. Reproducibility is a concern due to LLM randomness, and the effect of inaccurate regional prompts on LLM interaction is not explored.
- **Counter-intuitive ablation result**: Adding fine-grained descriptors alone (without the conditional context prompt) hurts performance (Table 3, row 2). This should be verified on other OVD models (e.g., ViLD, Detic) to understand whether the context prompt is necessary for leveraging descriptors.
- **Hyperparameter and implementation ambiguities**: The constants \(m,n\) in Eq. (2) are not ablated; optimal values (e.g., proportional to ROI dimensions?) are unclear. The “number of high-frequency descriptors” in Table 7 seems conflated with the number of dictionary update iterations—what is the optimal iteration count? The overall number of hyperparameters (descriptors, iterations, thresholds) is non-negligible.
- **Missing variance over runs**: The variance of results (e.g., on LVIS over 3–5 independent runs) is not reported, especially given the LLM’s randomness.
