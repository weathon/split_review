- Decision: Accept
- Scores: 5, 8, 8, 6

## Merged Review

### Summary
The paper proposes Chain-of-Focus (CoF) Prompting for Large Autoregressive Vision Models (LAVMs), inspired by Chain-of-Thought. CoF generates intermediate reasoning steps via visual saliency (U2-Net) and selects prompts based on query similarity (Jaccard index of VQ-GAN codebooks) and target informativeness (number of unique codebook indices). Evaluated on image segmentation, object detection, image inpainting, and pose estimation using LLaMA-300M/1B/7B backbones. Two reviewers score 8, one 6, one 5. Reviewers agree the idea is interesting and well-motivated, but disagree on the significance of empirical gains and the breadth of task coverage.

### Strengths
- **Innovative adaptation of chain-of-thought to vision.** Creative insight that images have an inherent logical structure exploitable via progressive saliency, analogous to human visual attention. (Reviewer 1, 4)
- **Well-motivated and easy to reproduce.** The use of off-the-shelf saliency scores, Jaccard similarity of VQ-GAN codebooks, and unique-index counts is reasonable and reproducible. (Reviewer 3)
- **Comprehensive evaluation across models and tasks.** Tested on LLaMA-300M, LLaMA-1B, LLaMA-7B; tasks include segmentation, pose estimation, object detection, inpainting; ablations isolate cognitive reasoning, query relevance, and annotation diversity. (Reviewer 1, 2, 4)
- **Intuitive visualizations** (e.g., Figure 3). (Reviewer 2)
- **Detailed ablation studies** clarifying contributions of each component. (Reviewer 4)
- **Innovative methods and significant experimental results.** (Reviewer 2) – though Reviewer 3 and Reviewer 1 found gains modest relative to baselines.

### Weaknesses
- **Limited evidence that intermediate reasoning steps are the key factor.** In Figure 4, going from 0 to 2 reasoning steps shows only modest improvement; more steps (just 2) do not show clear advantage. It is unclear whether using more diverse, relevant, and annotation-rich visual prompts (without decomposition) could match or outperform CoF’s progressive steps. (Reviewer 3; similar question by Reviewer 1: “Would the model perform equally well if it viewed the same number of images within reasoning steps, not randomly selected, such as viewing the same number of final step reasoning images?”)
- **Comparative baseline too simple.** The main baseline is random prompt selection; the performance gain over it is not as significant as expected. (Reviewer 3)
- **Task coverage is contested.** Reviewer 1 states the method is tested on only two tasks (segmentation and pose estimation) compared to prior work like “A Generalist Painter.” Reviewer 4 says experiments focus on “few select tasks, mainly segmentation and pose estimation.” In contrast, Reviewer 3 lists four tasks (segmentation, detection, inpainting, pose estimation). Broader evaluation on tasks requiring temporal reasoning (video understanding) or 3D structure understanding is missing. (Reviewer 1, 4)
- **Computational complexity and resource overhead insufficiently addressed.** The prompt pool uses 50,000 training images with annotations, raising privacy concerns and requiring significant storage and retrieval resources. The computational cost of searching this large pool during inference is not thoroughly analyzed. There is no breakdown of time per step (saliency detection, prompt generation, inference) or memory footprint (saliency maps, intermediate representations). (Reviewer 2, Reviewer 4)
- **Comparison of computational complexity across methods is absent.** (Reviewer 2)
- **Figure 3 lacks ground-truth visualizations.** (Reviewer 2)
- **Failure case analysis is surface-level.** The paper mentions failures like pure black predictions but does not categorize failure types or explore mitigation strategies (e.g., error detection, refined prompt selection). (Reviewer 4)
- **Dependence on saliency detection quality not explored.** CoF relies on U2-Net; no analysis of how performance varies with different saliency detectors (lower accuracy, noise). Saliency models may over-attribute attention to faces, animals, or intensive actions, biasing reasoning steps. (Reviewer 4; also raised as a question by Reviewer 3)
- **Vague terminology.** Terms like “informative”, “informativeness”, “relevance” (vs “relevancy”) are not clearly defined. The difference between image relevancy and query relevance (e.g., Figure 2, line 140 vs line 216) is ambiguous. (Reviewer 3)
- **Missing related work discussion.** No comparison to Chain-of-Spot (2024) and Chain-of-Sight (2024). (Reviewer 3)
- **Distribution shift not addressed.** No evaluation of when the prompt pool contains no data related to the test distribution. (Reviewer 2)
- **Alternative formulation not compared.** Reviewer 1 asks: if CoF simply progresses from single-object images to two-object to multi-object, where are the disadvantages compared to the proposed saliency-based approach? (Reviewer 1; missing ablation)
- **Alternative saliency measures not explored.** Beyond attention-grabbing objects, no alternatives considered. (Reviewer 3)

**Reviewer disagreement:** One reviewer (score 5) is skeptical about why CoF works and questions task coverage; two reviewers (score 8) find the results significant and visualizations intuitive; one reviewer (score 6) acknowledges strengths but requests deeper analysis of failures, complexity, and generalization.
