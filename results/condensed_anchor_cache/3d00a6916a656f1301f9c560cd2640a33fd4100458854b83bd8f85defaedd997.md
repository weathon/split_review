## Merged Review

### Summary
The paper replaces Multi-Layer Perceptrons (MLPs) in PointNet with Kolmogorov-Arnold Network (KAN) layers to create PointNet-KAN for 3D point cloud classification and part segmentation. It uses Jacobi polynomials (including special cases Legendre, Chebyshev, Gegenbauer) to construct the KAN layers and evaluates across polynomial degrees. The work is the first to apply KAN in the 3D domain, showing competitive performance to PointNet on benchmark datasets (ModelNet40, ShapeNet Part) with a shallower architecture, though results are mixed.

### Strengths
+ First work to introduce KAN into point cloud analysis tasks, providing a foundation for future integration (Reviewer 3, confidence 4).
+ Paper is logically coherent, with complete formulas, and includes substantial experimentation across polynomial degrees and special types (Reviewers 1, 3).
+ The approach accommodates Jacobi polynomials and their special cases (Reviewer 1, confidence 3).
+ The paper is well-written and easy to understand (Reviewer 1).
+ Integrating KAN into the 3D domain is interesting and may benefit the field (Reviewer 2, confidence 4).
+ Provides valuable guidance for subsequent application of KAN in point cloud tasks (Reviewer 3).

### Weaknesses
- **Limited novelty and contribution**: The method is a straightforward replacement of MLPs by KANs in PointNet without architectural innovations or adaptations for 3D point cloud properties (e.g., irregularity, unorderness) (Reviewer 1, confidence 3; Reviewer 2, confidence 4). Reviewer 3 (confidence 4) acknowledges the first application but the paper is seen as lacking technique improvements beyond direct substitution.
- **Weak experimental performance**: On ModelNet40 classification, PointNet-KAN only marginally surpasses PointNet, and on ShapeNet Part segmentation it performs lower than PointNet (Tables 1, 2). The improvements are less than 2%, raising questions about practical benefit (Reviewers 1, 2, 3). The performance drop on part segmentation needs detailed category-level analysis beyond mean IoU (Reviewer 3).
- **Lack of motivation for KAN in 3D**: The paper does not illustrate benefits beyond KAN learning its own activation functions; it is unclear why KAN is specifically advantageous for point clouds (Reviewer 2).
- **Missing real-world dataset evaluation**: Experiments are limited to synthetic datasets (ModelNet40, ShapeNet Part). The paper should include the more challenging ScanObjectNN dataset to assess generalizability (Reviewer 1, confidence 3; Reviewer 3, confidence 4).
- **No time complexity analysis**: The computational cost of KAN layers (especially with higher-degree polynomials) during training/testing is not discussed. A breakdown is needed to justify replacing MLPs, as increased polynomial degree raises parameter count (Table 3) without clear benefit (Reviewer 1).
- **Confounding effect of parameter count vs. polynomial degree**: Table 3 shows marginal accuracy improvements when increasing Jacobi polynomial degree from 2 to 4, but this may be due to increased parameters. The paper does not isolate the effect of polynomial degree from model size (e.g., by comparing models with similar parameter counts) (Reviewer 1).
- **Sensitivity to input variations**: On ModelNet40, PointNet-KAN shows a substantial performance drop when input does not include normal vectors. The paper lacks investigation or explanation for this sensitivity, including per-class accuracy analysis (Reviewer 3).
- **Incomplete robustness experiments**: Only point quantity variations are tested. Missing experiments with Gaussian noise and rotation, which are common real-world challenges (Reviewer 3).
- **Missing qualitative segmentation results for special polynomials**: Visual comparisons for Legendre, Chebyshev, and Gegenbauer polynomials are not provided, though results for Jacobi polynomials are shown (Reviewer 1).
- **Limited architecture exploration**: Only PointNet is used as the base model. The paper should try embedding KAN into other MLP-based architectures like PointMLP to test broader applicability (Reviewer 2, confidence 4; Reviewer 3, confidence 4).
- **No analysis of tensor size and global features**: The impact of tensor dimensions and global feature size on performance is not explored, which would provide insights into scalability (Reviewer 3).
- **Figure 2 lacks visual comparison**: The segmentation visualization should include comparisons with other methods to demonstrate effectiveness (Reviewer 3).
