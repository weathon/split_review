## Merged Review

### Summary
The paper proposes PFEDRL-REP, a personalized federated reinforcement learning framework that learns a shared feature representation across agents and agent-specific weight vectors to handle environment heterogeneity. A specific instance, PFEDTD-REP, using temporal difference learning, is analyzed and claimed to achieve the first linear convergence speedup w.r.t. number of agents in personalized FedRL under Markovian noise. Experiments on CliffWalking, CartPole, and Acrobot show improved learning and generalization compared to non-personalized baselines. Reviewer 2 is strongly positive (score 8), while Reviewers 1 and 3 are moderately positive (score 6), raising concerns about experimental validation and interpretation of the linear speedup.

### Strengths
- Novel personalized FedRL framework (PFEDRL-REP) that addresses heterogeneous environments by combining shared representations with agent-specific personalization.
- First theoretical proof of linear convergence speedup w.r.t. number of agents in personalized FedRL with TD learning and shared representations, under Markovian noise.
- Rigorous convergence analysis using two-timescale stochastic approximation, with clearly stated assumptions and a proof sketch.
- Well-structured and clear presentation of problem formulation, framework, and analysis.
- Practical relevance to real-world heterogeneous federated RL.
- Interesting experimental results on cliff-walking and cartpole, showing benefits in both policy evaluation and control settings.

### Weaknesses
- **Experimental evaluation is limited** to simple classic control tasks (CliffWalking, CartPole, Acrobot). Lacks complex environments with sparse rewards or high-dimensional state spaces, and no statistical significance or error bars are reported.
- **Missing comparisons**: No comparison with other personalized federated learning methods or parameter-sharing multi-agent RL algorithms.
- **Linear speedup claim is potentially misleading**: Corollary 4.15 states that one can proportionally reduce the number of iterations T as N increases while keeping the same convergence rate. This is not true linear acceleration (where convergence rate inherently improves with N), and the claim could mislead readers. Moreover, sample collection grows linearly with N, making a trivial speedup. No experimental ablation varying the number of agents N is provided to validate the speedup, unlike prior FedRL work (e.g., Fan et al., which is missing from related work). How to determine the optimal number of agents is unclear.
- **Personalization lacks formal definition and validation**: No metric or theoretical guarantee that agent-specific parameters capture meaningful environment-specific adaptations. Unclear how the number of agents N affects personalization quality, and whether there is a tradeoff between personalization strength and global convergence speed or performance. The effect of completely different environments (no shared structure) on the results is not addressed.
- **Privacy concern**: Sharing a common representation may breach privacy, which is not discussed.
- **Problem formulation**: The transition from (1) to (2) in Section 2.2 is not justified—why it preserves problem properties is unclear.
- **Applicability concern**: Shared feature representations may not capture similarity across diverse environments, and agent-specific weights may not capture all heterogeneity nuances, limiting universal applicability.
- Reviewer 1 notes the theoretical speedup is not particularly exciting given linear growth in sample collection. Reviewer 3 emphasizes the missing ablation on agent count and the misleading linear speedup claim. Reviewer 2 is more favorable but also requests more complex environments.
