## Merged Review

### Summary
The paper proposes CoINR, a post-hoc compression method for pre-trained implicit neural representations (INRs). It applies compressed sensing: given weight vector \(w\in\mathbb{R}^n\), a random sensing matrix \(A\in\mathbb{R}^{n\times m}\) (with \(n\ll m\)) is used to find a sparse representation \(x\) via \(\min\|x\|_1\) s.t. \(w=Ax\). The indices and values of non-zero entries of \(x\) are then compressed with Brotli (a variant of ZIP). Because \(A\) is fixed at the decoder by a random seed, it does not need to be transmitted. Experiments on images (Kodak), occupancy fields, and NeRF show rate-distortion improvements over COIN, COIN++, and INRIC. The method is plug-and-play and can be applied to any pre-trained INR.

### Strengths
- **Novel idea**: Using compressed sensing / sparse coding for INR weights is neat and has not been explored elsewhere (R1, R3). The random sensing matrix avoids transmission and is well motivated (R3).
- **Post-hoc and plug-and-play**: The approach does not rely on a specific INR architecture and can improve existing compression pipelines (R1, R4). Works across multiple modalities (images, occupancy fields, NeRF) (R3, R4).
- **Clear method description**: Figure 2 and the algorithmic steps are clearly presented (R3).
- **Interesting analysis**: Appendix shows sparsity levels across hidden neurons scale linearly with the number of hidden neurons (R4).
- **Improved performance**: Significant improvements over INRIC and COIN baselines in terms of rate-distortion (R4).

### Weaknesses
**Critical mathematical errors**
- **Line 238 CLT claim**: “According to the Central Limit Theorem (CLT), a normally distributed random variable can be produced through a finite linear combination of any random variables” is incorrect. The CLT does not guarantee Gaussianity in a non-asymptotic regime and does not hold for a finite linear combination of arbitrary random variables (R1).
- **Claim that weights are Gaussian is contradicted by own Figure 1b**: The histograms show distributions that are either more concentrated or more heavy-tailed than a Gaussian. It is also unclear whether Figure 1b plots weights from a single INR or across instances (R1). Because of these fundamental errors, R1 believes the paper may be beyond repair for ICLR.

**Incomplete related work and missing baselines**
- Missing references to Bayesian INR compression (Guo et al., NeurIPS 2023) and RECOMBINER (He et al., ICLR 2024), which also use linear weight-sharing (R1, R4). Also missing: Modality-Agnostic Variational Compression (Schwarz et al., ICML 2023), sparse INRs (Lee et al., 2021), dictionary-based approaches (Yüce et al., 2021), occupancy field compression (Lu et al., 2021), and NeRF compression methods (Bird et al., Isik et al., Shi et al., Takikawa et al.) (R2, R3).
- Because of these works, the claim “None of the existing methods have explored fundamentally compressing the INR by identifying patterns within its parameter space before applying standard techniques such as quantization and entropy coding” is not true (R4).
- The image compression results still have a large gap compared to traditional codecs like BPG or learned models (Ballé et al., ICLR 2018) (R2). For occupancy fields and NeRF, RD curve comparisons are missing (R2).

**Missing ablation studies and experimental details**
- No ablation on how quantization affects reconstruction quality (R1).
- No ablation on different distributions for the entries of the sensing matrix \(A\) (R1).
- The attempted compression methods described in Section 3.2 (e.g., structured/unstructured pruning) are not supported by experimental evidence; the discussion is anecdotal (R1).
- For NeRF, the comparison is unfair: the baseline NeRF file size is uncompressed, while the proposed method uses quantization and entropy coding. A proper baseline would be NeRF with quantization and entropy coding (R4).
- For COIN++ experiments (Fig. 4), it is confusing whether the base network is included in the rate. COIN++ does not need to encode a base net; the reported curve is lower than the original COIN++ paper. It remains unclear whether the method still helps if the base net is excluded (R4).
- No error bars are provided for the randomness of matrix \(A\); results may vary with different seeds (R4).
- Supplementary Figures 12–15 (presumably NeRF) do not include COIN results, unlike Figures 10–11 (R3).

**Presentation and clarity issues**
- Most figures in the main text (Figures 1, 3, 4, 6, 7, 8, 9, 10, 11) have illegibly small text, labels, legends, and tick marks (R1, R3).
- Section 3.2 lists alternative methods in the main description but would be better placed in a discussion/limitations section; some methods (e.g., pruning) are not used in the final method (R3).
- Experiments C1–5 and Figures 3/4 are hard to parse; reorganisation would improve focus (R3).
- The introduction’s first paragraph is very general and could be removed (R1).
- The term “entropy coding” for Brotli (a Lempel-Ziv based universal coder) is misleading; entropy coding usually implies an explicit statistical model with arithmetic coding (R1).

**Minor concerns**
- Need to clarify whether the method is solely a post-processing step (no additional training/fine-tuning) and provide optimization run-time details (R3 question). Also clarify whether Figures 10/11 use INRIC, COIN, or another base INR (R3).
- The hyperparameters for Gaussian / SIREN activations should be discussed, as performance depends critically on them (R3 suggestion).
- Including BD-Rate / BD-PSNR metrics would improve the analysis (R3 suggestion).
