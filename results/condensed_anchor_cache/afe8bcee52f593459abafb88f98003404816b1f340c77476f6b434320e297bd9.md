## Merged Review

### Summary
This paper proposes Open-World Continual Learning (OWCL), a setting where a deployed model detects out-of-distribution objects and incrementally learns them using scarce data. The method, OpenLD, combines a frozen pre-trained feature extractor with Linear Discriminant Analysis (LDA) to perform OOD detection (via Mahalanobis distance) and class-incremental learning without catastrophic forgetting. Experiments on CIFAR-10, CIFAR-100, and TinyImageNet are presented. One reviewer was significantly more positive (score 6) than the other three (scores 3), praising the topic and method’s effectiveness, while the majority raised fundamental concerns about the setting’s novelty, methodological choices, comparisons, and scalability.

### Strengths
- The problem of combining OOD detection with continual learning in a realistic open-world scenario is important and relevant, addressing a gap in prior class-incremental learning that assumes pure new-class chunks.
- The OpenLD approach is neat and conceptually simple: both OOD detection and incremental classification use the same distance-based framework (Mahalanobis distance + LDA), avoiding catastrophic forgetting by using a shared covariance matrix and updating class means incrementally.
- Experimental results on CIFAR-10, CIFAR-100, and TinyImageNet demonstrate that OpenLD can handle new OOD classes without losing performance on previously learned classes, and it outperforms compared methods in accuracy and robustness.
- The paper includes experiments across various backbone architectures (e.g., ViT-S/16 DINO, ViT-B/16 SAM) and presents a well-written related work section that summarizes relevant continual learning and OOD detection literature.
- The paper’s flow and presentation are easy to follow (noted by one reviewer despite others raising presentation issues).

### Weaknesses
1. **Lack of novelty and oversight of existing frameworks** – The setting resembles a combination of pre-trained models with continual fine-tuning (which is common for transformer-based CL) and a simple concatenation of existing OOD detection with few-shot class-incremental learning. Two generalized continual learning frameworks [1,2] are overlooked. Why cannot an existing OOD method plus an existing few-shot class-incremental learning method already handle the proposed problem?
2. **Over-reliance on a frozen pre-trained model** – OpenLD never fine-tunes the pre-trained encoder on in-distribution (ID) data before deployment or on new data after deployment. This limits the ability to learn new features for existing categories, which may hurt recognition of known classes over time. The large gap between OpenLD and the Joint Fine-tuning upper bound (especially on larger datasets like TinyImageNet) indicates the approach is not scalable and depends heavily on the fixed features. Starting with the strongest possible model on ID classes is more realistic.
3. **Unrealistic assumption of shared covariance and scalability concerns** – The method assumes all classes share the same covariance matrix. In practice, some classes have larger intra-class variance than others. As the number of categories grows, a shared covariance matrix may cause reduced accuracy or increased computational burden. The performance gap in Table 1 widens with more classes, questioning scalability.
4. **Insufficient comparisons and baseline selection** – The paper does not compare against obvious simpler baselines such as nearest neighbor, nearest centroid, or prototypical networks, nor does it compare with fine-tuning-based continual learning methods. It does not benchmark against the strongest fine-tuned model on ID classes. The motivation for using LDA over these alternative distance-based classifiers is not provided. More comparison methods should be included (e.g., neural network uncertainty or ensemble OOD detectors).
5. **Missing methodological justification** – No explanation is given for why Mahalanobis distance is used, what its theoretical or empirical advantages are over other distances (e.g., Euclidean distance for nearest class mean), or why LDA is preferred. A simple ablation comparing Mahalanobis distance to alternatives is absent.
6. **Practicality issues of the OWCL setting** – The scenario still requires a human to annotate every detected OOD sample, which seems non-realistic for true autonomous lifelong learning. The line between "OWCL" and standard OOD detection + few-shot CL is blurry; it is unclear whether the OOD detection performed here is simply standard OOD detection (the same methods are reused) or if a "continual OOD detection" challenge is actually addressed.
7. **Small-scale datasets and limited evaluation** – Experiments are only on CIFAR-10, CIFAR-100, and TinyImageNet, which are not representative of a true “open world”. Larger datasets such as iNaturalist should be used.
8. **Missing ablation: fine-tuning before deployment** – It is unclear whether the pre-trained model is fine-tuned on the ID train set before deployment. If not, this should be justified because the large performance gap suggests a stronger baseline should be established. Additionally, the paper assumes ID data after deployment is discarded, which is unrealistic.
9. **Presentation and reproducibility issues** – Figure 1 caption does not explain the figure. Table 1 caption does not specify which performance metric is shown. Text is copied from the introduction to Section 2.1, reducing quality. Table formatting needs improvement.
10. **Inconsistent claims in results** – Line 454 claims OpenLD consistently outperforms methods without C^E, yet for CIFAR-10 in Figure 2 this is not true. Lines 471–472 request explanations for why ViT-S/16 DINO and ViT-B/16 SAM are expected to show poorer results, and why ViT-B/16 DINO (same size as ViT-B/16 SAM) is expected to perform better.

[1] Fei Mi, Lingjing Kong, Tao Lin, Kaicheng Yu, Boi Faltings, “Generalized Class Incremental Learning”
[2] Siddeshwar Raghavan, Jiangpeng He, Fengqing Zhu, “Online Class-Incremental Learning For Real-World Food Image Classification”
