- Decision: Reject
- Scores: 3, 8, 5

## Merged Review

### Summary
This paper introduces the Shared Recurrent Memory Transformer (SRMT), which extends memory transformers to decentralized multi-agent reinforcement learning by pooling and broadcasting individual agent memories to enable implicit coordination. The method is evaluated on a toy bottleneck navigation task and the POGEMA benchmark (Mazes, Random, Warehouses). The three reviewers disagree substantially: Reviewer 1 gave a low score (3), finding the baseline selection poorly motivated and the results modest, and noting missing comparisons with MARL communication methods. Reviewer 2 gave a high score (8), praising the rigorous evaluation, clear architecture, and real-world relevance, but noting scalability and ablation gaps. Reviewer 3 gave a moderate score (5), commending the motivation and background but missing key baselines and ablation studies. All reviewers agree the writing is clear and the idea well-grounded; all also identify missing comparisons and insufficient analysis of components.

### Strengths
- **Clear motivation and grounding**: The idea of using a global shared memory for coordination via transformers is well motivated, and the background and related works are well discussed (Reviewers 1, 3). The paper is generally clearly written and polished, and Figure 1 usefully complements the written algorithm description (Reviewer 1).
- **Rigorous evaluation on multiple benchmarks**: SRMT is evaluated on both a bottleneck navigation task (with sparse and directional rewards) and the POGEMA benchmark (Mazes, Random, Warehouses), showing adaptability across diverse coordination scenarios (Reviewer 2). The analysis in Figure 10 is a nice addition (Reviewer 1).
- **Addresses a significant challenge**: The approach of facilitating indirect communication via shared memory addresses a key difficulty in decentralized multi-agent coordination, with potential real-world applications where communication is unreliable or costly (Reviewer 2).
- **Architecture explanation**: The method is clearly explained with diagrams and flowcharts, and the comparisons with baselines are presented straightforwardly (Reviewer 2).

### Weaknesses
- **Insufficient baseline comparisons** (all reviewers):
  * No MARL communication baselines were included (e.g., [1]), despite sharing a similar goal of enabling agent coordination (Reviewer 1). References to works such as RATE and ATM are discussed in Section 2.2 but not compared experimentally, making it difficult to assess the advantage of SRMT over existing MARL memory mechanisms (Reviewer 3).
  * In the bottleneck task, only basic single-agent memory mechanisms are compared; more advanced memory mechanisms such as relational memory [1] and AMRL [2] from single-agent RL are missing (Reviewer 3).
  * The baselines that are used are not well motivated or described in sufficient detail, and the results in Figure 5 show only modest advantages for SRMT and its variants (Reviewer 1).
  * No comparison with centralized approaches on key metrics (e.g., optimality, computational cost, communication overhead) is provided, which is needed to understand the trade-offs of decentralized coordination (Reviewer 2).
  * A reviewer specifically asked why MAMBA (with discrete communication protocol) outperforms SRMT in some scenarios, implying the global shared memory may not always be the best choice and raising the question of how to select the right method (Reviewer 3). Another reviewer asked whether combining shared memory with limited explicit communication could benefit high-density environments (Reviewer 2).
- **Missing component ablation and memory analysis** (Reviewers 2, 3):
  * No ablation study validates the contribution of each SRMT component (self-attention, cross-attention, shared memory itself) (Reviewer 3). A reviewer noted that the paper lacks analysis of how shared memory influences individual agent behavior and decision-making, e.g., visualizations of memory representations over time (Reviewer 2). An ablation removing the shared memory is necessary to quantify its impact (Reviewer 2).
  * One reviewer specifically asked for analysis of internal dynamics: how agents utilize shared memory during task execution and its evolution over time (Reviewer 2).
- **Scalability and map complexity concerns** (Reviewers 2, 3):
  * Evaluation is limited to small-to-medium environments; scalability to very large maps, highly dense settings, or a significantly larger number of agents is uncertain. The paper lacks rigorous analysis of how shared memory scales with number of agents and map complexity, particularly when agent count exceeds shared memory capacity, and does not test varying obstacle densities or sizes (Reviewer 2). Reviewers asked about training time growth with more agents and whether capacity becomes a bottleneck (Reviewers 2, 3).
- **Reward structure interaction not deeply explored** (Reviewer 2):
  * While performance varies across reward structures, a more detailed exploration of how reward shaping influences learning (e.g., impact of sparse rewards on convergence rate, final performance, and interaction with shared memory) is missing. This would help tailor SRMT to tasks with only sparse rewards.
- **Other missing analyses** (Reviewers 2, 3):
  * A reviewer asked for the number of network parameters for each method, as SRMT uses transformers and ResNet and may gain advantages from higher parameter counts (Reviewer 3).
  * A reviewer asked about integration with hierarchical pathfinding methods (e.g., combining local and global strategies) (Reviewer 2).
- **Presentation issues** (Reviewers 1, 3):
  * Error bars in Figure 4 are too muddled to interpret (Reviewer 1).
  * Language could be tightened: e.g., L043 "has to reach its goal" is colloquial; contraction in L497 (Reviewer 1).
  * Typo: Line 36, "MAPF" is not defined (Reviewer 3).
  * A reviewer considers [2] (first work discussing attention in MARL) a necessary work to acknowledge, but it was omitted (Reviewer 1).
