## Merged Review

### Summary
The paper proposes BOOD, a framework that generates boundary-near OOD images by first selecting ID features closest to the decision boundary (via minimal perturbation steps to change classifier prediction), perturbing them with gradient ascent to cross the boundary, then decoding the synthetic OOD features into images using a diffusion model. The generated OOD data regularize OOD classifier training. Experiments on CIFAR-100 and ImageNet-100 as ID show significant gains over SOTA (e.g., 29.64% FPR95 reduction on CIFAR-100), though improvement on ImageNet-100 is marginal.

### Strengths
- First framework to explicitly generate OOD data around the decision boundary, providing informative features for shaping the ID/OOD decision boundary. The approach is intuitively and technically sound.
- Performance gains on CIFAR-100 are substantial: 29.64% decrease in average FPR95 (40.31% vs. 10.67%) and 7.27% improvement in average AUROC (90.15% vs. 97.42%). Synthesized images look visually reasonable as boundary cases.
- The paper is well-written with clear structure, smooth logic, and thorough explanation of methods and algorithmic procedures; formulas and notations are well-defined.
- Ablation experiments, hyperparameter analysis, and visualization experiments are considered comprehensive by R3 (though other reviewers request more analysis – see Weaknesses). R3 specifically notes the ablation/hyperparameter/visualization experiments as a strength.

### Weaknesses
- **Computational cost**: R1 and R2 note that calculating boundary positions of numerous features and generating images via diffusion models is computationally time-consuming. R2 requests analysis of computation-performance tradeoffs (e.g., performance vs. number of images generated per class). R1 asks for comparison of actual memory requirements.
- **Marginal improvement on ImageNet-100**: R2 points out that while CIFAR-100 improvement is strong, ImageNet-100 (also 100-class natural images) shows only marginal gain, raising uncertainty about general effectiveness. More in-depth discussion on when BOOD provides significant advantages over prior approaches is needed.
- **Insufficient justification of adversarial perturbation strategy**: R4 questions whether perturbing features to change class identity might inadvertently produce features of other ID classes; theoretical or empirical evidence that the perturbation reliably yields features distinct from existing classes is needed. R1 and R4 request comparative analysis with alternative perturbation strategies (e.g., random Gaussian noise, displacement from class centroids). R4 explicitly asks for an ablation study comparing the proposed adversarial perturbation against these simpler alternatives.
- **Hyperparameter selection**: R1, R2, and R4 note that hyperparameters (pruning rate r, max perturbation K, regularization weight β) are crucial but their selection basis is not well justified; guidelines for applying BOOD to new ID datasets would be helpful. While R3 considers the hyperparameter analysis comprehensive, R1 and R4 request more thorough sensitivity analysis with wider ranges and more intuitive visualizations. R1 specifically asks for the basis for selecting the hyperparameter(s) (the paper treats the perturbation step count as a hyperparameter).
- **Limited SOTA comparison**: R3 notes that Table 2 could include more recent 2024 methods to better highlight advantages.
- **Performance on specific OOD datasets**: R4 observes that BOOD performs significantly worse than NPOS on the Textures dataset (Table 2) and requests an explanation based on dataset characteristics or method limitations.
- **Domain generality concerns**: R2 notes the method is bounded by stable diffusion's training distribution; effectiveness is uncertain for very different domains (SVHN, texture, medical imaging) or fine-grained classification tasks.
- **Missing architectural details**: R4 points out that architectures of the image encoder and OOD classification model are insufficiently described (e.g., number/type of layers, activation functions), hindering reproducibility.
- **Equation error and notation issues**: R4 identifies an error in Equation (2) – denominator should be Γ(y_j)^T z, not as written; suggests a thorough review of all equations. R3 notes a notation conflict between additional perturbation steps c (lines 287-288) and earlier use of C for number of classes.
- **Missing descriptions of figures**: R1 notes that Figures 2, 3, and 4 lack descriptions in the main text, requesting more comprehensive evaluation.
- **Comparison with real OOD data**: R2 asks how necessary synthetic OOD data is compared to using publicly available real OOD data (e.g., Hendrycks et al. ICLR 2019) for augmentation, and whether training with real OOD data generalizes to unseen OOD data.
- **Typos**: R2 points out citation formatting errors (L047, L179, L232).
