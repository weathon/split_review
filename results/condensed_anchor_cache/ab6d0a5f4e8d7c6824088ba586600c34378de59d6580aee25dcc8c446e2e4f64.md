## Merged Review

### Summary

The paper introduces Structural Quantile Normalization (SQN), a differentiable feature scaling method that balances Gaussian approximation with structural preservation. SQN fits a Gaussian KDE to a feature's distribution, then applies the inverse Gaussian CDF to the KDE-based CDF estimate. PCHIP splines are used in Fast-SQN to achieve linear scalability while enforcing smoothness and monotonicity. The method is evaluated on the California Housing dataset and compared with classical and ordered quantile normalization, Box-Cox, and Yeo-Johnson transformations, using feedforward neural networks.

### Strengths

1. **Well-motivated and clearly written** (R1, R2, R3). The paper is easy to follow and provides a reasonable literature review with elegant graphs (R3).
2. **Fast-SQN efficiently solves the computational issue** via a clever spline interpolation layer (R1) – PCHIP splines are an interesting proposal to achieve linear scalability while maintaining smoothness and monotonicity (R4).
3. **The method covers existing methods as special cases** (R2). Table 1 shows efficacy on the given dataset (R1). Feature preprocessing is an important task (R4).

### Weaknesses

1. **Experimental validation is insufficient.** Only the California Housing dataset is used (R1, R2, R3, R4). R3 notes it is a basic textbook/toy dataset and not convincing. R4 stresses the need for a benchmark of tabular datasets. R2 observes that only the *target* feature is normalized (line 390), whereas rescaling input features would be more typical. R1 questions applicability to image data and whether KDE limits applicability to high dimensions – the method seemingly works only in one dimension (R3).
2. **Lack of error bounds and significance.** Table 1 reports point estimates without error bounds or multiple runs (R1, R2). For example, in model 3 Fast-SQN improves RMSE over YJN by only 0.001; mean and standard deviation over several random seeds are missing (R2).
3. **No empirical benefit of differentiability is demonstrated.** Despite its emphasis as an advantage, differentiability offers no benefit in the current experiment setting (R2, R4).
4. **Theoretical support is absent.** R3 (with high confidence 5) states there is no theoretical contribution: the proposition in the appendix is formulated non-rigorously (type of convergence not specified; KDE depends on random empirical measure but ω‑wise convergence is not clarified). The take‑away of Proposition 1 and its concrete implication for the method are unclear (R3). R3 also asks whether any *provable* guarantee exists that SQN must improve downstream learning.
5. **Similarity to prior work (KDIT) limits originality.** R4 (confidence 5) notes the overall approach is the same as KDIT (McCarter, TMLR 2023): use KDE to smooth the pdf, then apply inverse cdf of a reference distribution. Differences are minor: (A) SQN uses Gaussian as reference (interpolating between z‑score and quantile normalization) whereas KDIT evaluates only uniform reference (min‑max vs. quantile); (B) SQN uses PCHIP splines for linear complexity, KDIT uses a polynomial‑exponential kernel (Hofmeyr, TPAMI 2019). R4 also questions whether everywhere smoothness from PCHIP is valuable given the use of non‑everywhere‑smooth ReLU activations.
6. **Evaluation with non‑SotA models.** The method is combined with feedforward neural networks, which are not state‑of‑the‑art for tabular data, obscuring whether performance gains come from preprocessing or the architecture (R4). R4 suggests combining with linear methods or modern approaches (e.g., TabPFN, CSDI‑T, TabDDPM).
7. **Minority negative view (R3, score 1, confidence 5):** R3 strongly criticizes the lack of theoretical and experimental support, calling the numerics unconvincing and the method one‑dimensional only. R3 also questions how SQN applies to general probability measures in ℝ^d (e.g., via Sklar's theorem and copulas) and whether the operation is invertible and regular in high dimensions.
