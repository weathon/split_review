## Merged Review

### Summary
The paper proposes ECALP, a graph-based framework for training-free adaptation of vision-language models. It dynamically constructs a graph over text prompts, few-shot examples, and test samples, using iterative label propagation for inference. A context-aware feature re-weighting mechanism is introduced to improve task adaptation. The method requires no additional unlabeled support set and supports efficient real-time inductive inference. Extensive experiments on zero/few-shot fine-grained classification, style-transfer, and out-of-distribution detection demonstrate performance gains over prior methods. Four reviewers rated the paper 6, 6, 6, and 8 (Reviewer 4 is distinctly more positive).

### Strengths
- **Comprehensive experiments with strong results**: The method is evaluated across a wide range of datasets and tasks, with well-justified baselines and ablation studies. Empirical results show clear improvements. (R1, R2, R3, R4)
- **Clear presentation and structure**: The paper is well-written, easy to follow, and figures effectively highlight the pipeline. (R1, R2, R4)
- **Clear motivation**: The introduction and abstract lay a good foundation; the motivation is easy to see. (R1)
- **No need for additional unlabeled support set**, unlike related methods (e.g., ZLaP). (R2)
- **Innovative dynamic graph expansion** enabling real-time adaptation and efficient use of test samples. (R3, R4)
- **Novel context-aware feature re-weighting** that aligns well with pre-trained VLM properties. (R3, R4)
- **Iterative solution reduces computational cost** and enhances scalability, supported by wall-clock time analysis (Table 6) and time complexity (Appendix A.1). (R3, R4)
- **Use of K-nearest neighbors within each modality** is a novel and well-motivated approach. (R4)

### Weaknesses
- **Figure 1 appears to have a labeling error**: the inputs to the second image encoder and the text encoder seem mixed up (also noted by Reviewer 4). (R1, R4)
- **Contribution is somewhat limited** given the similarity to the label propagation idea in ZLaP, despite improvements in performance and removing the need for an unlabeled support set. (R1)
- **Few-shot robustness is inconsistent**: In appendix detailed results, ECALP does not always achieve best performance. On OxfordPets and Food101, accuracy *decreases* as the number of shots increases, which weakens the claim of robustness in low-shot scenarios. The authors should explain this behavior. (R1)
- **Performance improvement over SOTA is limited**; second-highest results should be underlined for clarity. (R2)
- **Computational efficiency reporting is unclear**: Does the reported testing time include the dynamic graph construction process, or only the label propagation time? (R2)
- **CUDA memory usage is not compared**; the method likely requires additional storage, and a memory comparison with prior methods is needed. (R2)
- **Potential cumulative error from initial test samples**: If the initial test samples create an incorrect adjacency graph, could this lead to accumulating errors during iterative propagation? (R2)
- **Effectiveness on corrupted tasks with low severity (e.g., level 1) is not evaluated**. (R2)
- **Sensitivity to label propagation iterations \(T\) is not analyzed**. (R2)
- **More detailed motivation behind the model design is preferred**; the reasoning for specific design choices should be elaborated. (R3)
- **Implementation complexity**: The method may be complex to implement for large-scale or varied tasks; detailed guidelines would be beneficial. (R3)
- **Generalization assumption**: The approach assumes context-aware feature re-weighting will generalize across different tasks, but this may not hold for all types of data or significant domain shifts. (R3)
- **Ablation finding requires explanation**: In Table 4, without Text Reweight, the model achieves *slightly better* performance under the 16-shot setting on ImageNet. The authors should shed light on this phenomenon. (R1)
- **Trade-off not evaluated**: It would be valuable to analyze performance degradation when using one-step label propagation instead of iterative propagation, to help practitioners balance complexity and accuracy. (R4)
- **Combination with prompt learning methods unexplored**: When using additional 16-shot training samples (as in Table 2), ECALP incorporates them into the graph rather than for training. Could ECALP also be applied on top of traditional prompt learning methods like CoOp and CoCoOp? (R4)
- **How multiple textual prompts per class are obtained is unclear**: In Line 161, the value of \(M\) (number of prompts per class) can vary from class to class, but the generation process is not explained. (R4)
