## Merged Review

### Summary
The paper proposes a BP-modified local loss method that adjusts the local gradient using the true BP gradient to reduce bias while introducing additional variance, improving performance of local loss training with negligible memory overhead. The method is analyzed via a stochastic modified equation, showing a bias-variance trade-off and deriving optimal scaling factors. Experiments on CIFAR-100 with ResNet-50 and ViT-b16 using full-tuning, LoKr, and LoRA show up to 36% test accuracy improvement for Forward-Forward, 20% for LoCo, 11% for MPC, achieving on average 7.7% accuracy loss relative to BP with up to 75% memory savings.

### Strengths
- **Strong empirical results:** Up to 36% test accuracy improvement for Forward-Forward algorithm, 20% for LoCo, and 11% for MPC on CIFAR-100 (ResNet-50/ViT-b16), significantly outperforming prior local loss methods.
- **Negligible additional memory:** The BP-modified local loss increases GPU memory very little (up to 75% memory savings compared to full BP), with detailed implementation strategies (lazy update, mini-batch splitting) to manage cost.
- **Convincing theoretical analysis:** Provides a theoretical derivation using stochastic modified equations (Ornstein-Uhlenbeck process) to model bias-variance trade-off and derive optimal scaling factors α_h and λ_h, which are well motivated.
- **Innovation:** The method of modifying local loss gradients with true BP gradients is novel and addresses the slow/non-convergence issue of prior local loss methods.
- **Highly readable paper:** Presentation is clear, with detailed implementation descriptions and well-structured arguments (noted by Reviewer 4).

### Weaknesses
- **Limited experimental scope:** Experiments are primarily on CIFAR-100 (relatively small dataset). Missing evaluations on larger datasets such as ImageNet with full-resolution images, which are standard benchmarks for image classification and would better demonstrate scalability and meet the motivation of training large models. Tasks beyond image classification (e.g., object detection, NLP) are not explored, limiting generality.
- **Missing throughput/latency comparison:** There is no comparison of training throughput (e.g., images per second) or per-epoch time against other local loss methods. The overhead of computing the offset Δg_{h,t} (including lazy update and split mini-batch) is not quantified, especially as network depth increases.
- **No training convergence time analysis:** The paper does not report the number of epochs or total training time required to reach convergence, which is critical for evaluating efficiency.
- **Insufficient hyperparameter sensitivity analysis:** The method introduces several hyperparameters (offset batch size B', sampling period K, scaling factors λ_h and α_h). There is no systematic sensitivity analysis or practical guidance on tuning these for different models/datasets. The theoretically derived optimal scaling factors are not empirically validated for their robustness.
- **Limited analysis of delayed gradient adjustment:** The impact of using delayed gradients (due to lazy update) on convergence rate and stability is not analyzed. The paper lacks discussion on how accumulated noise interacts with optimizer momentum and potential oscillations or divergence. A more rigorous study (e.g., Hessian eigenvalue analysis) is needed.
- **Theoretical model simplifications:** The use of the Ornstein-Uhlenbeck process as a linear model to describe non-convex, non-linear deep network training is a strong approximation. No empirical evidence is provided to support that this linear model holds across layers (shallow vs. deep layers may have different gradient dynamics). The analysis does not account for non-convexity or layer-wise heterogeneity in gradient behavior, raising questions about its accuracy and relevance.
- **Minor presentation issues:** Some phrasing (lines 31-33) could be paraphrased for readability; adding more figure descriptions would help reader understanding.
