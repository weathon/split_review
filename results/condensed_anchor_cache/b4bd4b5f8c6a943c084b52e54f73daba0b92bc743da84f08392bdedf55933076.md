## Merged Review

### Summary
PointMIL introduces Multiple Instance Learning (MIL) to achieve inherently locally interpretable point cloud classification on a per-point basis. The framework consists of a feature encoder (3D Transformer, DGCNN, or PointNet) and a MIL pooling layer (Instance, Attention, Additive, Conjunctive) that outputs point-level importance scores. A contextual prior is injected into the attention mechanism. Experiments are conducted on medical (IntrA, biological cells) and general 3D object (ModelNet40, ShapeNetPart) benchmarks. Claimed as the first work to apply MIL to interpretable point cloud classification.

### Strengths
- Well-written, easy to follow, and well-organized (R1, R2).
- Clear and innovative motivation addressing the interpretability gap in point cloud classification (R2, R3).
- First to achieve locally interpretable point cloud classification on a per-point basis using MIL; first to introduce MIL for interpretable learning in the 3D domain (R1, R4).
- Compelling visual results that highlight important regions for classification (R1).
- Quantitative results show performance improvements over baselines on multiple benchmarks: ModelNet40, ShapeNetPart, IntrA, and a biomedical cell dataset (R1, R4).
- Can be integrated as a simple module into existing point cloud classification models, enhancing both classification performance and interpretability (R4).

### Weaknesses
- **Limited technical contribution & novelty**: The approach mainly combines typical point cloud encoders with existing MIL pooling methods without deeper exploration or modifications tailored to point cloud data. The feature extractor is a straightforward combination of Transformer and DGCNN; MIL pooling directly applies existing ideas without improvements for point cloud characteristics. Specific challenges encountered and addressed when applying MIL to point clouds are not discussed (R1, R2, R3). Performance improvements are likely largely due to the additional feature extraction network rather than the interpretability mechanism itself (R3).
- **Missing analysis of MIL pooling methods**: There is no analysis explaining why certain MIL pooling methods (e.g., Additive, Conjunctive) perform better than others in Tables 4, 5, 6 (Appendix A.1). Such insight is needed to guide selection or adaptation of pooling methods in future work (R1, R4).
- **Outdated/limited backbones**: Evaluated backbones (PointNet, DGCNN, CurveNet, PointMLP, PointNeXt) are relatively outdated; more recent and widely adopted models are missing, including Point Transformer (ICCV 2021), sparse convolutional architectures, Point-MAE, PointTransformer V3, and even classic models like PointNet++ (R1, R2, R4). This limits assessment of generalizability and performance against state-of-the-art. Discussion on how PointMIL could adapt to these backbones is needed, along with side-by-side interpretability outputs for representative examples across backbones (R1).
- **Marginal performance gains**: The performance improvement on ModelNet40 and ShapeNetPart is marginal (R2).
- **Limited discussion of interpretation**: Despite interpretability being the main contribution, the discussion about interpretation is limited, while network design details occupy a large portion (R2).
- **Contradiction in claims**: The paper states that “most local interpretability methods for point cloud classification are post-hoc” and “no one has yet offered an inherently locally interpretable model,” which appears conflicting (R2). Additionally, by modifying the backbone (adding a Transformer feature extractor), the interpretability analysis may not reflect the original model's behavior, conflicting with the goal of general interpretability (R3).
- **Questionable practicality & robustness**: Lacks experiments on real-world datasets (e.g., ScanObjectNN), robustness tests against noise, rotation, and other transformations. Experiments are limited to clean datasets, weakening conclusions about practical utility (R4).
- **Missing experiments and validation**: 
    - Why is the local approach effective compared to global/local features? (R2).
    - MIL pooling is widely used in 2D images; what is the main difference from those methods? Exploit a specific design for point clouds (R2).
    - Is the classification performance comparison fair? PointMIL eliminates downsampling to achieve point-level predictions, while methods like PointNet++ use downsampling (R4).
    - Is PointMIL applicable to scene-level tasks like scene segmentation? (R4).
    - The highlighted red points are claimed important solely based on higher importance scores. Validation via removal tests (e.g., removing red points causing accuracy drop) would strengthen conclusions (R3).
- **Minor errors/omissions**:
    - Line 195-197 mentions five MIL pooling methods but only four are listed (Instance, Attention, Additive, Conjunctive) (R1).
    - Table 2 reports PointNet mACC as 86.0, whereas the original paper reports 86.2; verify discrepancy (R1).
    - Citation in L100 should be (Tan & Kotthaus, 2022); check remaining citations (R2).
    - $\hat{y}$ in Equation 8 is not defined (R4).
    - Error in Table 4 in the appendix (R4).
