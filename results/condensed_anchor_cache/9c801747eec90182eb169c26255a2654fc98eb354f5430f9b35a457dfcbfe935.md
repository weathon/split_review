## Merged Review

### Summary
The paper proposes two complementary methods for contextualized document embeddings: (1) a batch sampling technique that uses clustering (via GTR embeddings) to group similar documents together within batches, increasing contrastive difficulty; (2) an architectural modification that explicitly encodes neighboring document information into the representation. Both methods improve performance over standard biencoders, especially out-of-domain, and achieve state-of-the-art on the MTEB benchmark without hard negative mining, score distillation, large batch sizes, or intra-GPU example sharing. The approach is intended to capture corpus-level statistics that neural biencoders miss.

### Strengths
- **Well-motivated approach**: The paper interprets dense embedding training from a statistical perspective and convincingly argues that standard biencoders lack contextual information from neighboring documents. This is a clean, principled motivation (Reviewers 1, 4).
- **Effective methods**: Both the clustering-based batch sampling and the contextual architecture yield clear improvements, with the combination achieving SOTA on MTEB (Reviewers 2, 3, 4).
- **SOTA without common tricks**: The method achieves competitive or superior performance without hard negative mining, large batch sizes, score distillation, or intra-GPU example sharing – techniques often required by prior work (Reviewers 2, 4).
- **Well-written and clear**: The paper is well-organized, methods are explained clearly, and each section flows logically (Reviewer 3).
- **Thorough experiments and ablations**: Extensive ablation studies (including analysis of cluster size, context aggregation, etc.) provide insight into the contributions of each component (Reviewers 3, 4).
- **Reproducibility**: Hyperparameters, datasets, and model details are listed, facilitating reproduction (Reviewer 4).

### Weaknesses
- **Claim of “no hard negative mining” is misleading**: The first step (grouping similar documents into batches) effectively functions as hard negative mining and is shown to be a key contributor. Moreover, the best-performing model uses an extra explicit hard negative per query (Reviewer 1). This should be clarified.
- **Missing evaluation on domain shift**: Despite motivation centered on out-of-domain adaptation, the paper does not evaluate in a true domain-shift paradigm (e.g., train on one domain, test on another). It is unclear how the clustering-based context captures domain shift at inference time (Reviewer 2). (Minority: Reviewer 2 is explicitly critical here.)
- **Context is actually harder in-batch negatives**: The paper motivates context as providing corpus-level information, but the clustering approach may simply increase the difficulty of in-batch negatives rather than providing true contextual meaning. This needs further justification (Reviewer 2).
- **Training details unclear**: It is not specified whether the final model is M1, M2, or both, nor how the two-stage training pass works (Reviewer 1). For MTEB evaluation, it is unclear how in-context documents are selected for the second-stage encoding (Reviewer 1).
- **Computational cost not reported**: The contextual architecture encodes each document twice (once with M1, once with M2). Wall-clock training time (not just steps) should be reported to understand the trade-off between performance gains and extra cost (Reviewer 3).
- **Model selection process ambiguous**: The paper states hyperparameters are chosen from small-scale experiments but then selects the best supervised model from BGE finetuning. The candidate set and selection metric are not specified, making it hard to assess the validity of the final model (Reviewer 3).
- **Missing per-dataset breakdown on BEIR**: Table 1 reports only the overall BEIR score, but the paper claims largest improvements on ArguAna and SciFact (smaller, OOD datasets). Without individual dataset results, it is hard to understand performance patterns and potential failures (Reviewer 3).
- **Over-reliance on context**: The method assumes relevant neighbors are available for contextualization. It is unclear how the model performs without context (e.g., using null tokens) – could it become overly reliant on context? This also introduces potential computational overhead from padding with null tokens (Reviewer 4).
- **Dependence on GTR for clustering**: The effectiveness hinges on accurate clustering using GTR embeddings. No ablation with simpler embedding models is provided to test robustness; failure to capture nuances could hinder performance (Reviewer 4).
- **Self-attention confusion**: Section 9.4 (“position-agnostic embedding”) states that dataset input tokens are set to zero during self-attention. Given the critical role of self-attention in contextualization, it is unclear how the model can route context information under this design. Clarification is needed (Reviewer 4).
- **Notation issue**: Equation on page 4 uses symbol “m” in two different contexts, causing potential confusion (Reviewer 4).
- **Resemblance to RETRO**: The contextual architecture is conceptually similar to RETRO; a discussion of the connection and differences would be helpful (Reviewer 4).
- **Missing variant in Figure 5**: Section 6 reports that using a single hard negative per query improves performance, but the results for both variants (with and without that hard negative) are not shown in Figure 5 (Reviewer 4).
- **Minority reviewer skepticism**: Reviewer 1 (score 6) questions whether current SOTA embeddings already provide good nuanced representations, and whether the method is actually necessary. This reflects a lower confidence in the contribution compared to Reviewers 3 and 4 (score 8). Reviewer 2 (score 6) similarly questions the utility of the context mechanism for domain shift. This disagreement should be considered when assessing the paper’s impact.
