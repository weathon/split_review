## Merged Review

### Summary
Reviewers generally agree that SOLE introduces a reasonable unified framework for open-vocabulary 3D instance segmentation by merging mask proposal and semantic prediction, incorporating CLIP features early in the pipeline. The method achieves state-of-the-art results on ScanNetv2, ScanNet200, and Replica, and is well-motivated and presented. However, all reviewers note significant concerns about computational efficiency (per-point CLIP extraction, image-to-3D projection) and a lack of detailed speed/memory analysis. Additional weaknesses include reliance on over-segmentation ground truth, incomplete ablations (e.g., CMD under different voxel sizes, hyperparameter sensitivity), unresolved questions about feature fusion design, and missing domain adaptation experiments on ScanNet++. One reviewer (score 8) was notably more positive about the problem framing and presentation, while the other three rated the paper 6, pointing out experimental gaps and implementation overhead.

### Strengths
- Reasonable design that unifies mask proposal and understanding, rather than decoupling them.
- Strong quantitative results across multiple benchmarks (ScanNetv2, ScanNet200, Replica) with large improvements over OpenIns3D and OpenMask3D.
- The problem is interesting and has broad application prospects for interactive 3D scene understanding.
- Clear motivation and well-structured presentation; methods are easy to follow.
- New perspective: directly predicting semantic-related masks from 3D point clouds with multimodal information.
- Proposed feature ensemble module effectively fuses 3D backbone features and 2D CLIP features.
- The multimodal association MEA (Mask-Entity Association) improves performance via fine-grained visual-language alignment.
- Multimodal fusion network integrates visual and language semantics, enhancing segmentation quality and generalizability.
- Three types of multimodal associations (MVA, MCA, MEA) successfully align 3D segmentation with language instructions.

### Weaknesses
- Significant efficiency concerns: extracting per-point CLIP features requires converting 3D points to 2D images and projecting back, which is slow and memory-intensive. The method still requires images at test time, unlike baselines that do not associate semantic features from text. A detailed breakdown of speed and memory consumption is missing; only some numbers appear in the appendix.
- Relies on graph-based over-segmentation ground truth inherited from Mask3D, which may introduce issues.
- The five parts of the Feature Backbone (Fig. 2) are not clearly explained; better illustration would improve self-containment.
- The transition from class-agnostic to class-aware via point-wise CLIP features incurs significant computational overhead, and the accuracy of transferring 2D frame features to point-wise features is not justified.
- In Table 5, it is unclear whether the Cross-Modality Decoder (CMD) is effective under a voxel size of 4cm; the ablation removing CMD at that voxel size is missing.
- Sensitivity to hyperparameters λ_MMA, λ_dice, λ_BCE is not discussed; more analysis is needed.
- Tables 1–4 omit results of Open3DIS with both 2D and 3D supervision; the reason is not explained.
- Equation (4) uses L2 distance instead of cosine similarity to measure feature distances; cosine similarity is standard in OpenSeg and CLIP. Also, p(·,·) on line 341 should be p(·).
- The three types of associate features reside in different feature spaces; learning a single mask feature to aggregate all via Eq. (4) is difficult. Table 6 shows that using all three associations may not be optimal. Using separate mask features for each and concatenating them is a plausible alternative.
- Line 457 incorrectly states that “small voxel size can save memory”; larger voxel size reduces the number of voxels and is more memory efficient.
- Some references are outdated (e.g., Open3DIS is published in CVPR 2024) and should be updated.
- The claim that class names are not used is not an advantage; class names are easier to annotate than ground-truth 3D masks, and whether to leverage them is a design choice.
- Missing domain adaptation testing on ScanNet++ (over 1,500 class-agnostic categories and an open-vocabulary subset of 100 classes); such an evaluation would better demonstrate generalizability.
- Opportunities to expand multimodal associations with other large language models (e.g., 3D-LLM, Ferret, OSPrey) beyond DeCap are not explored.
