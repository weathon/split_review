## Merged Review

### Summary
The paper proposes a method for compositional instruction following in RL: an LLM parses natural language instructions into Boolean formulas over primitive tasks, and pre-trained compositional value functions (WVFs) are used to construct the policy/Q-function. Environment reward signals are used to select in-context examples for the LLM. The method is evaluated on 162 tasks in BabyAI, achieving a 92% success rate (matching an oracle) and outperforming a non-compositional CNN-DQN baseline in final performance and generalization. Experiments compare GPT-3.5 and GPT-4.

### Strengths
- The paper is well-written and easy to follow (Reviewer 1, Reviewer 2). (Reviewer 4 found it hard to follow – noted in Weaknesses.)
- The method shows improved generalization to unseen tasks (Reviewer 1, Reviewer 3, Reviewer 4).
- The idea of using environment reward signals to choose in-context examples for the LLM is novel and interesting, bridging LLM and RL feedback (Reviewer 1, Reviewer 2, Reviewer 3).
- Using an LLM as a semantic parser reduces engineering effort for obtaining logical formulas from natural language, compared to prior work that assumes such formulas or a parser are given (Reviewer 1).
- The combination of zero-shot compositional generalization from WVFs with LLM parsing is novel and enables policies for a wide range of instructions (Reviewer 2, Reviewer 3).
- The evaluation covers a substantial set of 162 tasks (Reviewer 4).
- The proposed method achieves a high success rate (92%), matching an oracle parser, and significantly outperforms the baseline in final performance (Reviewer 1, Reviewer 4).

### Weaknesses
- **Unfair / too-primitive baseline.** Multiple reviewers noted that the baseline lacks pretrained language embeddings or LLM knowledge, while the proposed method uses LLM parsing. This makes the comparison of sample efficiency and performance unconvincing. Stronger baselines were suggested: using an LLM encoding (e.g., hidden layer) as instruction input (Reviewer 2), including other BabyAI baselines (e.g., Carta et al., 2023) (Reviewer 4), and learning a separate RL policy or fine-tuning a language model to map instructions to Boolean expressions (Reviewer 3).
- **Sample efficiency claim is not well supported.** The baseline stops improving after its pretraining steps, and the proposed method’s pre-training time is substantial; after that time the baseline already reaches reasonable performance, so the cost may outweigh the gain. The plot (Figure 3) shows a final performance advantage, not sample efficiency in the strict sense (same performance with fewer samples) (Reviewer 1, Reviewer 4).
- **Requires manual specification of primitive tasks / WVFs.** The approach needs a predefined set of primitive tasks and their value functions, making it less practical for realistic scenarios. Automating WVF discovery or allowing dynamic modification would strengthen the work (Reviewer 2, Reviewer 3).
- **Only Boolean combinations supported.** The method handles AND/OR/NOT but not temporal compositions (e.g., sequential tasks), limiting applicability to richer instructions (Reviewer 2).
- **Contribution considered incremental by some reviewers.** Since WVFs were already known (Nangue Tasse et al., 2020) and LLMs are already used as parsers (Shin et al., 2021), the main novelty – using LLM to parse into Boolean formulas for WVFs – is straightforward. In BabyAI, a perfect parser can be programmed easily, making LLM unnecessary for this domain. (Reviewer 2, Reviewer 4; contrast with other reviewers who found the combination novel.)
- **Insufficient empirical validation.** Experiments are only on one simple environment (BabyAI). Additional domains (e.g., continuous state/action, robot manipulation) are needed to assess generality (Reviewer 3).
- **Writing is hard to follow for those unfamiliar with WVF.** More background on WVF is needed; the abstract should capture the main idea (using LLM to parse instructions for WVFs); an algorithm summarizing the full workflow (including how parsed symbols select WVF basis and downstream training) would help (Reviewer 4). (Reviewer 1 and Reviewer 2 found the paper clear – this is a minority view.)
- **Figure 4 presentation.** Should be formatted like Figure 3, with clear separation of pretraining and training phases for a fair comparison (Reviewer 1).
- **Missing ablations and clarifications.**
  - No ablation on the success-rate threshold for adding Boolean expressions to the LLM prompt; this could affect sample efficiency (Reviewer 1).
  - It is unclear whether evaluation uses the most likely parse or an average over the beam of 10 parses (Reviewer 1).
  - The number of runs used for Figure 3 is not stated; variance (especially for GPT-3.5) appears high (Reviewer 4).
  - Using abstract symbols (e.g., for “grey object”) instead of natural-language labels may make parsing harder (Reviewer 1).
