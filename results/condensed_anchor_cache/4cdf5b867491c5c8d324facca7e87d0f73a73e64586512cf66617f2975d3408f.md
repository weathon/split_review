## Merged Review

### Summary
This paper proposes InterpGN, a framework for time-series classification that integrates a Shapelet Bottleneck Model (SBM) with a deep neural network (DNN) using a gating function based on SBM’s confidence. SBM learns shapelets with an RBF-based distance to build logical predicates; a linear classifier operates on these predicates. The gating mechanism measures SBM confidence via a modified Gini index and mixes SBM and DNN outputs. The model is evaluated on 30 UEA multivariate time-series datasets and MIMIC-III, providing both local and global explanations. Reviewers note the novelty of the gating mechanism and the use of shapelets as concepts for interpretability, but raise substantial concerns about interpretability when the DNN is used, limited baseline comparisons, insufficient explanation evaluation, and clarity of the method description.

### Strengths
*   **Novel gating mechanism**: The gating function based on SBM’s confidence (modified Gini index) preserves interpretability for simple cases and calls on the DNN for complex samples. Several reviewers found this original and smart. (R1, R3, R5)
*   **Original extension of Concept Bottleneck Models to time series**: Successfully using shapelets as “concepts” in a CBM framework adds value. (R1, R3, R4)
*   **Provides both local and global explanations**: Local explanations give sample-specific shapelet importance; global explanations offer rule-based class characteristics. (R1, R4, R5)
*   **New quantitative metrics for interpretability and shapelet quality**: Metrics measure shapelet closeness to data and classifier weight sparsity, demonstrating improvements over existing shapelet-learning methods. (R1, R2, R5)
*   **Strong empirical results with thorough ablation studies**: InterpGN achieves comparable or superior accuracy on benchmark datasets; ablation studies examine K, β, ε, and diversity loss. (R1, R2, R3, R4)
*   **Theoretically sound integration and clean separation**: The clean separation between interpretable expert (SBM) and DNN, and the gating based on expert confidence, are well motivated. (R5)
*   **Well-written manuscript with clear visualizations**: Figures 1, 2, and 4 effectively illustrate core ideas. (R1, R4)
*   **Addresses an important topic**: Explainability in time-series classification is compelling, especially since capturing temporal patterns is often not intuitive. (R1, R2)

### Weaknesses
*   **Gating mechanism undermines interpretability**: When the DNN expert is used, InterpGN becomes a black box. Unlike IME (Ismail et al., 2023) where a single expert per sample is used, InterpGN mixes outputs, removing interpretability for any sample where the DNN contributes. (R1, R3, R4) Minority: R1 notes the gating does not clarify how the DNN is modulated by shapelet information when confidence is low; R4 notes model collapse (Handwriting dataset in Fig.10) where η=0 makes SBM explanations irrelevant.
*   **Model collapse possible**: In the worst case, η is always 0 (e.g., Handwriting dataset), so the model fully relies on the unexplainable DNN while the SBM explanation does not affect the final prediction. No design prevents this collapse. (R4)
*   **Performance improvement too small**: Only 0.6% average accuracy gain over DNN despite added parameters, raising concerns about practical utility. (R1)
*   **Missing key baseline comparisons**: No LTS baseline (the original shapelet learning method) to isolate the effect of the RBF kernel. No comparison with other interpretable methods for interpretability metrics (e.g., LIME, CBM works). Missing recent methods. (R2, R4, R5)
*   **Method description lacks clarity**: How shapelets are optimized end-to-end (gradient flow, loss integration) is not explained. The MoE/gating section (Eq.6-7) is vague, especially how SBM sparsity is measured and used to weight DNN. The paper calls SBM a “rule-like classifier” but only uses a linear layer, creating confusion. Terminology “predicate” (used as a continuous value, not a condition) is non-standard. (R2, R3, R4)
*   **Euclidean distance for shapelet matching may be suboptimal**: Euclidean distance is sensitive to offsets and warping; alternatives like cosine similarity or correlation were not explored. (R4)
*   **Limited shapelet expressiveness**: Only K=5 and K=10 shapelets tested; larger K (100, 1000) not evaluated, which limits ability to capture complex patterns. Fixed shapelet lengths (L) and minimum length fixed at 3 may miss important patterns. (R4, R5)
*   **Interpretability metrics unconvincing**: Using weight sparsity (w) is scale-dependent and threshold-sensitive; a Gini-index-based measure would be more robust. No formal evaluation of explanation faithfulness (e.g., following metrics from existing literature). A user study would strengthen claims. (R4, R5) The value of global explanation beyond local explanations is not well justified. (R1)
*   **Missing ablation studies**: Performance of DNN-only and SBM-only models not reported. Loss terms: the shapelet diversity loss (L_div) shows no benefit in ablations, yet is included without justification. (R3, R4)
*   **Implementation limitations**: Only one DNN expert type (FCN) tested; code not provided for reproducibility. (R3, R5)
*   **Limited real-world evaluation**: Only MIMIC-III for in-hospital mortality; no analysis of failure cases or datasets where InterpGN underperforms. (R5)
*   **Hyperparameter sensitivity unclear**: No guidance on choosing shapelet lengths L, RBF kernel parameter ε, balance parameter β, or maximum shapelet channels (Kmax=40). The model’s sensitivity to these choices is not discussed. (R1, R5)
*   **Minority views on contribution and clarity**: One reviewer (R2) finds the main contribution (RBF kernel over Euclidean distance) modest and the state-of-the-art review brief. Another (R3) notes the paper claims SBM is “rule-like” but uses a linear classifier, causing confusion. Several typos noted (e.g., “interpretablity”). (R2, R3)
*   **Other missing aspects**: No location information for shapelets (e.g., end of input may be more important); no adversarial robustness discussion; no analysis of how the gating mechanism performs when the interpretable expert is confidently wrong. (R4, R5)
