## Merged Review

### Summary
The paper proposes Dynamical Skill Refinement (DSR), an on-policy RL method for hierarchical policies with skills. It unifies the optimization of high-level and low-level policies to address sub-optimal pretrained skills and temporal abstraction shift, using random network distillation (RND) to dynamically adjust action refinement and prevent skill space collapse. Theoretical analysis and experiments on sparse-reward robotic manipulation tasks are provided.

### Strengths
- Well-written, well-motivated, and theoretically grounded (Reviewers 1,2,3).
- Solid proofs for theorems (Reviewer 1).
- Multiple figures improve clarity (Reviewer 2).
- Addresses crucial challenges: learning from sub-optimal datasets and overcoming skill space collapse (Reviewer 3).
- Demonstrates better performance against several state-of-the-art RL-with-skills methods (Reviewer 1,2).

### Weaknesses
- Theoretical novelty and distinctions from prior work are not clearly established. The difference from ReSKILL regarding temporal abstraction shift is not shown in the theorems (Reviewer 1). How DSR differs from classic online hierarchical RL (e.g., [2], [3]) is unclear; Theorem 3 appears to be a straightforward Bellman application without novel insights, and those references provide stronger bounds (Reviewer 2). The paper does not elaborate why ReSKILL cannot guarantee performance improvement (Reviewer 1, question).
- The dynamical skill refinement mechanism (RND, residual policy) adds complexity with limited novelty. DirectRefinement shows comparable performance in the ablation (Reviewer 3). Skill space collapse is only observed in PyramidStack; more tasks and analysis on why collapse occurs are needed (Reviewer 3). The meaning of “skills not well initialized” in this ablation is unclear (Reviewer 3, question). Sensitivity of RND hyperparameters (learning rate, threshold) is not studied (Reviewer 1).
- It is unclear whether skill refinement is necessary if the high-level policy can simply learn to avoid sub-optimal skills; the unified objective’s direct link to addressing dataset sub-optimality is not convincingly shown (Reviewer 2, Reviewer 3).
- Experimental evaluation is limited to a few manipulation tasks. No navigation or long-horizon environments (e.g., MetaWorld, Franka Kitchen) are included (Reviewers 1,3). Transfer learning capability (a key promise of skill-based RL) is not demonstrated (Reviewer 2).
- Performance discrepancy: In PyramidStack, ReSkill’s average return in this paper is ~10, while the original ReSkill paper reports >15 under equivalent settings; the gap needs explanation (Reviewer 3, question).
- Missing details: how skills are extracted using VAE (Reviewer 1, question), dataset collection procedure and sub-optimality (Reviewer 3, question), sparse reward definition and how episodic return is computed (Reviewer 3, question).
- Presentation can be improved: Figure 4 is small; Figure 3 might be clearer as an equation; pseudocode should be in the main text rather than in the appendix (Reviewer 3).
