## Merged Review

### Summary
The paper proposes a black-box framework for estimating confidence in LLM responses. It uses multiple perturbation strategies (prompt paraphrasing via back-translation, sentence permutation, stopword removal, entity frequency amplification, stochastic decoding, and split-output response consistency) to generate features and trains a logistic regression model to produce confidence scores. The method is evaluated on Flan-ul2, Llama-13b, and Mistral-7b on four QA tasks, and on Pegasus-large and BART-large on two summarization tasks, reporting AUROC improvements of up to 10% over baselines (semantic sets, lexical similarity). The logistic regression yields interpretable feature importance and shows zero-shot cross-model generalization on the same dataset. Ratings range from 5 to 6; reviewers disagree on the strength of the empirical results versus concerns about evaluation, scope, and baselines.

### Strengths
- **Important problem**: Estimating uncertainty in LLM output, especially open-ended generation (e.g., summarization), where token-level entropy is insufficient. [R1, R3]
- **Simple, extensible black-box framework**: Aggregates multiple consistency signals (prompt perturbations, stochastic decoding, split-response NLI) into a single meta-scorer. [R1, R2, R3]
- **Competitive empirical results**: Outperforms baselines by up to 10% AUROC across several QA and summarization datasets and models. [R1, R2, R4] *(Note: R1 flags the evaluation metric as a primary weakness)*
- **Interpretability and insight**: Logistic regression weights reveal that repeated sampling from the original prompt is the most predictive feature, more so than prompt perturbations. Useful for understanding which perturbations matter. [R1, R2]
- **Cross-model transferability**: The same trained logistic regression generalizes zero-shot across different LLMs on the same dataset, potentially enabling general-purpose calibrators. [R2, R3]
- **Black-box nature makes work appealing** for closed or API-era models. [R4]
- **Good communication of approach, drawbacks, and strengths** (though some reviewers note presentation issues). [R2]

### Weaknesses
- **Evaluation metric (ROUGE) is a primary weakness**: ROUGE (n-gram overlap with ground truth) is used for open-ended summarization. Several perturbations (e.g., repeating/mixing entity sentences) disproportionately capture entity processing rather than genuine correctness, undermining validity. [R1] Also, the paraphrasing implementation (Helsinki-NLP En→Fr→En) was weak and often dropped content, affecting evaluation quality. [R3]
- **Limited model scope**: Only relatively small, white-box-accessible models are evaluated (Flan-ul2, Llama-13b, Mistral-7b). Evaluating black-box methods on models for which full access is available is less motivated; experiments on closed API models (GPT-4, Claude) are missing. Since the contribution is empirical, this regime limits impact. [R3] (R2 also notes limited scope, but as a cost limitation.)
- **Missing baselines**: Several relevant baselines are not included:
  * Verbalized confidence (Tian et al., 2023) [R2]
  * Frequency-estimated semantic entropy (Kuhn et al., 2023) instead of only counting equivalence sets [R2]
  * White-box approaches on an auxiliary open-weight model (P(true) or P(IK) from Kadavath et al., 2022) [R2]
  * Log-probability methods (e.g., https://arxiv.org/abs/2006.09462) [R3]
  * Quantitative comparison to aggregation methods (e.g., https://arxiv.org/abs/2306.13063) [R3]
  These missing comparisons make it hard to assess the method’s added value. [R2, R3]
- **No calibration evaluation**: The paper claims (line 083) that because logistic regression is simple, confidence estimates will be well-calibrated, but no calibration metric (e.g., ECE) is provided. This claim needs empirical support. [R2]
- **Error bars / statistical significance**: Results are presented without error bars; it is unclear how randomness in sampling affects final scores. Only three runs may be insufficient; standard deviations should be reported. [R2, R4]
- **High computational cost not discussed**: The method requires many repeated samples and perturbations. Compared to a single decoding, it is expensive; it is unclear if this extra compute is deployed optimally (e.g., better to invest more in stochastic decoding). A cost-AUROC trade-off analysis is missing. [R1, R3]
- **Perturbation choices are ad-hoc and insufficiently justified**: Why were these specific perturbations chosen over others? For paraphrasing, why use Helsinki-NLP rather than an LLM? Sentence permutation may produce invalid outputs due to unresolved anaphora—this is not analyzed. The framework is not novel; the contribution should be the specific choices, but no justification or ablation is provided. [R3] (R4 also questions robustness and manual intervention in featurization.)
- **Lack of theoretical support**: There is no principle reason why these features should correlate with correctness. Using multiple techniques together helps, but a theoretical grounding is absent. [R4]
- **Presentation issues**:
  * Section 3.2 (featurization) is hard to follow and would benefit from an example. [R3]
  * Section 3.1 is misleadingly titled “prompt perturbations”; stochastic decoding and split-response consistency change the output, not the input, and should be in a separate subsection. [R2, R3]
  * The intro uses notation for confidence but no notation for the (complicated) feature extraction. [R1]
  * Small errors: “aver to these values as a features” (80-81), “complimentary” → “complementary” (169), “greedy ,” (149), “Since, ” (083). [R2]
- **Missing cross-dataset transferability**: The paper shows same-dataset cross-model transfer, but not same-model cross-dataset transfer. It is important to know if one fixed set of weights works across datasets, or if a simple baseline like SP lexical similarity alone is sufficient. [R2]
- **Unaddressed design questions** (included as missing experiments/ablation):
  * Why is Entity Frequency Amplification only applied to named entities? Could it be applied generally? [R3]
  * How was NLI computed for split-response consistency (SRC)? This only works for long outputs; why not compute NLI on different samples? How does SRC relate to maieutic prompting (https://arxiv.org/pdf/2205.11822)? [R3]
  * Why not include graph-based features (eigenvalue, eccentricity, degree) in the logistic regression? [R2]
  * How robust and automated is the featurization? How much manual intervention is needed for each dataset? [R4]
  * The few cases where the proposed method does not outperform baselines differ between AUROC and AUARC—why? [R4]
  * Would the gains remain with a different evaluation criterion (e.g., Llama 3 70B as judge)? [R1]
  * How important is the linear model assumption? Could non-linear models (e.g., random forests) further improve AUROC? [R3]
- **Reviewer disagreement**: Ratings are split (5, 6, 5, 6). R2 initially assigned 5 and revised to 6, indicating some concerns were resolved; R1 and R3 consistently assigned 5, citing serious concerns about evaluation (ROUGE) and regime (small models). R4 (6) highlighted black-box appeal and strong results, while R2 (6) praised extensibility and interpretability. This contrast underscores differing assessments of soundness and contribution. [R1, R2, R3, R4]
