## Merged Review

### Summary

This paper presents DV-3DLane, an end-to-end multi-modal (camera + LiDAR) 3D lane detection framework that leverages dual-view representations: perspective view (PV) and bird’s-eye view (BEV). Three key components are introduced: (1) a bidirectional feature fusion strategy to integrate multi-modal features into each view, (2) a unified query generation approach using lane-aware knowledge from both views, and (3) a 3D dual-view deformable attention mechanism that aggregates discriminative features from PV and BEV for accurate 3D lane detection. Experiments on the OpenLane benchmark show state-of-the-art performance, with an 11.2 F1 score improvement and a 53.5% reduction in errors.

### Strengths

- **Original contributions**: The bidirectional feature fusion unifies both sensor modalities (camera and LiDAR) in both view spaces (PV and BEV), effectively leveraging modal-specific information. Ablation shows sensor fusion gains >10% F1 over LiDAR-only and ~20% over camera-only. (Reviewers 1, 2, 3)
- **Unified query generation** using lane-aware knowledge from both views contributes to performance (though modest, <1% F1 gain). (Reviewer 1)
- **3D dual-view deformable attention** further improves results. (Reviewer 1)
- **Achieves state-of-the-art performance** on the OpenLane benchmark. (Reviewers 1, 2, 3, 4, 5)
- **Well-written and easy to follow**, with clear problem framing and contribution exposition. (Reviewers 2, 4)
- **Detailed ablation study** making the improvement from each step evident. (Reviewers 1, 2)
- **Novel idea**: query clustering from multiple perspectives. (Reviewer 5)
- **Runtime optimization** considered and code will be released. (Reviewer 5)

### Weaknesses

- **Evaluation inconsistency**: Main experiment (Table 1) uses OpenLane1000, while ablation (Table 4) uses OpenLane300, making results incomparable. (Reviewer 2)
- **Comparison with prior SOTA LATR**: In the 1.5m range, the proposed method does not achieve overwhelming improvement despite adding LiDAR, and uses a weaker backbone (ResNet-18/34 vs. ResNet-50). This suggests possible saturation and an unfair comparison. (Reviewer 2)
- **Most baselines in Table 1 are camera-only**: To justify multi-modal fusion as a key contribution, the paper should compare against multi-modal versions of existing methods. The camera-only performance is not competitive with recent methods like GroupLane. (Reviewer 4)
- **Adaptive query generation questioned**: In Table 4, queries generated from PV and BEV alone perform worse than random queries, suggesting the adaptive generation module does not work. The improvement from clustering may stem from the extra network rather than the query generation itself. (Reviewer 4)
- **Feature fusion approach viewed as tricky**: The bidirectional fusion and deformable attention for multi-modal features are considered incremental or lacking innovation. (Reviewer 4)
- **'Lane-aware prior knowledge' in abstract is unclear** and not explained in the main text. (Reviewer 2)
- **Missing experiments on other datasets** (e.g., OpenLane-Huawei with more horizontal lines, Apollo) to test generalizability. (Reviewers 1, 2, 3)
- **Tolerance to calibration parameter noise not tested**, despite the method relying on known camera parameters for PV-to-3D lifting and DV feature concatenation. (Reviewer 3)
- **Figure 1 incomplete**: Missing light-weight methods like GenLane. (Reviewer 2)
- **Minor typo**: “instruction” should be “introduction”. (Reviewer 1)
- **Figure 7**: Line (d) should be increased or removed; figures are too small. (Reviewer 1)
- **Some related work not cited**; suggested citations include Liu et al. (AAAI 2022), Yao et al. (ICCV 2023), Li et al. (CVPR 2022), and Ai et al. (ICRA 2023). (Reviewer 2)

**Contrast among reviewers**: One reviewer (score 1) praised the novelty, SOTA results, runtime optimization, and code availability, while another (score 3) strongly questioned the contributions from multi-modality and query generation, considering the feature fusion and deformable attention as incremental or lacking novelty.
