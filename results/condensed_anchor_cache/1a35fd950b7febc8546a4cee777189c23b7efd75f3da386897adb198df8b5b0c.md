- Decision: Reject
- Scores: 3, 3, 3, 3

## Merged Review

### Summary
The paper introduces LVM-Net, a method for efficient long-form video reasoning that uses a fixed-size memory representation and a neural sampler to store discriminative patches from input videos. It requires only a single pass over the video and achieves 18x–75x inference speed-ups on the ReST-ADL dataset for retrieval tasks while reporting competitive predictive performance.

### Strengths
- Significant inference speed-ups (18x–75x) on ReST-ADL, which is crucial for real-time applications and enables deployment on edge devices with limited memory. (Reviewers 1, 2, 3)
- The writing is good (Reviewer 1). (Note: this contrasts with writing criticisms in Weaknesses.)
- The neural sampler is easy to follow (Reviewer 4).
- Innovative use of a fixed-size memory and single-pass processing to reduce computational demands (Reviewer 3).

### Weaknesses
- **Performance not competitive**: LVM-Net achieves only 8.6% on the main metric versus 12.8% (TubeDETR) and 30.0% (ReST). Other reported baseline performances are also low, which significantly harms the paper’s contribution. (Reviewer 1)
- **Limited evaluation**: Validation is only on the ReST-ADL dataset. The paper claims applicability to video retrieval, summarization, and question answering, but only tests retrieval. Experiments on other datasets (e.g., MM-Bench, Video-bench) and tasks (summarization, QA) are needed to support the broad claims. (Reviewers 2, 3, 4)
- **Incomplete baselines**: The comparison lacks several relevant methods mentioned in the related work (e.g., MeMViT and other token-efficiency methods). Only random sampling is compared in Table 3. Also, inference time for ReST is missing from Table 1 (only Modified TubeDETR is reported). (Reviewers 1, 3)
- **Weak novelty / insufficient technical depth**: The fixed-size memory resembles a replay buffer from continual learning; the neural sampler is borrowed from (Xie et al., 2019). The only claimed novelty is the auxiliary loss and architectural design, but this is seen as an “innovative trick” rather than a substantial contribution. The motivation for using a neural sampler and the main differences from prior works like TubeDETR are unclear. (Reviewers 1, 2, 4)
- **Ambiguous method description**: The neural sampler output is described inconsistently (“outputs scores for k (clip) tokens and m (memory) tokens” vs “outputs m discriminative visual tokens”). It is unclear which components are trained (only the neural sampler? also the positional encoding layer?). The overall method explanation is confusing. (Reviewers 1, 3)
- **Writing and presentation issues**: Numerous grammar errors, omitted articles, prolixity, and inconsistent figure references (e.g., “Figure 1(a)” vs “Figure 1a”). The terms “video reasoning” and “video understanding” are used interchangeably but have different meanings. Figure 2 is rough and poorly labeled; Figure 1(b) is not discussed. (Reviewers 3, 4)
- **Missing figure**: The caption of Figure 2 references Figure 3, but Figure 3 does not appear in the paper. (Reviewer 3)
- **Redundant content**: The ReST dataset is introduced multiple times, including in the preliminaries section. (Reviewer 3)
- **Missing analysis**: No visualization or analysis of the tokens stored in the Memory Bank is provided, making it hard to assess their representativity relative to the full video representation in Figure 1(a). (Reviewer 1)
- **Incomplete inference time reporting**: The ratio of running time between inference stage 1 and stage 2 is not provided; it is unclear if stage 1 is included in Table 1. (Reviewer 1)
