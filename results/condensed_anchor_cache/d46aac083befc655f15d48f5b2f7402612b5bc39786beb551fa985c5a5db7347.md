## Merged Review

### Summary
The paper studies Exogenous Block MDPs (Ex-BMDP), where observations decompose into a low-dimensional controllable latent state (deterministic dynamics) and high-dimensional exogenous noise. Prior work required episodic resets; this paper proposes STEEL, the first provably sample-efficient algorithm for learning controllable dynamics from a single continuous trajectory. The algorithm forces cycles via repeated action sequences, waits out the mixing time to collect near-i.i.d. samples, and uses a classifier oracle to identify latent states. Sample complexity depends on controllable latent space size, encoder function class complexity, and mixing time. Experiments on combination lock and multi-maze environments are shown. Three reviewers rated the paper 8; one reviewer (score 1) recommended desk rejection due to formatting violation.

### Strengths
- Clearly written with a strong introduction and related work that contextualize the gap and contribution (R1, R3).
- Addresses a challenging setting: infinite-horizon, single trajectory, partial observability, function approximation, all with sample-complexity guarantees (R1, R4).
- Removes the need for episodic resets that prior Ex-BMDP work required; this is a meaningful novelty and more realistic (R4).
- Algorithm design is intuitive: forcing cycles and using a classifier oracle to detect unique states (R1), with a clear high-level description (R3).
- Assumes a more general emission function (only partial inverse exists) than the block structure assumed in prior work (R4).
- Limitations and future work are discussed openly (R1).
- Theoretical analysis is solid, with sample complexity polynomial in latent space size, mixing time, and encoder class complexity (R3).

### Weaknesses
- **Restrictive assumptions**: The algorithm crucially depends on deterministic latent dynamics and a reachability condition (each state reachable from any other). These are rarely satisfied in real-world stochastic environments, and it is unclear whether any stochasticity can be tolerated (R3, R4).
- **High practical sample complexity**: Despite polynomial scaling, millions of samples are required even in toy experiments, raising concerns about applicability when data collection is expensive (R3).
- **Algorithm explanation clarity (Section 4)**: The main text is hard to follow; the pseudocode is integrated in a way that forces switching between text, code, and appendix. Moving pseudocode to the appendix and providing more high-level explanation in the main text would help (R1).
- **CycleFind dataset construction**: The mechanism for generating disjoint datasets D0 and D1 for different candidate cycle lengths is insufficiently explained. It is unclear how the algorithm ensures these datasets are truly representative of distinct cycles and not overlapping segments of the same cycle, given a continuous trajectory (R1).
- **Choice of encoder hypothesis class**: The paper assumes access to a hypothesis class F that includes the true encoder, but gives no general procedure for constructing such a class with a reasonable size in practical settings beyond the specific examples (R4).
- **Training oracle**: The algorithm assumes an oracle that optimally distinguishes two observation sets (minimizing 0-1 loss). No concrete example or computational cost for constructing such an oracle is provided; it is unclear how to implement this without prior knowledge of the true classifier (R4).
- **Unknown mixing time**: The algorithm requires an upper bound on the mixing time of the exogenous dynamics, but it is not discussed how to obtain such a bound when the exogenous process is unknown (R4).
- **Block assumption on Q**: The block structure assumption on the observation distribution given the controllable state may be restrictive when emission noise makes states hard to distinguish without filtering. Is this assumption necessary and can it be weakened? (R3).
- **Missing lower bound**: No lower bound is provided for the sample complexity of Ex-BMDP under deterministic latent dynamics, so it is unclear whether STEEL is nearly optimal or further improvement is possible (R3).
- **Minority negative review**: One reviewer (score 1) criticized that the paper violated formatting instructions by reducing font size for Algorithms 1 and 2, taking up 10 pages, and recommended desk rejection. The other three reviewers gave high scores (8, 8, 8) and did not comment on formatting. This formatting concern should be addressed to comply with submission guidelines (R2).
- **Baseline evaluation**: Experiments compare STEEL with prior methods (Lamb et al., 2023; Levine et al., 2024) that lack theoretical correctness guarantees and may appear more sample-efficient. Also reporting the percentage of runs where these baselines correctly identify states and transitions would better highlight STEEL's reliability advantage, rather than focusing only on sample efficiency (R1).
