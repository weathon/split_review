## Merged Review

### Summary
The paper investigates how transformer LMs decode relational knowledge (subject-relation-object). It hypothesizes that for some relations, the object representation can be approximated by an affine transformation (Linear Relational Embedding, LRE) of the subject representation, computed via the Jacobian ∂o/∂s. Using 47 relations, the authors measure faithfulness (how well LRE-predicted object matches LM decoding) and causality (whether editing the subject embedding via LRE inverse changes the predicted object). They also introduce the Attribute Lens for visualizing when relational information emerges across layers. The results show high but imperfect faithfulness/causality, with heterogeneity across relations.

### Strengths
- Novel insight into how relational knowledge is linearly represented in LMs, contributing to deeper understanding (R2, R3; all reviewers agree it is interesting).
- Smart use of local derivative (Jacobian) to obtain the affine transformation, aligned with traditional knowledge graph embedding methods (R1).
- Extensive experiments confirming the findings, with comparison to reasonable baselines/ablations (R2, R3).
- Causality demonstration via low-rank pseudoinverse perturbation of subject is useful (R1).
- Presentation is excellent, easy to follow, and results are comprehensive (R2, R3; R1 also rates presentation 3 "good").
- Application of Attribute Lens (similar to Logit Lens) is interesting and practical (R2, R3).
- Important topic that will raise interest at the conference (R3).
- Note: One reviewer (R1) considers the contribution “fair” (score 2), while R2 rates it “good” (3) and R3 “excellent” (4), reflecting disagreement in perceived novelty.

### Weaknesses
- **Context prompt sensitivity** (R1): It is unknown how the conclusion is affected by the context prompt (e.g., “[s] plays the”). Would the linearity hold with different contexts expressing the same relation? Missing systematic analysis.
- **Faithfulness is not high for most relations** (R1): The paper reads more like a case study than a systematic measurement covering a broader range. It is hard to conclude what percentage of relations match the linearity hypothesis. What level of faithfulness is required to say linearity holds? (R1)
- **Causality > Faithfulness** (R1): The paper does not explain why causality scores are usually higher than faithfulness scores.
- **Multi-token object handling** (R1, R3): Table 4 uses only the first token to determine correctness for multi-token objects. It is unclear if this strategy is applied to all experiments (including causality). This could lead to false positives. R3 notes that LLaMA-13B gets 0% on president birth year/election year because its tokenizer represents each digit as a separate token; using only the first token makes correct prediction impossible. This is a shortcoming of the measurement and should be discussed.
- **Inconsistency in dataset/figure** (R3): Table 4 shows GPT-J gets 0% correct on “occupation gender” (so no examples should remain per dataset filtering description), yet Figure 3 reports near 100% faithfulness for that relation. This inconsistency needs explanation.
- **Configuration of affine parameter estimation** (R2): Only n=8 examples are used to estimate W and b. Would more examples be feasible? What is the variance, not just the mean? (R2)
- **Limitations insufficiently discussed** (R3): For a fixed subject and relation, multiple true objects can exist. This affects dataset generation (filtering out non-generated objects) and questions whether an invertible (injective) function can reasonably approximate a non-injective relation. This aspect should be discussed.
- **Minor presentation issues** (R2): p.4 “of LM’s decoding” → “of the LM’s decoding”; p.5 “by (Merullo et al., 2023)” → “by Merullo et al. (2023)”; p.7 “is a higher” → “is higher”; p.8 “visualizes a next” → “visualizes next”.
- **Additional questions** (R1, R2): Does a “sample” mean a single example? (R2) Are there examples where LRE cannot fully capture the computation but still performs a successful edit? (R1)
