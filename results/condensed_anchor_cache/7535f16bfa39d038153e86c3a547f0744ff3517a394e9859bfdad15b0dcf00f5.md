## Merged Review

### Summary

This paper proposes a vision-only GUI agent framework (SeeAct-V) with an external LLM planner and a visual grounding model (UGround) that maps referring expressions to pixel coordinates. UGround is trained on a large-scale hybrid synthetic dataset (19M GUI elements over 1.3M web screenshots) using a combination of rule-based and LLM-based generation of visual, positional, and functional referring expressions. Evaluated on six benchmarks spanning grounding, offline agent, and online agent tasks across web, desktop, and mobile platforms, UGround achieves up to 20% absolute improvement over existing visual grounding models, and SeeAct-V matches or outperforms state-of-the-art agents that use additional text-based inputs.

### Strengths

- Novel human-like embodiment that reframes GUI interaction as a pure visual grounding problem, challenging the conventional reliance on HTML and accessibility trees.
- Largest GUI visual grounding dataset to date (19M elements, 1.3M screenshots), collected via an innovative hybrid synthesis pipeline combining rule-based and LLM-based approaches, with three types of referring expressions (visual, positional, functional).
- Strong cross-platform generalization across web, desktop, and mobile without platform-specific training.
- Significant performance gains: UGround improves grounding accuracy by up to 20% absolute over existing models (e.g., on grounding benchmarks).
- Comprehensive evaluation across six benchmarks covering three settings (grounding, offline agent, online agent) on three platforms.
- Practical impact: eliminates dependency on noisy/incomplete text representations, reduces computational overhead of accessibility tree extraction, and mimics human interaction patterns.
- Thorough motivation and analysis: quantifies overhead costs of text-based representations and convincingly demonstrates benefits of vision-only approach.
- Clear methodology; public release of dataset and model ensures reproducibility.
- Well-structured and clearly articulated paper (minority reviewer score 5 agrees on clarity and solid effectiveness).

### Weaknesses

- **Dependency on external LLM planner**: UGround cannot operate independently as a complete GUI agent; agent performance depends on the planner, not just grounding data. The scaling curve (Figure 5 on Web-Hybrid) shows that increasing grounding data alone does not enhance agent performance, limiting the potential of the SeeAct-V framework. No end-to-end training with downstream tasks is performed.
- **Data efficiency and redundancy**: Heavy reliance on large-scale synthetic data raises cost concerns. Web training data may contain repetitive layouts and similar UI elements, risking overfitting. Room for improvement in deduplication and grouping of near-duplicate screenshots and similar elements.
- **Limited coverage**: Training data collected only from web environments; lacks desktop UI data, which may limit generalization to diverse widget types and platform-specific icons. Some reviewers suggest a small-scale experiment on non-web GUI tasks to validate cross-environment transfer.
- **Missing ablation studies** (minority reviewer with score 5 strongly criticizes): No ablation to disentangle contributions of model design (image resolution setting) versus training data in comparisons (Table 2) where methods differ in both. Also missing ablation on the three types of referring expressions (visual, positional, functional) to quantify their individual contributions.
- **Inefficiency**: Input image size set to 36 grids of CLIP@224 produces 9,216 image tokens; an ablation study on whether this high resolution is necessary is recommended.
- **No timing/latency comparisons**: End-to-end latency experiments comparing vision-only approach to methods using accessibility trees in online agent tasks are not provided.
- **Evaluation gaps**: The widely-used WebArena/WorkArena/OSWorld/WindowsAgentArena benchmarks are not included; reasons for omission are not explained.
- **Discrepancy in Mind2Web-Live results (Table 7)**: The image-based model (GPT-4o with UGround) achieves higher Completion Rate (CR) but comparable or lower Success Rate (SR) than text-based models; the relationship between grounding method and CR/SR across input modalities needs analysis.
- **Data quality concerns**: Large-scale synthetic data generated by LLMs (LLaVA-Next-13B, GPT-4o, LLaMA-3-8B) risks hallucinations; a human evaluation on a random sample of referring expressions (e.g., 1000) is recommended. Also needed: deeper dataset diversity analysis (PCA, t-SNE), breakdown of GUI element types, and verification of alignment with planning instructions.
- **Missing related work**: Discussion of current GUI agents is absent from the main text (minority reviewer critique).
- **Typos**: Citation error for CogAgent in line 307.
- **Copyright concerns**: Use of Common Crawl webpage data; authors should address data usage policy and compliance with copyright laws.
