## Merged Review

### Summary
The paper introduces a novel task—explaining differences between two audio recordings using natural language—and proposes new datasets (Audio Caps Difference (ACD) and Clotho Difference (CLD)) derived from AudioCaps and Clotho. The datasets contain three tiers of LLM-generated difference descriptions (concise, brief, detailed) that are human-verified and hallucination-corrected for the test subset. The authors propose the ADIFF model, which encodes both audios, uses a cross-projection module and a separator token to compare the two audio representations, and prompts a frozen LLM (GPT-2) with a three-stage training process. Baseline comparisons include a “naive” baseline (an ablated version of ADIFF) and Qwen-Audio Chat. Evaluation uses objective metrics and human evaluation; multiple ablation studies examine cross-projection, LLM size, position captioning, and training stages. The paper also provides hallucination detection tools using HTS-AT event predictions.

### Strengths
- **Novel task definition.** Defines and motivates the previously underexplored area of audio difference explanation, with clear significance for audio forensics, quality assessment, and audio generation.
- **Dataset contribution.** Creates two new datasets (ACD, CLD) with three tiers of descriptions, human verification on test sets, and hallucination filtering, providing a foundation for future research.
- **Model architecture novelty.** Introduces a cross-projection layer and separator token to explicitly compare two audio embeddings, a component absent in prior audio-language models.
- **Thorough evaluation and ablations.** Includes both objective and subjective (human) evaluations; ablation studies cover cross-projection, LLM size, position captioning, three-stage training, and a random-weight audio encoder lower bound.
- **Hallucination detection.** Provides a tool to detect hallucinated audio events using HTS-AT encoder predictions.
- **Three-tier captioning approach.** Incorporates human perception primitives (audio events, scenes, signal properties, emotions), enriching data quality and practical usability.
- **Discussions on hallucination in annotation.** Thoughtful analysis of LLM tendency to hallucinate and how filtering enhances dataset quality.

### Weaknesses
- **Baseline is insufficient.** The “naive” baseline is an ablated version of the same model, not a strong independent baseline; comparisons guarantee ADIFF performs better. The SOTA model Qwen-Audio Chat is also not finetuned for this task, raising the question whether finetuning a stronger model without ADIFF could solve the task using only the dataset.
- **Insufficient evidence for cross-projection importance.** The ablation comparing baseline with/without cross-projection does not control for LLM finetuning—the main model finetunes the LLM, which could itself learn cross-comparison, making the cross-projection layer potentially redundant. The specific LLM variant used in this ablation is not reported. Additionally, no comparison of “baseline + LLM finetuning” vs “baseline + cross-projection + LLM finetuning” is provided.
- **Arbitrary three-tier captioning.** No ablation studies examine whether tiers are hierarchical (e.g., if training only on tier-3 yields good performance on lower tiers), and the choice of three levels appears unsupported.
- **Dataset limitations.** AudioCaps and Clotho captioning quality is questionable; larger caption datasets (e.g., WavCaps) are not considered. The number of audio pairs in each dataset split is unclear—Table 1 reports audio counts, but the task requires pairs (a_i, a_j, e_i). It is also not explained how multiple captions per audio (especially in AudioCaps train) are selected as LLM seeds.
- **Metric choices insufficient.** The captioning metrics used (e.g., in Tables 2,4,5,6) can be biased toward words irrelevant to audio differences. Additional benchmarks (e.g., checking differences in sounding objects via SED or signal processing characteristics) would strengthen evaluation. Consolidating to fewer, more representative metrics would improve clarity.
- **Presentation and clarity issues.** Tables are difficult to follow: model names are often missing, best values are not highlighted, results overlap between Tables 2 and 4, and key information (e.g., which GPT-2 variant is used) is absent. The human evaluation in Table 3 lacks sufficient detail: number of evaluators, fairness measures, explanation of scores, and why the evaluation datasets (Studio, FSD50K, GTZAN) are different from ACD/CLD. The claim “ADIFF sees the largest improvement in granularity metric” is not clearly visible in the table.
- **Compute scaling comparison flawed.** Section 5.3 equates compute across different-sized models by training them for the same number of epochs, ignoring the higher per-epoch cost of larger models, undermining scaling conclusions.
- **Human evaluation concerns.** It is unclear why Qwen-Audio Chat (the only ALM supporting two audio inputs) is a valid baseline for subjective evaluation if it was not designed for audio difference explanation. The evaluation datasets do not include ACD or CLD, and the number of human annotators, inter-rater agreement, and fairness safeguards are not reported.
- **LLM finetuning details missing.** It is not specified whether full finetuning or PEFT is used; the choice impacts the argument for cross-projection and the ability to scale to larger LLMs.
- **Architectural detail needed.** The length of audio prefixes ([prefix 1], [prefix 2]) fed to the cross-projection layer is unclear—whether HTS-AT outputs a single token per audio or a sequence—and the explanation in Figure 3 is insufficient.
- **No analysis of difference types.** The distribution of differences described across tiers (e.g., changes in sounding objects vs. characteristics within the same category) is not provided, which would help validate the LLM-generated annotations.
