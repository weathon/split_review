## Merged Review

### Summary
The paper proposes CARPRT (Class-Aware Prompt Reweighting) for zero-shot image classification with vision-language models like CLIP. It identifies that existing prompt reweighting methods (e.g., ZPE) use a class-shared weight vector, which is suboptimal because it assumes class-conditional independence. CARPRT computes a class-specific weight matrix by calculating relevance scores between images and prompt–class pairs, then averaging maximum scores per class across prompts. Experiments on multiple benchmarks (fine-grained datasets, ImageNet variants) show that CARPRT often improves accuracy over ZPE, especially on fine-grained datasets like EuroSAT and Flowers102. Reviewer ratings are 5, 6, 6, 6; one reviewer (R1, score 5) is more critical about the limited gains and computational concerns.

### Strengths
- **Motivation and novelty**: The paper is the first to apply class-aware weighted prompt ensemble; the need for class-specific weights is empirically demonstrated and intuitively reasonable.
- **Theoretical foundation**: Provides a solid probabilistic (Bayesian) framework that identifies the conditional independence limitation in prior methods; the approach is mathematically sound and interpretable.
- **Clarity**: Well-written and easy to follow, with detailed analyses, clear formulations, and an algorithmic procedure.
- **Simplicity and implementation**: CARPRT is a simple implementation that adheres to the key principles from the probabilistic analysis; it automates prompt reweighting, reducing dependency on manual prompt crafting.
- **Experimental coverage**: Extensive experiments across 10+ fine-grained datasets and 3 ImageNet variants, using both ViT and ResNet backbones; hyper-parameter studies are adequate.
- **Performance on fine-grained datasets**: Notable improvements on datasets like EuroSAT and Flowers102; the method achieves state-of-the-art results on several benchmarks.

### Weaknesses
- **Limited improvement**: Performance gains are marginal (often <1%) in many cases, especially on ImageNet variants (e.g., ImageNet-A, ImageNet-R) where gains are modest. This raises concerns about the method’s significance and contribution.
- **Computational complexity**: CARPRT computes weights across both prompt and class dimensions, but no complexity analysis is provided. The added cost may not be justified by the limited gains.
- **Dependence on pseudo-labels**: The method relies on accurate pseudo-labels to derive class-specific weights, but the paper does not analyze pseudo-label accuracy across multiple prompts (which may predict different labels) or the impact of noisy pseudo-labels on final accuracy. The failure modes when pseudo-labels are significantly incorrect are not studied.
- **Derivation gaps**: The mapping from the probabilistic derivations (Eq.6, Eq.7, Eq.13) to the final weight formula (Eq.16) is not rigorous; correspondences between the formulations and the implementation (e.g., how Pr(W|P) is handled, point estimation of W) are not explicitly presented.
- **Sensitivity to hyperparameters and prompt pool**: Only overall results for hyperparameters (e.g., τ=3.0) are shown. The suitability of these settings across all datasets is unclear; detailed per-dataset hyperparameter analysis is missing. The method’s effectiveness may depend on the quality/diversity of the prompt template pool, but its impact is not empirically studied (e.g., size, diversity, necessity of combining templates from different datasets for a given test set). No analysis is provided on whether CARPRT works with learned prompts.
- **Missing comparisons and analyses**:
  - Only weighted baselines (ZPE) are compared; it is unclear whether CARPRT can enhance existing prompt engineering methods.
  - No experiments on other large datasets (e.g., Places365) to evaluate significance on broad-class datasets.
  - No analysis on fine-grained datasets with class imbalance; does class-aware weighting improve performance there?
  - The paper does not test other models for class distributions (e.g., GMMs) beyond the energy-based approach.
- **Minor issues**: Typos (e.g., “iaccuracy” in Ln 431); the toy example in Proposition 3 (Ln 880-889) is confusing—derivation steps are not clearly justified.
- **Questions posed as weaknesses**:
  - How does the accuracy of pseudo-labels affect CARPRT vs. ZPE?
  - How does the diversity and size of the prompt template pool affect performance?
  - Could the derivation from Eq.13 to Eq.16 be made more explicit?
  - Are the hyperparameter settings (e.g., τ=3.0) optimal for each dataset individually?
