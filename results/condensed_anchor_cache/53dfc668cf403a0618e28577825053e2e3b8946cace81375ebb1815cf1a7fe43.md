## Merged Review

### Summary

The paper introduces scDiff, a conditional diffusion generative model that unifies multiple single-cell analysis tasks (cell annotation, imputation, novel cell type identification, perturbation prediction, few-shot learning) by casting them as posterior estimation problems. The framework consists of a diffusion model (adapted from standard denoising score matching), a set of condition-specific encoders that map conditioning information (e.g., cell type, batch, perturbation) into numerical embeddings, and a cross-attention unit that fuses those embeddings with the diffusion model’s hidden states. Experiments on several scRNA-seq datasets show competitive or state-of-the-art results across tasks. The work is significant for unifying disparate tasks under one model, but reviewers raise concerns about novelty, clarity of the conditioning mechanism, lack of thorough validation, and reproducibility.

### Strengths

- **Unified framework**: The paper casts three major single-cell tasks (cell labeling, expression imputation, knowledge transfer) into a single posterior estimation problem, and the conditional diffusion model provides a natural way to handle them under one architecture. This is considered a valuable conceptual contribution (R1, R3, R4).
- **Competitive performance**: The results on multiple benchmarks are impressive and often match or exceed task-specific baselines (R1, R2). However, some reviewers caution that baselines may not be optimally tuned (see Weaknesses).
- **Comprehensive evaluation**: The range of tasks and datasets (including real and simulated data) is broad, covering important settings such as novel cell type discovery and few-shot classification (R1, R3, R4).
- **Well‑written exposition** (R1): The paper is clear, attributes prior work well, and provides a good introduction to how diffusion models can be applied to single-cell data. Figure 1 clearly illustrates the overall approach (R4).
- **Flexibility**: The use of conditioners allows incorporating prior knowledge from large language models (LLMs) or graph neural networks, and the model supports zero‑shot and few‑shot conditioning (R1, R3).

### Weaknesses

- **Novelty/lack of core innovation**:  
  – The model applies standard diffusion model techniques without methodological novelty. One reviewer (R1) finds this acceptable as a well‑executed application, but several others (R3, R4) view the lack of machine‑learning novelty as a significant limitation.  
  – The unified posterior estimation framing is not new; variational autoencoders have been used similarly in single‑cell analysis (R3).  
  – The approach forces three separate tasks into one framework without strong motivation; each task could be solved individually with similar architectures (R4).

- **Insufficient model description and lack of clarity**:  
  – The conditioning mechanism is only sketched: it is unclear how different conditioning inputs (cell type, batch, perturbation) are encoded and integrated, what the architecture of the conditioners is, and how the cross‑attention unit automatically detects which task is being performed (R2, R4).  
  – The paper includes a lengthy introduction of standard diffusion model basics (Section 2.2 to Eq. 9) that is not a contribution and should be moved to the appendix (R4).  
  – The choice of a 6‑layer encoder and 1‑layer decoder (instead of the more common U‑Net) is not justified for scRNA‑seq data. Whether a simpler model would suffice is not addressed (R2, R4).  
  – The nature of the “posterior estimation” is misleading: the model does not perform actual inference beyond standard diffusion training. R1 suggests rephrasing to “probabilistic modeling using a shared model.” R4 questions how the prior is used at all, especially for prediction‑oriented tasks like cell labeling and knowledge transfer.

- **Lack of experimental details and reproducibility concerns**:  
  – Training details (batch size, learning rate, optimizer, number of diffusion steps) are missing, making reproduction difficult (R2).  
  – For small datasets (e.g., Jurkat, ~3000 cells), it is unclear whether the model is trained from scratch or fine‑tuned (R2, Q1).  
  – The specific sampling/inference procedure for each task is not clearly defined (e.g., how many steps, which conditioning inputs are used) (R2).  
  – The authors tuned their own model but report default parameters for competing methods; this makes the comparison less reliable. Using established benchmarks (e.g., OpenProblems) with fixed splits and tuned baselines would be more informative (R2).

- **Unsound assumptions and missing ablations**:  
  – The missing‑value imputation task assumes that all zero‑expressed genes are missing (i.e., no biological zeros). This is biologically questionable; a model that learns the mask matrix \(M\) would be more appropriate (R3).  
  – The uniform prior over cell types (Eq. 1) may hurt performance on unbalanced datasets; its impact on classification tasks (e.g., Appendix C) should be evaluated (R2, Q2).  
  – The rationale for using a linear encoder/decoder for single‑cell data is not explained (R3).  
  – The paper does not characterize the computational cost of the unified model versus equivalent task‑specific models (R3).  
  – For the few‑shot experiments using LLM embeddings (e.g., Liver dataset, ~30 cell types), the benefit of high‑dimensional (64–128 dim) representations over simpler alternatives is not justified (R2, Q5).

- **Missing comparisons and baselines**:  
  – The paper mentions using LLMs as prior conditioners but does not compare against recent LLM‑based single‑cell models (e.g., scGPT, Geneformer). Such comparisons are needed to contextualize performance (R4).  
  – Table 1 lacks the number of clusters and chance‑level accuracy per dataset, making it hard to assess the meaningfulness of the reported results (R3).  
  – For imputation (Table 2a), only correlation is reported; average normalized error would be more informative (R3). The number of genes used per task/dataset is not given (R3).

- **Minor inconsistencies and presentation issues**:  
  – The imputation conditioning is phrased as \(p(x \mid m \cdot x)\) but is actually an approximation \(p(x^* \mid m \cdot x)\); this should be explicitly acknowledged (R1).  
  – Experimental settings (e.g., Section 4.2.1) are confusing and need clarification (R3).  
  – In Figure 2, chance level is not shown, and the number of cell types is limited; in Figure 3, the top and bottom subfigures show inconsistent relative performance patterns that need explanation (R3).  
  – Equation 10 (TimeEmbed) requires further elaboration (R3).  
  – The paper states that the conditioner extracts \(L\) numerical representations; the meaning of \(L\) is not defined (R2, Q3). Examples of “mapping designed to suit input types” are missing (R2, Q4).

*Minority positive view*: One reviewer (R1, score 8, confidence 5) is very positive, considering the paper a well‑written baseline that justifies its lack of core innovation through useful application. The above weaknesses reflect a consensus among the other three reviewers (scores 6) who, while recognizing the value of the unified framework, find substantial issues in clarity, novelty, and experimental rigor.
