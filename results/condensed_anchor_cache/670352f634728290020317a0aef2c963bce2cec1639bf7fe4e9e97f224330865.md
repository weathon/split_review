## Merged Review

### Summary

The paper introduces LINA, a neuro-symbolic framework that uses an LLM to perform logical reasoning autonomously without external solvers. LINA comprises an Information Extraction Module (context classification, query extraction, propositional logic extraction) and a Symbolic Reasoning Module (iterative deductive reasoning with verification). The framework combines symbolic representations (propositional logic) with natural language to mitigate information loss. Experiments on five datasets (FOLIO, ProofWriter, ReClor, LogiQA) using GPT-3.5 and GPT-4o show improvements over baselines including LINC, CoT, CoT-SC, ToT, and SatLM, claiming up to 24.34% improvement over LINC on FOLIO and 24.02% over CoT on other datasets. Theoretical complexity analysis and ablation/case studies are provided.

### Strengths

- **Originality (R1):** LINA replaces the external solver (Z3 in SatLM) with an LLM-based deductive engine, making it more adaptable to loosely defined questions and improving generalization. Theoretical proofs on complexity are provided.
- **Framework design (R3):** The combination of symbolic and natural language aims to address poor generalization to different question formats and information loss.
- **Experimental results (R1, R3):** LINA outperforms LINC, CoT, CoT-SC, ToT, and SatLM across five datasets using GPT-3.5 and GPT-4o, with up to 24.34% improvement over LINC on FOLIO and 24.02% over CoT on other datasets. An ablation study and case study are included.
- **Clarity and reproducibility (R1, R2):** Figure 1 effectively illustrates the pipeline; the appendix contains actual prompts. Code and data are provided. The writing is well-structured.
- **Research problem (R2):** Neuro-symbolic integration for improving LLM reasoning is a well-motivated problem.

**Note:** One reviewer (R1, overall rating 6) was more positive, praising the originality and theoretical contributions. However, the other three reviewers (R2, R3, R4; ratings 5, 3, 3) raised substantial concerns detailed below.

### Weaknesses

- **Limited novelty and commonality (R2, R3, R4):** The core concept of an agentic framework using formal logic is relatively common. Prior works such as SymbCoT (R3) also leverage natural language and FOL; the main difference is the iterative process. Other prior works [1,2] (R4) have similar designs. The novelty is considered minor.
- **Poor motivation and justification (R4, R2):**  
  * The paper’s claim that translation to formal logic causes information loss (L48) is true only for datasets without FOL groundtruth (ReClor, LogiQA), which are not intended for formal logic methods in the first place (R4).  
  * The claim that reliance on external tools (Z3, Prover9) leads to poor generalization (L78) is problematic: tool usage generally increases capability, and SAT is a generic problem setting (R4).  
  * The advantages of converting natural language to formal logic before LLM reasoning are not clearly established (R2).  
  (R1 found this motivation convincing, but the majority do not.)
- **Inappropriate framing for ReClor/LogiQA (R4):** Not all problems in ReClor and LogiQA can be framed as deductive reasoning (e.g., “which argument supports/challenges”, “shares the same reasoning pattern”). The approach assumes deductive reasoning is universally applicable, which is inappropriate.
- **Questionable experimental details and results (R1, R3, R4):**  
  * The reported accuracy for GPT-4o on ReClor (76%) is far lower than the leaderboard accuracy of 90.10% for GPT-4-0613 on ReClorTeam; the reason is not explained (R1, R4).  
  * It is unclear how many ICL examples were used for the GPT CoT baselines; given the low accuracy, the baselines may be weak (R4).  
  * Including LINC (designed for NLI) on ReClor and LogiQA benchmarks is not sensible, as these are not NLI tasks (R4).  
  * The choice to use the train set of FOLIO but validation sets for other datasets is not justified (R3).
- **Missing analysis and transparency (R3):**  
  * No analysis of accuracy per proof depth on ProofWriter, which would demonstrate robustness to increasing reasoning complexity.  
  * No error analysis to identify where failures occur.  
  * The claim that the framework addresses information loss and improves generalizability is not supported by direct analysis.
- **Insufficient details on modules (R2, R3):**  
  * Information Extraction Module: The context classification scheme and determination of “ease of translation” are unclear; it is not specified how many classes are used and which parts are translated into symbolic logic (R3).  
  * Reasoning Module: The interaction between logical statements (LS), natural language (NL), and the hypothesis (H) to reach conclusion C is not explained. The purpose of the `Check()` operation (error checking vs. contradiction/support verification) and the error-handling logic (adjusting C or resetting C=H) are not specified. The Reasoning Process Judgment component appears in Figure 1 but is omitted from Algorithm 1 (R3).  
  * Hypothesis generation and its integration into the framework lack explanation (R3).
- **Self-bias and model dependency (R2):** The same LLM serves as both deductive reasoner and supervisor/judge, which may introduce self-bias. No mitigation mechanism is discussed. The framework’s applicability to smaller models (e.g., 7-8B parameters) is not tested.
- **Lack of quantitative support for z3 claim (R3):** The paper states that the LLM cannot generate effective z3 solver code or easily adapt for execution, but no quantitative data (e.g., execution success rates) is provided to support this observation.
- **Limited scope and expressiveness (R2):** Deduction with formal logic is restricted if required deduction rules are not explicitly included. It is unclear if the framework can extend to broader reasoning tasks such as math reasoning, coding, or QA.
- **Clarity issues (R1, R3):** Figure 2 is difficult to interpret without sufficient context, and it is unclear why the CoT approach does not explore additional steps (R1). The Reasoning Module and its components are not clearly described, hampering understanding (R3).
