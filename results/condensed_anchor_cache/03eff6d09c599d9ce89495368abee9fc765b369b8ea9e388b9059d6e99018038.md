## Merged Review

### Summary
The paper presents Accordion, a three-stage pipeline (reference creation, design planning, layer generation) built around a fine-tuned Vision Language Model and off-the-shelf vision tools (SAM, inpainting, OCR) to convert pixel-based graphic designs into editable layered formats. Reviewers acknowledge the system produces visually nice results and has practical applications, but broadly agree that novelty is low—the contribution is primarily an integration of existing components with a small fine-tuned dataset (Design39K). One reviewer is significantly more critical, labeling it an engineering work unsuitable for a research venue like ICLR.

### Strengths
- The overall workflow successfully generates layered graphic designs, and result images are delightful.  
- The workflow is versatile across different design scenarios (text-to-template, adding text on background, text de-rendering, design variations).  
- The problem and research direction are solid with many real-world applications; recent commercial products (e.g., ChatGPT Canvas) validate the importance.  
- The paper shows many results across different application types.  
- The proposed method is straightforward as long as training data is provided.

### Weaknesses
- **Limited novelty**: All reviewers note the contribution is small. The work integrates existing tools (SAM, OCR, inpainting, background removal, a Vision LLM) with only a finetuned VLM on an internal dataset (Design39K) as the new element. One reviewer states “this is an engineering work” and not suitable for an ICLR research paper.
- **Unclear which part is proposed**: It is not clearly separated from prior components. “Reference Creation” uses an existing Vision LLM with only a prompt; the planning and layer stages could be achieved by combining existing works (e.g., text de-rendering, layer decomposition, code generation from a design image).
- **Confounding factor in comparisons**: It is not clear whether better results come from a better base image generator rather than the proposed planning/decomposition; a fair comparison applying the planning and layering method to designs from other generators is missing.
- **Lack of evaluation on in-the-wild designs**: No experiments applying the method to real existing graphic designs (e.g., from the web) are reported; the pipeline seems tailored to AI-generated references.
- **Presentation clarity**: The intended use case is ambiguous. The first stage name “reference creation” suggests references are outputs, but the main application appears to be converting AI-generated images into editable files as post-processing. The paper should state this upfront. Section 3 (Methodology) contains only high-level summaries with no specific technical descriptions or algorithm details.
- **Missing runtime and resolution analysis**: Reviewer 3 requests a runtime breakdown for Stages 1, 2, 3 and various editing tasks (waiting time critical for an editing system). Also, the system’s adaptability to high-resolution images (>5M pixels) and performance under those conditions is not addressed.
