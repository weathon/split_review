## Merged Review

### Summary
Traditional GNNs suffer from feature oversmoothing due to diffusion-like message passing on undirected graphs. The authors propose Continuous Edge Direction (CoED) GNN, which assigns differentiable fuzzy edge directions—varying continuously between pointing i→j and j→i—to each edge, allowing preferential feature flow and enabling long-range transmission. A complex-valued Laplacian (real and imaginary parts for opposite directions) is introduced. The architecture aggregates neighbor features scaled by learned directions, processing in-neighbors and out-neighbors separately alongside self-features. CoED GNN is particularly suited to graph ensemble data (fixed structure, multiple feature realizations). Theoretical analysis proves expressivity limits via a generalization of the WL test for fuzzy directed graphs. Experiments on synthetic and real-world datasets show performance gains.

### Strengths
- The paper is well-written, well-motivated, and addresses significant topics (expressive power, directed GNNs, oversmoothing) [R1, R2, R4].
- The idea of learning optimal edge directions using differentiable fuzzy directions and phase angles is novel, intuitive, and effective [R2, R4].
- Theoretical analysis is rigorous and formalizes the expressive power of the proposed model, including a generalization of the WL test for directed graphs with fuzzy edges; the method is shown to be more expressive than the Magnet Laplacian [R1, R2, R4].
- The evaluation on graph ensemble data is intriguing and addresses an important task that demands attention [R1].
- The fuzzy Laplacian enables directional message passing that preserves discriminative features over longer distances, leading to performance gains on both synthetic and real-world datasets [R3].

### Weaknesses
- **Missing baselines and related work comparisons:**
  - Important baselines with similar concepts (e.g., [3] from R1) are omitted; the approach should be compared to other directed Laplacians (e.g., from normalized adjacency matrix, random walk Laplacian) to contextualize the fuzzy Laplacian contribution [R1, R2].
  - The separate in-/out- aggregation idea is similar to DIGRAC [1] (flow-imbalance objective); discussion and empirical comparison with DIGRAC are needed [R4].

- **Unconvincing node classification evaluation:**
  - CoED achieves the best result on only 1 out of 5 datasets in Table 1 [R2].
  - Experiments are missing on several standard datasets used by DirGNN (e.g., SNAP-PATENTS, ROMAN-EMPIRE, ARXIV-YEAR) and on larger-scale heterophilous datasets [R1, R2].
  - The Chameleon and Squirrel datasets are known to have significant duplicate data and problematic splits; filtered versions should be used [R1, R2].
  - The heterophilous datasets used (Texas, Wisconsin) are very small, and results do not approach current SOTA [R1]; R2 notes that adding an MLP after DirGNN’s final layer significantly improved its performance on these datasets.
  - Only one homophilous dataset is included [R1].
  - Recommended additional datasets include AM-Photo, AM-Computer, Citeseer, and filtered versions of Chameleon/Squirrel [R1, R2].

- **Insufficient analysis of edge direction learning:**
  - Table 1 compares a CoED version *without* edge direction learning; results *with* learned directions for node classification should be shown [R4].
  - It is unclear how performance changes when edge directions are made learnable (prior work [3] suggests improvement) [R1].
  - The learned edge directions are essentially edge weights; GAT learns edge weights using node features and therefore should perform at least as well—why CoED outperforms GAT requires theoretical justification (e.g., spectral analysis of the fuzzy Laplacian) [R3].
  - An alternative simpler approach (e.g., using a shared learnable function like Sigmoid(f(u_i,u_j)) and 1−Sigmoid(…)) could replace the complex-valued mechanism; related work superGAT could be extended to directed graphs with separate in-/out- aggregation [R2].

- **Lack of explanation and validation for oversmoothing:**
  - The claim that CoED alleviates homogenization (oversmoothing) is not sufficiently justified; the authors should provide spectral analysis of the fuzzy Laplacian versus standard Laplacians and experimental validation showing reduced oversmoothing [R3].

- **Technical and clarification issues:**
  - The theorem highlighted in the abstract and introduction is not explicitly stated in the main paper [R1].
  - In Equation (1), notation is confusing: the same symbol “i” is used for the imaginary unit and the node index [R3].
  - In line 315, it is not clear where α should appear in the formula [R4].

- **Missing implementation and empirical details:**
  - No source code is provided [R4].
  - No explicit runtime comparison (e.g., a table) is given for CoED versus MagNet and other baselines [R1, R4].
  - It would be insightful to visualize the learned edge directions for some directed or undirected graphs [R4].
  - The method does not handle edge features, which are common in real-world directed graphs; this extension should be discussed or explored [R2].
