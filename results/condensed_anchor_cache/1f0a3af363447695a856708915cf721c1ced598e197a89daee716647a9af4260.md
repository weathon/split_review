## Merged Review

### Summary
The paper proposes Multiresolution Meta-Framelet-based Graph Convolutional Network (MM-FGCN) for adaptive multiresolution representation learning on graphs. It uses meta-learning to learn a set of framelet filters parameterized by a meta-band-pass filter based on polynomial splines, avoiding handcrafted fixed transforms. Chebyshev approximation avoids eigen-decomposition. The method is evaluated on node and graph classification tasks. Reviewers note novelty and theoretical foundation, but raise concerns about meta-training cost, scalability to large graphs, missing baselines, small datasets, and missing implementation details.

### Strengths
- Adaptive multiresolution representation learning, capturing micro and macro patterns simultaneously.
- Solid theoretical motivation and proof, including framelet filter construction satisfying denseness and dilation properties.
- Significant improvement on node classification (especially disassortative tasks) and graph classification tasks.
- Fewer parameters than previous methods: meta-framelet generator uses only parameters \(\Theta\) and \(\omega\).
- Relatively novel method combining spectral filtering and meta-learning.
- Adequate ablation studies (e.g., Table 3 comparing direct training vs. meta-learning).
- Good performance on various tasks (node and graph classification).
- Paper is well-written and easy to follow; preliminary section provides necessary background.

### Weaknesses
- **Meta-training cost**: Requires additional meta training; no time cost details for meta-learning or inference provided.
- **Why meta-learning?**: The reason meta-learning outperforms directly training framelet transforms is not explained (Table 3 shows effectiveness but mechanism remains mysterious). Missing details on how meta dataset \(S_{meta}\) is split from main dataset \(S_{main}\).
- **Scalability**: Chebyshev approximation seems more expensive than graph-structure-based approaches; model may be hard to scale to large graphs (e.g., ogbn tasks). Datasets used (Cora, Citeseer, Pubmed) are small/toy; lack of evaluation on larger graphs with many nodes per graph (vs. total number of graphs).
- **Performance vs. SOTA**: One reviewer states performance is not close to SOTA, citing recent studies [1],[2]. Another reviewer (R4) notes lack of comparison with well-known baselines: GIN (Xu et al., 2018) and graph transformers (e.g., Rampášek et al., 2022). Missing comparisons make it difficult to assess relative strengths. (Note contrast: R2 and R3 praise performance as good.)
- **Missing implementation details**: No specification of neural network \(M_\xi\) (what it outputs, how \(\omega\) is structured). No details on data splitting procedure. No mention of code release, hindering reproducibility.
- **Missing analysis**: Would like to see how filters change during training to demonstrate adaptivity (claimed fixed transforms are avoided). For graph classification, performance with MM-FGPool vs. standard graph pooling is not provided.
- **Minor issues**: Missing “translation” before property near (Mallat, 2006) (R2). Typo in Section 3: “denseness, dilation property, and property (Mallat, 2006)” (R4).
- **Other missing details**: Geom-GCN in Table 6 lacks standard deviation – why?
