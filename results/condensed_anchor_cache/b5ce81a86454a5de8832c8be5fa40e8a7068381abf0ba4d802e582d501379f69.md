## Merged Review

### Summary
This work adapts the LLM-based FunSearch framework to automatically design acquisition functions (AFs) for Bayesian optimization. FunBO takes an initial AF (e.g., Expected Improvement) as input, uses an LLM to iteratively propose modified Python programs representing new AFs, evaluates each by running full BO loops on a set of training objective functions (allowing varying dimensions), and scores the performance. The output is an interpretable AF expressed as computer code. Experiments on global optimization benchmarks and hyperparameter tuning show that the discovered AFs outperform generic AFs (EI, PI, UCB) and are competitive with function-specific meta-learned AFs (MetaBO). One reviewer (R3) notes that the method is limited to settings with a distribution of similar functions available for training and is not suitable for one-off problems. Another reviewer (R5) highlights a surprising strong performance of random search on the out-of-distribution benchmark, raising credibility concerns.

### Strengths
- **Novel Application and Problem Formulation**: Applying LLM-guided program search (FunSearch) to acquisition function discovery is novel (R1, R3). Formulating AF learning as an algorithm discovery problem and outputting interpretable code is a promising direction (R1, R2, R5).
- **Interpretable Acquisition Functions**: Unlike black-box neural network–based meta-learned AFs, FunBO produces AFs as explicit Python code, enhancing interpretability and explainability (R2, R5). The functional form of discovered AFs is reported analytically (R1, R3).
- **Exhaustive and Convincing Experimental Evaluation**: Extensive benchmarks demonstrate that FunBO-discovered AFs outperform general-purpose AFs and are competitive with function-specific AFs (R1, R2, R3, R5). The method generalizes to out-of-distribution functions and few-shot adaptation settings (R1, R5). The iterative refinement scheme converges in relatively few iterations (R2).
- **Clear Writing and Easy to Follow**: The paper is well-written and the method is intuitively presented (R2, R3, R4).

### Weaknesses
- **Restrictive Input Space of Learned AFs** (all reviewers): The generated AFs only take predictive mean, predictive variance, and incumbent as arguments. They cannot represent acquisition functions that require the full covariance matrix, such as Entropy Search or Knowledge Gradient, potentially sacrificing performance (R1, R3, R4, R5). One reviewer (R3) finds the interpretability argument unconvincing: general-purpose AFs are already interpretable, and the functional form shown (e.g., line 399) may not be easily modifiable if it performs poorly.
- **Requires Repeated Optimization Runs on a Distribution of Functions** (R3): FunBO demands access to a training set of objective functions from the same distribution as the target, and multiple BO evaluations per iteration. This excludes one-off optimization tasks and limits practical applicability. The paper should clarify how to gauge sufficient training set size for a given problem (R3).
- **Curse of Dimensionality from Discretization** (R1, R4): The AF takes a collection of points as input (discretized), not a continuous function. This design may suffer from the curse of dimensionality, whereas standard AFs are optimized via gradient ascent on the continuous domain.
- **Misleading Terminology about "Structure of Past Functions"** (R1, R4): The paper may blur the line between meta-learning a surrogate model (which learns explicit function structure like unimodality, periodicity) and meta-learning an AF. FunBO does not exploit or learn any function structure directly; it only adjusts the AF based on the GP’s predictive mean/variance and the incumbent. The output AF is conditioned on the choice of surrogate model (GP with RBF kernel), so changing the surrogate would require re-running FunBO.
- **Sensitivity and Out-of-Distribution Averaging** (R1, R4): The authors state that FunBO was run multiple times for OOD results, but report only the best results, not the average. This raises cherry-picking concerns (R1, R4). One reviewer (R5) notes that random search performs surprisingly well on the OOD benchmark, questioning the credibility of the experimental setup.
- **Lack of Theoretical Insight** (R5): The method relies on an empirical pipeline without theoretical guarantees or insights into why the discovered AFs work and how they might transfer.
- **Computational Intensity** (R5): The iterative learning scheme requires a full BO loop evaluation for each candidate AF, making training computationally expensive.
- **Limited Comparison with Recent Meta-BO Work** (R3, R5): Comparisons with Entropy Search, Knowledge Gradient, and portfolio-based UCB (adaptive β) are missing (R3). Comparisons with more recent meta-acquisition functions (e.g., Maraval et al., 2024; End-to-end meta-BO with transformer neural processes) would be helpful to better position FunBO’s empirical performance (R5).
- **Scale Sensitivity and Scalability Concerns** (R2): The experiments are limited to low-dimensional (<10D) problems. The proposed method’s sensitivity to input scale (covariate shift between training and test tasks) and its ability to scale to larger real-world problems (e.g., robot learning, hyperparameter optimization of deep neural networks) are not addressed. Evidence for zero-shot transfer from small-scale to large-scale problems would be valuable.
- **Sampling Strategy** (R3): Why sample only 2 candidates per iteration? Ablation studies on the scoring function (e.g., using negative cumulative regret instead of simple regret) are missing.
- **Visualization** (R3): Figure 3 (right panel) is too busy; the authors could adopt the style of Garnett (2023) showing queries as ticks at the bottom. It also does not clearly demonstrate the benefits of FunBO; EI appears “stuck” at the global optimum, but UCB with the wrong trade-off parameter β might cause over-exploitation. Policies that automatically adjust β should be included as baselines.
