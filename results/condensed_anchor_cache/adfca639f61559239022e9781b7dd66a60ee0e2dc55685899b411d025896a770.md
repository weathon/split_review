## Merged Review

### Summary

MuLan is a training-free multimodal-LLM agent for progressive multi-object text-to-image generation. It uses an LLM to decompose a complex prompt into sequential subtasks, each generating one object via Stable Diffusion while conditioning on previously generated objects. A VLM provides feedback to check alignment and trigger regeneration if needed. The process also supports human intervention at intermediate steps. The paper evaluates on 200 prompts with spatial relationships and attribute bindings, comparing against SDXL and PixArt-α among others.

### Strengths

- The paper is well-written and easy to follow.
- MuLan demonstrates good control over the generation process and produces high-quality images that align well with the given prompts.
- The approach supports human-AI interaction throughout the generation process, allowing users to make intermediate changes.
- The use of LLMs for decomposition and VLMs for feedback is sensible and effectively addresses the challenge of handling multiple objects, spatial relationships, and attribute bindings.
- MuLan is training-free and model-agnostic, requiring no additional fine-tuning.
- Qualitative results surpass those of SDXL and PixArt-α in generating multi-object scenes.
- The method generates objects that adhere closely to the instruction, ensuring consistency with the original prompt.

### Weaknesses

- **High computational cost and inference time:** MuLan’s inference time increases with the number of objects, limiting scalability in real-time applications. The overall generation process is lengthy because each object must be generated sequentially. No quantitative latency comparison with baselines or analysis of the accuracy-efficiency trade-off is provided, making it difficult to assess practical applicability. Furthermore, open-source models like SD3 already achieve accurate compositional generation without such a multi-step cost, raising questions about MuLan’s efficiency advantage. It is also unknown how many regeneration iterations MuLan typically requires when the VLM detects a deviation from the prompt.
- **Lack of novelty:** Using LLMs as planners for image generation has been explored in prior works (e.g., RPG). The novelty claim is weak given the existence of similar approaches.
- **Insufficient evaluation and baselines:** The experimental evaluation is limited. Only plain text-to-image methods (e.g., SD1.4, SDXL) are compared; other LLM-based planning approaches or compositional generation methods (e.g., RPG, Ranni, Composable) are not included. The evaluation relies primarily on qualitative results without a wider range of objective metrics. There is no ablation study to demonstrate the benefits of progressive generation or the specific design choices (e.g., the VLM feedback mechanism). Missing comparisons with more recent state-of-the-art models (FLUX, SD3) leave it unclear whether MuLan offers any advantage over these stronger base models. The paper does not provide enough results for prompts involving overlapping objects (especially human-animal interactions) or edge cases with extreme relative sizes and complex occlusions.
- **Dependence on base model capabilities:** MuLan’s performance is heavily reliant on the underlying diffusion model (Stable Diffusion). The experiments use relatively weak base models (SD1.4, SDXL), and it is unclear if the method scales to more advanced models like SD3 or FLUX. Moreover, the method may already be outperformed by these newer models, making the multi-step pipeline redundant.
- **Limited spatial control from rough masks:** The rough masks are restricted to only four relative positions (left, right, top, bottom). This severely limits the ability to represent nuanced spatial relationships such as partial occlusion, diagonal placement, or complex layouts, compared to methods that support continuous spatial variations.
- **Unclear feedback adjustment mechanism:** Section 3.4 lacks a detailed description of how the VLM’s feedback is quantified and translated into specific adjustments of the backward guidance. It is unclear which parameters (e.g., learning rate, gradient scale, noise schedule) are modified and how these modifications are determined based on the assessment of object size, position, and attributes. This lack of algorithmic detail impairs reproducibility.
- **Generated image quality issues:** Despite following instructions, generated images sometimes exhibit unrealistic proportions (e.g., refrigerator, chair, and table the same size; pumpkin and door similarly sized). One review noted that the outputs are not as visually appealing as those produced by base models alone.
