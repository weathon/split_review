## Merged Review

### Summary
This paper proposes a pluggable Machine Unlearning Framework for partial-set Source-Free Unsupervised Domain Adaptation (SFUDA). It generates noise samples for source-private classes and pseudo-labeled target samples, then forgets source-specific categories in a forgetting stage and adapts via self-supervised learning on target data. Experiments are conducted on Office-Home and Office-31 datasets. Reviewers disagree: two rate 3 (weak/poor) and two rate 5 (good), reflecting contrasting views on novelty, experimental fairness, and thoroughness.

### Strengths
- The idea of using machine unlearning to eliminate negative transfer from source-only categories is new and provides a different perspective from classical weighting methods in adversarial learning (R1, R3, R2).
- The method is shown effective on Office-Home and Office-31 datasets when plugged into several SFUDA baselines (R2, R4).
- Ablation studies are sufficient to demonstrate the contribution of each component (R3).
- The paper is well-written and easy to follow (R4).
- The framework is simple and adaptable to various pre-trained models (R1, R4).

### Weaknesses
- **Unfair experimental setup and assumptions:** The method assumes the target label set \(C_t\) is fully known (e.g., by using source model predictions to identify source-only classes \(C_f\)). Reviewers question how this can be done accurately without target labels, given strong source bias and no guarantee that selected categories are exclusively from the source (R1, R3). This setup is particularly questionable given recent vision-language model (e.g., CLIP) alternatives and seems tailored to the method (R2).
- **Insufficient benchmarks and comparisons:** Experiments are limited to Office-Home and Office-31. Missing large-scale datasets like DomainNet, VisDA-2017, and ImageNet that are standard in prior work (R1, R2, R3, R4). The comparison baselines are out-of-date; more recent (2023–2024) partial-set SFUDA approaches and classic PDA methods should be included, as well as universal setup SFDA baselines (R2, R4).
- **Incomplete experimental tasks:** In Tables 1–3, only partial domain combinations are tested. Missing tasks such as A→D, A→W, W→D for SSDA and →D, →W for MSDA are needed to fully evaluate performance across diverse domain shifts (R4).
- **Limited generality and task scope:** As a hot-swappable module, it should apply to tasks beyond image classification (e.g., semantic segmentation, object detection), but only a few image classification models are tested (R2).
- **Theoretical and algorithmic justification insufficient:** The theoretical analysis focuses on domain adaptation, not on why noise samples cause unlearning of the original class. A theoretical grounding of the unlearning mechanism is missing and would be more impactful (R2). Also, Algorithm 1 lacks details on how noise samples are generated, what criteria ensure they are distinct from source data, and the specific loss functions used in each stage (R4).
- **Efficiency concerns:** The method relies on top-K pseudo-labeling and multiple inference steps for unlearning, reducing computational efficiency despite the claim that it does not require high-performance hardware (R1, R2).
- **Potential overfitting due to biased pseudo-labeling:** The identification of \(C_f\) depends on predictions from the source-pretrained model, which carries strong source bias; the resulting target samples may be unreliable (R1, R3).
- **Contribution limited by straightforward combination:** The approach appears to be a direct combination of two existing research directions (machine unlearning and SFUDA) with a potentially biased setup, limiting the novelty (R2).
- **Minor issues:** Notation and formatting inconsistencies need correction (R2). The frame diagram (Fig. 2) is not intuitive; subgraphs should be labeled and symbols like N(0,1) explained (R3). Algorithm 1 and figure font size need improvement (R4). Typo in line 189: \(x_s^i \to x_t^i\) (R4). Additional visualizations (t-SNE, CAM, confusion matrix) would strengthen the analysis (R4).
- **Open questions:** Why is a special module needed for negative transfer if standard SFUDA with sufficient class spacing can already achieve partial adaptation? (R3). How is \(C_f\) accurately selected without target labels? (R3). The paper should compare with classic/latest PDA methods, not only SFUDA (R3).
