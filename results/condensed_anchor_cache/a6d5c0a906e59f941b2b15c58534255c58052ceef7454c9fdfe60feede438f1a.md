## Merged Review

### Summary
DistillHGNN is a knowledge distillation framework to accelerate hypergraph neural networks (HGNNs) while preserving accuracy. It uses a teacher model (HGNN + MLP) that produces soft labels and transfers structural/high-order information to a lightweight student model (TinyGCN + MLP). Contrastive learning helps the student retain high-order relationships. The method achieves inference time reductions comparable to traditional HGNNs with significantly lower resource requirements. Each reviewer noted the innovative dual distillation and thorough experimental evaluation, but concerns about memory evidence, information loss from hypergraph-to-graph conversion, inductive learning limitations, scalability, baseline selection, and presentation clarity were raised. Reviewer scores were 8, 6, 5, indicating a range of assessments.

### Strengths
- **Innovative dual distillation**: Combines soft-label knowledge distillation with structural knowledge transfer via contrastive learning, addressing limitations of prior single-mode methods (Reviewers 1, 2, 3).  
- **Substantial speedup**: Achieves up to 80% reduction in inference time while maintaining accuracy comparable to traditional HGNNs (Reviewers 1, 3).  
- **Thorough experimental evaluation**: Tested on multiple real-world datasets (CC-Citeseer, CC-Cora, IMDB-AW, DBLP) with a clear setup covering accuracy, inference time, and comparisons to baselines including LightHGNN (Reviewers 1, 2).  
- **Well-structured and clearly written**: Methodology, architecture, and loss functions are explained in detail, facilitating understanding and reproducibility (Reviewers 1, 2).  

### Weaknesses
Reviewer confidence and assessments varied: while one reviewer (score 8) reported only minor issues, others (scores 6 and 5) raised more significant concerns.

- **Unsubstantiated memory efficiency claims**: No quantitative memory comparison is provided against other distillation methods (LightHGNN, GLNN, KRD) that also use lightweight MLPs. The claim relies on an architectural argument rather than empirical validation (Reviewer 1).  
- **Missing baselines**: Comparison with GNN- and GCN-based distillation approaches is absent. The set of hypergraph baselines omits recent HGNN models that use different aggregation or attention mechanisms (Reviewers 1, 2).  
- **Loss of high-order information**: Converting a hypergraph to a homogeneous graph via \(A = \mathcal{H}W\mathcal{H}^T - D_v\) flattens higher-order interactions into pairwise relationships. The paper does not sufficiently address how this information loss is mitigated. *Question*: Can mechanisms like LightHGNN’s high-order soft-target constraints be incorporated, and can visualizations show how high-order knowledge is preserved? (Reviewer 2)  
- **Inductive learning limitation**: The method relies on homogeneous graphs during inference. For new samples, graph reconstruction and preprocessing (e.g., recomputing the adjacency matrix) are costly, making the model impractical for dynamic or real-time environments. *Question*: What strategies reduce this reconstruction overhead for inductive scenarios? (Reviewer 2)  
- **Small-scale evaluation only**: All datasets have 3k–6k nodes (CC-Citeseer, CC-Cora, IMDB-AW, DBLP), similar to Cora. No larger or synthetic datasets (e.g., ogbn-arxiv, ogbn-products with hypergraph structures) are tested, leaving scalability and generalizability unclear (Reviewers 2, 3).  
- **Writing and presentation issues**:  
  - Figure 1 caption is overly long; it should be condensed and details moved to the main text (Reviewers 1, 3).  
  - Line 152 references “Framework 1” instead of “Figure 1” (Reviewer 1).  
  - Figure 2 plots accuracy vs. inference time, which can be misinterpreted as implying dependency; separating the metrics is recommended (Reviewer 1).  
  - Algorithm 1 (line 669) updates the teacher model via backpropagation, which is atypical for knowledge distillation (teacher is usually fixed); justification is missing (Reviewer 1).  
  - Figure 6 should use the same accuracy axis range across subplots for easier visual comparison (Reviewer 1).  
  - Dataset characteristics (e.g., density, sparsity, inductive properties) are not described, making it hard to assess generalization (Reviewer 3).  
  - Citation style could be improved (e.g., using `\citet{}` for author references) (Reviewer 3).
