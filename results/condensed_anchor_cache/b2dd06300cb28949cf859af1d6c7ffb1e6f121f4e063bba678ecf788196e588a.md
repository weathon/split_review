## Merged Review

### Summary
The paper proposes NormWear, a foundation model for multivariate wearable physiological signals (PPG, ECG, EEG, GSR, IMU). The model uses continuous wavelet transform (CWT) tokenization, channel-aware attention, and a memory-stream inspired fusion mechanism. It is pre-trained on ~37,500 samples from public datasets and evaluated on 11 downstream datasets (18 tasks) covering mental health, body state, biomarker estimation, and disease risk. The model is also extended to zero-shot inference via representation alignment with text embeddings. Interpretability analyses include feature visualization, t-SNE, and nonlinear dynamics across layers. The paper shares code and references to public data.

### Strengths
- **Originality and problem importance.** The paper tackles the under-explored area of foundation models for multivariate wearable physiological signals, an original contribution according to multiple reviewers.
- **Thoughtful design components.** CWT-based tokenization is well-motivated, channel-aware attention and the fusion approach are ablated and address modality inconsistency. The zero-shot capability via text alignment is novel.
- **Broad downstream evaluation.** Evaluation spans 11 public datasets and 18 applications (mental health, body state, biomarker estimation, disease risk), providing holistic assessment.
- **Competitive performance against selected baselines.** NormWear outperforms Chronos (language-based time-series model) and a ViT baseline across many tasks.
- **Interpretability efforts.** The paper provides feature visualizations, t-SNE embeddings, and nonlinear dynamics analysis, aiming to improve trust.
- **Openness.** Authors use public datasets and share code.

### Weaknesses
- **Pre-training data scale and generalizability concerns.** Pre-training uses ~37,500 samples (62 hours, <1100 subjects), which is small for a "foundation model". Some modalities have very few subjects (e.g., EEG from only 45 subjects). Downstream test sets are also small (e.g., Driver Fatigue Detection: 12 subjects total, ~2–3 in test set). This raises risks of overfitting and domain shift; the "foundation model" claim is weaker given the limited data. The authors should discuss limitations and consider subject-stratified cross-validation for small-N tasks.
- **Insufficient and often weak baselines; fundamental performance issues.** Chronos is a forecasting model not designed for these downstream tasks, and the ViT setup for zero-shot is unclear. Missing comparisons with simple baselines (mean predictor, linear/logistic regression with demographics) and self-supervised approaches (BYOL, TF-C, SimCLR). Spot-checking by one reviewer on 7 of 12 tasks showed that simple methods equal or outperform NormWear:
  - Hemoglobin Estimation: constant predictor accuracy 88.68% > best NormWear.
  - Fetal Heart Rate: constant predictor 96.31% > best NormWear (even a single fixed value 140 bpm gave 96.38%).
  - Blood Pressure: bivariate linear regression (Age, BMI) 91.49% equivalent to best NormWear.
  - Hypertension Risk: logistic regression (Age, BMI, sex) ROC AUC 0.720 > best NormWear.
  - Diabetes Risk: logistic regression ROC AUC 0.672 > most NormWear variants.
  - Brain Stroke Risk: logistic regression 0.792 > best NormWear.
  - Brain Disease Risk: logistic regression 0.779 > best NormWear.
  Zero-shot performance (Table 2) is near random for many tasks (e.g., Heartbeat Abnormal Detection ROC AUC < 0.5; multiple tasks < 0.60; hemoglobin and fetal heart rate zero-shot worse than constant guess). This suggests the model may not learn meaningful representations for zero-shot inference.
- **Many missing or unclear technical details.**
  - Semantic alignment for zero-shot (Section 3.2) is not explained: how text embeddings are obtained, which datasets/language model, and how the training proceeds.
  - Memory Stream Inspired Mechanism (Section 2.4) is unclear: how MSiTF optimizes for human sensing, computation of recency/importancy scores, how the gate is determined, and how scores contribute (text mentions summation but Fig. 3 shows independent paths). Eq. 1 uses both L1 and cosine loss without justification.
  - Architectural hyperparameters are omitted: patch selection (number of patches per segment), token dimension, number of attention heads, positional encoding, MLP hidden dimension, normalization.
  - Downstream evaluation (linear probing) details are lacking.
  - Data preprocessing (bandpass filtering, de-trending, Gaussian smoothing parameters) is insufficiently described; the impact of resampling ECG to 65Hz (losing meaningful information) is not discussed.
  - Dataset references and task details should be inline in all tables (Table 2 and Appendix A tables), and task type (classification vs. regression) and input signals per task should be listed.
- **Writing, presentation, and clarity issues.**
  - Unbacked claims throughout (e.g., "completely ignores frequency domain", "channel-independent structures fail to capture cross-channel relationships", visualization pipeline assisting clinicians without evidence).
  - Figures are hard to follow; elements in Fig. 3 (mean/std, likelihood parameters) are not explained in main text.
  - No dedicated related work section.
  - Formatting errors (missing spaces, table captions not above tables).
  - Y-axis labels missing numeric values and units (Appendix F reconstructions).
  - Some references incomplete (missing DOI/URL for Liang 2018, Bousseljot 1995, Jianliang Min 2017).
- **Interpretability analysis insufficiently validated.**
  - t-SNE plot (Fig. 4a) shows clustering by signal type, which may be achievable with simple handcrafted metrics; no quantitative comparison provided.
  - Feature associations and time step relevance (Fig. 4b) are not linked to known physiological features or predictions; no evidence they are meaningful for the target task.
  - Nonlinear dynamics analysis lacks interpretation connecting to physiological understanding.
