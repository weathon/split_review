## Merged Review

### Summary
This paper studies coresets for a new clustering problem: $k$-means of line segments. The distance from a point $x$ to a segment $S$ is defined as $D(S, x) = \int_{s \in S} \|p-x\|\,ds$ (integral over the segment). The goal is to find $k$ centers minimizing $\sum_{S} \min_{x \in X} D(S, x)$. The main contribution is a coreset construction that first discretizes each segment using $\varepsilon'$-equally spaced points, then applies the coreset algorithm of Feldman & Schulman (2012) to the resulting weighted point set. For constant $k$ and $\varepsilon$, the coreset size is $O(\log^2 n)$ (with a factor $\mathrm{poly}(k)$ that is exponential in $k$). The approach is extended to convex shapes. Experiments on synthetic and real data compare the method to baselines including a previous coreset for lines.

### Strengths
- Introduces a new clustering problem for segments (all reviewers), extending the notion of coresets to this setting (Reviewer 2).
- Provides an algorithm with theoretical guarantees and empirical evaluation (Reviewers 1, 4).
- The framework is general and not restricted to segments; it applies to multi-dimensional convex shapes (Reviewer 3).
- While some reviewers (Reviewer 3, score 5) find the problem well-motivated and fundamentally different from existing work, others strongly disagree (see Weaknesses).

### Weaknesses
- **Motivation and problem formulation**:  
  The motivation is unclear across all reviews. The paper lacks discussion of real-world applications or scenarios where this specific problem (integral-of-distance along a segment) is relevant. It is not explained why this distance measure is more appropriate than alternatives (e.g., Hausdorff distance, average of endpoints). The distinction from existing notions of $k$-segmentation (Jubran et al., 2021; Rosman et al., 2014) is not clarified. The introduction is too brief for non-experts, and the experimental section does not connect the problem to the conducted experiments (Reviewers 1, 2, 3, 4).

- **Technical novelty and contribution**:  
  The main technical step is a black-box application of Feldman & Schulman (2012), which limits the contribution. The core idea (uniform discretization of each segment followed by a known coreset construction) is straightforward and not surprising. The novelty claimed for using equally spaced points is not justified. Overall, the technique is incremental (Reviewers 1, 2, 3, 4).

- **Theoretical limitations**:  
  Both the coreset size and running time have an exponential dependence on $k$ (factor $k^k$), making them practical only for very small $k$. The claimed size $O(\log^2 n)$ does **not** improve over the previous bound $O(\log n / \varepsilon^2)$ by Har-Peled (Reviewers 1, 3, 4).  
  Several theoretical details are lacking or ambiguous:
  - The definition of $D$ does not include a square for “$k$-means” (Reviewer 3).
  - The order of arguments in $D((C,w’),p)$ vs. $D(p,(C,w))$ is inconsistent (Reviewer 3).
  - How to set $d^*$ (the VC-dimension) in Algorithm 2 is not explained (Reviewer 3).
  - Skipping Algorithm 2 and using only Algorithm 1 + a standard $k$-means algorithm is claimed to work, but this is incorrect because the objective is not point $k$-means (Reviewer 3).
  - Definition 2.7 does not state that $S$ is a subset of $\mathbb{R}^d$ (Reviewer 3).

- **Experiments and comparisons**:  
  - The comparison with Feldman’s algorithm is inappropriate because that algorithm was designed for a different problem (Reviewer 1).  
  - Figure 3 middle row plot is unclear; what do the vertical and horizontal segments represent? The baseline “Approx” is not introduced anywhere in the paper (Reviewer 3).  
  - The evaluation of “OPT” is misleading—it is computed via the coreset rather than a direct brute-force (Reviewer 3).  
  - The experiments do not demonstrate why this problem formulation is relevant for the chosen datasets (Reviewer 2).

- **Writing and presentation errors**:  
  - Figure references are swapped: “right figure” is actually left, etc. (Reviewer 4, lines 58–64 and 287–294).  
  - Proof of Lemma B.2 uses notations only defined later in Theorem B.3, making it hard to follow (Reviewer 4).  
  - Inequality (43) is incorrect because the left-hand side is non-positive (Reviewer 4).  
  - Several expression corrections are needed (e.g., line 1047, line 1060–1063, line 1163) (Reviewer 4).  
  - Minor issues: Title should be “$k$-means” not “$k$-mean” (Reviewer 3). Line 40: “union” should be “set/collection” (Reviewer 3). Line 69: coreset is a weighted subset of input points, but input is segments (Reviewer 3). Algorithm 1 line 1: $r$ is not defined in that context (Reviewer 3). Algorithm 2 line 3: comment references Definition 2.3 incorrectly (Reviewer 3).
