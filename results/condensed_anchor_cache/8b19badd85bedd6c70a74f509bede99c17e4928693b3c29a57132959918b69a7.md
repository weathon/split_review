## Merged Review

### Summary
The paper proposes FineR, a training-free method that leverages large language models (LLMs) for fine-grained visual recognition (FGVR) by converting part-level visual attributes from images into text and feeding them to an LLM for subordinate-level category reasoning. It aims to circumvent the need for expert annotations. The method shows promising performance on multiple FGVR datasets and introduces a new Pokemon dataset. Reviewers agree the paper is well-written and easy to follow, but they raise concerns about novelty, missing comparisons, insufficient verification, and dataset limitations.

### Strengths
- The utilization of LLMs for vocabulary-free FGVR is novel and provides a new way to do training-free FGVC. (Reviewers 1, 3)
- The paper is generally well-written, clear, and easy to follow. (All reviewers)
- Good performance is demonstrated in Table 1, outperforming several state-of-the-art FGVR and LMM models. (Reviewers 1, 3)
- The method effectively uses LLMs to alleviate the need for high-quality paired expert annotations. (Reviewers 1, 2)
- A novel Pokemon dataset is introduced to benefit FGVC research. (Reviewer 3)

### Weaknesses
- **Novelty is debatable.** The approach seems an intuitive combination of existing large-scale models (VQA, LLM, VLM). Using LLMs without any training raises questions about the contribution. Extracting visual attributes from images for recognition is widely used in generalized zero-shot learning. A similar idea (LLM-generated concepts for visual recognition) already appears in recent work (ICCV 2023). (Reviewers 1, 2, 3)  
- **Missing comparisons and experiments.** The paper does not compare against important baselines:
  - Transhp (image classification with hierarchical prompting) for fine-grained classification; could prompting alone be better?
  - V2L (vision+language for product retrieval, champion of FGVC 9).
  - Generalized zero-shot learning methods that also use visual attributes (e.g., [a]).
  - Prompt-learning approaches on VLMs (e.g., CoOp, CoCoOp) that achieve >90% accuracy for zero-shot FGVC.  
  The accuracy on CUB is relatively low, so further verification and corresponding analyses are needed. (Reviewers 1, 2, 3)  
- **Lacks complete recognition example.** A full step-by-step example explaining the whole procedure is missing; more examples from Fig. 2 and failure cases would help understanding. (Reviewers 1, 2)  
- **Pokemon dataset issues.** The dataset description lacks crucial details (exact number of samples, train/test split). Since Pokemon is not a real-world FGVC category, it is questionable whether LLMs (trained on real-world data) can discriminate fine-grained Pokemon patterns, limiting the dataset’s contribution to the FGVC community. (Reviewer 3)  
- A reviewer (score 6) notes that relying solely on LLM concepts for FGVC (instead of jointly using visual representations) is a questionable design direction, especially given the strong results from VLM prompting. (Reviewer 3)
