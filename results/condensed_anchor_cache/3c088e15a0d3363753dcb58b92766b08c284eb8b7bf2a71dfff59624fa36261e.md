## Merged Review

### Summary
The paper proposes RGMG, a reinforcement-learning-based KG reasoning method that incorporates a multi-relational graph attention network (MGAT) for entity/relation embeddings and a query-aware action embedding enhancement (QAE) module. Experiments on WN18RR, FB15K-237, and NELL-995 show competitive performance against existing RL-based methods (e.g., MINERVA, M-Walk, CURL). The approach is direct and easy to understand.

### Strengths
- Incorporation of a multi-relational GNN into RL-based KG reasoning is a reasonable direction and the overall structure is straightforward (Reviewers 1, 2, 3).
- The proposed RGMG outperforms existing RL-based methods on the three benchmarks, showing promising results (Reviewers 3, 4).
- The ablation study, relation-wise performance, and visualization of paths/embeddings provide useful analysis (Reviewer 3).
- The query-aware action embedding (QAE) module is an interesting idea (Reviewer 4).

### Weaknesses
- **Limited novelty:** The framework largely combines existing components (multi-relational GNN + RL agent) without fundamental innovation. The RL module itself remains unchanged; only input embeddings are modified (Reviewers 2, 3, 4). The main contribution, QAE, is essentially incorporating relation embeddings into message-passing — a common technique (Reviewer 3). One reviewer (Reviewer 2) felt the novelty is very poor, deeming it an implementation of previous methods.
- **Motivation not fully supported:** The paper argues RL is needed for multi-hop reasoning, yet no experiment explicitly tests multi-hop connections. The key motivation is not empirically validated (Reviewer 1).
- **Outdated and insufficient baselines:**
  - Only five baselines compared: DistMult (2015), ComplEx (2017), MINERVA (2017), M-Walk (2018), CURL (2022) (Reviewers 1, 3, 4).
  - Missing KG embedding methods like HAKE and PairRE (Reviewer 1).
  - Missing GNN-based methods like CompGCN, which should be a direct baseline given the GNN component (Reviewer 1).
  - Missing recent path-based and GNN-based methods like NBFNet and A*Net, which achieve much higher performance and support inductive reasoning and interpretable paths (Reviewer 3).
  - The paper claims state-of-the-art status in §4.4, but does not compare against current SOTA methods (Reviewer 1).
- **Resource cost not evaluated:** The paper criticizes CURL for increasing inference cost due to an extra agent, but no computational time or resources comparison is provided for RGMG, which also adds complexity via GNN modules. This omission weakens the claimed advantage (Reviewers 1, 2). One reviewer (Reviewer 4) noted RGMG consumes more resources than non-RL methods yet still underperforms them.
- **Scope limitation:** RL-based KG reasoning is out-of-date; current trends favor path-based and GNN methods, which outperform RGMG (Reviewer 3).
- **Presentation quality is poor with many errors:**
  - Typos: “out dual agents” should be one agent; “$e_a$” should be “$e_{a_l}$”; confusing references to “line 5” and “lines 6-9” (should be equations); “$z′rt−1$ and $x′vt−1$” format unclear (Reviewers 1, 3).
  - Figure 3 caption identical to Figure 2 (Reviewers 1, 3, 4).
  - Figure 2 shows 1000 iterations while text says first 3000; validation tuple counts (3034, 543, 17535) unclear (Reviewer 3).
  - Tables (e.g., Table 1, Table 3) need formatting; figures have low DPI (Reviewer 4).
  - Overall, paper not yet ready for publication (Reviewers 1, 3, 4).
- **Unexplained observations:** In Figure 2, the QAE helps noticeably only on FB15K-237; no explanation is provided (Reviewer 4).

**Questions that overlap with criticisms / missing comparisons:**
- What is the key advantage of RGMG over CURL given both add computational overhead? (Reviewer 1)
- Does MGAT with attention outperform the simpler CompGCN? (Reviewer 1)
- Can the method be compared with recent path-based and GNN-based methods like NBFNet and A*Net? (Reviewers 3, 1)
