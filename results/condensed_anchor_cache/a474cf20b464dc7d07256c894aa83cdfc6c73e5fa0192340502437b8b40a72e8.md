## Merged Review

### Summary
The paper proposes Self-TPT, an efficient test-time prompt tuning framework for vision-language models. It introduces Contrastive Prompt Learning (CPT) as a text-only self-supervised task to refine class embeddings, and a gradient matching (GM) loss to align CPT gradients with the classification task. CPT is applied both during source prompt learning and at test time for new class adaptation, avoiding per-image optimization. Evaluation on base-to-new, cross-dataset, and domain generalization benchmarks claims state-of-the-art performance with reduced inference cost. Reviewers are divided: three rate 5–6 (majority positive, with concerns about novelty and justification), while one reviewer rates 3, citing a fundamental flaw in handling domain shifts and problematic ablation design.

### Strengths
- Novel idea of varying the class token insertion points (front, middle, end) within prompt sequences as text augmentation for contrastive learning, creating positive pairs. (R1)
- CPT during supervised prompt learning complements the supervised objective. (R3)
- CPT is text-only and can be applied to target class names without accessing test images, avoiding per-sample optimization and reducing computational costs. (R1, R2, R3)
- The observation that CPT partially mimics the supervised learning gradient motivates the gradient matching loss to further enhance performance. (R1, R3)
- Comprehensive experiments across three challenging zero-shot benchmarks (base-to-new, cross-dataset, domain generalization) demonstrate effectiveness. (R1, R2, R3)
- The method is simple, straightforward to implement, and well-written/easy to follow. (R4)
- The motivation to reduce test-time overhead (avoiding multiple forward/backward passes) is meaningful and practical. (R4)

### Weaknesses
- **Justification of class token position augmentation**: The choice of placing the class token at the front, middle, and end (rather than randomly) is arbitrary. No convincing argument is given why these specific positions encourage more robust feature representations compared to other augmentation strategies. (R1)
- **Gradient matching loss not well justified**: It is hard to see a strong relation between contrastive loss (more robust, possibly better generalization) and CE loss (discriminative). The GM loss may force alignment between two objectives that are not inherently aligned, potentially hindering optimization. Table 5c shows very little improvement and even performance loss in some settings; more evidence or theoretical analysis is needed. (R1, R2)
- **Loss weight distribution**: The paper does not specify how weights among L_ce, L_CPT, and L_GM are distributed in Stage 1. Additional experimental results on weight sensitivity are needed. (R1)
- **Insufficient comparison with recent methods**: The paper should compare with more recent 2024 prompt learning approaches (e.g., Any-shift prompting, PromptKD), not just test-time tuning baselines. (R1, R3)
- **Novelty limited**: Leveraging multiple prompts has been shown effective in prior work (KgCoop, PromptAlign). The method also requires three additional prompts (for CPT), increasing prompt count. The gradient matching loss provides negligible gains. (R2)
- **Fundamental flaw in handling domain shifts**: The CPT framework operates solely on the text branch, so it cannot adapt to domain shifts in images (e.g., source real photos → target sketches with same labels). This raises doubts about results in Table 4; improvements may instead stem from prompt ensembling rather than domain adaptation. (R4 – minority, rating 3)
- **Ablation studies are problematic**: It is well established that learning multiple soft prompts and ensembling them can improve accuracy (e.g., >1% gain in prior work). The ablation study does not include comparable baselines that use similar ensembling techniques. For domain generalization (same class names), theoretically the method should offer no benefit, yet improvements are reported – an inconsistency. The suggested proper ablation: learn 4 soft prompts independently with cross-entropy and ensemble them. The experiment in Table 5(a) is not the referred one. (R4)
- **Use of test images**: Since CPT does not use test images, it could be treated as an additional loss for supervised prompt learning. Can CPT be combined with per-sample TPT? Is self-TPT-v just an output ensemble? (R3)
- **Applicability and clarification questions**: Can CPT be applied with existing methods (e.g., CoOp+Self-TPT)? (R2) In Table 5c, what is the setting for the first line? The numbers differ from line 3 of Table 5a – please clarify. (R2) There is a writing error in Table 5: “w/o hand” should likely be “w/o end”. (R1)
