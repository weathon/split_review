## Merged Review

### Summary
The paper proposes an unsupervised text-to-speech (TTS) method using an unconditional score-based generative model (SGM) guided by a set of end-to-end ASR models via classifier guidance, and similarly uses a speaker verification model for speaker control. The key finding is that using multiple ASR guidance models drastically improves pronunciation accuracy compared to a single model, which tends to generate poor-sounding speech that fools the ASR. The CTC-based guidance eliminates the need for a phoneme duration predictor. Reviewer scores were 5, 3, 3, 3. One reviewer (score 5) found the method simple and sound; the other three (score 3) raised significant concerns about novelty, motivation, missing comparisons, and limited contribution.

### Strengths
- The proposed method is simple and sound (R1).
- Using an ensemble of multiple ASR models for guidance significantly improves performance, preventing poor guidance that occurs with a single model (R1, R2, R3).
- The work extends classifier guidance to also control speaker identity via a speaker verification model (R2).
- It eliminates the need for phoneme-level alignment by training a CTC-based text classifier (R3).
- The research direction is interesting and the use of classifier guidance in diffusion-based TTS is underexplored (R4).

### Weaknesses
- **Motivation and novelty**: The motivation is unclear—the method is not truly unsupervised because a supervised ASR model (trained on 80 hours of labeled data) is required for inference. For a semi-supervised setup, the benefit over pre-training–fine-tuning approaches (e.g., Generative Pre-training for Speech with Flow Matching) is not explained (R2). The novelty is limited: Guided-TTS already uses a phoneme predictor as classifier guidance; the only differences are using an E2E-ASR and an ensemble of ASR models, which appears to be the main new insight (R2). Another reviewer considers the contribution more suitable for a short paper (R4).
- **Missing key comparisons**: 
  - No comparison to classifier-free guidance trained on the same LibriTTS data, using the same ASR system to transcribe speech content as input (R4).
  - No comparison to prior semi-supervised or unsupervised TTS baselines (Guided-TTS, SpeechFlow, Simple and Effective Unsupervised Speech Synthesis) (R2).
  - For pronunciation accuracy, the proposed method shows a large gap relative to ground truth; it should be compared to norm-based guidance used in similar research like Guided-TTS (R3).
  - To demonstrate the benefit of speaker verification guidance, a comparison with a speaker-conditioned diffusion model using explicit labeling (e.g., speaker IDs or embeddings) is needed (R3).
  - Text guidance should be compared to conventional TTS structures (R3).
- **Duration prediction not fully addressed**: The paper uses ground-truth duration; it is not a complete TTS model. Section 6.4 only provides a preliminary inspection on duration prediction’s impact via WER, without MOS evaluation (R1).
- **Ablation and analysis gaps**:
  - It is unclear whether using more ASR models improves performance because the ensemble avoids adversarial samples (high likelihood but low quality) or simply because the effective guidance weight increases. The authors should present ablation results scanning different guidance weights with a single model or fewer models (R2).
  - The impact of the number of ASR guidance does not saturate at 12; why not further increase the number in experiments? (R1)
  - It is unclear whether the observed improvement is due to the number of guidance models or the performance of the individual ASR models (which are small, trained on only 80 hours). A comparison with a more sophisticated off-the-shelf ASR model (e.g., Whisper) is requested (R1).
  - The perturbation used for the ASR model (line 182) is not specified; the authors should report how much performance degrades if the ASR model is not trained on perturbed Xt (R2).
- **Computational cost**: Using multiple ASR models inevitably increases computational costs—calculating gradients in parallel consumes memory, while sequential calculations slow inference speed (R3).
- **Presentation and statistical rigor**:
  - No confidence intervals are provided for MOS measurements; these are essential (R3).
  - Table 1 presentation should show the number of ASR guidance rather than listing all model IDs (same for Table 2) (R1).
- **Disagreement**: One reviewer (score 5) found the method simple and sound, while the three other reviewers (score 3) judged the contribution too limited and the experiments insufficient to support the claims.
