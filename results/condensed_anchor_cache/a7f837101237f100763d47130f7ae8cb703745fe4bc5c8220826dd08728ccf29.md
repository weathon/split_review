## Merged Review

### Summary
This paper proposes D2NWG, a diffusion-based neural network weight generation method conditioned on target datasets. It uses a latent diffusion process to model and sample weight distributions from pretrained models, enabling generation of task-specific weights for transfer learning. Evaluations span few-shot/zero-shot learning, model retrieval, classifier head adaptation, LoRA weight generation, and LLM weight adaptation across vision and language tasks. The method outperforms several meta-learning and pre-trained baselines.

### Strengths
- **Novel approach**: Combining latent diffusion models with neural network weight generation is a new direction (only two other unpublished works known, Wang et al. 2024, Jin et al. 2024). The idea is conceptually simpler than bi-level meta-learning optimization.
- **Comprehensive experiments**: Extensive evaluation across diverse settings: few-shot learning, zero-shot learning, model retrieval, classifier head adaptation, LoRA weight generation, domain transfer, conditioned weight generation, and adapting LLM weights (Reviewers 1,3,5). Covers multiple datasets and tasks in both vision and language.
- **Robust performance**: Strong empirical evidence showing D2NWG outperforms state-of-the-art meta-learning methods and pretrained models across seen and unseen datasets (Reviewers 2,5). The method exhibits robust performance in-distribution and on unseen datasets (Reviewer 5).
- **Multiple encoding/vectorization methods**: The paper considers multiple ways to vectorize model weights (model-wise, layer-wise) and encode datasets (Set Transformer for images, LLM embeddings for language, contrastive encoding) (Reviewer 3).
- **Dataset conditioning**: Conditioning on target dataset encoding increases generality to new unseen datasets compared to prior approaches that rely on pretrained model diversity (Reviewer 1).

### Weaknesses
- **Missing ablations and baselines**: No ablations testing the effectiveness of individual components (dataset encoding, layer-vectorization, spectrum ranking) (Reviewer 1). Crucial baselines missing – e.g., a simple parameter prediction diffusion model (e.g., Peebles et al. 2022) without dataset encoding to measure generalization improvement from dataset encoding, a core claimed contribution (Reviewer 1).
- **Generalization concerns for dataset encoding**: The method may only generalize to new datasets in-distribution for the dataset encoder. If the encoder is trained on ImageNet-like natural images, it may not transfer to medical images. Table 17 shows poorer accuracies for unseen datasets (Reviewer 1). The effectiveness heavily depends on dataset encoding mechanisms (Set Transformer, CLIP) – this reliance may limit adaptability to unique datasets; no systematic analysis of how different encoding strategies affect generated weight quality (Reviewer 5).
- **Inequality in encoding strength between modalities**: Image dataset encoding uses Set Transformer over samples, while language encoding simply uses LLM embeddings of task descriptions, which appears weaker (Reviewer 1). It is not explored whether image datasets could also be encoded via task descriptions using LLM/VLM (Reviewer 1).
- **Uncertainty about scaling and practical significance**:
  - Training an effective diffusion model requires substantial computational resources; practical significance is questionable (Reviewer 2).
  - Maintaining extensive collections of pretrained weights across many datasets incurs large storage and computational overhead, possibly exceeding traditional pretraining (Reviewer 5). No clear breakdown of training time, resource consumption, or comparison to existing methods (Reviewers 2,5).
  - The VAE for parameter encoding adds significant computational workload and hyperparameter tuning – alternative encoding methods (e.g., simpler dimensionality reduction, more efficient autoencoder architecture) are not explored (Reviewer 3).
- **Limitations in generated parameters**: Tables 1 and 2 tag D2NWG with 'CH', indicating only the last classifier layer is generated (like linear probing), casting doubt on whether full parameter generation with robust performance is achievable (Reviewer 2). The paper acknowledges limitations of existing methods to small models/subset of parameters, but generates only classifier heads and LoRA (small parameter subsets) (Reviewer 4). Claim of "generating weights for architectures with over 200 million parameters" is not supported by experiments (Reviewer 4).
- **Zero-shot adaptation concerns**: The concept of "zero-shot adaptation" is questionable because weights are conditioned on the target dataset (possibly the test set), which can be considered test data leakage, limiting practical utility (Reviewer 2). Also, generated weights still require fine-tuning for unseen tasks (Section 4.3), contradicting claims of eliminating fine-tuning – for seen tasks, not fine-tuning is expected; for unseen tasks, fine-tuning is still needed (Reviewers 2,4).
- **Lack of theoretical foundation**: No comprehensive theoretical framework explaining why diffusion-based weight generation enhances transfer learning or generalization. The curse of dimensionality in high-dimensional parameter spaces is not addressed, and the claim about existence of a latent vector approximating target weights needs rigorous justification given non-convex loss landscapes (Reviewer 5).
- **Poor presentation and organization**: Experimental sections are poorly organized – like subsections written separately and directly combined (Reviewer 4). Frequent setting changes starting Section 4.1.3 make experiments hard to follow; unclear training/test dataset splits, definition of "unseen", and how diffusion model is trained (Reviewer 4). The main paper does not explain how "unseen architecture" is used in Figure 1 (method generates for seen architecture then wraps with "careful concatenation" only described in Appendix) (Reviewer 4). Lack of decision framework for choosing dataset encoding methods (Section 3.3) – unclear when to use each method (Reviewer 3).
- **Ambiguities in approach and claims**:
  - When to use model-wise vs layer-wise vectorization is not specified (Reviewer 4).
  - Set-based dataset encoding lacks intuitive explanation (e.g., $x_p^{y_i}$) (Reviewer 4).
  - In dataset-conditioned training, why is the weight latent also used as a condition? In text-to-image diffusion only text conditions – if conditioned on weight latent, inference without initial weight latent is unclear (Reviewer 4).
  - Section 3.5 claims ranking LLM layers by importance, but experiments in Section 4.4 are about LoRA – relevant experiments should be in main paper (Reviewer 4).
  - Section 4.4 seems to be on seen tasks, not clearly stated (Reviewer 4).
- **Minor issues**: Multiple typos and formatting errors (e.g., double dot line 116, "ios" typo, "Parametrs", missing colons, formatting inconsistencies) (Reviewers 1,3,4). Writing suggestions: specify task descriptions for NLP encoding in Section 3.3, reorganize Section 3.3 for clarity (Reviewers 1,4).

**Reviewer disagreement**: While one reviewer (score 8) highlighted robust performance and strong empirical evidence, other reviewers (scores 5, 5, 6, 6) raised substantial concerns about practical significance, presentation quality, missing ablations, generalization to out-of-distribution datasets, and gaps between claims and contributions.
