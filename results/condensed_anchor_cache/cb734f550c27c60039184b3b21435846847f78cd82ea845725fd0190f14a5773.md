## Merged Review

### Summary
The paper proposes a VQA benchmark built from visual classification datasets, using semantic hierarchies to generate follow-up questions for fine-grained evaluation. It also compares NLP and LLM-based metrics, validated via human judgment, and evaluates several vision-language models on objects, actions, and attributes. One reviewer (score 5, confidence 3) was more critical, raising concerns about cropping and action evaluation, while two reviewers (scores 8, confidence 5) were very positive and found the approach original and useful, but noted missing dataset statistics.

### Strengths
- Proposes a new evaluation topic for VQA models: assessing fine-grained object, activity, and attribute classification (Reviewer 1).
- Intuitive solution for constructing a benchmark using class semantic hierarchy from classification datasets (Reviewer 1).
- Comprehensive evaluation of many open-source VQA systems (Reviewer 1).
- Innovative evaluation methodology: benchmark derived from well-known visual classification datasets enables granular comparison of text-generative and discriminative models (Reviewer 2).
- Addresses coarse answer challenges via automatically generated follow-up questions based on label hierarchy (Reviewer 2).
- Enhanced ambiguity management: adapts classification benchmarks for open-ended VQA with follow-up procedure using concept hierarchies to ensure desired detail (Reviewer 2).
- Rigorous examination of VQA and NLP metrics, grounded in human evaluation; Table 7 is especially useful for clarifying metric appropriateness for open-ended VQA scoring (Reviewers 2, 3).
- Original idea: using semantic hierarchy to ask follow-up questions is a neat way to deal with underspecification and multiple correct answers (Reviewer 3).
- Useful empirical evaluation of models on different aspects (attribute recognition, coarse vs. fine-grained recognition) (Reviewer 3).

### Weaknesses
- Cropping images to objects and using ImageNet (object-centric) limits the scope to natural use cases such as VQA v2 or VizWiz (Reviewer 1, score 5; moderate confidence). This criticism was not raised by Reviewers 2 and 3.
- Cropping activity images was risky: actions like “sit down” and “stand up” may require temporal frames (Reviewer 1).
- The paper omits certain statistical details about the oVQA dataset, including distribution of question/answer lengths, number of entity class labels, and question formats/types; this raises concern about possible imbalance (Reviewer 2, high confidence).
- Suggestion: Figure 2 would be easier to read if subbenchmarks were labelled “attribute”, “object” instead of OVAD, COCO (Reviewer 3; not a substantial weakness).
