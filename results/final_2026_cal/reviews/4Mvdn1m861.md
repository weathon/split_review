## Summary

This paper proposes TokenCount, a training-free object counting framework that repurposes the Segment Anything Model (SAM) for counting without architectural modifications or auxiliary models. The method has two components: (1) a probabilistic prompt generation stage that samples prompts from a multinomial distribution derived from SAM's image embedding similarity with the exemplar, and (2) an output token-based verification stage that uses SAM's decoder output tokens with a TS-SS (Triangle Similarity-Sector Similarity) metric to distinguish positive from negative instances. The method achieves MAE 16.25 on FSC-147 (best among SAM-only training-free methods) and MAE 4.68 on CARPK (outperforming all listed supervised methods).

## Strengths

- **Novel use of SAM's output tokens for counting verification.** Repurposing SAM's internal output tokens as verification criteria — bypassing the need for costly post-processing of image embeddings — is a genuinely interesting and clean idea. The ablation (Table 5) shows that using output token space (MAE 16.25) outperforms image embedding space (MAE 16.94), and Figure 5 provides qualitative PCA evidence that output tokens separate positive/negative instances more cleanly.

- **Strong CARPK results with a training-free, single-model approach.** On CARPK, the method achieves MAE 4.68 and RMSE 6.13, outperforming all supervised methods listed in Table 1 (FamNet 18.19, BMNet+ 5.76, SAFECOUNT 5.33, LOCA 9.97). This is a genuine accomplishment for a method that requires no training and uses only SAM — no DINO, no CLIP, no auxiliary networks.

- **Clean architecture without additional models.** Unlike SAM+α methods such as TFCAC (which uses DINO as an additional image encoder) or OmniCount (which uses multiple priors), this method relies entirely on SAM's intrinsic architecture. The paper reports 1.69s/image inference on FSC-147 and claims >2× speedup over TFCAC, which is meaningful for practical deployment.

- **Comprehensive ablation studies.** The paper provides clear ablation on verification metrics (Table 3: dot product 19.58 → cosine 16.48 → TS-SS 16.25), iterative sampling configurations (Table 4), and verification space (Table 5: output token vs. image embedding). This allows readers to understand where each design choice contributes.

## Weaknesses

### Major

- **Abstract overclaims relative to the paper's own data.** The abstract states the method "achieves superior accuracy with an MAE of 16.25, outperforming existing training-based and training-free counting methods." However, Table 1 shows that on FSC-147, multiple training-based methods achieve substantially lower MAE: BMNet+ (14.62), SAFECOUNT (14.32), PseCo (13.05), and LOCA (10.79). TFCAC (SAM+α, MAE 12.26) also outperforms. The claim is false as written for FSC-147. The CARPK results genuinely do outperform all listed supervised methods, but the abstract does not qualify this per-dataset. The paper's own Results section (line 286) is more measured ("best performance among training-free SAM only methods"), so the abstract needs to be revised to match.

- **TS-SS improvement over cosine similarity is marginal and unvalidated.** The improvement from cosine similarity (MAE 16.48) to TS-SS (MAE 16.25) is only 0.23 MAE — a ~1.4% relative improvement. No confidence intervals, standard deviations, or statistical significance tests are reported. Given that FSC-147 has 147 categories and the MAE scale is ~16.5, this gap could easily be within the noise floor. The claim that "non-hybrid metrics have reached a performance plateau" and the central motivation for TS-SS rest on thin empirical ground without variance estimates.

- **Missing direct comparison to grid/superpixel prompt generation under the same pipeline.** The paper motivates probabilistic prompt generation against grid and superpixel methods in Section 2.2, yet never runs a controlled experiment comparing them within the same verification pipeline. Table 4 shows that more iterations/prompts improve performance, but this is expected and does not isolate whether the probabilistic strategy adds value over simpler deterministic sampling at the same budget. Without this comparison, the contribution of the probabilistic stage is unclear.

- **No inference speed comparison with other methods under the same hardware.** The paper reports its own throughput (1.69s/image) but provides no comparison to TFCAC, TFOC, or C-Anything running on the same GPU. The claim that it is "more than twice as fast" as TFCAC (line 288) is unverifiable from the data presented.

### Minor

- **Method description lacks precision in a few places.** (a) The initial exemplar prompt `e` — is it a point, a box, or a mask? The Implementation section says "point prompt generation" for sampling but doesn't clarify what `e` is for the initial mask computation. (b) The probability distribution update for negative cases says values are "decreased" without specifying the mechanism (multiplicative? subtractive? by what factor?). (c) The number of exemplars used for FSC-147 few-shot setting is not stated — essential for fair comparison with methods like LOCA and FamNet which use 3.

- **No threshold sensitivity analysis for TS-SS verification threshold (set to 300).** The TS-SS metric produces a value with unintuitive range (product of triangle area and sector area components). The paper tunes this threshold on validation but provides no analysis of how sensitive performance is to this choice.

- **PCA visualization (Figure 5) is only for two example images.** The paper should provide a quantitative separation metric (e.g., cluster purity, silhouette score) across the full dataset rather than qualitative evidence on two images.

### Trivial

- Figure 5 caption is confusing: the text says the second column shows image embeddings and the third shows output tokens, but the caption describes them inconsistently across mentions.

- The "SAM" row in Table 1 (vanilla SAM segmenting everything with grid prompts) is an unconventional baseline — it would benefit from a footnote clarifying how its MAE 42.48 is obtained.

## Novel Insights

The key insight that emerges across both reviews is that the paper's genuine methodological contribution (using SAM's output tokens for instance verification) is partially undermined by two gaps: (1) the failure to demonstrate that the TS-SS metric provides more than marginal gains over cosine similarity, and (2) the lack of a controlled comparison isolating the probabilistic prompt generation from simpler alternatives. These gaps are fixable with additional experiments, but as presented, the reader cannot confidently attribute the method's performance to the claimed innovations rather than to more mundane factors (simply sampling many prompts, or a threshold-specific artifact of TS-SS on this dataset).
