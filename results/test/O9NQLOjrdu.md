## Summary

This paper proposes a zero-shot image classification method that uses a multimodal LLM (Gemini Pro) to generate two additional textual representations of the input image — an image description and an initial class prediction — encodes these alongside the image using CLIP, fuses the three features via simple averaging, and classifies via nearest-mean to class label features. The approach is evaluated on ten benchmark datasets with consistent gains over zero-shot baselines including CLIP and CuPL.

## Strengths

- **Consistent SOTA accuracy across a broad set of benchmarks.** As shown in Table 1, the method's "combined" variant achieves the best zero-shot results on 9 out of 10 datasets. On ImageNet (73.4%), it outperforms CLIP ViT-L/14 (65.1%) and CuPL (66.6%) by substantial margins. The gains are not concentrated on one dataset but appear across both fine-grained (Cars, Pets) and generic (ImageNet, Places) classification tasks.

- **Novel use of multimodal LLM for image-specific text generation.** Unlike prior approaches (e.g., CuPL) that only use LLMs to generate class descriptions, this method uses a *multimodal* LLM to describe the *input image itself* and to produce an initial class prediction. The ablation study (Table 2) demonstrates that both the description feature (DF) and prediction feature (PF) contribute meaningfully beyond the image feature (IF) alone, and that fusing all three yields the best results.

- **Fixed, universal prompts requiring no per-dataset engineering.** Section 2 explicitly states that the same prompts \(p_\texttt{d}\) and \(p_\texttt{c}\) are used across all datasets. This contrasts with CLIP/CALIP, which use dataset-specific templates for Pets, DTD, and Cars (noted in Section 3), making the method easier to adopt in practice.

- **Comprehensive ablations on features, fusion strategies, and backbones.** Table 2 systematically ablates each feature and its combinations across all 10 datasets. Table 3 ablates three fusion strategies (max similarity, avg similarity, avg feature) across three CLIP backbones, confirming the chosen average-feature fusion is best. These experiments strengthen confidence in the design choices.

## Weaknesses

### Fatal
None.

### Major
None.

The core claim — that fusing multimodal LLM outputs with CLIP image features improves zero-shot classification — is well-supported by the evidence in Table 1 and the ablation studies. The weaknesses below are substantive but do not invalidate the central contribution.

### Minor

- **Ambiguous reporting of the headline accuracy gains.** The abstract and introduction claim "an average accuracy gain of 4.1 percentage points" and "an increase of 6.8 percentage points on the ImageNet dataset, compared to prior methods," without specifying which prior method(s) serve as the baseline. The 6.8 pp on ImageNet matches the improvement over CuPL (73.4 − 66.6 = 6.8), but the average of 4.1 pp cannot be straightforwardly verified from Table 1 using any single baseline (e.g., over CLIP ViT-L/14 the average is ~8.4 pp; over CuPL it is ~7.0 pp). The numerical claim is imprecise as written; the paper should state the reference method(s) and ideally report per-dataset gains.

- **No discussion of potential LLM training-data leakage.** The method is presented as "zero-shot," but Gemini Pro — the multimodal LLM used to generate initial predictions and descriptions — is trained on a large, undisclosed web corpus that may include images/labels from standard benchmarks like ImageNet. If so, the "initial prediction" feature could benefit from test-set exposure, complicating the zero-shot interpretation. This limitation is not acknowledged. While this concern is not unique to this paper (it applies to CuPL, GPT-based methods, and essentially all LLM-augmented zero-shot work), the authors should at minimum discuss it and consider mitigation (e.g., testing on a dataset postdating Gemini Pro's training cutoff, or comparing with an open VLM whose training data is documented).

- **Exact prompt text not provided.** The prompts \(p_\texttt{d}\) (image description) and \(p_\texttt{c}\) (initial classification) are described only generically. For a method whose novelty lies partly in its prompting pipeline, the exact wording is needed for reproducibility and to assess whether prompt design choices drive the gains. If these were in a parser-stripped appendix, they should be moved to the main paper; if not, they must be added.

- **LLM generation parameters for class descriptions undisclosed.** The paper states that class descriptions were generated by "prompting Gemini Pro to describe each class label in the dataset 50 times" (Section 3) but does not specify the temperature, sampling strategy, or how the 50 prompts are varied. This matters for reproducibility since LLM outputs can be sensitive to these settings.

- **No discussion of result variability.** The paper does not state whether the LLM outputs or the overall pipeline are deterministic. If the LLM uses non-zero temperature, results may vary across runs; this should be clarified and, if applicable, accompanied by a variance estimate.

### Trivial

- The paper uses "4.1 percentage points" in the abstract and "4.1\%" in Section 1 (line 24) to mean the same quantity — "percentage points" is the correct terminology when referring to absolute accuracy differences.

## Nice-to-Haves

- A deeper analysis of *when* the initial prediction feature (PF) helps versus hurts (e.g., separating classes by LLM confidence, or measuring correlation between PF correctness and final gain) would strengthen the understanding of the method's behavior.
- A discussion of whether a smaller, open-source VLM (e.g., LLaVA) could substitute for Gemini Pro at lower cost would be useful for practitioners.
