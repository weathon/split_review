## Summary

This paper extends submodular-Bregman divergences (Iyer & Bilmes, 2012b) to arbitrary set functions via the difference-of-submodular (DS) decomposition, calling the result the difference-of-submodular Bregman divergence (DBD). The authors prove (Theorem 3.1′) that any set function can generate a proper divergence by decomposing it into two strictly submodular functions, and show (Theorem 3.4) that richer function classes yield strictly richer divergence families. They then propose a learnable DBD using ε-PointNet and demonstrate its effectiveness on set clustering and retrieval tasks using ModelNet40, substantially outperforming fixed submodular Bregman divergences.

## Strengths

1. **Formal extension of Bregman divergences to arbitrary set functions via DS decomposition**: Theorem 3.1′ proves that any set function can generate a proper divergence through DS decomposition, removing the prior restriction to submodular/supermodular functions. This is the paper's core theoretical contribution and directly enables the DBD.

2. **Theorem 3.4 (expressive power)**: Shows that if one class of set functions strictly contains another, the corresponding DBD class is also strictly larger. This provides a principled motivation for using expressive neural-network-based set functions over fixed submodular ones.

3. **Large empirical gains over fixed submodular Bregman divergences**: On ModelNet40 set clustering (Table 2), the learned DBD achieves Rand index values substantially higher than the best fixed submodular Bregman divergence (e.g., ~0.45–0.50 vs ~0.17). This demonstrates that learnability and expressive power translate to practical benefits.

4. **Ablation confirms benefit of DS decomposition**: Every w/ decomposition variant outperforms the corresponding w/o decomposition variant across all three supergradient types, and standard deviations are also reduced, supporting the value of the decomposition.

5. **Insightful comparison of supergradient types**: The paper shows that grow and shrink supergradients yield comparable performance while the bar supergradient is significantly worse, and explains this by the bar supergradient's lack of local dependence on Y (independence from Y noted in Section 5.2). This provides practical guidance.

## Weaknesses

### Fatal
None.

### Major

1. **Unjustified existence of strict supergradients for strictly submodular functions in the DS construction.** Theorem 3.1′ and the construction in Section 4 require a strict supergradient \(g_Y^2 \in \tilde{\partial}^{f^2}(Y)\) where \(f^2\) is strictly submodular (from the strong DS decomposition, Theorem 3.2). However, Proposition 2.5 — the paper's only explicit construction — gives strict supergradients **only when \(f\) is strictly supermodular**. The paper does not provide any proof or construction showing that the three supergradients (grow, shrink, bar) from Table 1 are strict supergradients when applied to a strictly submodular \(f^2\). The connection via \(-f^2\) (which is strictly supermodular) is never articulated or verified; indeed, a strict supergradient of \(-f^2\) translates to a strict *sub*gradient of \(f^2\), not a strict supergradient. This is a genuine theoretical gap: the central claim that the DBD satisfies Definition 1.1 for arbitrary set functions is not fully supported without establishing that \(\tilde{\partial}^{f^2}(Y)\) is nonempty and that the formulas in Table 1 yield elements of it. This weakness is structural because it affects the theoretical foundation of the proposed divergence.

### Minor

1. **The \(k\)-means clustering experiment lacks theoretical justification.** The paper states (Section 5.2) that "the \(k\)-means algorithm with a Bregman divergence is justified by Banerjee et al. (2005)." However, Banerjee et al.'s analysis assumes a standard Bregman divergence generated by a strictly convex, differentiable function on a convex domain — neither of which holds for the DBD (whose generating function is a set function, and the "gradient" is a semidifferential of a submodular function). The DBD is a structurally different object, so the convergence and optimality guarantees of Bregman \(k\)-means do not directly apply. The experiments are still informative as empirical validation, but the paper should explicitly acknowledge this gap rather than citing Banerjee et al. as blanket justification.

2. **The w/ vs w/o decomposition comparison may be confounded by capacity.** The paper adjusts the hidden layer width of the w/o decomposition model (64×128 instead of 64×64) to approximately match parameter count, but a two-network architecture (w/ decomposition) has fundamentally different representational capacity from a single larger network. The improvement from DS decomposition could partly reflect architectural benefits of two separate networks rather than the decomposition structure itself. This is minor because the improvement is consistent across all supergradient types.

## Suggestions

1. **Close the strict supergradient gap**: Provide a proof (or cite an existing result) that the grow/shrink/bar supergradients in Table 1 are strict supergradients when applied to a strictly submodular function, or provide an alternative construction. This is the most important theoretical fix. One possible route: show that for strictly submodular \(f\), the grow supergradient satisfies \(\hat{g}_Y(X) - \hat{g}_Y(Y) > f(X) - f(Y)\) for all \(X \neq Y\) using the strict diminishing-returns property; or use the symmetry that if \(-f^2\) is strictly supermodular, a strict supergradient of \(-f^2\) can be transformed appropriately.

2. **Acknowledge the \(k\)-means theoretical gap** explicitly, and either provide empirical evidence that the DBD-based \(k\)-means converges meaningfully (e.g., plot objective values across iterations) or use a clustering method whose theoretical guarantees do not depend on the standard Bregman framework.

3. **Clarify the notation**: Theorem 3.1' uses h_Y and g_Y, but the construction in Section 4 uses h_Y^1 ∈ ∂_{f^1}(Y) (non-strict) while the theory requires h_Y^1 ∈ ∂̃_{f^1}(Y) (strict). For a conference audience unfamiliar with submodular analysis, clarifying when the implementation is using strict vs. non-strict semidifferentials and justifying that the greedy extreme point yields a strict subgradient for strictly submodular f^1 would greatly improve the paper's readability and trustworthiness.
