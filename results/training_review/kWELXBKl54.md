## Summary

This paper frames Meteorological Anomalies Analysis (MAA) as a Visual Question Answering (VQA) problem. It contributes: (1) SPOT, a computer-vision pipeline for extracting color-region coordinates from heatmaps; (2) ClimateIQA, the first meteorological VQA dataset (8,760 heatmaps, 254k QA pairs across four task types), built from ERA5 reanalysis data via automated template generation; and (3) Climate-Zoo, a collection of three fine-tuned VLMs (Llava-1.6, Qwen-VL-Chat, Yi-VL-6B) that substantially outperform general-purpose VLMs on this dataset.

## Strengths

- **First large-scale meteorological VQA dataset with spatial grounding**: ClimateIQA contains 254k question-answer pairs across four task types (Verification, Enumeration, Geo-Indexing, Description) built from real ERA5 wind gust data and paired with geographic knowledge bases (IHO Sea Areas, World Bank boundaries). This directly addresses a genuine gap — no prior dataset existed for VLM-based meteorological heatmap interpretation — and provides a reproducible foundation for future work.

- **Dramatic and well-motivated performance gains over general VLMs**: The paper demonstrates through an initial assessment (Section 3) that even GPT-4-Vision, with four different prompting strategies, achieves only 5–12% recall on basic red-region identification. After fine-tuning on ClimateIQA, Climate-Zoo models reach ~0.90 F1 on verification tasks and near-zero Haversine distances on geo-indexing tasks. The gap between the baselines' failure modes (color confusion, hallucinations) and the fine-tuned models' success is convincingly documented.

- **Task-specific evaluation metrics appropriate to the domain**: Rather than relying on generic VQA accuracy, the paper designs four distinct metrics — F1 (verification), Element Match Score (enumeration, capturing both omissions and hallucinations), Haversine distance (geo-indexing, measuring actual geographic error), and BLEU/ROUGE/GPT-4 scores (description). This is a thoughtful evaluation design that reveals model behavior at a granular level.

- **Practical ablation study on dataset size**: The ablation (Table 2) shows that Yi-VL-6B achieves strong results with as few as 10k samples while Llava-1.6 benefits from larger data. This provides practical guidance for resource-constrained applications and reveals interesting differences in pre-training transfer.

## Weaknesses

### Fatal
None.

### Major

- **Unsupported 100% accuracy claim for SPOT**: The paper asserts that "color spatial location obtained via SPOT has a 100% accuracy" (lines 21, 82). No ground-truth metric is defined, no human-annotated evaluation set is constructed, and the confidence of the underlying OpenCV contour extraction and K-Means clustering on smooth-gradient heatmaps is never quantified. Furthermore, the outlier-rerouting step (reported 97.7% efficiency before correction, line 80) replaces ~2.3% of points with "the nearest valid contour" — a heuristic whose accuracy is unvalidated and could introduce systematic shifts to wrong color regions. A claim of "100%" in an engineering system that involves computer vision preprocessing, clustering, and heuristic correction requires rigorous validation (e.g., human annotation of a random sample of SPOT output) to be credible. This overclaim weakens trust in the data creation pipeline.

- **Evaluation is entirely on synthetically generated data from the same automated pipeline**: All test results (Tables 1, 2) are on a held-out portion of ClimateIQA, whose questions and answers are generated by the same template-based pipeline (SPOT + geographic databases + blank-filling). This means the test distribution is identical to the training distribution — every answer is deterministically correct by construction. The paper provides no evaluation on real human-annotated data, heatmaps with different color schemes or data sources (satellite, radar), or free-form questions outside the template structure. While the paper partially acknowledges this in the Limitations section (Section 7), the current results primarily measure how well models fit the template distribution rather than genuine generalization to realistic MAA conditions. The paper's conclusion claiming "a robust framework for anomalies detection and interpretation" is not fully supported by the evidence presented.

### Minor

- **Baseline comparison setup is underspecified and potentially imbalanced**: The paper reports that all baseline VLMs (Llava-v1.6, Qwen-VL-Chat, Yi-VL-6B, GPT-4-Vision) achieved F1 = 0 and match score = -1 on verification and enumeration tasks (line 151). The prompts used for these baselines in the main evaluation are not described — the paper only mentions prompt-tuning in general terms (Section 5) and refers to "Table 6" (question templates for *dataset creation*, not for baseline prompting). While the initial assessment (Section 3) convincingly shows GPT-4-Vision struggles even with careful prompting (5–12% recall), the complete failure of *all* baselines on enumeration tasks (which require listing specific geographic names from the knowledge base) may reflect a prompt-format mismatch rather than genuine inability. The paper would be stronger if the baseline prompts were specified and the results confirmed with format-agnostic evaluation.

- **The initial assessment experiments are described qualitatively, with quantitative recall rates only for GPT-4-Vision**: The initial assessment (Section 3) provides quantitative recall for GPT-4-Vision (5%, 7%, 12%) but only qualitative descriptions for other failure modes. The other three baseline models used in the main evaluation (Qwen-VL-Chat, Yi-VL-6B, Llava-1.6) are not assessed in the initial study, making it unclear whether they share the same failure patterns. A small-scale preliminary evaluation of all baselines would strengthen the motivation.

## Suggestions

1. **Remove or rigorously support the "100% accuracy" claim for SPOT.** Define a clear accuracy metric (e.g., proportion of points whose assigned color region matches a human-annotated ground truth), sample and annotate a subset of heatmaps, and report the measured accuracy. A 95–99% figure with transparent methodology would be far more credible than an unsubstantiated 100%.

2. **Specify the exact prompts used for baseline models in the main evaluation (Table 1).** Show the prompt template in the paper or appendix. If the baselines were asked a different question format than the fine-tuned models, explain why this is necessary and how it affects comparability.

3. **Add at least a small out-of-distribution evaluation set.** A hand-annotated set of 50–100 heatmaps with different color schemes or data types (e.g., temperature precipitation heatmaps, different colormaps) would test whether the fine-tuned models generalize beyond the ClimateIQA template distribution and would substantially strengthen the paper's practical relevance claim.

4. **Clarify the distinction between "prompt-tuning" (Section 5) and the prompts used for baseline evaluation.** Section 5 mentions "prompt-tuning" but it is not clear whether this was applied to the baselines in Table 1 or only to the Climate-Zoo models.

## Score and Decision

This paper makes a genuine contribution — the first VQA dataset for meteorological heatmap analysis, a useful data-extraction pipeline (SPOT), and convincing evidence that domain-specific fine-tuning solves failure modes observed in general VLMs. The core weaknesses are (a) an overclaimed and unsupported 100% accuracy figure for SPOT, (b) evaluation limited to the same synthetic distribution as training, and (c) underspecified baseline prompts. None of these are fatal; they are addressable in revision. The paper's originality and practical value are clear.
