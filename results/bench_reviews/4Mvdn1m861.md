## Summary

This paper proposes TokenCount, a training-free object counting framework built on SAM that combines two components: (1) a probabilistic prompt generation stage that iteratively samples prompts from a similarity-based probability distribution and suppresses already-verified regions, and (2) an output token-based verification stage that uses SAM's decoder output tokens (rather than image embeddings) with a TS-SS geometric similarity metric to distinguish positive from negative instances. The method is evaluated on FSC-147 and CARPK, achieving MAE 16.25 and 4.68 respectively, competitive among SAM-only training-free approaches.

## Strengths

- **Probabilistic prompt generation is a well-motivated and effective idea.** The iterative scheme that samples from a multinomial distribution based on exemplar similarity, then suppresses probability mass over already-verified regions (Figure 3, Section 3.1), directly addresses the redundancy and missed-object problems of grid/superpixel prompting. Table 4 shows clear trends: increasing prompts per iteration from 32→128 consistently lowers MAE (e.g., 21.74→16.25 at 16 iterations), and the design is shown to achieve reasonable computational cost (1.69s/image on FSC-147).

- **Output token-based verification outperforms image embedding verification, as shown in Table 5.** The paper directly compares the same framework using output tokens (MAE 16.25) vs. image embeddings (MAE 16.94). PCA visualizations in Figure 5 further illustrate that output tokens yield more separable positive/negative clusters than image embeddings. This demonstrates the core claim that SAM's decoder output tokens contain useful discriminative information that can be exploited without auxiliary models.

- **Strong performance on CARPK.** The method achieves MAE 4.68 and RMSE 6.13 on CARPK (Table 1), outperforming all listed training-based methods (BMNet+ 5.76, SAFECount 5.33) and all SAM-only training-free baselines (TFOC 10.97). This is a legitimate strong result on a practical real-world benchmark.

- **Systematic ablation of verification metrics (Table 3) and iteration/prompt trade-offs (Table 4).** Table 3 compares dot product, cosine similarity, L2 distance, and TS-SS, establishing a clear performance hierarchy. Table 4's exploration of (iteration, prompts-per-iteration) pairs with mean prompt counts provides practical guidance for balancing accuracy vs. computational cost.

## Weaknesses

### Fatal
None. The paper's methodological flaws are significant but do not invalidate all contributions.

### Major

- **The abstract makes an overclaim that is contradicted by the paper's own data.** The abstract states the method achieves MAE 16.25, "outperforming existing training-based and training-free counting methods." However, Table 1 shows TFCAC (a training-free, SAM+DINO method) achieves MAE 12.26 on FSC-147—substantially better. The paper's body correctly acknowledges this in Section 4.2 ("although our proposed method is inferior in performance to the state-of-the-art TFCAC"), but the abstract's blanket claim is factually inaccurate based on the data presented. This needs to be corrected.

- **The contribution of the TS-SS metric is minimal.** Table 3 shows TS-SS achieves MAE 16.25 vs. cosine similarity at 16.48—a mere 0.23 MAE difference (1.4% relative improvement). Given the paper motivates TS-SS as a critical methodological contribution (Sections 3.2) with elaborate geometric formulations (Equations 2-3), the near-parity with simple cosine similarity undermines the claimed importance of this component. The paper's own explanation that "non-hybrid metrics have reached a performance plateau" (Section 4.3) inadvertently confirms that the plateau is already near the TS-SS result, making the added complexity hard to justify.

- **The improvement from output token verification over image embedding verification is modest.** Table 5 shows 16.25 vs. 16.94 MAE—a 0.69 (4%) improvement. Without variance estimates or significance tests, and given the stochasticity of the probabilistic sampling, this could partially reflect noise. The paper also does not ablate the verification stage in isolation: both conditions in Table 5 use the same probabilistic prompt generation, so it is unclear how much of the gain comes from better prompt placement (stage 1) vs. better verification (stage 2). An ablation that fixes the prompt set and varies only the verification method would be necessary to attribute the gain.

- **The FSC-147 evaluation does not specify the number of exemplars used for the few-shot setting, and the CARPK evaluation uses 12 exemplars without clarifying whether baselines used the same setup.** The standard FSC-147 protocol uses 3 exemplars. The paper states "For CARPK... we randomly selected 12 objects from the training set to use as exemplars" but does not disclose what exemplar count baselines used. If comparative methods used fewer exemplars (a common practice), the CARPK results favoring this paper could partially reflect the exemplar advantage rather than methodological superiority. The paper should report performance under the standard 3-exemplar protocol for FSC-147 and state the exemplar configuration for all baselines.

### Minor

- **No variance or significance measures are reported.** The probabilistic prompt generation introduces randomness via multinomial sampling, yet all metrics are reported as point estimates. Confidence intervals or results across multiple seeds are needed to assess the reliability of the reported improvements.

- **No sensitivity analysis for key hyperparameters.** The token verification threshold (300), t-scale factor (0.066), patience (5), and NMS threshold are described as set "based on validation experiments" (Section 4.1), but no grid search results or sensitivity curves are shown. For a method described as "training-free," the reliance on carefully tuned parameters without robustness analysis is a concern.

- **Failure cases are discussed only qualitatively.** The paper shows one failure case in Appendix Figure 8 and notes degradation in dense, small-instance scenarios, but does not quantify how frequently such failures occur or categorize them by failure mode (SAM segmentation error vs. verification error vs. prompt generation error).

- **The one-shot counting comparison (Table 2) is framed positively but the results are relatively weak.** The method's MAE of 18.57 under one-shot is substantially worse than LOCA (12.53) and TFCAC (15.15), and not clearly competitive with training-based methods. The paper's framing as "comparable" and "promising" overstates the one-shot results.

### Trivial

- Some notation in Equation (1) could be clarified: the Hadamard product between **F**[*I*] (64×64×256) and **M**[*R*] (64×64×1) relies on broadcasting, which is standard but should be explicitly noted.

## Nice-to-Haves

- An ablation that keeps prompts fixed and varies only the verification method (output token vs. image embedding vs. simple similarity map thresholding) would cleanly isolate the contribution of the verification stage.
- Sensitivity plots for the token verification threshold, t-scale factor, and patience would improve reproducibility and show robustness.
- Systematic timing benchmarks comparing inference speed against TFCAC and other training-free methods on identical hardware would substantiate the speed claims.

## Removed Points

These points are flagged to be removed; treat them with caution.

- **Criticism that "training-free" is misleading because SAM itself was trained.** This is standard usage across the training-free counting literature (TFOC, C-Anything, etc.), where "training-free" means no task-specific fine-tuning. The paper is consistent with field conventions.
- **Criticism about dimension mismatch in Equation (1).** The Hadamard product between 64×64×256 and 64×64×1 is valid via standard broadcasting. No error exists.
- **Criticism about missing baselines (CountGD, SIGMA, RepAdapter).** The instruction framework prohibits flagging missing related works without external verification.
- **Criticism that the method "requires SAM" as if that were a weakness.** Every SAM-based training-free method requires SAM; this is not a distinguishing weakness.
- **Claim that "the gains could entirely come from probabilistic prompt generation."** This is speculative; Table 5 does show output tokens outperform image embeddings under the same prompt generation, providing some evidence of verification-stage benefit. The concern is partially addressed but an ablation that fully isolates the verification stage is a nice-to-have, not a fatal omission.

## Novel Insights

None beyond the paper's own contributions. The reviewers identified that the TS-SS metric's gain over cosine similarity is marginal (0.23 MAE), which the paper itself acknowledges indirectly, and that the output token verification improvement over image embeddings is modest (0.69 MAE). These findings suggest that the paper's main practical value lies more in the probabilistic prompt generation component than in the geometric verification metric, which the paper does not sufficiently acknowledge.
