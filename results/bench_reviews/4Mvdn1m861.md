## Summary

This paper proposes TokenCount, a training-free object counting framework that operates on top of SAM without architectural modifications or auxiliary models. It introduces two components: (1) a probabilistic prompt generation stage that iteratively samples prompts from a probability distribution derived from SAM's image encoder, and (2) an output token-based verification stage that uses SAM's decoder output tokens with the TS-SS similarity metric to distinguish positive from negative instances. The method is evaluated on FSC-147 and CARPK benchmarks.

## Strengths

- **Repurposing SAM's output tokens for verification is a genuinely novel and well-motivated idea.** The paper provides a clear geometric rationale (Section 3.2) for why output tokens — which entangle semantic and positional information through bidirectional attention — are better suited for instance verification than raw image embeddings. The PCA visualization in Figure 5 convincingly demonstrates that output tokens separate positive and negative prompt features into distinct clusters, while image embeddings show substantial overlap.

- **Strong results on CARPK (MAE 4.68).** The method outperforms all listed supervised and training-free baselines on this dataset except TFCAC, while using only SAM without additional models. This demonstrates genuine value in structured scenes where SAM produces clean masks.

- **Competitive standing among SAM-only training-free methods on FSC-147.** The full pipeline achieves MAE 16.25, substantially better than TFOC (19.95), C-Anything (27.97), and vanilla SAM (42.48), and surpasses the training-based Counting-DETR (16.79). This 3.7 MAE gap over the closest SAM-only baseline is meaningful and supports that the proposed pipeline improves over prior training-free approaches.

- **Ablation on verification metrics (Table 3) and iterative sampling (Table 4) provides some evidence that each component contributes**, even if some gains are small. The trend across iterations and prompt counts is monotonic and consistent.

## Weaknesses

### Fatal

None.

### Major

- **The abstract contains a factually incorrect overstatement that undermines credibility.** The abstract claims the method "outperforms existing training-based and training-free counting methods" without qualification. This is false: on FSC-147, LOCA (MAE 10.79), PseCo (13.05), BMNet+ (14.62), and SAFECount (14.32) all substantially outperform the proposed MAE of 16.25. The body text (Section 4.2) is appropriately careful — noting the method outperforms *some* training-based methods and achieves best performance among *SAM-only* training-free methods — but the abstract misrepresents the results. This is not merely sloppy writing; it is a structural problem because the headline claim is wrong and sets false expectations about the contribution.

- **The contribution of the probabilistic prompt generation stage cannot be isolated from the available experiments.** The ablation study (Table 4) varies only parameters of the probabilistic stage (iterations, prompts per iteration) and never compares against a simple deterministic prompt strategy (e.g., uniform grid, superpixel) when paired with the *same output-token verification*. The paper argues (Section 3.1) that the probabilistic approach addresses limitations of grid and superpixel methods, but no experiment tests whether the full pipeline with deterministic prompting + output-token verification would perform similarly. Since the verification stage is the other claimed core contribution, the paper does not establish how much each component independently contributes — a critical gap for a paper whose contributions are framed as two synergistic stages.

### Minor

- **Efficiency claims lack measured evidence.** The paper states the method is "more than twice as fast" as TFCAC (Section 4.2) and reports 1.69 sec/image for its own method, but provides no runtime measurements for any baseline. Without head-to-head timing on identical hardware, the efficiency advantage is asserted rather than demonstrated. The architectural argument (no DINO encoder, fewer prompts) is plausible but not a substitute for measurement.

- **Gains from the TS-SS metric and output-token space are marginal and lack statistical characterization.** TS-SS achieves MAE 16.25 vs. cosine similarity 16.48 (Δ=0.23 MAE; Table 3), and output-token space vs. image-embedding space differs by 0.69 MAE (Table 5). No confidence intervals, standard deviations, or significance tests are reported. While these small margins do not invalidate the findings, they weaken the claim that these components provide decisive improvements, and they make it difficult to assess robustness across data splits.

- **Hyperparameter sensitivity is not analyzed.** Key parameters — the token verification threshold (300), temperature τ in the softmax, the IoU threshold (0.95) and patience (5) for early stopping, and the probability decrement factor for negative masks — are reported as fixed values with no sensitivity study. The probability decrement factor is not even specified numerically ("the value of the probability distribution at that mask region is decreased"), which affects reproducibility.

- **No baseline for one-shot setting on CARPK.** Table 2 reports one-shot results only for FSC-147. The CARPK one-shot scenario is not evaluated, making the one-shot evaluation incomplete across benchmarks.

### Trivial

- The link between the algebraic formulation (Equation 1) and the multinomial sampling step could be clarified — specifically, how the 64×64 probability map maps to image coordinates for SAM prompting. This does not affect correctness but could confuse readers.

## Nice-to-Haves

- A comparison of probabilistic vs. deterministic (uniform grid) prompting with the same output-token verification would strongly strengthen the paper. Even a single-row ablation demonstrating that the probabilistic strategy reduces the number of prompts needed for equivalent accuracy would support the efficiency claims.
- Runtime benchmarking of baselines (TFOC, C-Anything, TFCAC) on the same hardware would substantiate efficiency claims.
- Sensitivity analysis of the key hyperparameters (τ, threshold, IoU, patience) would improve confidence in the method's robustness.
- Aggregate failure-case metrics (e.g., performance on dense/small-object subsets) would help understand the method's limitations quantitatively rather than only through qualitative examples.

## Novel Insights

The paper's key insight — that SAM's decoder output tokens form a representation space where positive and negative instances are more separable than in the image embedding space — is genuinely interesting and supported by the PCA evidence (Figure 5). The geometric motivation that output tokens entangle semantic and positional information (Section 3.2) provides a compelling reason why a hybrid metric like TS-SS is needed, and the ablation hierarchy (Table 3: dot < cosine ≈ L2 < TS-SS) aligns with this reasoning. This observation about output tokens may generalize beyond counting to other downstream tasks that rely on SAM.

## Suggestions

- **Fix the abstract.** Replace "outperforming existing training-based and training-free counting methods" with a precise statement, e.g., "outperforming prior training-free SAM-only methods and matching or exceeding several training-based approaches."
- **Add the deterministic prompt baseline ablation.** A single experiment comparing (probabilistic + token verification) vs. (uniform grid + token verification) vs. (superpixel + token verification) would resolve the major weakness about isolating contributions and is straightforward to run.
- **Report TFCAC and TFOC runtimes on the same hardware.** Even a single paragraph with approximate measurements would substantiate the efficiency claims.
- **Specify the probability decrement factor for negative masks** to improve reproducibility.
