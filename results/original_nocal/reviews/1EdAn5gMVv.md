## Summary

The paper proposes SpatialBoost, a framework that injects 3D spatial knowledge into pre-trained vision encoders by converting 3D information (depth, segmentation, 3D reconstruction) into language-based question-answering data, then fine-tuning the encoder through an LLM with a dual-channel attention mechanism to avoid catastrophic forgetting. The method is evaluated across a broad set of tasks including depth estimation, segmentation, 3D scene understanding, robot control, classification, and retrieval.

## Strengths

1. **Comprehensive and convincing evaluation across diverse tasks**: Tables 1–5 show consistent improvements over four strong base encoders (OpenCLIP, SigLIPv2, DINOv2, DINOv3) on depth estimation, segmentation, 3D scene understanding, robot control, classification, and retrieval. The breadth of evaluation — spanning spatial and non-spatial tasks — convincingly demonstrates both spatial knowledge injection and preservation of general capabilities.

2. **LLM-based supervision demonstrably outperforms pixel-level alternatives**: Table 6 directly compares LLM-based fine-tuning against linear, SAM, and VGGT decoders, showing that only the LLM approach yields simultaneous improvements in classification (+2.32%), segmentation (+7.97%), depth (-15.79%), and VLR (+2.04%), while pixel-level alternatives cause degradation on multiple tasks. This provides concrete evidence that language-guided supervision adds value beyond simple distillation from expert teacher models.

3. **Hierarchical multi-turn CoT structure is validated**: Table 7 ablates the ordering of the pixel→object→scene reasoning hierarchy and shows that the forward order outperforms random and reverse orders across classification, segmentation, and depth. This directly validates the claim that the dataset design itself drives improvements, not merely the presence of additional data.

4. **Dual-channel attention effectively prevents catastrophic forgetting**: Figure 6 shows that full fine-tuning drops DINOv2 ImageNet accuracy from 86.3% to 79.5%, and LoRA to 83.7%, while dual-channel attention improves to 87.6%. This finding is important for the community: it provides a practical recipe for fine-tuning vision encoders with LLM-level supervision without sacrificing pre-trained knowledge.

5. **Scalable performance with increasing data**: Figure 5 shows monotonic improvements with dataset size (50K→300K), indicating the framework can exploit larger data effectively — a practical asset for real-world deployment.

## Weaknesses

### Fatal
None.

### Major

1. **Potential scene-level overlap between ScanNet training data and 3D evaluation benchmarks (Table 3)**. The multi-view VQA construction (Section 4.1) uses 200K samples from sources including ScanNet (Dai et al., 2017), and the evaluation in Table 3 uses the Lexicon3D benchmark on ScanNet scenes. The paper does not state whether any scene-level train/test separation was enforced between the ScanNet images used for training data generation and those used for evaluation. This is a genuine concern because the vision encoder could learn scene-specific visual features that inflate 3D understanding results. **However**, this concern is partially mitigated by: (i) the multi-view training data draws from multiple sources (Ego4D, NeRF, Mip-NeRF 360, another 3D dataset) — ScanNet is only one source among many; (ii) large improvements are also observed on benchmarks completely independent of ScanNet (NYU depth, ADE20K segmentation, ImageNet classification, CortexBench robot learning), which would not be explained by scene-level overlap; and (iii) the evaluation protocol uses frozen visual backbones with task-specific heads trained on 3D point cloud representations, which is a different modality from the 2D images used in training. Nonetheless, the authors must clarify this in a rebuttal and ideally provide an evaluation with explicitly held-out scenes.

### Minor

2. **Asymmetric comparison in Table 6 (LLM vs. pixel-level decoders)**. The pixel-level baselines (linear depth, linear seg, SAM decoder, VGGT decoder) are trained on direct regression/classification tasks, while the LLM approach is trained on the rich multi-turn CoT QA data. The superiority of the LLM approach could reflect the richer training signal rather than the superiority of language as a supervision modality per se. A fairer comparison would train all decoders on the same QA data, converted appropriately to each decoder's target format. The paper's current conclusion ("LLM consistently outperform[s] pixel-level supervision methods") is overstated based on this comparison.

3. **No human evaluation or quality checks on automatically generated QA data**. The multi-turn CoT data is generated by GPT-4o using teacher model outputs (Depth Pro, SAM, VGGT). No sample quality statistics, human evaluation, or consistency checks are reported. Given the hierarchical structure and the use of automatically extracted 3D information (which can contain errors from the teacher models), some assessment of data quality would strengthen confidence in the approach.

4. **Dual-channel attention is adapted from prior work (Hong et al., 2023a)** and the paper is transparent about this. The contribution is in its application to this setting, not the mechanism itself.

### Trivial
None.

## Nice-to-Haves

- **Evaluation on held-out 3D scenes**: Repeating Table 3 using scenes from a 3D dataset not used in training (e.g., Matterport3D, HM3D) would definitively rule out contamination concerns and strengthen the paper.
- **Comparison against other spatial knowledge injection methods**: Adding baselines such as multi-view contrastive learning (MV-MWM, Sermanet et al.) or direct 3D coordinate supervision would better situate the method among existing approaches. However, the current comparisons (pixel-level supervision, naive post-training) already provide useful baselines.
- **Qualitative examples**: Showing a concrete image, the generated QA chain, and the model's spatial reasoning before/after SpatialBoost would help readers understand what spatial knowledge is being acquired.
