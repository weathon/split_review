## Summary

This paper proposes TokenCount, a training-free object counting framework that reuses SAM's built-in components without architectural modifications or auxiliary models. It introduces two components: (1) a probabilistic prompt generation stage that samples prompts from a similarity-derived probability distribution and iteratively refines the distribution based on verification feedback, and (2) an output token-based verification stage that uses TS-SS (Triangle Similarity–Sector Similarity) to distinguish positive from negative instances directly from SAM's decoder output tokens. The method achieves competitive results on FSC-147 (MAE 16.25, best among SAM-only methods) and CARPK (MAE 4.68, outperforming all supervised methods).

## Strengths

- **Output token verification improves over image-embedding verification under the same pipeline.** Table 5 shows that using output tokens as the verification space yields MAE 16.25 vs. 16.94 for image embeddings on FSC-147. This controlled experiment (same prompt generation) directly supports the paper's central claim about the value of output tokens.

- **Best among SAM-only training-free methods on FSC-147.** The method achieves MAE 16.25 on FSC-147, outperforming other SAM-only methods (TFOC: 19.95, C-Anything: 27.97, vanilla SAM: 42.48) by a clear margin. This establishes it as the current best approach within its resource class.

- **Strong CARPK results — beats all supervised methods.** On CARPK, MAE 4.68 surpasses every supervised method (best: SAFECOUNT 5.33) and all training-free methods except TFCAC (4.39, which uses an additional DINO encoder). The paper honestly acknowledges TFCAC's superior accuracy but notes >2× faster inference.

- **TS-SS hybrid metric is empirically validated over standard metrics.** Table 3 provides a clean ablation: TS-SS (16.25) outperforms cosine similarity (16.48), L2 distance (16.53), and dot product (19.58). This justifies the paper's geometric motivation for the hybrid metric.

- **Ablation of iteration count and prompt density is thorough.** Table 4 systematically varies iterations (8/16/32) and prompts per iteration (32/64/128), showing monotonic improvement that demonstrates the verification stage works as intended and giving practitioners a concrete accuracy–efficiency trade-off.

## Weaknesses

### Fatal
None.

### Major

1. **Abstract and claims are overstated relative to the evidence.** The abstract states: "our method achieves superior accuracy… outperforming existing training-based and training-free counting methods." This is contradicted by the paper's own Table 1: on FSC-147, TFCAC (training-free, 12.26 MAE), LOCA (training-based, 10.79), PseCo (13.05), SAFECOUNT (14.32), and BMNet+ (14.62) all achieve better MAE than the proposed method (16.25). The claim is only defensible within the subset of "SAM-only training-free methods" — a qualification inconsistently applied. On CARPK the claim is more justified, but the abstract does not distinguish the two datasets. Overclaiming undermines the paper's credibility.

2. **Probabilistic prompt generation is not compared against simpler baselines, leaving efficiency claims unsubstantiated.** The paper repeatedly claims that its method "efficiently generates prompts" and is "unlike simple grid or superpixel-based methods," but the experiments contain no comparison against a uniform grid or random sampling baseline with matched prompt counts (e.g., ~1400 prompts). Table 4 shows that performance improves with more prompts, but without a grid baseline it is impossible to tell whether the gains come from the iterative probabilistic strategy or simply from using many prompts. The efficiency advantage over deterministic methods is asserted, not demonstrated.

3. **Key comparisons lack statistical significance measures despite stochastic sampling.** The improvements that drive the paper's central claims are modest: TS-SS vs. cosine similarity is a 0.23 MAE difference (16.48→16.25); output tokens vs. image embeddings is a 0.69 MAE difference (16.94→16.25). The prompt generation pipeline samples stochastically, yet no variance, confidence intervals, or significance tests are reported for any of Tables 1, 3, or 5. Given that different random seeds could shift results by a similar magnitude, it is unclear whether these differences are meaningful.

### Minor

1. **Key hyperparameters are reported without sensitivity analysis.** The token verification threshold (300) and temperature scale (τ=0.066) are stated but no analysis is provided showing how performance varies over a reasonable range of these values. Since they directly affect the verification and prompt generation stages, their stability should be documented.

2. **High RMSE on FSC-147 (133.11) is not discussed.** The method's RMSE on FSC-147 is among the highest in Table 1 (exceeded only by SAM itself at 137.50, and close to TFOC's 132.16 and C-Anything's 131.24). This implies large errors on some images, which is worth analyzing (e.g., are these the same small-instance cases the paper qualitatively acknowledges?).

3. **PCA visualization for output token superiority has an inconsistent caption.** The figure description in the main text and the embedded caption give conflicting accounts of which column corresponds to which feature space. The visualization is qualitative and lacks a separability metric (e.g., silhouette score) that would quantitatively support the claim. The qualitative trend is visible but the presentation needs correction.

4. **Missing "no verification" ablation baseline.** The ablation study compares different verification metrics (Table 3) but does not include a baseline that counts all generated masks without any verification. Such a baseline would quantify the contribution of the verification stage itself.

## Removed Points

These points are flagged to be removed from consideration; treat them with caution:

- *"Comparison between output token and image embedding spaces (Table 5) uses the same prompt generation pipeline, which may obscure the true effect because prompt generation itself relies on image embedding similarity. This confound is not discussed."* — This is a controlled experiment: the same prompts are used, and only the verification space changes. If anything, the similarity-based prompts would bias *for* the image-embedding verification, making it harder to show an advantage for output tokens. Not a valid confound.

- *"The method does not outperform TFCAC"* — The paper explicitly acknowledges this ("Although our proposed method is inferior in performance to the state-of-the-art TFCAC") and notes the efficiency advantage. Not a hidden or unaddressed weakness.

- *"Missing evaluation on ShanghaiTech/UCF-QNRF"* — These are crowd-counting datasets, a different problem setting from exemplar-based class-agnostic counting which is the paper's stated scope. This is scope creep.

- *"TFOC is cited but its similarity-based approach is not explained in enough detail to understand the claimed difference"* — The paper clearly states that TFOC uses "embedding similarity as its criterion" and that "the ambiguity of the similarity itself introduced significant uncertainty." The difference (output tokens vs. image embedding similarity) is the paper's key argument; it is clearly stated.

- *"The iterative probability update is not new (e.g., active learning techniques use similar strategies)"* — Generic criticism. The paper is not claiming novelty for iterative sampling as a general concept; it claims novelty for applying it in this specific prompt-generation-for-SAM-counting context.

- *"No per-prompt time is given for comparison"* — The paper gives total per-image time (1.69s), which is the practically relevant measure. Per-prompt time is an implementation detail that can be inferred.

- *"One-shot results (Table 2) are worse than multiple training-based and training-free methods"* — The paper positions one-shot as "competitive" and provides honest numbers. The one-shot setting is acknowledged as more challenging, and the paper does not claim superiority here.

## Novel Insights

The intersection of the two proposed components is a noteworthy angle: the probabilistic prompt generation uses image-embedding similarity to bias sampling toward promising regions, while the verification stage abandons image embeddings entirely and uses SAM's own output tokens with a geometrically-motivated similarity metric. This creates an interesting asymmetry — the prompt generation relies on the very representation (image embeddings) that the verification stage is designed to circumvent. The paper does not explicitly discuss this asymmetry, but it suggests a design principle: use the cheaper, noisier signal (image-embedding similarity) for coarse exploration, and the richer, more discriminative signal (output tokens) for precise verification. This two-stage design could be applicable beyond counting.
