## Summary

The paper presents ACDC, a zero-shot method that combines pre-trained autoregressive models (ARMs) and diffusion models (DMs) at inference time to improve multimodal generation quality. ACDC applies SDEdit-based diffusion correction to frames generated by ARMs and uses an LLM-based memory module to preserve global context across story prompts. Experiments on coherent story generation (using Show-o, UIO-2 with SD v1.5) and autoregressive video generation (using LWM with AnimateDiff) show consistent improvements across multiple metrics without any fine-tuning.

## Strengths

- **Zero-shot integration of ARMs and DMs without fine-tuning (verified §3, lines 35-36).** The method works with off-the-shelf pre-trained models from different families, requiring no architectural modifications or additional training. This is validated across three ARMs (Show-o, UIO-2, LWM) and two DMs (SD v1.5, AnimateDiff).

- **Consistent and substantial quantitative improvements in story generation (verified Table 1).** ACDC improves frame consistency by +10.4% (Show-o: 0.8211→0.9062) and CLIP similarity by +7.16% (28.76→30.82), with similar gains on UIO-2. ImageReward scores approach near-zero for Show-o+ACDC, a large jump from -0.5752.

- **Demonstrated reduction of error accumulation in autoregressive video generation (verified Table 3, §4.2).** ACDC applied to LWM yields gains in subject consistency (+3.43%), background consistency (+1.45%), and aesthetic quality (+7.33%) while dynamic degree does not decrease, indicating improvements come without sacrificing motion.

- **LLM memory module ablation validates its importance (verified Table 2).** ACDC with memory achieves CLIP similarity 30.85 vs. 29.43 without memory, and FID 101.4 vs. 101.6. The memory module demonstrably preserves global context across frames.

- **Model agnosticism demonstrated across multiple ARM/DM pairs.** The method is tested with three different ARMs and two types of DMs (image and video), with the algorithm described independently of specific architectures.

## Weaknesses

### Fatal
None.

### Major

- **FID evaluation against synthetic, diffusion-based ground truth (§4.1, line 190).** The paper computes FID using "pseudo-ground truth images" generated by SDXL-lightning. Because both the correction module (SD v1.5) and the pseudo-ground truth generator (SDXL-lightning) are diffusion models, this metric is biased in favor of methods with a diffusion correction step. SD v1.5 achieves an FID of 32.11 while ARMs score 60+ — a gap largely driven by this shared inductive bias. The paper acknowledges this limitation ("Although the FID score lags behind SD v1.5, this can be partly attributed to the fact that we consider SDXL-generated images as ground truth") but does not provide an alternative real-image FID evaluation. The other three metrics (frame consistency, CLIP similarity, ImageReward) are not affected by this bias and still show consistent improvements, so the core claims are not invalidated, but the FID evaluation weakens the evidence for the image quality claim.

- **LLM memory module specifications are underspecified (§3, lines 107-112).** The paper states the memory module uses "an LLM" parameterized with φ but does not specify which LLM model (e.g., GPT-4o-mini, Llama-3, etc.), the exact prompt template, the system/user prompt structure, or whether it is used zero-shot or with in-context examples. (While "gpt-4o-mini" is mentioned for *benchmark generation* in §4.1, this is a different use.) This omission hinders reproducibility of a core component. The project page may address this, but the paper itself should document it.

### Minor

- **Non-monotonic ablation trend lacks analysis (Table 2, lines 220-221, 233-235).** ACDC #2 (correction applied to only the first two frames) achieves a *higher* frame consistency (0.888) than ACDC #6 (correction applied to all six frames, 0.853). This is counter-intuitive for a method designed to reduce error accumulation. The paper acknowledges this ("frame consistency is slightly compromised") but offers no analysis of why — e.g., whether SDEdit at the chosen noise level occasionally disrupts content structure, or whether the re-encoding loop introduces drift. While this does not invalidate the method, it raises a question about robustness worth addressing.

- **Motion smoothness improvement in video experiments is very small (Table 3: 0.9479 → 0.9501, +0.23%)** and statistical significance is not discussed. Given that the VBench metrics involve single-run evaluation, it is unclear whether this improvement is meaningful.

- **Video generation experiments lack explicit statement that the memory module is not used (§4.2).** From the description (single prompt, fixed throughout), it is clear the memory module is not employed, but the paper could explicitly state this and note that the memory component is task-dependent.

## Nice-to-Haves

- A real-image FID evaluation (e.g., on PororoSV, FlintstonesSV, or collected story frames) would strengthen the image quality claims. Alternatively, dropping the FID claim and relying on the three unbiased metrics would be acceptable.

- Reporting wall-clock time or relative computational cost of the diffusion correction step would help practitioners evaluate the zero-shot trade-off in resource-constrained settings.

- An ablation varying the SDEdit noise strength t' across a wider range (with analysis of the correction-vs-preservation trade-off) would improve understanding of the method's sensitivity.

- A comparison with other zero-shot correction approaches (e.g., VQGAN re-encoding without diffusion, or single-frame diffusion upscaling) would clarify that the SDEdit component is specifically necessary.

## Novel Insights

The key insight from the reviews is that the non-monotonic trend in Table 2 (ACDC #2 outperforming ACDC #6 in frame consistency) may point to a deeper phenomenon: SDEdit correction, when applied indiscriminately to every frame, could introduce subtle perturbations that slightly reduce inter-frame consistency even as it improves per-frame quality. This suggests that optimal correction scheduling (which frames to correct, and at what noise strength) may be non-trivial — an avenue the paper does not explore but that could be practically important. Beyond this, the reviews do not surface insights beyond the paper's own contributions.
