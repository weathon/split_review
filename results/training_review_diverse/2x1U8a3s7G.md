## Final Consolidated Review

## Summary

This paper introduces prompt diffusion, the first application of diffusion models to prompt learning for vision-language models. The method (1) overfits prompts to individual training samples via gradient descent, (2) trains a diffusion transformer to generate these overfitted prompts from noise conditioned on image features, and (3) during inference generates sample-specific prompts from random noise + test image features using a fast ODE-based sampler (5 steps, 0.045s overhead). The approach is demonstrated as a plug-and-play module across 5 prompt learning methods (VPT, CoCoOp, MaPLe, PromptSRC, CoPrompt) in textual, visual, and multi-modal settings, evaluated on 15 datasets across base-to-new, cross-dataset, and domain generalization.

## Strengths

1. **Novel and timely integration of diffusion models into prompt learning.** The paper is the first to introduce diffusion models into the prompt space, formulating prompt generation as an iterative denoising process rather than the standard one-shot deterministic optimization. This is a genuine methodological innovation over existing prompt learning approaches.

2. **Consistent empirical improvements across a very broad evaluation.** The method improves all 5 baselines (VPT, CoCoOp, MaPLe, PromptSRC, CoPrompt) across all 3 generalization settings (base-to-new, cross-dataset, domain generalization) over 15 diverse datasets. The improvements are not cherry-picked — they are observed across textual, visual, and multi-modal prompt learning methods, with base-to-new harmonic mean gains of +1.08% to +2.87% and cross-dataset gains of +1.02% to +2.47%.

3. **Diffusion model convincingly outperforms alternative generative models in ablation.** Table 4 shows the diffusion model (78.02 harmonic mean) significantly outperforms GAN (75.99), VAE (76.17), and normalizing flows (76.32) when all are trained on the same overfitted prompt targets with the same conditioning. This directly supports the choice of diffusion over simpler generative alternatives.

4. **Practical efficiency via ODE-based fast sampling.** Using AMED-Solver, the method requires only 5 function evaluations during inference, adding just 0.045 seconds per prediction over the CoCoOp baseline. This makes the approach viable for deployment — a rare case where a generative component adds meaningful accuracy without prohibitive inference cost.

5. **Modality-agnostic plug-and-play design is demonstrated.** The same prompt diffusion framework is applied without architectural modification to textual (CoCoOp), visual (VPT), and multi-modal (MaPLe, PromptSRC, CoPrompt) prompt learning methods, showing genuine versatility.

## Weaknesses

### Fatal
None.

### Major

### Minor

1. **No standard deviations or measures of variability reported.** All results are averaged over 3 random seeds (line 189), but no standard deviations, confidence intervals, or per-seed ranges are shown. Given that gains are in the 1–3% range and prompt learning methods exhibit non-trivial seed-to-seed variability, the reader cannot assess whether the improvements are reliable. This is the most significant evidential gap in the paper.

2. **Missing experimental comparison against Bayesian prompt learning (Derakhshani et al., 2023).** The paper cites this directly relevant prior work (line 48) which also formulates prompt learning as a probabilistic inference problem to improve generalization. Since the paper's own contribution is probabilistic (generative prompt sampling), a head-to-head comparison is needed to calibrate the contribution. Without it, it is unclear whether the proposed diffusion-based approach is superior to an existing probabilistic alternative.

3. **Hyperparameters for the per-sample overfitting step are underspecified.** The paper uses "a minimal number of iterations I" (line 121) and a figure indicates iteration 5 is used (line 307), but the learning rate for this per-sample gradient descent optimization is never stated. This is a reproducibility concern — the overfitting step is a core component, and without its optimization details, the method cannot be precisely reproduced.

4. **Training cost of the per-sample overfitting stage is not reported.** Each training sample requires an additional optimization loop (multiple gradient steps). The paper reports inference overhead (0.045s) but is silent on training overhead. For a method that processes every training sample individually, this cost could be substantial, and omitting it makes the "good trade-off" claim incomplete.

5. **No sensitivity analysis for the loss-balancing hyperparameter \(\beta\).** The final training objective (Eq. 5) combines a diffusion loss and a cross-entropy term weighted by \(\beta\) (line 155), yet no ablation or sensitivity study is provided. It is unclear how robust the results are to this choice.

6. **Generative ablation baselines (GAN, VAE, normalizing flows) lack architectural and training details.** The paper describes them only briefly (lines 245–253), making it difficult to assess whether the comparison is fair. For instance, were these baselines given the same transformer capacity as the diffusion model? Were hyperparameters tuned per method? Without this information, the reported gap may partly reflect suboptimal baselines.

## Nice-to-Haves

- **Oracle-prompt comparison**: Computing an "oracle" per-sample prompt (using true labels at test time, for analysis only) and measuring how close the diffused prompt gets to it would directly validate the conditioning mechanism.
- **Deterministic regressor baseline**: Comparing the diffusion model against a non-iterative conditional predictor (e.g., MLP mapping image features directly to prompts) would isolate whether the iterative refinement of diffusion provides unique value beyond any conditional mapping.
- **Prompt space analysis**: Simple analyses (e.g., PCA of generated prompts, diversity metrics, similarity to training-set prompts) would provide insight into what the diffusion model has learned.
- **Testing on additional backbones**: The method is tested only on CLIP-ViT-B/16. While the 5 prompting methods provide diversity, results on a second backbone (e.g., ViT-L/14 or ALIGN) would strengthen the claimed modality-agnosticism.

## Suggestions

2. **Include Bayesian prompt learning (Derakhshani et al., 2023)** as an additional baseline in the main experiments or at least in the ablation study. This directly addresses the most closely related probabilistic prompt learning approach.
3. **Specify the learning rate and exact number of gradient steps** for the per-sample overfitting optimization, and report the total training time overhead.
