## Summary

The paper proposes TOKENCOUNT, a training-free framework for class-agnostic object counting using SAM without architectural modifications. It has two components: (1) probabilistic prompt generation that iteratively samples prompts from a similarity-derived probability distribution, and (2) output token-based verification that uses TS-SS similarity on SAM's decoder output tokens to classify prompts as positive/negative. Evaluated on FSC-147 (MAE 16.25) and CARPK (MAE 4.68), the method achieves competitive SAM-only training-free results, notably beating all supervised methods on CARPK.

## Strengths

1. **Output token verification outperforms image-embedding verification (Table 5, ΔMAE = 0.69).** This is the paper's most concrete empirical contribution. Using SAM's decoder output tokens as the verification space (MAE 16.25) yields better results than using the image embedding space (MAE 16.94) while keeping everything else fixed. This directly supports the core claim that output tokens carry useful discriminative information beyond what the image embedding provides.

2. **Strong CARPK result (MAE 4.68, beating all supervised methods listed in Table 1).** On CARPK, the method surpasses every training-based method (BMNet+ 5.76, SAFECOUNT 5.33, LOCA 9.97) and all SAM-only training-free methods, while being second only to TFCAC (4.39) among training-free approaches. This is a genuine achievement and demonstrates the method's practical value in controlled vertical scenes.

3. **Systematic ablation study covering the three main design axes (Tables 3, 4, 5).** The paper ablates the verification metric (TS-SS vs. dot product, cosine, L2), the iteration/prompt budget trade-off, and the vector space (output token vs. image embedding). Each ablation supports the design choices and quantifies their effect. Table 4's iteration-prompt sweep is particularly useful for understanding the accuracy-efficiency Pareto frontier.

4. **Probabilistic prompt generation with iterative update is a reasonable mechanism for adaptive exploration.** The update rule (zeroing probability at positive regions, decreasing at negative regions) provides a principled way to spread prompts across the image without redundant sampling, demonstrated indirectly by the improvement from 8×32 to 16×128 settings in Table 4 (MAE drops from 29.10 to 16.25).

## Weaknesses

### Major

1. **The abstract and introduction systematically overstate the results, contradicting the paper's own Table 1.** The abstract claims *"our method achieves superior accuracy with an MAE of 16.25, outperforming existing training-based and training-free counting methods."* This is false as written for FSC-147. From Table 1, five methods achieve **better** MAE: LOCA (10.79), PseCo (13.05), BMNet+ (14.62), SafeCount (14.32), and TFCAC (12.26). The method outperforms *some* training-based methods (FamNet, CFOCNet+, Counting-DETR) but is clearly worse than several others.

   The abstract also states: *"our method achieves comparable performance to training-free approaches that require additional models alongside foundation models."* TFCAC (the main training-free competitor with an additional encoder) achieves MAE 12.26 vs. 16.25 — a **32.6% relative gap**. In counting, this is a material difference (~4 more errors per image on average), not "comparable."

   The paper's own body correctly acknowledges TFCAC's superiority (line 230: *"our proposed method is inferior in performance to the state-of-the-art TFCAC"*), but the abstract does not reflect this. This disconnect between the abstract/contributions framing and the evidence in Table 1 is a significant scientific communication failure. The paper needs to recalibrate all these claims to accurately describe its actual standing: a competitive SAM-only method that is worse than several training-based methods and TFCAC on FSC-147, but strong on CARPK.

2. **The PCA visualization (Figure 5) has contradictory caption texts that make it impossible to interpret.** The extracted text contains three versions of the Figure 5 caption. The first version states: *"The second column shows a 2D PCA plot for the top image where positive… points are well-separated. The third column shows a 2D PCA plot for the top image where positive and negative points overlap."* The third version states the opposite about the same columns: *"The second column shows how features from positive and negative prompts overlap… The third column shows how positive and negative prompts form distinct and clearly separable clusters."* The main text (line 295) says image embeddings for the top image are *"distributed separately"* (well-separated), which further compounds the confusion. The reader cannot determine which column corresponds to which vector space, and whether the visualization actually supports the claim. This needs to be corrected with a clear, consistent caption and preferably supplemented with quantitative separability metrics (e.g., Fisher discriminant ratio or k-NN classification accuracy in each space).

### Minor

3. **No error bars or variance reported despite at least two sources of stochasticity.** The prompt generation samples from a multinomial distribution (stochastic), and the CARPK evaluation randomly selects 12 exemplars. Both imply run-to-run variance. The paper reports only point estimates for all metrics. Without error bars, the 0.23 MAE advantage of TS-SS over cosine similarity (Table 3) and the 0.69 MAE advantage of output tokens over image embeddings (Table 5) could easily be within the noise of a single run. Reporting mean ± std over 5–10 runs would substantially strengthen the evidence.

4. **TS-SS metric advantage over cosine similarity is marginal (0.23 MAE, ~1.4%) with no statistical or analytical justification.** Table 3 shows TS-SS (16.25) vs. cosine similarity (16.48) vs. L2 distance (16.53). The 0.23 improvement over cosine similarity is tiny — likely within the noise given the lack of error bars. The paper claims this *"establishes a clear and logical motivation for adopting a geometric approach like TS-SS"* (Section 4.4), but a 1.4% relative gain on a single dataset does not constitute a compelling case, especially since TS-SS is borrowed from document clustering (Heidarian & Dinneen, 2016) with no analysis of why its geometry is natural for SAM's output tokens. The paper should either provide a stronger justification, replace TS-SS with cosine similarity (which is simpler and nearly as good), or at minimum frame the result honestly as marginal.

5. **Several method details needed for reproducibility are underspecified.** (a) How is the exemplar converted into a SAM-compatible prompt? Equation (1) shows M = g(F^I, e) where g is SAM's mask decoder, but SAM's decoder requires either a point or box prompt — the paper does not specify how e is transformed into such a prompt. (b) When the probability distribution is updated for negative classifications, the paper says values are *"decreased"* but does not specify by how much or according to what rule. (c) The verification threshold of 300 for TS-SS is stated without any sensitivity analysis; since TS-SS is an unbounded product of two components, the threshold's meaning depends on the scale of output token norms, which may vary across images and categories.

6. **The "probabilistic" framing is overstated.** The prompt generation computes a deterministic similarity map, applies ReLU, temperature scaling (τ = 0.066, which makes the distribution extremely peaked), and softmax — then samples from the resulting multinomial. The temperature is so low that the distribution is effectively a near-deterministic argmax. Calling this "probabilistic prompt generation" overclaims the stochastic element.

### Trivial

7. The conclusion claims *"demonstrating performance equal to or better than existing methods"* — this is contradicted by the paper's own data as noted above.
8. The Discussion section states: *"Our method, composed solely of SAM without additional models, demonstrates superior computational efficiency compared to state of the art. This limitation affects scalability for real-time applications."* These two sentences appear contradictory and need clarification.

## Nice-to-Haves

- Add error bars (mean ± std over multiple runs) to all main results and ablations, given the stochastic prompt sampling.
- Provide a sensitivity analysis of the TS-SS verification threshold (e.g., sweep 100–500, show effect on MAE and precision/recall).
- Report category-wise MAE breakdown on FSC-147 by object size (small/medium/large) to substantiate the qualitative limitation about small-instance degradation.
- Include a direct latency comparison with TFCAC on the same hardware, since the paper claims "more than twice as fast" inference but does not tabulate the comparison.
- Compare against a simple grid baseline using the same number of prompts per image, to isolate the benefit of the probabilistic sampling strategy over uniform sampling with equal budget.
