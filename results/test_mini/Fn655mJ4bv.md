## Summary

The paper proposes SOInter, an interpretation method for structured output models that identifies important input features for a target output variable. The core idea is to train an energy network to approximate the black box's behavior and use a structured hinge-like loss that incorporates the full output vector (not just the target) during interpreter training, thereby accounting for correlations between output variables. The method uses a Gumbel-Softmax-based neural network to produce $k$-hot feature masks, and the energy network is fine-tuned iteratively alongside the interpreter. Experiments on synthetic data, Bibtex multi-label classification, and Weizmann-Horse segmentation are presented.

## Strengths

- **Novel and well-motivated problem formulation.** The paper identifies a genuine gap: existing interpretation methods treat each output independently, ignoring the correlations that define structured output models. The idea of incorporating output correlations during interpreter training is a novel contribution to the XAI literature.

- **Synthetic experiments show quantitative improvement over generic baselines.** On synthetic data with known relevant features (energy functions $\mathcal{E}_1$, $\mathcal{E}_2$), SOInter achieves higher accuracy and median rank closer to the ground truth (2.5) compared to LIME, Kernel-SHAP, and L2X across varying input dimensions and output variables (Figs. 3–4). The trends are consistent across multiple runs (5 repetitions shown with variance bands).

- **Principled energy-based training procedure for black-box access.** The method does not require access to the black box's internal structure. The energy network learns to approximate the black box, and the fine-tuning step (Eq. 10) adjusts it to the perturbed inputs generated by the current interpreter, handling the distribution shift introduced by masking.

- **Qualitative validation on a real structured task.** On Bibtex multi-label classification (Table 1), the top-30 aggregated features per tag contain semantically relevant words for tags like "games" and "molecular," with some confirmed by human experts.

## Weaknesses

### Major

- **Real-data experiments lack quantitative evaluation of the core claim.** The Bibtex experiment (Table 1) provides only qualitative word lists with no baseline comparison, no quantitative metric (e.g., fidelity, precision/recall), and no controlled test of whether the highlighted features actually affect the target output. The Weizmann-Horse segmentation experiment (Fig. 5) is purely qualitative — the observation that selected pixels are near the target pixel could partially arise from spatial correlation. Without quantitative real-data evaluation, it is difficult to assess whether SOInter provides meaningful explanations on real problems.

- **Table 2 (F1 measure) is presented without any context.** The table appears after the conclusion with the caption "F1 measure obtained by selected features" but does not specify the dataset, the task, the prediction model, or what the F1 score measures. The numbers (e.g., 0.261 for 150 features vs. 0.057 random) suggest SOInter-selected features outperform random selection, but the complete absence of experimental context renders this result uninterpretable.

- **No ablation isolating the claimed contribution.** The paper's central claim is that conditioning on other output variables improves interpretation. However, there is no comparison against a version of SOInter that uses the same architecture and loss but does **not** condition on $\tilde{\mathbf{y}}_{-t}$ (i.e., only uses the target output). Without this ablation, the observed performance gains in synthetic experiments could be attributed to the energy-based training framework rather than specifically to the incorporation of output correlations.

### Minor

- **Synthetic ground truth evaluation has limitations.** The paper defines the four features appearing in $\mathcal{E}_1$ and $\mathcal{E}_2$ as ground-truth important features for all target outputs. While features 5+ are genuinely irrelevant, the instance-level importance of features within {1,2,3,4} for a specific target output (e.g., $x_1$ vs. $x_2$ for $y_1$ in $\mathcal{E}_1$ depending on $y_2$) is not instance-dependent in this evaluation. A more precise ground truth would derive instance-specific importance by measuring how perturbing each input feature changes the target output while other outputs are held fixed. The current evaluation is still informative (it tests whether the interpreter identifies features the model uses at all), but the metrics should be interpreted with this caveat.

- **Theoretical motivation (Eq. 1) is heuristic rather than rigorous.** The entropy inequality $H(\alpha|x, y_t^{sb}) > H(\alpha|x, y_t^{sb}, y_{-t}^{sb})$ provides intuition for why incorporating other outputs could help, but the framing treats $\alpha$ as a random variable in a Bayesian sense while the actual algorithm performs point estimation via gradient descent. The connection between the information-theoretic argument and the specific energy-based loss function is not formally established. This does not invalidate the method — many interpretation papers use heuristic motivations — but the theoretical framing oversells the rigor.

- **Missing ablation/convergence details.** Learning rates $\beta$ and $\beta'$ in the iterative optimization (Eq. 12) are not specified. No convergence curves or sensitivity analysis to the number of iterations are provided. The argmin inference inside the energy network (Eq. 10) for fine-tuning is not described (e.g., optimization method, complexity for large output spaces like Bibtex's 159 labels).

### Trivial

- The notation in Eq. 9 (`\mathcal{\mathbf{y}^{sb}_t,\;\tilde{\mathbf{y}}_{t}}`) is garbled in the parsed text, though Eq. 90 makes clear this is a margin term $\mathcal{L}(\mathbf{y}^{sb}_t, \tilde{\mathbf{y}}_t)$.

## Nice-to-Haves

- **Ablation study**: Compare SOInter against the same method without conditioning on $\tilde{\mathbf{y}}_{-t}$.
- **Quantitative real-data metrics**: For Bibtex, report fidelity (whether the target output changes when non-selected features are masked) or compare against LIME/L2X baselines on the same task. For Weizmann-Horse, compute intersection-over-union with gradient-based saliency maps or measure prediction-preservation after masking non-selected pixels.
- **Instance-specific ground truth for synthetic data**: Instead of assuming all four features are equally important for all targets, derive ground truth by perturbing each feature and measuring the effect on the specific target output.

Comparing against generic baselines (LIME, SHAP, L2X) is standard practice for new approaches. An *ablation* (SOInter without conditioning on other outputs) would be desirable but is a missing experiment, not a comparison against nonexistent methods.
