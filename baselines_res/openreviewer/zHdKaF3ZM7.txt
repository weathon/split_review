# Review

## Summary
The paper proposes a new RNN model that uses a linear recurrence relation but a non-linear output layer. The non-linear output layer is a MLP that uses as its weights the hidden state of the RNN. The hidden state of the RNN is updated with a linear recurrence relation that uses as input the difference in the input data between consecutive time steps. The proposed model is evaluated on a diverse set of tasks, including image completion, energy prediction, traffic forecasting, dynamical system reconstruction, and time series classification. The proposed model performs well on all the tasks and in particular it performs better than state of the art models on traffic forecasting and dynamical system reconstruction.

## Strengths
* The proposed model is novel and interesting. It has the linear efficiency of linear RNNs but also the capacity to learn complex functions thanks to the non-linear output layer.
* The proposed model performs well on a diverse set of tasks, including image completion, energy prediction, traffic forecasting, dynamical system reconstruction, and time series classification.
* The proposed model performs particularly well on traffic forecasting and dynamical system reconstruction, outperforming state of the art models by a large margin.
* The paper is well written and easy to follow.

## Weaknesses
* The proposed model is only evaluated on a small set of image datasets (MNIST and CelebA). It would be interesting to evaluate it on a larger and more diverse set of image datasets.
* The proposed model is only evaluated on a small set of NLP datasets (the UEA-MTSCA). It would be interesting to evaluate it on a larger and more diverse set of NLP datasets.
* The paper does not provide any theoretical analysis of the proposed model. It would be interesting to provide a theoretical analysis of its expressivity and learning capacity.

## Questions
* Have you considered evaluating the proposed model on a larger and more diverse set of image datasets? What do you expect the results to be?
* Have you considered evaluating the proposed model on a larger and more diverse set of NLP datasets? What do you expect the results to be?
* Can you provide any theoretical analysis of the proposed model? What are its expressivity and learning capacity?
